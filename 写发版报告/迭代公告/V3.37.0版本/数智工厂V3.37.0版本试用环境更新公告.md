# 华彬数智工厂系统V3.37.0试用版本更新公告

尊敬的集团及各基地数智工厂负责人：

为进一步强化数智工厂系统功能，优化各基地基地实际使用体验，经过严谨测试与部署，数智工厂系统 V3.37.0 版本已于 2026 年 05 月 12日 完成湖北、广东、贵州、福建基地试用环境的迭代升级工作，本次升级聚焦生产流程优化、数据管理精细化及跨模块协同效率提升，现将核心内容公告如下：

## 一、更新内容

### （一）生产模块拓展

湖北基地新增表单：新增表单（0项）-。优化表单（6项）-调整-"打码工序"表单，① 接班签字时，工序记录处的第一条记录、最后一条记录中的合格品跟理论合格品进行比较，不一致时弹窗提示 / ② 接班签字时“入库成品总箱数”与“【包装工序】 - 工序统计 ”处的“本班使用”校验。当不一致时，弹窗提示且拦截接班签字；"称料工序记录"表单，“已完成”单据在距称量日期的次月内支持修改（次月后修改消失） / 支持修改除“称量数据”、“配方箱分配”外的其它内容；"称料香精工序记录"表单，“已完成”单据在距称量日期的次月内支持修改（次月后修改消失） / 支持修改除“称量数据”、“配方桶分配”外的其它内容；"非本岗位人员进入称料间记录"表单，支持添加多条记录，组长一次签字确认即可；"生产基地KPI考核指标"表单，数据展示默认为当月；"生产基地一般考核指标"表单，数据展示默认为当月；成品破损率、离职率去掉编辑图标；一般质量事故、一般安全事故默认为0。

## 二、影响范围

本次版本迭代为平滑升级，系统将保持正常运行，不影响基地对系统的常规操作。但在新功能首次使用或数据同步过程中，可能会出现短暂加载延迟的情况，建议基地避开业务高峰时段进行复杂操作，以免影响工作效率。同时，由于各基地生产模块功能优化调整较多，涉及福建、贵州、广东和湖北基地的生产作业记录、工序表单操作等相关业务的岗位，在操作新版功能时请谨慎核对数据，确保业务流程准确执行。

## 三、更新后注意事项

功能熟悉与数据核对：本次更新新增和优化的功能较多，请各基地在使用前仔细阅读各模块对接负责人发送的详细迭代说明文档，熟悉新功能操作流程。对于生产、品质、仓储等关键业务数据，建议在更新后 48 小时内进行全面核对，若发现数据异常或功能使用问题，及时联系对应模块对接人。

系统兼容性检查：部分新增功能（如小程序扫码提报功能）对设备操作系统版本有一定要求，若出现无法正常使用的情况，请及时更新设备系统至最新版本，或联系技术支持人员获取解决方案。

账号安全：更新完成后，为保障账号安全，请定期更换登录密码，并避免在公共网络环境下长时间登录系统。

由于小程序各基地未发布体验小程序版本代码，如果涉及小程序试用功能，统一在正式版本更新后在线上版本直接使用小程序。

新增和优化功能涉及到新增权限时，系统默认不勾选，需要基地对接人勾选对应的权限按钮给到相关角色权限，以防员工无法正常使用功能
