
# 数智工厂版本更新公告生成提示词

## 任务说明

你将收到 **4个省份的Excel迭代信息汇总文件**（福建、广东、贵州、湖北），需要根据这些Excel的数据，生成一份与 `数智工厂V3.37.0版本试用环境更新公告.docx` **格式、风格、结构完全一致** 的Word发版公告。

---

## 一、输入数据源解析

### 1.1 每个Excel文件的Sheet结构

每个省份的Excel文件固定包含以下10个Sheet，名称顺序如下：

1. `概览统计`
2. `仓储板块 `（注意：部分省份的Sheet名末尾可能有空格）
3. `生产板块`
4. `质量板块`
5. `设备板块`
6. `安全板块`
7. `人事行政板块`
8. `财务板块`
9. `基础板块`
10. `基础综合`

### 1.2 每个Sheet内部的格式

**第1行**：标题行。格式如：`{省份}基地-{板块名}-{日期}系统更新内容`
- 例：`福建基地-仓储板块-2026年05月11日系统更新内容`
- 例：`广东基地-设备板块-2026年05月11日系统更新内容`

**第2行**：列头行。固定5列：`序号 | 类型 | 单据 | 内容 | 备注`

**第3行及之后**：具体的数据行。每行5个单元格：
- `序号`：数字编号（1, 2, 3...），同类别的连续条目会留空
- `类型`：`新增功能` 或 `优化项`（注意两者的区分！）
- `单据`：具体表单名称，如 `原料日报配置`、`生产基地KPI考核指标`
- `内容`：该条迭代的详细描述（核心内容）
- `备注`：补充说明（很多时候为空）

### 1.3 概览统计Sheet的特殊格式

概览统计Sheet格式特殊，包含：
- 单元格A1：`{省份}基地-数智工厂{版本}版本迭代概览`
- 行：`本次试用迭代` → 右侧为日期（如 `2026-05-12`）
- 行：`基地试用周期` → 右侧为周期（如 `05月12日-05月18日（共7天）`）
- 行：`下次试用迭代` → 右侧为日期
- 行：`序号 | 板块 | 新增 | 优化 | 合计` → 统计表头
- 后续行：各板块的新增/优化数量统计
- 末尾行：`数智工厂试用环境地址：https://...`
- 末尾行：`注：所有试用反馈登记在《{省份}基地数智系统功能推进计划表》`

### 1.4 数据中需要特别注意的格式

- Excel单元格内容中的换行符（实际是手动换行）在处理时统一视为空格分隔
- 内容单元格中常出现 ` / ` 或 `①②③` 等层级序号，原样保留
- 部分内容单元格中出现"详见图中红色框圈中区域"这类描述，原样保留
- 单据名称带【】或不带，按Excel中原文输出

### 2.2 各章节内容映射规则（核心）

#### ▶ 章节（一）生产模块拓展 — 规则特殊

**这是唯一按"基地"分述的章节！** 输出4段，每段对应一个基地：

**第一段——湖北基地**：读取 `湖北3.37.0版本迭代信息汇总0511.xlsx` 的 `生产板块` Sheet

**第二段——广东基地**：读取 `广东3.37.0版本迭代信息汇总0511.xlsx` 的 `生产板块` Sheet

**第三段——贵州基地**：读取 `贵州3.37.0版本迭代信息汇总0511.xlsx` 的 `生产板块` Sheet

**第四段——福建基地**：读取 `福建3.37.0版本迭代信息汇总0511.xlsx` 的 `仓储板块` Sheet 中的 `生产板块` Sheet（不对！是福建Excel的"生产板块"Sheet）

每段的格式模板为：
```
{省份}基地新增表单：新增表单（{新增总数}项）{分隔符}优化表单（{优化总数}项）{分隔符}调整-
  第一条条目内容中提到的"表单名称"，
  第二条条目内容中提到的"表单名称"，
  ...全部条目用中文分号"；"连接...
  "生产基地KPI考核指标"表单，数据展示默认为当月；
  "生产基地一般考核指标"表单，数据展示默认为当月；成品破损率、离职率去掉编辑图标；
  一般质量事故、一般安全事故默认为0。
```

**每段生成规则详解**：
1. 统计该省生产板块Sheet中"类型"=`新增功能`的条目数量 → `新增总数`
2. 统计该省生产板块Sheet中"类型"=`优化项`的条目数量 → `优化总数`
3. 湖北/广东的分隔符为 `-`（即：`新增表单（6项）-。优化表单（6项）-调整-`）
4. 贵州/福建的分隔符不同，为 `调整`（即：`新增表单（5项）调整-`，注意没有中间的`-。`）
5. 将所有条目的「单据」和「内容」合并为自然语言描述：
   - 每条的格式：`"{单据}"表单，{内容}`
   - 多条之间用中文分号"；"连接
   - 连续序号为空的条目，视为上一条的延续，合并描述
6. 内容中的 ` / ` 替换为中文标点"；"或自然换行语言
7. 末尾固定加上：`"生产基地KPI考核指标"表单，数据展示默认为当月；"生产基地一般考核指标"表单，数据展示默认为当月；成品破损率、离职率去掉编辑图标；一般质量事故、一般安全事故默认为0。`（如果该省Excel生产板块中已包含这两项，则不需要重复，按实际内容即可）

#### ▶ 章节（二）至（六）— 合并4省统一输出

规则：
1. 从4个Excel的对应板块Sheet中读取所有数据行
2. **不去重**：即使4个省有完全相同的条目（如"生产基地KPI考核指标"），也按实际Excel逐条列出
3. **不按基地区分**：不标注这条是哪个省的
4. **条目前缀**：
   - 若类型=`新增功能`，开头写：`新增"XXX"表单，`
   - 若类型=`优化项`，开头写：`优化"XXX"表单，`
   - 若单据列为空（如Excel中序号=1但单据空），则按"新增"或"优化"+内容输出
5. 每条正文一行，行首加前缀，末尾为Excel中的"内容"原文
6. 内容中的 ` / ` 按原样保留（代表子项分隔），不要随意替换为标点

## 三、语言与格式风格要求

### 3.1 语言风格

- 语言必须**正式、书面化**，避免口语化表达
- 迭代内容的描述**必须完全沿用Excel中的原文**，不做润色、不做改写
- 不要添加任何Excel中不存在的描述、解释、举例
- 不要修改、简化、合并Excel中的条目
- 内容中涉及表单名的统一用中文双引号 `""` 括起来（如 `"打码工序"表单`）
- 内容中涉及表单名原本用 `【】` 括起来的，保留原格式（如 `【样品检验报告】`）

### 3.2 正文格式细节

- 每个功能条目的开头格式：
  - 生产模块基地汇总段：`"XXX"表单，{内容}`
  - 其他模块单条条目：`优化"XXX"表单，{内容}` 或 `新增"XXX"表单，{内容}`
- 同一条目中的子项（用`1、2、3、` 或 `①②③` 标识）原样保留
- 内容中出现的 `/` 按Excel原文保留（代表并列子项）
- 段落末尾统一使用中文句号 `。`

### 3.3 标题格式

- **标题 Heading 1**：`华彬数智工厂系统V{版本号}试用版本更新公告`
- **标题 Heading 2**：`一、更新内容`、`财务功能功能优化`、`系统基础功能升级`、`二、影响范围`、`三、更新后注意事项`、`四、技术支持`
- **标题 Heading 3**：`（一）生产模块拓展`、`（二）品质管理强化`、`（三）设备能源管理升级`、`（四）仓储管理优化`、`（五）安全管理拓展`、`（六）人事行政功能拓展`

### 3.4 开头称谓与引入段
