## 1. 页面概述

- **所属模块**：生产管理 > 生产基础信息
- **页面名称**：产品名称
- **页面路由**：`/product/production-baseinfo/index156/name`
- **路由名称**：`StandardConfigProductionManagementName`
- **API端点**：
  - 列表：`POST /produce/produce_name/getList`
  - 详情：`POST /produce/produce_name/detail`
- **请求参数**：`{ "page": 1, "size": 10, "name": null }`

页面用于管理产品名称信息，包含产品名称、单罐规格、包装规格、产品大类、产品小类、状态、工艺规程等配置。

## 2. 页面功能说明

### 页面顶部操作区域

| 元素 | 类型 | 说明 |
|------|------|------|
| 产品名称 | 文本输入框 | 搜索条件，按产品名称搜索 |
| 重置 | 按钮 | 重置搜索条件 |
| 搜索 | 按钮 | 执行搜索 |
| 新增 | 按钮 | 打开新增产品信息抽屉 |

### 表格列定义

| 列名 | 字段 | 说明 |
|------|------|------|
| 序号 | - | 行序号 |
| 产品名称 | name | 产品名称 |
| 单罐规格 | specification | 单罐容量（如：250ml/罐） |
| 包装规格 | pack | 包装规格（如：2*12罐/箱） |
| 产品大类 | big_cate | 产品大类（ND1=红牛） |
| 产品小类 | sku | 产品小类（ND1-1=普通红牛，ND1-2=强化红牛） |
| 状态 | status | 产品状态（0=停用，1=启用） |
| 备注信息 | remark | 备注说明 |
| 创建人 | ct_name | 创建人姓名 |
| 创建时间 | create_time | 创建时间 |
| 更新人 | up_name | 更新人姓名 |
| 更新时间 | update_time | 更新时间 |
| 操作 | - | 编辑、启用/禁用、删除 |

## 4. 操作功能

### 4.1 搜索功能

页面顶部提供搜索区域，支持按"产品名称"进行模糊搜索：
- **产品名称**：文本输入框，输入关键词后点击"搜索"按钮
- **重置**：清空搜索条件，恢复默认列表

### 4.2 新增产品信息

点击"新增"按钮后，右侧弹出"新增产品信息"抽屉式对话框：

![新增对话框](截图/产品名称-新增对话框.png)

#### 表单字段

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 产品名称 | 下拉选择 | 是 | 可选值：红牛维生素功能饮料、红牛维生素功能饮料（牛磺酸强化型）、战马能量型维生素饮料 |
| 单罐规格 | 数字输入 | 是 | 单位为ml/罐，最小值1，默认值1 |
| 包装规格 | 文本输入 | 是 | 如：2*12罐/箱 |
| 产品大类 | 单选按钮 | 是 | 可选值：红牛、战马 |
| 产品小类 | 下拉选择 | 是 | 可选值：普通红牛、强化红牛 |
| 产品状态 | 单选按钮 | 是 | 可选值：启用、禁用 |
| 工艺规程 | 多行文本 | 是 | 最大500字符，详细描述产品工艺流程 |
| 备注信息 | 文本输入 | 否 | 备注说明 |

![产品名称下拉选项](截图/产品名称-新增-产品名称下拉选项.png)

#### 完整工艺规程内容

```
1、按"红牛维生素功能饮料"产品工艺标准生产。
2、包材的使用根据总公司下达的产品计划做好首检及在线控制。
3、各岗位依据产品《生产工艺流程》、《工序质量预控计划》及作业指导书等标准规范生产，按时保质保量完成生产计划产量。具体工艺执行如下：
1）称量：称料岗位作业指导书。
2）配料：配料岗位作业指导书。
3）拆包：拆包岗位作业指导书。
4）灌装封口：灌装封口岗位作业指导书。
5）制水：制水岗位作业指导书。
6）打码：打码岗位作业指导书。
7）包装：热缩、包装岗位作业指导书。
8）机码：机码岗位作业指导书。
9）入库：叉车岗位作业指导书。
10）在线质量控制：巡检员岗位作业指导书；化验员工作标准。
11）扫码：扫码岗位作业指导书。
12）污水：污水岗位作业指导书。
```

### 4.4 启用/禁用

表格操作列中根据当前产品状态显示不同按钮：
- **状态为"停用"时**：显示"启用"按钮，点击后可启用该产品
- **状态为"启用"时**：显示"禁用"按钮，点击后可禁用该产品

| 产品名称 | 当前状态 | 操作按钮 |

| 红牛维生素功能饮料（六罐装） | 停用 | 启用 |
| 红牛维生素功能饮料（牛磺酸强化型） | 启用 | 禁用 |
| 红牛维生素功能饮料 | 启用 | 禁用 |
