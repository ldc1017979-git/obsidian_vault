## 1. 页面概述

- **所属模块**：生产管理 > 生产基础信息
- **页面名称**：配方BOM清单
- **页面路由**：`/product/production-baseinfo/index156/bom-detailed-list`
- **路由名称**：`BomDetailedList`
- **API端点**：`POST /produce/weighing/bomList`
- **请求参数**：`{ "page": 1, "size": 10, "category_name": "普通红牛" }`

页面用于管理不同产品类型（普通红牛、强化红牛、战马）的配方BOM清单，包含物料信息及配方标准值配置。

---

## 2. 页面功能说明

### 页面顶部操作区域

| 元素 | 类型 | 说明 |
|------|------|------|
| 普通红牛 | 单选按钮 | 切换至普通红牛配方BOM清单 |
| 强化红牛 | 单选按钮 | 切换至强化红牛配方BOM清单 |
| 战马 | 单选按钮 | 切换至战马配方BOM清单 |
| 新增 | 按钮 | 打开新增标准对话框 |

### 表格列定义

| 列名 | 字段 | 说明 |
|------|------|------|
| 条码 | barcode | 物料条码 |
| 物料编号 | code | 物料编号 |
| 名称 | name | 物料名称 |
| 分类 | goods_class | 物料分类（如：原材料） |
| 计量单位 | measure_name | 计量单位（如：kg） |
| 保留小数 | goods_reserve_decimal | 保留小数位数 |
| 标准值 | ref_v | 配方标准值 |
| 标准范围 | ran_s~ran_e | 标准范围（起始~结束） |
| 称重单位 | unit | 称重单位（如：g、kg） |
| 称重保留小数 | reserve_decimal | 称重保留小数位数 |
| 单据类型 | rela_type | 单据类型（1=配方箱，2=配方桶） |
| 单据序号 | sort | 单据排列序号 |
| 操作 | - | 编辑、删除 |

## 4. 操作功能

### 4.1 新增标准

点击"新增"按钮后弹出"新增标准"对话框，包含以下表单字段：

![新增标准对话框](截图/配方BOM清单-新增标准对话框.png)

#### 物料信息区域

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 条码 | 下拉选择 | 是 | 选择物料条码，下拉列表展示所有可用物料 |
| 名称 | 文本输入 | 是 | 自动填充，根据条码选择后自动带出 |
| 条码 | 只读文本 | - | 显示选中物料的条码 |
| 规格型号 | 只读文本 | - | 显示选中物料的规格型号 |
| 分类 | 只读文本 | - | 显示选中物料的分类（如：原材料） |
| 计量单位 | 只读文本 | - | 显示选中物料的计量单位（如：kg） |
| 品牌 | 只读文本 | - | 显示选中物料的品牌 |
| 保留小数 | 只读文本 | - | 显示选中物料的保留小数位数 |

#### 配方信息区域

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 单位 | 下拉选择 | 是 | 称重单位，可选值包括：g、kg、mg、升、毫升、托、g/L、ug/L、mg/L、厘米、本、顶、PC、立方米、TIA、PAC、平方米、只、台、个、支、罐、片、瓶、箱、组、条、桶、张、双、卷、件、盒、包、米、块、套、把、根、袋、副等 |
| 保留小数 | 数字输入 | 是 | 称重保留小数位数（0-4） |
| 标准值 | 数字输入 | 是 | 配方标准值 |
| 标准范围 | 数字输入 | - | 标准范围（起始值~结束值），由两个数字输入框组成 |
| 单据类型 | 单选按钮 | - | 可选：配方箱、配方桶，支持取消选择 |
| 单据序号 | 文本输入 | - | 单据排列序号 |

![条码下拉选项](截图/配方BOM清单-新增-条码下拉选项.png)
