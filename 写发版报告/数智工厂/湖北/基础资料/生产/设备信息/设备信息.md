## 1. 页面概述

- **所属模块**：生产管理 > 生产基础信息
- **页面名称**：设备信息
- **页面路由**：`/product/production-baseinfo/index156/equipment-inform`
- **路由名称**：`equipment-inform`
- **API端点**：
  - 列表：`POST /produce/hb_equipment_information/getList`
  - 详情：`POST /produce/hb_equipment_information/detail`
  - 产线列表：`POST /apios/post/getProductLineList`
  - 设备台账选择：`POST /mro/Post/getEqipmentSelect`
- **请求参数**：`{ "page": 1, "size": 10 }`

页面用于管理设备信息，包含设备名称、线别、关联设备台账等配置。每个设备可关联多条产线的设备台账。

## 4. 操作功能

### 4.1 搜索功能

页面顶部提供搜索区域，支持按"设备信息"进行搜索：
- **设备信息**：文本输入框，输入关键词后点击"搜索"按钮
- **重置**：清空搜索条件，恢复默认列表

### 4.2 新增设备信息

点击"新增"按钮后，弹出"新增设备信息"对话框：

![新增对话框](截图/设备信息-新增对话框.png)

#### 表单字段

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 设备信息 | 文本输入 | 是 | 输入设备名称 |
| 操作/线别/关联设备台账 | 表格行 | 否 | 可动态添加多行，每行包含操作、线别、关联设备台账三个字段 |
| 备注 | 多行文本 | 否 | 输入备注信息 |

#### 线别下拉选项

| 选项 |
|------|
| 一线 |
| 二线 |
| 三线 |
| 四线 |
| 五线 |
| 六线 |

![操作下拉选项](截图/设备信息-新增-操作下拉选项.png)

#### 关联设备台账

关联设备台账为表格形式的选择器，共2315条数据，包含以下列：

| 列名 | 说明 |
|------|------|
| 可选状态 | 可选/已选 |
| 唯一码 | 设备唯一编码（如：YCJ-4K-62） |
| 资产名称 | 设备资产名称（如：4KG干粉灭火器、洗眼器） |
| 资产类型 | 设备资产类型（如：消防器材>4KG干粉灭火器） |
| 可用状态 | 正常 |

![线别下拉选项](截图/设备信息-新增-线别下拉选项.png)
