## 1. 页面概述

- **所属模块**：生产管理 > 生产基础信息
- **页面名称**：生产班组
- **页面路由**：`/product/production-baseinfo/production-team`
- **路由名称**：`StandardConfigProductionTeam`
- **API端点**：
  - 列表：`POST /qlty/Classtime/getClasstimeList`
- **请求参数**：`{ "page": 1, "size": 10, "name": null, "is_open": null }`

页面用于管理生产班组信息，包含班组名称、可用状态等配置。支持新建、编辑、删除和启用/禁用操作。

## 2. 页面功能说明

### 页面顶部操作区域

| 元素 | 类型 | 说明 |
|------|------|------|
| 生产班组 | 文本输入框 | 搜索条件，按班组名称搜索 |
| 可用状态 | 下拉选择框 | 搜索条件，按可用状态筛选（可用/禁用） |

| 列名 | 字段 | 说明 |
|------|------|------|
| 生产班组 | name | 班组名称 |
| 可用状态 | is_open | 启用/禁用开关（1=启用，0=禁用） |
| 创建人 | ct_name | 创建人姓名 |
| 创建时间 | create_time | 创建时间 |
| 更新人 | up_name | 更新人姓名 |
| 更新时间 | update_time | 更新时间 |
| 操作 | - | 编辑、删除 |

## 4. 操作功能

### 4.1 搜索功能

页面顶部提供搜索区域，支持以下搜索条件：
- **生产班组**：文本输入框，输入关键词后点击"搜索"按钮
- **可用状态**：下拉选择框，选项为"可用"和"禁用"
- **重置**：清空搜索条件，恢复默认列表

![可用状态下拉选项](截图/生产班组-搜索-可用状态下拉选项.png)

### 4.2 新建生产班组

点击"新建"按钮后，弹出"新增"对话框：

![新建对话框](截图/生产班组-新建对话框.png)

#### 表单字段

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 生产班组 | 文本输入 | 是 | 输入班组名称 |
| 可用状态 | 开关 | 否 | 启用/禁用，默认启用 |

### 4.3 编辑生产班组

点击表格行中的"编辑"按钮后，弹出"编辑"对话框，表单字段与新建相同，但预填充了当前行的数据。

![编辑对话框](截图/生产班组-编辑对话框.png)

以编辑"称料"为例，表单预填充数据如下：

| 字段 | 值 |
|------|-----|
| 生产班组 | 称料 |
| 可用状态 | 启用（开关开启） |

### 4.4 删除生产班组

点击表格行中的"删除"按钮后，弹出确认对话框：

![删除确认对话框](截图/生产班组-删除确认对话框.png)

确认对话框内容：**"确认要删除生产班组为：【称料】的该条内容吗?"**

- **取消**：放弃删除操作
- **确定**：确认删除该条记录

### 4.5 可用状态开关

表格中每行的"可用状态"列为开关控件，可直接点击切换启用/禁用状态：
- 开关开启（绿色）：表示该班组可用
- 开关关闭（灰色）：表示该班组禁用
