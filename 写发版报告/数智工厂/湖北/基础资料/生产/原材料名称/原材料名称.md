## 1. 页面概述

- **所属模块**：生产管理 > 生产基础信息
- **页面名称**：原材料名称
- **页面路由**：`/product/production-baseinfo/index156/raw-material-name`
- **路由名称**：`raw-material-name`
- **API端点**：
  - 列表：`POST /produce/hb_raw_material_information/getList`
- **请求参数**：`{ "page": 1, "size": 15, "name": null, "status": null }`

页面用于管理原材料名称信息，包含原材料名称、备注、状态等配置。

> **注意**：当前页面列表显示"暂无数据"，但API接口返回了8条数据（所有数据status=2）。此为前端渲染问题，API数据完整返回。

## 2. 页面功能说明

### 页面顶部操作区域

| 元素 | 类型 | 说明 |

| 列名 | 字段 | 说明 |

| 原材料名称 | name | 原材料名称 |
| 更新人 | up_name | 更新人姓名 |
| 更新时间 | update_time | 更新时间 |
| 制单人 | ct_name | 创建人姓名 |
| 创建时间 | create_time | 创建时间 |
| 操作 | - | 编辑、删除（数据行存在时显示） |

## 4. 操作功能

### 4.1 搜索功能

页面顶部提供搜索区域，支持按"原材料名称"进行搜索：
- **原材料名称**：文本输入框，输入关键词后点击"搜索"按钮
- **重置**：清空搜索条件，恢复默认列表

### 4.2 新增原材料名称

点击"新增"按钮后，弹出"新增原材料名称"对话框：

![新增对话框](截图/原材料名称-新增对话框.png)

#### 表单字段

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 原材料名称 | 文本输入 | 是 | 输入原材料名称 |
| 备注 | 多行文本 | 否 | 输入备注信息 |

对话框底部包含"取消"和"确定"两个操作按钮。
