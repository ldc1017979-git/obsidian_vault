## 1. 页面概述

- **所属模块**：生产管理 > 生产基础信息
- **页面名称**：产线工序
- **页面路由**：`/product/production-baseinfo/line`
- **路由名称**：`line`
- **API端点**：
  - 列表：`POST /produce/line/getList`
- **请求参数**：`{ "page": 1, "size": 10 }`

页面用于管理产线工序信息，包含工序名称、状态等配置。支持新增、编辑和启用/禁用操作。

---

## 2. 页面功能说明

### 页面顶部操作区域

| 元素 | 类型 | 说明 |
|------|------|------|
| 工序 | 文本输入框 | 搜索条件，按工序名称搜索 |
| 状态 | 下拉选择框 | 搜索条件，按状态筛选（启用/禁用） |
| 重置 | 按钮 | 重置搜索条件 |
| 搜索 | 按钮 | 执行搜索 |
| 新增 | 按钮 | 打开新增产线工序对话框 |

### 表格列定义

| 列名 | 字段 | 说明 |
|------|------|------|
| 工序 | name | 工序名称 |
| 更新人 | up_name | 更新人姓名 |
| 更新时间 | update_time | 更新时间 |
| 制单人 | ct_name | 创建人姓名 |
| 创建时间 | create_time | 创建时间 |
| 状态 | status | 启用/禁用（1=启用，0=禁用） |
| 操作 | - | 编辑、禁用 |

## 4. 操作功能

### 4.1 搜索功能

页面顶部提供搜索区域，支持以下搜索条件：
- **工序**：文本输入框，输入关键词后点击"搜索"按钮
- **状态**：下拉选择框，选项为"启用"和"禁用"
- **重置**：清空搜索条件，恢复默认列表

![状态下拉选项](截图/产线工序-搜索-状态下拉选项.png)

### 4.2 新增产线工序

点击"新增"按钮后，弹出"新增产线工序"对话框：

![新增对话框](截图/产线工序-新增对话框.png)

#### 表单字段

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 工序 | 文本输入 | 是 | 输入工序名称 |
| 状态 | 单选按钮 | 是 | 启用/禁用，默认选中"启用" |

### 4.3 编辑产线工序

点击表格行中的"编辑"按钮后，弹出"编辑产线工序"对话框，表单字段与新增相同，但预填充了当前行的数据。

![编辑对话框](截图/产线工序-编辑对话框.png)

以编辑"称料"为例，表单预填充数据如下：

| 字段 | 值 |
|------|-----|
| 工序 | 称料 |
| 状态 | 启用（单选按钮选中） |

### 4.4 禁用确认

点击表格行中的"禁用"按钮后，弹出确认对话框：

![禁用确认对话框](截图/产线工序-禁用确认对话框.png)

确认对话框内容：**"确定禁用吗？"**

- **取消**：放弃禁用操作
- **确定**：确认禁用该条工序

禁用后，该工序状态将变为"禁用"，操作列按钮将变为"启用"。
