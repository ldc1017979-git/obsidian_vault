## 1. 页面概述

仪器管理页面用于管理质量检测中使用的各类仪器设备信息，包括仪器编码、名称、出厂编号、型号、品牌、类型及可用状态等。页面路径为：质量管理 → 基础信息管理 → 仪器管理。

![仪器管理-列表页-第1页](仪器管理-列表页-第1页.png)

---

## 2. 搜索/筛选功能

页面顶部提供以下搜索/筛选条件：

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 仪器名称 | 文本输入框 | 支持模糊搜索 |
| 可用状态 | 下拉选择 | 可用/禁用 |
| 仪器类型 | 下拉选择 | 分析天平、电子秤、恒温箱、pH计、高效液相色谱仪、酶标仪、气相色谱仪、氨基酸分析仪、双道原子荧光光度计、近红外线检测仪、生化培养箱、糖酸一体机、自动旋光仪、紫外分光光度计 |

操作按钮：
- **搜索**：根据筛选条件查询数据
- **重置**：清空所有筛选条件

![可用状态下拉选项](仪器管理-可用状态下拉选项.png)

![搜索仪器类型下拉选项](仪器管理-搜索仪器类型下拉选项.png)

## 3. 功能按钮

| 按钮 | 位置 | 功能说明 |
|------|------|----------|
| 新建 | 搜索栏右侧 | 打开新增仪器对话框 |
| 列设置 | 列表右上角齿轮图标 | 控制表格列的显示/隐藏 |

## 4. 新建对话框

点击"新建"按钮弹出"新增检测仪器"对话框，包含以下字段：

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 仪器编码 | 文本输入 | 是 | 仪器的唯一编码 |
| 仪器名称 | 文本输入 | 是 | 仪器名称 |
| 出厂编号 | 文本输入 | 是 | 出厂编号 |
| 仪器型号 | 文本输入 | 是 | 仪器型号 |
| 仪器品牌 | 文本输入 | 是 | 所属品牌 |
| 仪器类型 | 下拉选择 | 是 | 可选项见下方 |
| 可用状态 | 开关 | 否 | 默认关闭（禁用） |

### 仪器类型下拉选项

分析天平、电子秤、恒温箱、pH计、高效液相色谱仪、酶标仪、气相色谱仪、氨基酸分析仪、高效液相色谱仪、双道原子荧光光度计、近红外线检测仪、生化培养箱、糖酸一体机、自动旋光仪、紫外分光光度计

## 8. 字段说明

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| 序号 | 数字 | 自动 | 系统自动生成的行号 |
| 仪器编码 | 文本 | 是 | 仪器的唯一编码，格式如 SHY-HWX-05、QA001 等 |
| 仪器名称 | 文本 | 是 | 仪器名称，如恒温箱、分析天平、pH计等 |
| 出厂编号 | 文本 | 是 | 仪器的出厂编号 |
| 仪器型号 | 文本 | 是 | 仪器的型号规格 |
| 所属品牌 | 文本 | 是 | 仪器的品牌，如梅特勒、安捷伦、SANYO、BINDER等 |
| 仪器类型 | 下拉选择 | 是 | 仪器分类，如恒温箱、pH计、分析天平等 |
| 可用状态 | 开关 | 否 | 启用/禁用，列表中显示为开关控件 |
| 创建人 | 文本 | 自动 | 创建该记录的用户 |
| 创建时间 | 日期时间 | 自动 | 创建时间 |
| 更新人 | 文本 | 自动 | 最后更新该记录的用户 |
| 更新时间 | 日期时间 | 自动 | 最后更新时间 |
