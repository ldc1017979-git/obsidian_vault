## 1. 页面概述

### 页面路径
质量管理 → 基础信息管理 → 定量项目

### 系统地址
`https://hbmms.y1b.cn:8424/#/quality-manage/index2/quantify`

### 主要功能
定量项目模块用于管理产品检验中的定量检测项目信息，包括项目名称、对应的检验依据标准、使用的检测仪器等。每条记录关联了不同产品类型（普通型、强化型、战马罐装）的检验依据，用于质量检验过程中引用对应的检测方法和仪器。

## 2. 搜索和筛选功能

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 项目名称 | 文本输入 | 按项目名称筛选，如"铅"、"总砷"等 |
| 可用状态 | 下拉选择 | 可选：可用/禁用 |

### 操作按钮
- **重置**: 清空所有搜索条件
- **搜索**: 根据条件查询定量项目数据

## 3. 功能按钮说明

### 3.1 新建
点击打开新建定量项目对话框，创建新的定量检测项目记录。

![定量项目-新建对话框](定量项目-截图/定量项目-新建对话框.png)

### 3.2 刷新
刷新当前列表数据（图标按钮）。

### 3.3 密度设置
设置表格行间距，可选：宽松、默认、紧凑。

### 3.4 列表内操作
每行数据提供以下操作按钮：
- **编辑**: 打开编辑对话框，修改定量项目信息
- **删除**: 删除该条定量项目记录（需确认）
- **可用状态开关**: 直接在列表中切换启用/禁用状态

## 4. 新建定量项目

### 对话框标题
**新增定量项目**

### 表单字段

| 字段名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 产品大类 | 下拉选择 | 是 | - | 产品分类，当前可选：红牛 |
| 项目名称 | 文本输入 | 是 | - | 定量检测项目名称，如"铅"、"总砷"等 |
| 普通型检验依据 | 下拉选择 | 否 | - | 普通型产品对应的检验依据标准 |
| 强化型检验依据 | 下拉选择 | 否 | - | 强化型产品对应的检验依据标准 |
| 战马罐装检验依据 | 下拉选择 | 否 | - | 战马罐装产品对应的检验依据标准 |
| 检测仪器 | 下拉选择 | 是 | - | 用于检测的仪器设备 |
| 可用状态 | 开关 | 否 | 默认关闭 | 启用/禁用该定量项目 |

### 产品大类下拉选项
![定量项目-产品大类下拉选项](定量项目-截图/定量项目-产品大类下拉选项.png)

| 选项 | 说明 |
|------|------|
| 红牛 | 红牛维生素功能饮料产品线 |

### 检测仪器下拉选项
![定量项目-检测仪器下拉选项](定量项目-截图/定量项目-检测仪器下拉选项.png)

| 选项 | 说明 |
|------|------|
| 高效液相色谱仪 | 用于有机化合物的分离和定量分析 |
| 气相色谱仪 | 用于挥发性有机化合物的分析 |
| 原子荧光光度计 | 用于重金属元素的检测 |
| 酶标仪 | 用于维生素B12等项目的检测 |
| 高速氨基酸分析仪 | 用于氨基酸类项目的检测 |
| pH计(多参数测定仪) | 用于pH值等参数的测定 |
| 恒温箱 | 用于微生物培养等恒温实验 |
| 分析天平 | 用于精确称量 |
| 自动卷边投影仪 | 用于罐体卷边质量检测 |

### 检验依据下拉选项
检验依据下拉选项与检验依据模块中维护的数据一致，包含国家标准、行业标准、客户标准和企业标准等。

### 底部按钮
- **取消**: 关闭对话框
- **确定**: 保存定量项目数据

## 5. 编辑定量项目

### 对话框标题
**编辑定量项目**

### 表单字段
与新建对话框基本相同，但有以下差异：
- **产品大类**: 不可修改（disabled状态），创建后不可更改
- **项目名称**: 可修改
- **检验依据**: 可修改（普通型/强化型/战马罐装均可修改）
- **检测仪器**: 可修改
- **可用状态**: 可修改

- 产品大类：红牛（不可修改）
- 项目名称：铅
- 普通型检验依据：GB 5009.12-2023
- 强化型检验依据：GB 5009.12-2023
- 战马罐装检验依据：GB 5009.12-2023
- 检测仪器：原子荧光光度计
- 可用状态：启用

## 8. 字段说明

### 8.1 序号
- **类型**: 数字
- **说明**: 数据记录的序号，每页从1开始

### 8.2 产品大类
- **类型**: 下拉选择
- **必填**: 是
- **说明**: 产品分类，当前系统中仅有"红牛"一个选项
- **注意**: 创建后不可修改

### 8.3 项目名称
- **类型**: 文本输入
- **必填**: 是
- **说明**: 定量检测项目名称，如"铅"、"总砷"、"苯甲酸"等

### 8.4 检验依据
- **类型**: 下拉选择（只读展示）
- **说明**: 列表中展示的检验依据为主检验依据，实际每条记录可关联3种产品类型的检验依据

### 8.5 检测仪器
- **类型**: 下拉选择
- **必填**: 是
- **说明**: 用于该检测项目的仪器设备名称

### 8.6 可用状态
- **类型**: 开关
- **说明**: 控制该定量项目是否可用，可直接在列表中切换

### 8.7 创建人
- **类型**: 文本
- **说明**: 创建该记录的操作人员

### 8.8 创建时间
- **类型**: 日期时间
- **格式**: YYYY-MM-DD HH:mm:ss
- **说明**: 记录创建时间

### 8.9 更新人
- **类型**: 文本
- **说明**: 最后更新该记录的操作人员

### 8.10 更新时间
- **类型**: 日期时间
- **格式**: YYYY-MM-DD HH:mm:ss
- **说明**: 记录最后更新时间
