## 1. 页面概述

- **所属模块**：仓储管理 > 基础信息
- **页面名称**：成品仓库管理
- **页面路由**：`/warehouse-manage/base-info/product-warehouse`
- **路由名称**：`ProductStockProductWarehouse`
- **API端点**：
  - 列表：`POST /apios/product_warehouse/list`
- **请求参数**：`{ "page": 1, "size": 10, "factory_code": null, "site": null, "factory_name": null }`

页面用于管理成品仓库信息，包含库存工厂名称、编码、对应车间、对应产线、库位地点、库位图形、存放物料大类、备注信息等配置。支持新增、编辑和删除操作。

## 4. 操作功能

### 4.1 搜索功能

页面顶部提供搜索区域，支持以下搜索条件：
- **库存工厂编码**：文本输入框，输入关键词后点击"搜索"按钮
- **库存库位地点**：文本输入框，输入关键词后点击"搜索"按钮
- **库存工厂名称**：文本输入框，输入关键词后点击"搜索"按钮
- **重置**：清空搜索条件，恢复默认列表

### 4.2 新增仓库

点击"新增仓库"按钮后，弹出"新增仓库"对话框：

![新增仓库对话框](截图/成品仓库管理-新增仓库对话框.png)

#### 表单字段

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 库存工厂编码 | 文本输入 | 是 | 输入工厂编码 |
| 库存工厂名称 | 文本输入 | 是 | 输入工厂名称 |
| 对应车间 | 下拉选择（单选） | 是 | 选项：一车间、二车间、三车间 |
| 对应产线 | 下拉选择（多选） | 是 | 选项：一线、二线、三线、四线、五线、六线 |
| 库存库位地点 | 文本输入 | 否 | 输入库位地点编码 |
| 存放物料大类 | 单选按钮 | 是 | 选项：红牛、战马、芙丝 |
| 库位图形 | 单选按钮 | 否 | 选项：有、无 |
| 仓库类型 | 单选按钮 | 否 | 选项：生产工厂、代存仓库 |
| 备注 | 文本输入 | 否 | 备注说明 |
| 所属单位 | 文本输入 | 否 | 所属单位 |
| 仓库面积(㎡) | 文本输入 | 否 | 仓库面积 |
| 理论库容(万箱) | 文本输入 | 否 | 理论库容 |

#### 对应车间下拉选项

![对应车间下拉选项](截图/成品仓库管理-新增-对应车间下拉选项.png)

选项列表：一车间、二车间、三车间

#### 对应产线下拉选项

![对应产线下拉选项](截图/成品仓库管理-新增-对应产线下拉选项.png)

选项列表：一线、二线、三线、四线、五线、六线（支持多选）

### 4.3 编辑仓库

点击表格行中的"编辑"按钮后，弹出"编辑仓库"对话框，表单字段与新增相同，但预填充了当前行的数据。

![编辑仓库对话框](截图/成品仓库管理-编辑仓库对话框.png)

以编辑"三期成品仓"为例，表单预填充数据如下：

| 字段 | 值 |
|------|-----|
| 库存工厂编码 | 8321 |
| 库存工厂名称 | 三期成品仓 |
| 对应车间 | 三车间 |
| 对应产线 | 五线、六线 |
| 库存库位地点 | 0004 |
| 存放物料大类 | 红牛（选中） |
| 库位图形 | 无（选中） |
| 仓库类型 | 生产工厂（选中） |
| 理论库容(万箱) | 61.2 |

### 4.4 删除仓库

点击表格行中的"删除"按钮后，弹出确认对话框：

![删除确认对话框](截图/成品仓库管理-删除确认对话框.png)

确认对话框内容：**"确认要删除项目名称为：【咸宁基地】的该条内容吗?"**

- **取消**：放弃删除操作
- **确定**：确认删除该条仓库记录
