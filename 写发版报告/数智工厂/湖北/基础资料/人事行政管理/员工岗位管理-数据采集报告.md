## 1. 页面概述

### 页面路径
人事行政 → 人事管理 → 员工岗位管理

### 系统地址
`https://hbmms.y1b.cn:8424/#/administration-manage/index10/index107/post`

### 主要功能
员工岗位管理模块用于管理企业内所有岗位的详细信息，包括岗位基本信息、工作安排、薪酬建议、任职条件、职责说明等。

## 2. 搜索和筛选功能

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 岗位名称 | 文本输入 | 支持模糊查询岗位名称 |
| 所属部门 | 下拉选择 | 选择具体的所属部门（只读） |

### 操作按钮
- **重置**: 清空搜索条件
- **搜索**: 根据条件查询岗位数据

## 3. 功能按钮说明

支持导出岗位数据为Excel或其他格式文件。

## 4. 新增岗位对话框

### 对话框字段说明

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 岗位名称 | 文本输入 | 是 | 岗位的名称 |
| 所属部门 | 下拉选择 | 是 | 岗位所属的部门 |
| 建议薪酬 | 数值范围 | 否 | 建议的薪酬区间（两个输入框：最低薪酬、最高薪酬） |
| 任职条件 | 多行文本 | 否 | 岗位的任职条件要求（限制100字符） |
| 岗位状态 | 单选按钮 | 是 | 启用/禁用 两种状态 |
| 显示顺序 | 数字输入 | 是 | 岗位在列表中的显示顺序 |
| 岗位职责 | 多行文本 | 否 | 岗位的职责说明（限制100字符） |
| 工作地点 | 文本输入 | 否 | 岗位的工作地点 |
| 工作内容 | 多行文本 | 否 | 岗位的主要工作内容 |
| 岗位标配人数 | 数字输入 | 否 | 该岗位的标准配置人数 |
| 工作班制 | 下拉选择 | 否 | 工作班制类型 |
| 岗位作业类型 | 下拉选择 | 否 | 岗位的作业类型分类 |
| 工作班时间 | 范围输入 | 否 | 工作班时间（天制、小时/天） |

### 底部按钮
- **取消**: 关闭对话框，不保存数据
- **确定**: 保存新增的岗位数据

## 8. 字段说明

### 8.1 岗位基本信息
- **岗位名称**: 企业在岗岗位的名称，如"总经理"、"安全专员"等
- **所属部门**: 岗位所属的部门或组织单元，如"湖北生产基地"、"安全管理部"等

### 8.2 薪酬与条件
- **建议薪酬**: 企业建议的薪酬区间，包含最低和最高薪酬
- **任职条件**: 胜任该岗位所需具备的学历、技能、经验等条件
- **岗位职责/责任说明**: 该岗位的主要工作职责和责任描述

### 8.3 工作安排
- **工作地点**: 岗位的工作地点或办公场所
- **工作内容**: 岗位的主要工作任务和工作内容描述
- **岗位标配人数**: 该岗位在标准配置下应该配备的人数
- **工作班制**: 工作的班次制度安排
- **岗位作业类型**: 岗位的作业类型分类
- **工作班时间**: 具体的工作时间安排

### 8.4 状态管理
- **状态**: 岗位的启用/禁用状态
  - 启用: 岗位正常使用
  - 禁用: 岗位暂时停用
- **显示顺序**: 岗位在列表或选择框中的显示优先级

### 8.5 审计信息
- **更新人**: 最后一次更新该岗位信息的操作人
- **更新时间**: 最后一次更新该岗位信息的时间
