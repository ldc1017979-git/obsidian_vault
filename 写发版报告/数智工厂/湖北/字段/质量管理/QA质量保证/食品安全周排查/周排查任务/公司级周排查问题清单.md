# 公司级周排查问题清单

## 页面概述
- **模块**: 质量管理 > QA质量保证 > 食品安全周排查 > 周排查任务 > 公司级周排查问题清单
- **URL**: `https://hbmms.y1b.cn:8424/#/quality-manage/index3/index38/qa-zhoupaicharenwu/company-weekly-issues`
- **功能说明**: 汇总公司级周排查中发现的问题，跟踪整改状态

## 一、列表页

### 1.1 搜索筛选字段

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 整改情况 | 下拉框(combobox) | 空 | 可选 | 筛选整改情况 |
| 2 | 年月份 | 日期范围选择器 | 当年1月1日-6月30日 | 可选 | 开始日期-结束日期 |

### 1.2 统计标签

| 序号 | 标签名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 已整改 | 已完成整改数量 |
| 2 | 整改不合格 | 整改验证未通过数量 |
| 3 | 待验证 | 已提交整改待验证数量 |
| 4 | 未整改 | 尚未整改数量 |

### 1.3 数据表格列

| 序号 | 列名 | 说明 |
| :--- | :--- | :--- |
| 1 | 年月份 | 问题所属年月 |
| 2 | 排查周期 | 排查日期范围 |
| 3 | 检查编号 | 关联检查编号 |
| 4 | 风险项目 | 风险项目名称 |
| 5 | 问题描述 | 问题描述内容 |
| 6 | 问题图片 | 问题图片(支持png/jep/jpeg/gif) |
| 7 | 问题类型 | 问题分类 |
| 8 | 问题地点 | 问题发生地点 |
| 9 | 整改情况 | 已整改/整改不合格/待验证/未整改 |
| 10 | 整改人 | 整改责任人 |
| 11 | 整改措施 | 整改措施描述 |
| 12 | 整改图片 | 整改后图片 |
| 13 | 整改完成时间 | 整改完成日期时间 |
| 14 | 备注 | 备注信息 |
| 15 | 操作 | 操作按钮 |

---

## 二、操作按钮

| 按钮 | 位置 | 功能 |
| :--- | :--- | :--- |
| 重置 | 搜索区 | 清空条件 |
| 搜索 | 搜索区 | 查询 |
| 推送整改消息 | 搜索区 | 向整改人推送整改提醒消息 |

## 三、交互说明

1. 整改流程：未整改 → 整改中 → 待验证 → 已整改/整改不合格
2. 支持推送整改消息功能，提醒整改人及时处理
3. 问题图片和整改图片仅支持png/jep/jpeg/gif格式
4. 统计标签实时显示当前查询条件下的各状态数量
