# 每月食品安全调度纪要

## 页面概述
- **模块**: 质量管理 > QA质量保证 > 食品安全周排查 > 每月食品安全调度纪要
- **URL**: `https://hbmms.y1b.cn:8424/#/quality-manage/index3/index38/fsi-monthlyDispatch`
- **功能说明**: 管理每月食品安全调度会议纪要，记录月度食品安全调度决策和安排

## 一、列表页

### 1.1 搜索筛选字段

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 记录编号 | 文本框(textbox) | 空 | 可选 | 按记录编号搜索，如202605 |
| 2 | 单据状态 | 下拉框(combobox) | 空 | 可选 | 筛选纪要状态（待审核/已审核） |

### 1.2 数据表格列

| 序号 | 列名 | 说明 |
| :--- | :--- | :--- |
| 1 | 记录编号 | 调度纪要编号，如202605 |
| 2 | 食品安全月份 | 调度对应的月份，如2026-05 |
| 3 | 会议名称 | 调度会议名称，如"5月份食品安全月调度会议" |
| 4 | 记录 | 会议记录人 |
| 5 | 会议日期 | 会议召开日期 |
| 6 | 会议地点 | 会议地点，如"大会议室" |
| 7 | 出席人员 | 出席人员列表，如"王蕾,孙军,刘娜,王振,李军,何勇" |
| 8 | 状态 | 待审核/已审核 |
| 9 | 操作 | 详情（已审核）/详情+撤回（待审核） |
