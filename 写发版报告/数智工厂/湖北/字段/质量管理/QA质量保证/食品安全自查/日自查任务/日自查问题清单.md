# 日自查问题清单

## 页面概述
- **模块**: 质量管理 > QA质量保证 > 食品安全自查 > 日自查任务 > 日自查问题清单
- **URL**: `https://hbmms.y1b.cn:8424/#/quality-manage/index3/index37/qa-rizicharenwu/daily-self-checklist`
- **功能说明**: 汇总各部门自查中发现的问题清单，用于问题跟踪和整改管理

## 一、列表页

### 1.1 搜索筛选字段

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 整改结果 | 下拉框(combobox) | 空 | 可选 | 筛选整改结果 |
| 2 | 检查日期 | 日期范围选择器 | 当月1日-当日 | 可选 | 开始日期-结束日期 |
| 3 | 整改人 | 下拉框(combobox) | 空 | 可选 | 筛选整改人 |
| 4 | 验收人 | 下拉框(combobox) | 空 | 可选 | 筛选验收人 |

### 1.2 统计标签

| 序号 | 标签名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 整改完成 | 已完成整改数量 |
| 2 | 整改不合格 | 整改验证未通过数量 |
| 3 | 待验收 | 已提交整改待验收数量 |
| 4 | 未整改 | 尚未整改数量 |

### 1.3 数据表格列

| 序号 | 列名 | 说明 |
| :--- | :--- | :--- |
| 1 | 年月份 | 问题所属年月，如"2026年5月" |
| 2 | 检查日期 | 检查日期 |
| 3 | 不符合项说明 | 问题描述内容 |
| 4 | 不符合图片 | 问题图片 |
| 5 | 问题类型 | 问题分类，如设施维护/卫生/有害生物防治/供应商管理 |
| 6 | 不符合项采取的防范措施 | 防范措施描述 |
| 7 | 整改图片 | 整改后图片 |
| 8 | 整改结果 | 整改完成/整改不合格/待验收/未整改 |
| 9 | 自查部门 | 发现问题的部门，如生产部/行政部/储运部 |
| 10 | 整改人 | 整改责任人 |
| 11 | 整改完成时间 | 整改完成日期时间 |
| 12 | 验收人 | 验收人姓名 |
| 13 | 验收时间 | 验收日期 |
| 14 | 备注 | 备注信息 |
| 15 | 操作 | 执行整改（未整改状态） |

---

## 二、操作按钮

| 按钮 | 位置 | 功能 |
| :--- | :--- | :--- |
| 重置 | 搜索区 | 清空条件 |
| 搜索 | 搜索区 | 查询 |
| 推送整改消息 | 搜索区 | 向整改人推送整改提醒消息 |
| 执行整改 | 操作列 | 填写整改措施和图片 |

## 三、交互说明

1. 问题来源: 各部门每日自查中勾选"否"的检查项自动生成问题清单
2. 整改流程: 未整改 → 执行整改 → 待验收 → 整改完成/整改不合格
3. 支持推送整改消息功能，提醒整改人及时处理
4. 不符合图片和整改图片仅支持png/jep/jpeg/gif格式
5. 统计标签实时显示当前查询条件下的各状态数量
