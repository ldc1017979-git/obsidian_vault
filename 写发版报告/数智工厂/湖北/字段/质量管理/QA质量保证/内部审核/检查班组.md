# 检查班组

## 页面概述
- **模块**: 质量管理 > QA质量保证 > 内部审核 > 检查班组
- **功能说明**: 管理内部审核检查班组配置

## 一、列表页

### 1.1 搜索筛选字段

| 序号 | 字段名称 | 输入类型 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 生产班组 | 文本框(textbox) | 可选 | 搜索班组名称 |

### 1.2 数据表格列

| 序号 | 列名 | 说明 |
| :--- | :--- | :--- |
| 1 | 检查班组 | 班组名称，如A班、B班 |
| 2 | 可用状态 | 开关(switch)，启用/禁用 |
| 3 | 创建人 | 创建人姓名 |
| 4 | 创建时间 | 创建时间 |
| 5 | 更新人 | 更新人姓名 |
| 6 | 更新时间 | 更新时间 |
| 7 | 操作 | 编辑 |

## 二、新增/编辑弹窗

| 序号 | 字段名称 | 输入类型 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 检查班组 | 文本框(textbox) | 必填(*) | 班组名称 |
| 2 | 可用状态 | 开关(switch) | 默认启用 | 启用/禁用 |

## 三、操作按钮

| 按钮 | 功能 |
| :--- | :--- |
| 新增检查班组 | 创建班组 |
| 编辑 | 编辑班组 |
| 搜索/重置 | 查询 |

## 四、交互说明

1. 检查班组用于内审任务的分配
2. 可用状态通过开关控制，支持启用/禁用
3. 列表支持分页显示
