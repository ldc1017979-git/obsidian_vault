# 供应商访问记录

## 页面概述
- **模块**: 质量管理 > QA质量保证 > 供应商审核 > 供应商访问记录
- **URL**: `/quality-manage/index3/supplier-audit/visit-records`
- **功能说明**: 查看供应商访问记录详情，由执行审核任务完成后自动生成，支持供应商签字确认

## 一、列表页

### 1.1 搜索字段（3个）

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | Placeholder |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 报告编号 | 文本框(textbox) | 空 | 可选 | 报告编号: |
| 2 | 访问日期 | 日期范围选择器 | 空 | 可选 | 开始日期 ~ 结束日期 |
| 3 | 审核进度 | 下拉框(combobox) | 空 | 可选 | 审核进度: |

### 1.2 列表字段（11列）

| 序号 | 列名 | 说明 |
| :--- | :--- | :--- |
| 1 | 序号 | 行号 |
| 2 | 报告编号 | 自动生成的编号，如GYS260305001 |
| 3 | 审核进度 | 如：待供应商签字、审核完成 |
| 4 | 供应商 | 供应商名称 |
| 5 | 供应内容 | 供应的产品/服务 |
| 6 | 访问日期 | 实际访问日期 |
| 7 | 访问人 | 访问人员姓名（多人用/分隔） |
| 8 | 联系人 | 供应商方联系人 |
| 9 | 创建人 | 创建该记录的人员 |
| 10 | 创建时间 | 记录创建时间 |
| 11 | 任务操作 | 详情/执行签字按钮 |

### 1.3 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按条件查询 |

### 1.4 行操作按钮

| 审核进度 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 待供应商签字 | 详情 | 查看详情 |
| 待供应商签字 | 执行签字 | 供应商签字确认 |
| 审核完成 | 详情 | 查看详情 |

> 注意：本页面无"新建"按钮，访问记录由执行审核任务完成后自动生成
