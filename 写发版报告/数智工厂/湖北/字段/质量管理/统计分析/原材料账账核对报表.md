# 原材料账账核对报表

## 页面概述
- **模块**: 质量管理 > 统计分析 > 原材料账账核对报表
- **URL**: `https://hbmms.y1b.cn:8424/#/quality-manage/statistic-analysis/raw-material-statement`
- **功能说明**: 原材料的账账核对统计报表，按产品分类汇总展示空罐、顶/底盖、纸皮等原材料的检测量和合格率

---

## 一、搜索筛选字段（2个）

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | Placeholder |

| 1 | 产品名称 | 下拉框(combobox) | 红牛维生素功能饮料 | 可选 | 请选择产品名称 |
| 2 | 年月日 | 日期范围选择器 | 空 | 可选 | 开始日期 ~ 结束日期 |

## 二、数据报表内容

### 2.1 红牛空罐信息确认单 — 空罐

| 统计项目 | 单位 | 说明 |
| :--- | :--- | :--- |
| 月度检测量 | 万罐 | 按产品版本统计月度检测量 |
| 入库检测量 | 万罐 | 入库检测数量 |
| 退库量 | 万罐 | 退库数量 |
| 退库原因 | - | 退库原因说明 |
| 合格率% | % | 检测合格率 |

- 按产品（如红牛-普通型）和版本区分（如普通型、31周年版、1元乐享版等）统计
- ORG制罐线区分：按托统计，分一线/六线/八线/九线/十线/十一线

### 2.2 顶/底盖检验报告 — 顶盖/底盖

| 统计项目 | 单位 | 说明 |
| :--- | :--- | :--- |
| 月度检测量 | 万片 | 顶盖/底盖月度检测量 |
| 入库检测量 | 万片 | 入库检测数量 |
| 退库量 | 万片 | 退库数量 |
| 退库原因 | - | 退库原因说明 |
| 合格率% | % | 检测合格率 |

### 2.3 纸皮进货检验报告 — 纸皮

| 统计项目 | 单位 | 说明 |
| :--- | :--- | :--- |
| 月度检测量 | 万张 | 纸皮月度检测量 |
| 入库检测量 | 万张 | 入库检测数量 |
| 退库量 | 万张 | 退库数量 |
| 退库原因 | - | 退库原因说明 |
| 合格率% | % | 检测合格率 |

- 按版本区分（如31周年版、1元乐享版、普通型等）统计
- 按厂家区分（如河南华洋、武汉菲利、武汉三叶、北京和玖、湖北丰环等）统计
- 各厂家对应版本明细统计

## 四、交互说明

1. 选择产品名称和日期范围后点击"搜索"刷新数据
2. 数据来源包括：红牛空罐信息确认单、顶/底盖检验报告、纸皮进货检验报告
3. 异常数据关联"原材料质量异常处置"单据
4. 空罐数据支持按版本区分和ORG制罐线区分两个维度
5. 纸皮数据支持按版本区分、厂家区分、各厂家对应版本三个维度
6. 只读统计报表，无新建/编辑功能
