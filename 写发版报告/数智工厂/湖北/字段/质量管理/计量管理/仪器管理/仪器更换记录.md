# 仪器更换记录

## 页面概述
- **模块**: 质量管理 > 计量管理 > 仪器管理 > 仪器更换记录
- **URL**: `https://hbmms.y1b.cn:8424/#/quality-manage/index13/index22/replace-record`
- **功能说明**: 记录仪器设备更换的历史记录

---

## 一、列表页

### 1.1 搜索筛选字段（3个）

| 序号 | 字段名称 | 输入类型 | 约束条件 | Placeholder |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 确认状态 | 下拉框 | 可选 | 请选择确认状态 |
| 2 | 更换人 | 下拉框 | 可选 | 请选择更换人 |
| 3 | 更换时间 | 日期范围 | 可选 | 开始日期~结束日期 |

### 1.2 数据表格列（12列）

| 序号 | 列名 | 说明 |
| :--- | :--- | :--- |
| 1~12 | 单据编号/仪器名称/更换时间/更换配件/更换原因/确认人签名/确认状态/确认时间/备注/制单人/创建时间/操作 | - |

### 1.3 操作按钮

| 按钮 | 功能 |
| :--- | :--- |
| 新建 | 打开新建抽屉 |
| 导出数据 | 导出列表数据 |

## 二、新建/编辑页面（抽屉）

### 2.1 表单字段（6个）

| 序号 | 字段名称 | 输入类型 | 约束条件 | Placeholder |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 仪器名称 | 文本框(textbox) | 必填 | - |
| 2 | 更换时间 | 日期时间选择器 | 必填 | 请选择时间 |
| 3 | 更换配件 | 文本框(textbox) | 必填 | 请输入更换配件 |
| 4 | 更换人 | 文本框(textbox) | 必填 | - |
| 5 | 更换原因 | 文本域(textarea) | 必填 | 请输入更换原因 |
| 6 | 备注 | 文本域(textarea) | 可选 | 请输入备注 |

### 2.2 操作按钮

| 按钮 | 功能 |
| :--- | :--- |
| 取消 | 关闭抽屉 |
| 保存 | 暂存 |
| 签字确认 | 确认更换 |

---

## 三、交互说明

1. 点击"新建"打开抽屉表单
2. 记录仪器名称、更换配件和更换原因
3. 保存后签字确认进入确认流程
