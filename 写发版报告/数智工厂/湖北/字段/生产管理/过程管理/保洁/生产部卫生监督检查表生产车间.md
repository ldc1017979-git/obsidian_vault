## 详情页 - 检查内容

静态检查项列表，分为车间操作区域卫生和人员卫生两组。

### 车间操作区域卫生

| 序号 | 检查项目 |
| :--- | :--- |
| 1 | 门、窗清洁密封性完好 |
| 2 | 地面、墙壁、窗台清洁，无积水、油污、碎屑等杂物。窗纱密封良好、无破损 |
| 3 | 车间内无蜘蛛网、飞虫 |
| 4 | 照明灯防护罩齐全 |
| 5 | 排水沟通畅、无异味 |
| 6 | 无蚊、蝇等小昆虫 |
| 7 | 更衣柜、鞋柜和板凳是否摆放整齐，干净 |
| 8 | 洗手台清洁，洗手池排水通畅，洗手液、消毒液充足，烘手器工作正常 |
| 9 | 脚踏消毒池内消毒液水量及浓度正常 |
| 10 | 卫生间无异味、积水、蜘蛛网，便池清洁、无水垢 |
| 11 | 风幕机、粘鼠板、灭蝇灯工作正常，清洁无灰尘 |

### 人员卫生

| 序号 | 检查项目 |
| :--- | :--- |
| 1 | 员工个人着装、卫生符合要求 |
| 2 | 车间人员无戴饰品、化浓妆、染指甲等 |
| 3 | 工作期间规定进行手消毒 |
