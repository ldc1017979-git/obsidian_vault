# 生产统计表

## 页面概述

- **功能说明**: 生产统计表管理，用于查看和导出生产统计数据
- **URL**: `https://hbmms.y1b.cn:8424/#/product/public/report/produce_daily`
- **所属模块**: 生产管理 → 公有内容 → 统计管理
