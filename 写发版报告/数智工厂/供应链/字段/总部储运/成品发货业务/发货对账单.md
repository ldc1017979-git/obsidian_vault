# 成品发货业务 - 发货对账单

## 页面概述

发货对账单页面用于管理和维护成品发货的对账信息，记录订单与实际发货的对应关系，支持财务对账和结算。

## 筛选条件

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 发货工厂 | 下拉选择 | 选择发货工厂筛选 |
| 仓库 | 下拉选择 | 选择仓库筛选 |
| 统计日期 | 日期范围 | 选择统计日期范围 |
| 商品信息 | 下拉选择 | 选择商品筛选，默认"全部" |
| 运输方式 | 下拉选择 | 选择运输方式筛选 |
| 库存工厂 | 下拉选择 | 选择库存工厂筛选 |
| 订单号 | 文本输入 | 输入订单号搜索 |

## 业务说明

1. 发货对账单用于财务对账，核对订单与实际发货的一致性
2. 对账记录包含订单、交货单、发货数量等关键信息
3. 支持按订单、日期、物料等维度查询对账数据
4. 对账数据支持导出到Excel，便于财务人员进行二次处理
5. 发货对账单与订单、发运记录等模块关联
