# 成品发货业务 - 发运记录

## 页面概述

发运记录页面用于记录和追踪成品的实际发运信息，包括装运单号、发运单号、实际发运数量、承运商、运输方式等详细信息。

![发运记录-列表页](screenshots/发运记录-列表页.png)

## 筛选条件

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 始发地 | 下拉选择 | 选择发运始发地，支持"请选择"默认值 |
| 目的地 | 下拉选择 | 选择发运目的地，支持"请选择"默认值 |
| 下单日期 | 日期范围 | 选择下单日期范围（开始时间至结束时间） |
| 产品信息 | 文本输入 | 输入物料代码/名称，占位符"请输入物料代码/名称" |
| 单号信息 | 文本输入 | 输入发运计划单号/交货单号/装运单号，占位符"请输入发运计划单号/交货单号/装运单号" |

## 业务说明

1. 发运记录记录成品实际发运的详细信息，是发货执行的核心数据
2. 每条发运记录关联对应的发运计划，便于追溯
3. 发运记录包含完整的物流信息，包括承运商、运输方式、线路等
4. 记录实际发运数量、出库数量等执行数据
5. 发运记录与发运计划、订单、对账单等模块关联
6. 可通过"查看批次"按钮查看每条发运记录的批次详情（批次、出库数量、单位、箱序列号）
7. 三个标签页（工厂销售订单、调拨单批导、芙丝水批导）共享大部分公共字段，但各有特有字段
8. "芙丝水批导"标签页当前无数据，"查看批次"按钮仅出现在工厂销售订单和调拨单批导标签页
