# 成品发货业务 - 发运统计

## 页面概述

发运统计页面用于对成品发运数据进行多维度汇总分析，支持按省份、仓库、商品、车辆等维度查看发运统计数据。

## 标签页

| 标签页名称 | 说明 |
|------------|------|
| 卸货仓库统计 | 按省份和卸货仓库维度统计发运数据 |
| 商品统计 | 按商品维度统计每日发运计划量与实际量 |
| 车辆统计 | 按仓库和承运商维度统计每日车辆数 |

## 业务说明

1. 发运统计提供多维度的发运数据分析，支持决策和运营管理
2. 卸货仓库统计：按省份和卸货仓库维度统计发运数据，包括占比分析
3. 商品统计：按商品维度统计每日发运计划量与实际量，含多级表头展示日期数据
4. 车辆统计：按仓库和承运商维度统计每日车辆发运情况
5. 商品统计和车辆统计均采用多级表头结构，支持跨日数据展示
6. 支持导出统计数据到Excel，便于二次分析和报告
7. 发运统计与发运计划、发运记录等模块关联
