# 合格证清单

> 模块路径: 供应商 > 合格证清单
> 页面URL: https://txcscm.y1b.cn/#/sup/supCertificateList

## 页面概述

合格证清单页面展示供应商视角的合格证记录列表，支持打印、上传出厂报告、作废等操作。

## 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 列表筛选 | 列表筛选 |

## 列表字段

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 序号 | 数值 | 行序号 |
| 操作 | 按钮组 | 打印、上传出厂报告、作废 |
| 是否批次首托 | 文本 | 是否为批次首托（是/否） |
| 合格证编号 | 文本 | 合格证编号（如11000046-260609-00100） |
| 合格证状态 | 文本 | 合格证状态 |

| 生产数量 | 数值 | 生产数量 |
| 标签证生成时间 | 日期时间 | 标签证生成时间（如2026-06-09 11:22:19） |
| 出厂检验报告 | 文本 | 出厂检验报告 |
| 生产日期 | 日期 | 生产日期 |
| 厂商批次 | 文本 | 厂商批次号（如142660838A） |
| 厂商产线 | 文本 | 厂商产线编号 |
| 包号/托盘号 | 文本 | 包号或托盘号 |
| 内部批次号 | 文本 | 内部批次号（如S26060901） |
| 物料名称 | 文本 | 物料名称 |
| 物料编码 | 文本 | 系统物料编码（如GC000037） |
| SAP物料编码 | 文本 | SAP系统物料编码 |
| 物料品类 | 文本 | 物料品类（如空罐、纸皮） |
| 包装规格 | 文本 | 包装规格（如2000张/托） |
| 到货检查结果 | 文本 | 到货检查结果 |
| 到货不合格处理 | 文本 | 到货不合格处理 |
| 质检抽检结果 | 文本 | 质检抽检结果 |
| 抽检不合格处理 | 文本 | 抽检不合格处理 |
| 退货数量 | 数值 | 退货数量 |
| 其它参数 | 按钮 | 其它参数项数（如"3项"） |
| 生产计划单号 | 文本 | 关联生产计划单号 |
| 要货计划单号 | 文本 | 关联要货计划单号 |
| 采购订单号 | 文本 | 关联采购订单号 |

| 供应商(一级) | 文本 | 一级供应商 |
| 供应商(二级) | 文本 | 二级供应商 |
