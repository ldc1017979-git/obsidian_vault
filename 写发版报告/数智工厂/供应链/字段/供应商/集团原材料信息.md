## 列表页

### 页面概述

集团原材料信息页面展示集团所有原材料的详细信息，支持补充规格、导入图片和导出操作。

### 筛选条件

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 物料名称 | 文本输入 | 按物料名称搜索 |
| 物料编码 | 文本输入 | 按物料编码搜索 |
| SAP物料编码 | 文本输入 | 按SAP物料编码搜索 |
| 物料品类 | 下拉选择 | 按品类筛选 |
| 物料归属 | 下拉选择 | 按归属分类筛选 |
| 线上促销 | 下拉选择 | 是/否 |

### 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 补充原材料规格 | 补充原材料规格信息 |
| 导入原材料图片 | 批量导入原材料图片 |
| 导出原料信息 | 导出原料信息Excel |
| 列表筛选 | 展开/收起筛选条件 |
| 详情 | 查看原材料详情 |
| 编辑 | 编辑原材料信息（权限内） |
| 搜索 | 按条件搜索 |
| 重置 | 重置筛选条件 |
