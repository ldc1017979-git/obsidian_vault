# 合格证清单

> 模块路径: 供应商 > 生产厂商 > 合格证清单
> 页面URL: https://txcscm.y1b.cn/#/sup/prod/supProducerCertificateList

## 页面概述

合格证清单页面展示生产厂商视角的合格证记录列表，支持打印操作。

## 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 列表筛选 | 列表筛选 |

| 字段名称 | 字段类型 | 说明 |

| 序号 | 数值 | 行序号 |
