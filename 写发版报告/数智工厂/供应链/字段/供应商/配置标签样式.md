## 列表页

### 页面概述

配置标签样式页面展示供应商视角的标签样式配置列表，支持添加、编辑、删除标签样式。

### 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 添加样式 | 新增标签样式配置 |
| 编辑 | 编辑现有标签样式 |
| 删除 | 删除标签样式 |

### 列表字段

| 字段名称 | 字段类型 | 示例值 | 说明 |
|---------|---------|--------|------|
| 序号 | 数值 | 1 | 行序号 |
| 操作 | 按钮组 | 编辑/删除 | 操作按钮 |
| 供应商 | 文本 | 奥瑞金科技股份有限公司佛山分公司 | 供应商名称 |
| 标签名称 | 文本 | 佛山标签 | 标签样式名称 |
| 适用物料品类 | 文本 | 空罐 | 适用物料品类 |
| 适用物料归属 | 文本 | 红牛 | 适用物料归属品牌 |
| 更新时间 | 日期时间 | 2026-06-10 09:59:44 | 最后更新时间 |

## 编辑/详情页（点击「编辑」按钮进入）

### 页面结构

编辑页面通过「基础信息」「标签信息」两个切换模块展示不同内容，并包含标签样式设计画布、尺寸设置、背景设置等功能区。

| 模块 | 内容形式 | 说明 |
|-----|---------|------|
| 基础信息 | 表单（label-value/下拉选择） | 展示标签样式基础配置（供应商、标签名称、适用物料品类、归属） |
| 标签信息 | 表格 | 展示标签参数配置（参数名称、数据类型、标签内容、操作） |
| 标签样式 | 画布区域 | 包含图片/Logo上传、标签元素列表（可拖拽）、画布预览 |
| 尺寸设置 | 表单 | 设置标签尺寸（宽、高，单位mm） |
| 背景设置 | 表单 | 设置背景颜色、边框颜色、边框粗细、圆角 |
| — | 按钮 | 新增一行（标签参数）、删除（标签参数行）、确认、关闭 |

| 字段名称 | 字段类型 | 示例值 | 说明 |
|---------|---------|--------|------|

### 6. 操作按钮（编辑页底部）

| 按钮名称 | 说明 |
|---------|------|
| 新增一行 | 在标签参数表格中新增一行配置 |
| 删除 | 删除标签参数表格中的某一行 |
| 确认 | 保存标签样式配置并关闭弹窗 |
| 关闭 | 不保存直接关闭编辑弹窗 |
| 上传 | 上传图片/Logo |
| 设定批次规则 | 配置批次规则（当数据类型为「系统按规则自动填充」时） |
| 收起 | 收起标签信息区域 |
