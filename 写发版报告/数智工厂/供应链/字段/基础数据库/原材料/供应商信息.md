# 供应商信息

> 模块路径: 基础数据库 > 原材料 > 供应商信息
> 页面URL: https://txcscm.y1b.cn/#/jichushuku/rawmaterials/supplier

---

## 页面概述

供应商信息页面展示原材料供应商基本信息列表，支持新增、导入、维护供应商账户组等操作。

---

## 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 新增 | 新增供应商信息 |
| 维护供应商账户组 | 维护供应商账户组 |
| 导入 | 导入供应商数据 |
| 批量提审 | 批量提交审批 |
| 批量删除 | 批量删除 |
| 批量反审 | 批量反审 |
| 列表筛选 | 打开列表筛选面板 |
| 详情 | 查看供应商详情 |
| 反审 | 反审供应商信息 |
| 编辑 | 编辑供应商信息 |
