# 原材料结算价格

> 模块路径: 基础数据库 > 原材料 > 原材料结算价格
> 页面URL: https://txcscm.y1b.cn/#/jichushuku/rawmaterials/raw_material_price

---

## 页面概述

原材料结算价格页面展示原材料与供应商的结算价格列表，支持新增、导入、批量操作。

---

## 操作按钮

|---------|------|
| 新增 | 新增结算价格 |
| 导入原材料价格 | 导入原材料价格数据 |
| 批量提审 | 批量提交审批 |
| 批量删除 | 批量删除 |
| 批量反审 | 批量反审 |
