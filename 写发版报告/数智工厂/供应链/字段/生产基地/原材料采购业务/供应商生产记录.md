# 供应商生产记录

> 模块路径: 生产基地 > 原材料采购业务 > 供应商生产记录
> 页面URL: https://txcscm.y1b.cn/#/base/yuancailiaocaigou/baseProductionPlan

## 页面概述

供应商生产记录页面以列表形式展示供应商的生产计划执行情况，支持列表筛选和查看详情。

## 筛选条件

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 生产计划单号 | 文本输入 | 输入生产计划单号搜索 |
| 生产状态 | 下拉选择 | 选择生产状态筛选 |
| 物料名称 | 文本输入 | 输入物料名称搜索 |
| 物料编码 | 文本输入 | 输入物料编码搜索 |
| SAP物料编码 | 文本输入 | 输入SAP物料编码搜索 |
| 线上促销 | 下拉选择 | 选择线上促销状态筛选 |
| 生产厂 | 文本输入 | 输入生产厂名称搜索 |
| 计划完成时间 | 日期范围 | 选择计划完成时间范围 |
| 码源处理状态 | 下拉选择 | 选择码源处理状态筛选 |
| 要货计划单号 | 文本输入 | 输入要货计划单号搜索 |
| 采购订单号 | 文本输入 | 输入采购订单号搜索 |
| SAP采购订单号 | 文本输入 | 输入SAP采购订单号搜索 |
| 采购方名称 | 文本输入 | 输入采购方名称搜索 |
| 采购方收货工厂 | 文本输入 | 输入采购方收货工厂搜索 |

## 操作按钮
