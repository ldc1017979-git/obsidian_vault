# 要货计划

> 模块路径: 生产基地 > 原材料采购业务 > 要货计划
> 页面URL: https://txcscm.y1b.cn/#/base/yuancailiaocaigou/demandPlan

## 页面概述

要货计划页面以列表形式展示基地视角的要货计划信息，支持列表筛选、查看详情、打印单据等操作。

## 筛选条件

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 要货计划单号 | 文本输入 | 输入要货计划单号搜索 |
| 要货计划状态 | 下拉选择 | 选择要货计划状态筛选 |
| 供应商编码 | 文本输入 | 输入供应商编码搜索 |
| 供应商名称 | 文本输入 | 输入供应商名称搜索 |
| 组织代码 | 文本输入 | 输入组织代码搜索 |
| 组织名称 | 文本输入 | 输入组织名称搜索 |
| 工厂代码 | 文本输入 | 输入工厂代码搜索 |

## 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 列表筛选 | 展开/收起筛选条件 |
| 详情 | 查看要货计划详情 |
| 打印单据 | 打印要货计划单据 |
| 变更 | 变更要货计划 |
| 作废 | 作纲要货计划 |
