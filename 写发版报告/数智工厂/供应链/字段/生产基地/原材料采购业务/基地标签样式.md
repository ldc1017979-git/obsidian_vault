# 基地标签样式

> 模块路径: 生产基地 > 原材料采购业务 > 基地标签样式
> 页面URL: https://txcscm.y1b.cn/#/base/yuancailiaocaigou/baseConfigurationLabel

## 页面概述

基地标签样式页面以列表形式展示各基地的标签配置信息，支持添加、编辑、删除标签样式。点击"编辑"可进入标签配置编辑页面，进行详细的标签参数、标签样式、标签内容等配置。

## 设定批次规则弹窗

当"数据类型"选择"系统按规则自动填充"时，需点击"设定批次规则"按钮配置批次号生成规则。

### 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 新增规则 | 新增一条批次规则 |
| 验证 | 验证批次号生成 |
| 关闭 | 关闭弹窗 |
| 确认 | 确认规则配置 |

### 厂商批次示例

| 字段名称 | 示例值 | 说明 |
|---------|--------|------|
| 厂商批次示例文本 | 测试文本10611 | 当前长度: 9，最多10位 |

### 批次规则表格

| 字段名称 | 字段类型 | 示例值 | 说明 |
|---------|---------|--------|------|
| 序号 | 数值 | 1 | 行序号 |
| 规则类型 | 下拉选择 | 固定文本/引用参数-厂商产线/引用参数-生产日期 | 规则类型 |
| 内容 | 文本/下拉选择 | 固定文本内容或参数格式（如 MMDD【月 日-4位】） | 规则内容 |
| 操作 | 按钮 | 删除 | 操作按钮 |

### 批次号验证

| 字段名称 | 示例值 | 说明 |
|---------|--------|------|
| 批次号验证 | 0 / 10 | 当前长度 / 最大长度 |

### 新增规则弹窗（子弹窗）

| 按钮名称 | 说明 |
|---------|------|
| 新增规则 | 新增一条批次规则 |
| 验证 | 验证批次号 |
| 确认 | 确认保存规则 |
| 关闭 | 关闭弹窗 |
