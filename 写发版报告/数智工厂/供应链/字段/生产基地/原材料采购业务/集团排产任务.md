# 集团排产任务

> 模块路径: 生产基地 > 原材料采购业务 > 集团排产任务
> 页面URL: https://txcscm.y1b.cn/#/base/yuancailiaocaigou/hqGroupProdSchedueTask

## 页面概述

集团排产任务页面采用日历视图+表格组合布局，包含日历选择器、排产任务表、排产汇总表和成品BOM表三个区域。

## 筛选条件

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 月份选择 | 月份选择器 | 选择年月（如2026-06） |
| 基地 | 下拉选择 | 选择生产基地（如湖北基地(8883)） |

## 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 查看总览 | 查看排产总览信息 |
| 收起 | 收起/展开日历视图（开关） |
| 新增产品行 | 每条产线的新增产品行按钮 |

## 日历视图

日历以月为单位展示，显示每日排产情况。周一至周日排列。

## 集团排产任务表

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 产线 | 文本 | 生产线编号（1线~6线） |
| 物料大类 | 下拉选择 | 物料大类分类 |
| 商品名称 | 下拉选择 | 商品名称 |
| 商品编码 | 文本 | 商品编码（自动填充） |
| 商品图示 | 文本 | 商品图示（默认"--"） |
| 计划产量(箱) | 数值输入 | 计划产量 |
| 操作 | 按钮 | 新增产品行 |

**合计行**: 显示所有产线计划产量合计

## 排产汇总表

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 商品名称 | 文本 | 商品名称 |
| 计划总产量(箱) | 数值 | 计划总产量（箱） |
| 计划总产量(万罐) | 数值 | 计划总产量（万罐） |
| 操作 | 按钮 | 操作按钮 |

## 成品BOM表

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|

| 物料编码 | 文本 | 物料编码 |
| SAP物料编码 | 文本 | SAP系统中的物料编码 |
| 万罐单耗 | 数值 | 每万罐消耗量 |

| 已要货数量 | 数值 | 已要货数量 |
| 预要货数量 | 数值 | 预要货数量 |
| 到货数量 | 数值 | 到货数量 |
| 在途数量 | 数值 | 在途数量 |
| 库存数量 | 数值 | 库存数量 |
