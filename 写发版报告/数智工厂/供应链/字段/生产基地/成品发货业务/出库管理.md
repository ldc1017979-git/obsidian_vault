# 出库管理

> 模块路径: 生产基地 > 成品发货业务 > 出库管理
> 页面URL: https://txcscm.y1b.cn/#/base/chenpinfahuo/outbound-manage-new

## 页面概述

出库管理页面以列表形式展示出库单信息，支持多条件筛选和合并操作。

## 筛选条件

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 状态 | 下拉选择 | 出库状态 |
| 卸货点 | 下拉选择 | 卸货点 |
| 记账日期 | 日期范围 | 开始时间-结束时间（默认近30天） |
| 产品信息 | 文本输入 | 产品信息搜索 |
| 单号信息 | 下拉选择+文本输入 | 单号搜索 |
| 工厂编码 | 文本输入 | 工厂编码 |
| 运输单位 | 下拉选择 | 运输单位 |
| 运输方式 | 下拉选择 | 运输方式 |
| 车牌信息 | 文本输入 | 车牌信息 |
| 成品批次 | 文本输入 | 成品批次 |

## 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 搜索 | 按条件搜索 |
| 重置 | 重置筛选条件 |
| 合并 | 合并出库单 |
