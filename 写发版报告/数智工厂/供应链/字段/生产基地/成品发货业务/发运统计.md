# 发运统计

> 模块路径: 生产基地 > 成品发货业务 > 发运统计
> 页面URL: https://txcscm.y1b.cn/#/base/chenpinfahuo/baseShippingStatis

## 页面概述

发运统计页面以交叉表形式展示发运统计数据，包含卸货仓库统计和车辆统计两个Tab页，支持多条件筛选和导出Excel。

---

## 列表页

### 筛选条件

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 发货工厂 | 下拉选择 | 发货工厂 |
| 仓库 | 下拉选择 | 仓库 |
| 统计日期 | 日期范围 | 开始时间-结束时间（默认当月1日至当天） |

| 省份 | 下拉选择 | 省份 |
| 运输方式 | 下拉选择 | 运输方式 |
| 物料类型 | 下拉选择 | 物料类型 |
| 库存工厂 | 选择 | 库存工厂 |

## 车辆统计

### 统计汇总

| 字段名称 | 字段类型 | 示例值 | 说明 |
|---------|---------|--------|------|
| 统计日期 | 日期范围 | 2026-05-28~2026-06-11 | 统计日期范围 |
| 合计计划车数 | 数值 | 0 | 合计计划车数 |
| 合计实际车数 | 数值 | 0 | 合计实际车数 |
| 合计未到车数 | 数值 | 0 | 合计未到车数 |
| 合计达成率 | 百分比 | 0.00% | 合计达成率 |

### 交叉表字段

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 序号 | 数值 | 行序号 |
| 仓库 | 文本 | 仓库名称 |
| 承运商 | 文本 | 承运商名称 |
| 合计 | 数值 | 该仓库-承运商组合下的合计 |
| [日期] - 计划车数 | 数值 | 指定日期的计划车数（动态列，每日期一列） |
| [日期] - 实际车数 | 数值 | 指定日期的实际车数（动态列，每日期一列） |
| [日期] - 未到车数 | 数值 | 指定日期的未到车数（动态列，每日期一列） |
| 汇总 - 计划车数 | 数值 | 汇总计划车数 |
| 汇总 - 实际车数 | 数值 | 汇总实际车数 |
| 汇总 - 未到车数 | 数值 | 汇总未到车数 |

### 列结构说明

车辆统计为交叉表布局：
- **固定列**（左侧）：序号、仓库、承运商、合计
- **动态日期列**（中部）：每一日为一组，组内包含「计划车数」「实际车数」「未到车数」三列（日期范围由筛选条件的统计日期决定）
- **汇总列**（右侧）：计划车数、实际车数、未到车数（全日期范围合计）
