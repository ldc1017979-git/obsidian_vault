# 出库计划

> 模块路径: 生产基地 > 成品发货业务 > 出库计划
> 页面URL: https://txcscm.y1b.cn/#/base/chenpinfahuo/outboundPlan

## 页面概述

出库计划页面以列表形式展示出库计划信息，支持多条件筛选、合并和选择出库操作。

## 筛选条件

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 发货工厂 | 文本输入 | 发货工厂名称 |
| 目的地 | 文本输入 | 目的地名称 |
| 发运日期 | 日期范围 | 开始时间-结束时间 |
| 商品信息 | 下拉选择+文本输入 | 商品筛选（默认"全部"） |
| 处理状态 | 复选框组 | 待处理（默认选中）/处理中/已处理 |

## 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 搜索 | 按条件搜索 |
| 重置 | 重置筛选条件 |
| 合并 | 合并出库计划 |
| 选择出库 | 选择出库（需先勾选行） |

## 列表字段

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 序号 | 复选框+数值 | 行选择+序号 |
| 处理状态 | 文本 | 处理状态 |
| 发运日期 | 日期 | 发运日期 |
| 发货工厂 | 文本 | 发货工厂（如三水基地、咸宁基地、湖北奥瑞金、广州） |
| 目的地 | 文本 | 目的地（如东莞、柳州、武汉等） |
| 线路 | 文本 | 线路编号（如ZZ0128、ZZ0132等） |
| 商品编码 | 文本 | 商品编码 |
| 商品名称 | 文本 | 商品名称 |
| 数量 | 数值 | 发运数量 |
| 派车数 | 数值 | 派车数量 |
| 已开单数 | 数值 | 已开单数量 |
| 承运商 | 文本 | 承运商名称（如数据在线、睿通、联悦） |
| 运输方式 | 文本 | 运输方式（如汽运） |
| 备注 | 文本 | 备注信息 |

## 处理状态枚举

| 状态值 | 说明 |
|--------|------|
| 待处理 | 待处理的出库计划 |
| 处理中 | 正在处理的出库计划 |
| 已处理 | 已处理的出库计划 |
