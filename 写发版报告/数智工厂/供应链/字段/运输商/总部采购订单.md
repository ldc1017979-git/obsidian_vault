## 列表页

### 页面概述

总部采购订单页面展示运输商视角的采购订单列表，支持列表筛选和查看详情操作。

### 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 列表筛选 | 打开列表筛选面板 |
| 详情 | 查看采购订单详情 |

## 详情页（点击「详情」按钮进入）

### 页面结构

详情页面通过 **8 个外层 Tab** 展示不同内容，各 Tab 的主要信息如下：

| Tab 名称 | 内容形式 | 说明 |
|---------|---------|------|
| 总部采购订单-详情 | 表单 + 按钮 | 核心详情页：展示采购订单基础信息，含「采购物料明细」按钮 |
| 原料采购订单详情 | 表单 | 展示原料采购订单基础信息 |
| 总部采购订单 | 表格 | 展示关联总部采购订单列表 |
| 要货计划 | 表格 | 展示关联要货计划列表 |
| 要货计划详情 | 表单 + 表格 | 展示要货计划基础信息及物料明细 |
| 码源申请记录 | 表格 | 展示码源申请记录明细 |
| 业务单据串联 | 表格 | 展示关联业务单据列表 |
| 单据内容 | 表格 | 展示物料明细信息 |
