# 角色管理

> 模块路径: 系统设置 > 角色管理
> 页面URL: https://txcscm.y1b.cn/#/setUp/role

## 页面概述

角色管理页面展示系统角色配置列表，记录各角色的名称、所属组织、成员数、授权项等信息，支持角色的增删改查及启用/禁用。

## 筛选条件

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| **角色名称** | **文本框** | **原文档缺失** - 按角色名称筛选 |
| **所属组织** | **下拉** | **原文档缺失** - 按所属组织筛选 |
| **状态** | **下拉** | **原文档缺失** - 按状态筛选 |
| **创建时间** | **日期选择** | **原文档缺失** - 按创建时间筛选 |

## 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 新增 | 新增角色 |
| 列表筛选 | 列表筛选 |
| **编辑** | **原文档缺失** - 编辑角色（行内操作） |
| **删除** | **原文档缺失** - 删除角色（行内操作） |
