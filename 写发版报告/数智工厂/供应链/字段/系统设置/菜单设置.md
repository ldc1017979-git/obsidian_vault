# 菜单设置

> 模块路径: 系统设置 > 菜单设置
> 页面URL: https://txcscm.y1b.cn/#/setUp/menu

## 页面概述

菜单设置页面展示系统菜单配置列表，以树状结构展示菜单层级关系，支持菜单的增删改查及排序调整。

## 筛选条件

**无列表筛选字段**

## 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 新增 | 新增菜单 |
| 全部展开 | 展开所有菜单层级 |
| 收起全部 | 收起所有菜单层级 |
| **新增** | **原文档缺失** - 新增子菜单（行内操作） |
| **编辑** | **原文档缺失** - 编辑菜单（行内操作） |
| **删除** | **原文档缺失** - 删除菜单（行内操作） |

## 列表字段

| 字段名称 | 字段类型 | 说明 | 示例值 |
|---------|---------|------|--------|
| 序号 | 数值 | 行序号 | 1 |
| 操作 | 按钮组 | 新增/编辑/删除 | 新增、编辑、删除 |
| 菜单名称 | 文本 | 菜单名称 | 系统设置 |
| 图标 | 文本 | 菜单图标 | - |
| 是否菜单 | 文本 | 是否为菜单（是/否） | 是 |
| 是否展示 | 文本 | 是否展示（显示/隐藏） | 显示 |
| 菜单路径 | 文本 | 菜单路径 | /setUp |
| 权限路径 | 文本 | 权限路径 | -- |
| 排序 | 数值 | 排序值（可调整） | - |
| 添加时间 | 日期时间 | 菜单添加时间 | 2024-07-08 17:16:16 |

| **菜单图标** | **文本框** | **原文档缺失** - 输入菜单图标 |
| **菜单路径** | **文本框** | **原文档缺失** - 输入菜单路径 |
| **权限路径** | **文本框** | **原文档缺失** - 输入权限路径 |
| **本地路径** | **文本框** | **原文档缺失** - 输入本地路径 |
| **是否展示** | **下拉** | **原文档缺失** - 选择是否展示 |
