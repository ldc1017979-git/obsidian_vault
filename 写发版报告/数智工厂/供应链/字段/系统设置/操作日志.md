# 操作日志

> 模块路径: 系统设置 > 操作日志
> 页面URL: https://txcscm.y1b.cn/#/setUp/operationLog

## 页面概述

操作日志页面展示系统用户操作记录列表，记录用户的登入/登出操作、操作时间、IP地址等信息，支持多条件筛选查询。

## 筛选条件

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 操作日期 | 日期范围 | 开始时间至结束时间 |
| 操作用户 | 文本框 | 操作用户姓名 |
| 操作账号 | 文本框 | 操作账号（手机号） |
| 所属角色 | 下拉 | 所属角色筛选 |
| 所属组织 | 下拉 | 所属组织筛选 |
| 操作类型 | 下拉 | 操作类型筛选 |

## 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 搜索 | 按条件搜索 |
| 重置 | 重置筛选条件 |
| 合并 | 合并显示 |

## 列表字段

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 序号 | 数值 | 行序号 |
| 操作用户 | 文本 | 操作用户姓名（如TEST-管理员） |
| 操作账号 | 文本 | 操作账号（手机号） |
| 所属角色 | 文本 | 所属角色名称（如供应商管理员、库管员等） |
| 所属组织 | 文本 | 所属组织名称 |
| 操作用户 | 文本 | 操作用户（同第一列） |
| 操作类型 | 文本 | 操作类型（登入/退出） |
| 操作功能 | 文本 | 操作功能描述（如登入成功、主动退出） |
| 操作时间 | 日期时间 | 操作时间 |
| 操作地点 | 文本 | 操作地点（如广东省.深圳市.龙岗区） |
| IP地点 | 文本 | IP地址 |
| 操作类型 | 文本 | 操作类型（登入/退出） |
| 浏览器信息 | 文本 | 浏览器版本（如Chrome 149.0.0.0） |
| 登录时长 | 文本 | 登录时长（如24分18秒、1时27分1秒） |
