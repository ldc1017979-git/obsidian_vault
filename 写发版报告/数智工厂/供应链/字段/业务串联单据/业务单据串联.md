# 业务单据串联

## 概述

业务单据串联是供应链系统的核心入口页面，提供所有采购订单的统一视图和跨模块业务流程串联管理。

## 列表页字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 序号 | 整数 | 行号 |
| 操作 | 按钮 | 操作按钮（详情） |
| 采购订单号 | 文本 | 内部采购订单编号 |
| SAP采购订单号 | 文本 | SAP系统对接的采购订单编号 |
| 采购订单状态 | 枚举 | 待审批/供应商备货中/供应商生产中/供应商发货中/基地入库中/已通过/已关闭 |
| 物料信息 | 弹窗 | 点击查看物料明细（N项） |
| 订单总数量 | 数值 | 订单总数量 |
| 供应商 | 文本 | 供应商名称 |
| 运输商 | 文本 | 运输商名称 |
| 采购方 | 文本 | 采购方公司名称 |
| 收货工厂 | 文本 | 收货工厂名称 |
| 订单创建日期 | 日期 | 订单创建时间 |

## 操作按钮

| 按钮名称 | 功能说明 |
|----------|----------|
| 列表筛选 | 展开/收起筛选条件 |
| 详情 | 查看采购订单详情 |
| 新建订单 | 创建新采购订单 |
| 导入订单 | 批量导入采购订单 |
| 导出订单 | 导出采购订单列表 |
| 打印单据 | 打印采购订单单据 |
| 变更 | 变更订单内容 |
| 作废 | 作废订单 |
| 审批 | 审批订单 |
| 驳回 | 驳回订单 |
| 搜索 | 按条件搜索 |
| 重置 | 重置筛选条件 |

## 物料信息弹窗

点击"N项"按钮弹出物料信息弹窗，包含以下字段：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 物料名称 | 文本 | 原材料/成品名称 |
| 物料编码 | 文本 | 内部物料编码 |
| SAP物料编码 | 文本 | SAP系统物料编码 |
| 采购订单量 | 数值 | 该物料的采购数量 |
| 超限比例(%) | 数值 | 允许的超额采购比例 |
| 最大订单量 | 数值 | 最大可采购数量 |
| 采购订单有效期起 | 日期 | 订单有效期开始日期 |
| 采购订单有效期止 | 日期 | 订单有效期结束日期 |
| 退货数量 | 数值 | 退货数量 |
| 线上促销 | 枚举 | 是/否 |
| 备注 | 文本 | 备注信息 |
| 采购单位 | 文本 | 采购计量单位 |
| 到货规格 | 文本 | 到货规格说明 |

## 筛选条件

| 筛选字段 | 类型 | 说明 |
|----------|------|------|
| 日期范围 | 日期选择器 | 订单创建日期范围（今天/昨天/近7天/近15天/近30天/本月/上月/本季/上季/本年） |
| 采购订单号 | 文本输入 | 按订单号搜索 |
| SAP采购订单号 | 文本输入 | 按SAP订单号搜索 |
| 采购订单状态 | 下拉选择 | 按状态筛选 |
| 供应商 | 下拉选择 | 按供应商筛选 |
| 采购方 | 下拉选择 | 按采购方筛选 |
| 收货工厂 | 下拉选择 | 按收货工厂筛选 |

## 采购订单状态枚举

| 状态值 | 说明 |
|--------|------|
| 待审批 | 订单创建后等待审批 |
| 供应商备货中 | 审批通过，供应商正在备货 |
| 供应商生产中 | 供应商正在生产 |
| 供应商发货中 | 供应商已发货，在途 |
| 基地入库中 | 货物到达基地，正在入库 |
| 已通过 | 订单全部完成 |
| 已关闭 | 订单被关闭或作废 |
