# 码源申请记录
> 模块路径: 服务商 > 码源申请记录
> 页面URL: https://txcscm.y1b.cn/#/serviceProvider/srvCodeSourceApplication

## 页面概述

码源申请记录页面展示服务商视角的码源申请列表，支持提审、修改码包操作。

## 操作按钮

| 按钮名称 | 说明   |
| ---- | ---- |
| 列表筛选 | 列表筛选 |

## 列表字段

| 字段名称     | 字段类型 | 说明                             |
| -------- | ---- | ------------------------------ |
| 序号       | 数值   | 行序号                            |
| 操作       | 按钮组  | 提审/修改码包                        |
| 活动码源单号   | 文本   | 活动码源编号（如BH260608-005-01-MY001） |
| 单据状态     | 文本   | 单据状态                           |
| 物料名称     | 文本   | 物料名称（如顶盖/206/2026扫码1元乐享-广西）    |
| 样品图示     | 文本   | 样品图示                           |
| 生产厂商     | 文本   | 生产厂商名称                         |
| 生产数量     | 数值   | 生产数量                           |
| 码源处理状态   | 文本   | 码源处理状态                         |
| 申请说明     | 文本   | 申请说明                           |
| 活动码源数量   | 数值   | 活动码源数量                         |
| 活动码包     | 链接   | 下载码包链接                         |
| 下载次数     | 数值   | 下载次数                           |
| 生产计划单号   | 文本   | 关联生产计划单号（如BH260608-005-01）     |
| 生产状态     | 文本   | 生产状态                           |
| 物料编码     | 文本   | 系统物料编码（如GC000074）              |
| SAP物料编码  | 文本   | SAP系统物料编码                      |
| 线上促销     | 文本   | 是否线上促销（是/否）                    |
| 计划完成时间   | 日期   | 计划完成时间                         |
| 已生产数量    | 数值   | 已生产数量                          |
| 未生产数量    | 数值   | 未生产数量                          |
| 包装规格     | 文本   | 包装规格                           |
| 已打印张数    | 数值   | 已打印张数                          |
| 已发货数量    | 数值   | 已发货数量                          |
| 未发货数量    | 数值   | 未发货数量                          |
| 要货计划单号   | 文本   | 关联要货计划单号                       |
| 采购订单号    | 文本   | 关联采购订单号                        |
| SAP采购订单号 | 文本   | SAP采购订单号                       |
| 客户名称     | 文本   | 客户名称                           |
| 客户工厂     | 文本   | 客户工厂                           |
