## 列表页

### 页面概述

要货计划页面展示服务商视角的要货计划列表，支持列表筛选和查看详情操作。

### 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 列表筛选 | 打开列表筛选面板 |
| 详情 | 查看要货计划详情 |

## 详情页（点击「详情」按钮进入）

### 页面结构

详情页面通过 **8 个外层 Tab** 展示不同内容，各 Tab 的主要信息如下：

| Tab 名称   | 内容形式    | 说明                            |
| -------- | ------- | ----------------------------- |
| 要货计划详情   | 表单 + 表格 | 核心详情页：展示要货计划基础信息（表单）及物料明细（表格） |

| 总部采购订单   | 表格      | 展示关联总部采购订单列表                  |
