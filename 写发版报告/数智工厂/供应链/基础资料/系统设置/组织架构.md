## 2. 筛选条件

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 组织名称 | 文本输入框 | 按组织名称搜索 |
| 组织类型 | 下拉选择框 | 按组织类型筛选 |
| 审批状态 | 下拉选择框 | 按审批状态筛选 |
| 搜索 | 按钮 | 执行搜索 |
| 重置 | 按钮 | 清空筛选条件 |
| 新增组织 | 按钮 | 打开新增组织表单 |

| 字段名 | 类型 | 是否必填 | 说明 |

| 组织名称 | 文本输入框 | 是 | 输入组织名称 |
