# 培训计划字段表

## 一、业务概述

培训计划模块用于管理企业培训活动的规划和执行。培训计划与培训记录是关联的：
- **计划内培训记录**：需要关联培训计划
- **计划外培训记录**：不需要关联培训计划

培训计划执行流程：待执行 → 执行中（培训记录：未开始→进行中→评估中）→ 已完成/已终止

## 二、业务流程图

```mermaid
sequenceDiagram
    participant Creator as 创建人
    participant System as 系统
    participant Trainer as 培训人
    participant Trainee as 受训人

    Creator->>System: 创建培训计划
    System->>System: 生成计划编号
    Creator->>System: 填写培训信息（主题、类别、部门、方式等）
    Creator->>System: 设置时间安排和提醒
    Creator->>System: 上传附件（可选）
    Creator->>System: 保存计划（状态：待执行）
    
    alt 创建培训记录（计划内）
        Trainer->>System: 在培训计划上创建培训记录
        System->>System: 关联培训计划编号
        Trainer->>System: 开始培训（培训记录状态：进行中）
        Trainee->>System: 签到扫码
        Trainer->>System: 结束培训（培训记录状态：评估中）
        Trainer->>System: 完成统计
        Trainer->>System: 完成评估
        System->>System: 更新培训计划状态为已完成
    end
    
    alt 创建培训记录（计划外）
        Trainer->>System: 创建独立培训记录
        System->>System: 无需关联培训计划
        Trainer->>System: 执行培训流程
    end
    
    alt 终止培训计划
        Creator->>System: 终止计划
        System->>System: 更新状态为已终止
    end
```

## 六、业务规则

### R01 - 数据完整性规则
- 培训主题、培训类别、培训部门、培训方式、培训人、时间安排为必填字段
- 创建人由系统自动带出当前登录用户

### R02 - 计划编号生成规则
- 计划编号格式：PXJH + 年份后两位 + 月份 + 日期 + 三位流水号
- 示例：PXJH260420002（2026年4月20日第2单）

### R03 - 培训计划与培训记录关联规则
- **计划内培训记录**：必须关联培训计划编号
- **计划外培训记录**：不需要关联培训计划
- 在培训计划详情页可直接创建关联的培训记录

### R04 - 状态流转规则
| 当前状态 | 操作 | 目标状态 | 说明 |
| :--- | :--- | :--- | :--- |
| 待执行 | 创建培训记录并开始 | 执行中 | 培训记录状态变为进行中 |
| 执行中 | 结束培训 | 执行中 | 培训记录状态变为评估中 |
| 执行中 | 完成统计+完成评估 | 已完成 | 必须两项都确认才能完成 |
| 待执行/执行中 | 终止计划 | 已终止 | 终止后不可恢复 |

### R05 - 培训记录操作规则
- **未开始**：可进行详情、编辑、开始培训、终止、删除操作
- **进行中**：可进行详情、编辑、签到扫码、结束培训操作
- **评估中**：可进行详情、完结统计、完成评估操作，两项都完成后状态变为已完成
- **已完成/已终止**：仅可查看详情

### R06 - 计划提醒规则
- 支持多选提醒时间：截止前30天、截止前15天、截止前7天
- 可选择多个提醒接收人

### R07 - 附件上传规则
- 支持多种格式：jpg、png、gif、jpeg、pdf、zip、rar、docx、doc、xlsx、ppt、pptx、pptm、xls
- 单文件大小限制：≤100M
