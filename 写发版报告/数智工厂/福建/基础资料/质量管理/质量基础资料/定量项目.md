## 1. 页面概述

- **页面路径**: 质量管理 → 基础信息管理 → 定量项目
- **页面URL**: `https://fjmms.y1b.cn:8424/#/quality-manage/index2/quantify`
- **页面功能**: 管理定量检验项目，包括项目的新增、编辑、删除和查询
- **数据总量**: 共13条记录

![列表页初始状态](截图/定量项目-列表页-初始状态.png)

## 2. 列表页功能

### 2.1 搜索区域

搜索区域包含以下筛选条件：

| 字段 | 类型 | 说明 |
|------|------|------|
| 项目名称 | 文本输入框 | 支持模糊搜索 |
| 可用状态 | 下拉选择框 | 选项：启用/停用 |
| 重置 | 按钮 | 清空搜索条件 |
| 搜索 | 按钮 | 执行搜索 |

| 选项 | 说明 |

## 4. 编辑定量项目

点击列表中的"编辑"按钮打开编辑对话框，标题为"编辑定量项目"。

编辑表单与新增表单字段一致，区别如下：
- **产品大类**：不可编辑（disabled状态），显示已选中的产品大类标签
- **项目名称**：可编辑，预填已有值
- **检验依据字段**：可编辑，预填已有值
- **检测仪器**：可编辑，预填已有值
- **可用状态**：可切换，预填已有状态

**编辑示例1 - 诱惑红（战马）**:

| 字段 | 值 |
|------|-----|
| 产品大类 | ND2（战马）- 不可编辑 |

| 普通型检验依据 | 未选择 |
| 强化型检验依据 | 未选择 |
| 战马罐装检验依据 | 未选择 |
| 检测仪器 | 电子天平 |
| 可用状态 | 启用 |
