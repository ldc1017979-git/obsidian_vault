## 1. 页面概述

| 项目 | 内容 |
|------|------|
| 页面名称 | 电子天平电子秤目录 |
| 所属模块 | 质量管理 > 基础信息管理 |
| 页面URL | `https://fjmms.y1b.cn:8424/#/quality-manage/index2/index195/electronic-scale` |
| 数据总量 | 2条记录 |
| 分页信息 | 每页10条，共1页 |
| 主要功能 | 电子天平/电子秤的目录管理，包含排序编号、使用地点、名称、仪器编号、型号、出厂编号、规格（Max/e/d）、砝码重量等信息 |

## 2. 页面导航路径

1. 登录系统进入工作台（Dashboard）
2. 点击左侧菜单「质量管理」展开子菜单
3. 点击「基础信息管理」展开子菜单
4. 点击「电子天平电子秤目录」进入页面

## 4. 列表页功能

### 表格列定义

| 列名 | 说明 |
|------|------|
| 排序编号 | 记录的排序序号 |
| 使用地点 | 仪器的使用地点（如：化验室） |
| 名称 | 仪器名称（如：分析天平、电子天平） |
| 仪器编号 | 仪器的唯一编号 |
| 型号 | 仪器的型号规格（如：ME204E、ME2002） |
| 出厂编号 | 仪器出厂时的编号 |
| 规格 | 包含Max、e、d三个子列 |
| Max | 最大称量值及单位 |
| e | 检定分度值及单位 |
| d | 实际分度值及单位 |
| 砝码重量 | 校准砝码的重量及单位 |
| 创建人 | 创建该记录的用户 |
| 创建时间 | 记录创建的时间 |
| 更新人 | 最后更新该记录的用户 |
| 操作 | 编辑、删除按钮 |

### 操作列按钮

| 按钮 | 功能说明 |
|------|----------|
| 编辑 | 打开编辑对话框，表单预填充当前数据 |
| 删除 | 弹出确认对话框，确认后删除该条记录 |

### 分页功能

| 功能 | 说明 |
|------|------|
| 每页条数 | 可选10/20/40/50条/页 |
| 页码导航 | 支持点击页码跳转，当前共1页 |
| 上一页/下一页 | 翻页按钮 |
| 前往 | 输入页码直接跳转 |

## 5. 新增电子天平电子秤表单

点击「新建」按钮后弹出"新增"对话框。

### 表单字段

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| 排序号 | 数字输入框 | 是（*） | 记录的排序序号 |
| 使用地点 | 文本输入框 | 是（*） | 仪器的使用地点 |
| 名称 | 下拉选择框 | 是（*） | 选择仪器名称，选项来自仪器管理中可用状态为"正常"的仪器列表 |
| 仪器编号 | 文本输入框 | 否 | 选择名称后自动填充，不可编辑 |

## 9. API数据接口

### 列表接口

| 项目 | 内容 |
|------|------|
| 接口地址 | `https://fjmms.y1b.cn:8424/qlty/Scaledevice/getScaledeviceList` |
| 请求方式 | POST |
| Content-Type | application/json;charset=UTF-8 |
| 认证方式 | Authorization请求头 |

#### 请求参数

```json
{
  "page": 1,
  "size": 10,
  "name": null,
  "inst_type_no": null
}
```

| 参数 | 类型 | 说明 |
|------|------|------|
| page | Integer | 页码，从1开始 |
| size | Integer | 每页条数 |
| name | String | 名称筛选，null表示不筛选 |
| inst_type_no | String | 型号筛选，null表示不筛选 |

#### 响应数据结构

```json
{
  "code": "1",
  "data": {
    "total": 2,
    "per_page": "10",
    "current_page": 1,
    "last_page": 1,
    "data": [...]
  },
  "msg": "success",
  "time": 0.02637004852294922
}
```

#### 数据字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer | 记录唯一标识 |
| sort | Integer | 排序编号 |
| use_place_id | String | 使用地点ID |
| use_place | String | 使用地点名称 |
| inst_id | Integer | 关联仪器ID |
| name | String | 仪器名称 |
| productserial_no | String | 出厂编号 |
| inst_type_no | String | 仪器型号 |
| inst_code | String | 仪器编号（可为null） |
| max_val | String | Max值 |
| max_unit | String | Max单位 |
| e_val | String | e值 |
| e_unit | String | e单位 |
| d_val | String | d值 |
| d_unit | String | d单位 |
| weight_val | String | 砝码重量值 |
| weight_unit | String | 砝码重量单位 |
| create_time | String | 创建时间 |
| update_time | String | 更新时间 |
| ct_uid | Integer | 创建人ID |
| ct_name | String | 创建人姓名 |
| up_uid | Integer | 更新人ID |
| up_name | String | 更新人姓名 |

### 仪器映射接口

| 项目 | 内容 |
|------|------|
| 接口地址 | `https://fjmms.y1b.cn:8424/qlty/Post/getInstMap` |
| 请求方式 | POST |
| Content-Type | application/json;charset=UTF-8 |

#### 请求参数

```json
{
  "is_open": 1
}
```

| 参数 | 类型 | 说明 |
|------|------|------|
| is_open | Integer | 筛选可用状态（1=正常），用于获取名称下拉框选项 |
