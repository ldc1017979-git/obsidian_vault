## 1. 页面概述

配方BOM清单页面用于管理各产品线的配方物料BOM（Bill of Materials）标准信息，包括物料条码、编号、名称、分类、计量单位、标准值、标准范围、称重单位、称重保留小数、单据类型和单据序号等关键信息。

页面支持按产品线切换查看，提供新增、编辑、删除等操作功能。

## 5. 新增标准对话框

点击"新增"按钮，弹出"新增标准"对话框，包含以下表单字段：

### 物料信息区域

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 条码 | 下拉选择 | 是（*） | 选择物料条码，下拉选项包含所有物料分类 |
| 名称 | 文本输入 | 是（*） | 自动填充，根据条码选择自动带出 |
| 条码 | 只读文本 | 否 | 自动显示物料条码 |
| 规格型号 | 只读文本 | 否 | 自动显示规格型号 |
| 分类 | 只读文本 | 否 | 自动显示分类 |
| 计量单位 | 只读文本 | 否 | 自动显示计量单位 |
| 品牌 | 只读文本 | 否 | 自动显示品牌 |
| 保留小数 | 只读数字 | 否 | 自动显示保留小数位数 |

### 配方信息区域

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 单位 | 下拉选择 | 是（*） | 称重单位选择（g、kg等） |
| 保留小数 | 数字输入 | 是（*） | 称重保留小数位数（0-4） |
| 标准值 | 数字输入 | 是（*） | 配方标准值 |
| 标准范围 | 数字区间输入 | 否 | 标准值允许范围（最小值-最大值） |
| 单据类型 | 单选按钮 | 否 | 物料箱 / 香精桶，可取消选择 |
| 单据序号 | 文本输入 | 否 | 单据排序序号 |

- **设备类**：称料系统、光检机、称重机、轴承类、空压机、检测设备、制水系统、密封类、通用管材管件、通用机械备件、冷却机、冷却塔、链道系统、注氮机、污水系统、气动配件、激光打码机、通用电器件、蒸汽间、喷码机、码垛机、封箱机、拆包机、泵类、工具、封口机、配料系统、灌装机、自动上盖机、包装机、热缩机

## 6. 编辑标准对话框

点击列表中某条记录的"编辑"按钮，弹出"编辑标准"对话框。表单结构与新增标准对话框相同，字段会预填充当前记录的数据：

- **物料信息**：条码（下拉选择）、名称（文本输入）、条码（只读）、规格型号（只读）、分类（只读）、计量单位（只读）、品牌（只读）、保留小数（只读）
- **配方信息**：单位（下拉选择）、保留小数（数字输入，0-4）、标准值（数字输入）、标准范围（数字区间）、单据类型（单选：物料箱/香精桶）、单据序号（文本输入）

![编辑标准对话框](截图/配方BOM清单-编辑标准对话框.png)

## 7. 删除确认对话框
