## 1. 页面概述

配方货品管理页面用于管理配方类货品的基础信息，包括货品的条码、名称、规格型号、分类、计量单位、品牌、自定义类别、保质期、默认价格、状态等。页面支持新建、编辑、删除、导入、打印标签等操作。

**页面URL**：`https://fjmms.y1b.cn:8424/#/product/production-baseinfo/index156/recipe-goods`

**数据总量**：共 17 条记录，分 2 页显示（每页 10 条）

## 5. 新建货品对话框

### 5.1 对话框概述

新建货品采用**表格式批量录入**方式，支持一次添加多行货品记录。

**对话框标题**：新建货品

**功能按钮**：
- **检查重复条码**：检查已输入的条码是否存在重复
- **添加**：添加一行新的空白录入行
- **取消**：关闭对话框
- **保存**：保存所有录入的货品数据

**提示信息**：
- "注：连接扫描枪后，在此页面扫描商品条码可自动添加一行"

### 5.2 录入字段

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| 序号 | 自动生成 | -- | 行序号，自动递增 |
| 条码 | 文本输入 | 否 | 空白时系统自动生成 |
| 名称 | 下拉搜索 | 是 | 货品名称，必填项（标*） |
| 品牌 | 文本输入 | 否 | 货品品牌 |
| 自定义类别 | 文本输入 | 否 | 用户自定义类别 |
| 规格型号 | 文本输入 | 否 | 货品规格型号 |
| 计量单位 | 下拉搜索 | 是 | 计量单位，必填项（标*） |
| 分类 | 下拉搜索 | 是 | 货品分类，必填项（标*） |
| 默认价格 | 文本输入 | 否 | 货品默认价格 |
| 保质期(天) | 文本输入 | 否 | 保质期天数 |
| 保质期预警(天) | 文本输入 | 否 | 保质期预警天数 |
| 保留小数 | 数字步进器 | 否 | 保留小数位数（0-4），默认0 |
| 税率(%) | 文本输入 | 否 | 税率百分比，默认13 |
| 操作 | 删除按钮 | -- | 删除当前行 |
