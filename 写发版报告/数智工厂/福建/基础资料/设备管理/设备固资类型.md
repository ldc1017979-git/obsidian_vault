## 1. 页面概述

设备固资类型页面用于管理设备固定资产的类型分类信息，采用树形结构展示资产类型的层级关系。页面支持搜索、新建资产类型、全部展开/折叠等操作功能。

当前页面数据状态：已加载数据，生产设备下共25个节点（含一线6个岗位、二线6个岗位）。

![设备固资类型-列表页](截图/设备固资类型-全部展开.png)

## 5. 新建资产类型对话框

点击"新建资产类型"按钮，弹出"新增设备固资类型"对话框，包含以下表单字段：

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 资产类型名称 | 文本输入 | 是（*） | 输入资产类型名称 |
| 排序 | 数字输入 | 否 | 输入排序值，默认为0 |
| 状态 | 单选按钮 | 否 | 选项：启用（默认选中）、停用 |
| 备注 | 文本输入 | 否 | 输入补充说明 |

### 状态选项

| 选项 | 说明 |
|------|------|
| 启用 | 资产类型处于启用状态（默认） |
| 停用 | 资产类型处于停用状态 |

对话框按钮：取消 / 确定

| 新增表单字段 | 资产类型名称（必填）、排序（数字，默认0）、状态（启用/停用）、备注 |
| 状态选项 | 启用（默认）、停用 |
| 表格列 | 资产类型名称、排序、状态、备注、创建人、创建时间、操作 |
