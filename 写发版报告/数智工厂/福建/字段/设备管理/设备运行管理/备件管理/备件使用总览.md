# 备件使用总览

## 页面概述

- **功能说明**：管理备件使用总览，展示备件的总数量、已使用数量和可用数量，支持按备件名称、条码、规格型号等条件筛选，支持查看明细
- **URL**：`https://fjmms.y1b.cn:8424/#/device-manage/equipment-operate/spare-manage/use-overview`

## 筛选条件

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 备件名称 | combobox | 空 | 可选 | 下拉选择备件名称 |
| 2 | 条码 | textbox | 空 | 可选 | 输入条码搜索 |
| 3 | 规格型号 | textbox | 空 | 可选 | 输入规格型号搜索 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件搜索 |

## 列表字段

| 序号 | 字段名称 | 字段类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 备件名称 | 文本展示 | - | - | 如"注氮机传感器线"、"轴承1" |
| 2 | 条码 | 文本展示 | - | - | 如"40044798"、"40040714" |
| 3 | 规格型号 | 文本展示 | - | - | 如"940.244016"、"GB276-94 6202-2z" |
| 4 | 品牌 | 文本展示 | - | - | 如"SKF"、"FESTO"、"西门子"，无则显示"--" |
| 5 | 单位 | 文本展示 | - | - | 如"台"、"个"、"根"、"盘" |
| 6 | 总数量 | 文本展示 | - | - | 如"2"、"1" |
| 7 | 已使用数量 | 文本展示 | - | - | 如"2"、"1" |
| 8 | 可用数量 | 文本展示 | - | - | 如"0" |
| 9 | 操作 | 按钮 | - | - | 查看明细 |
