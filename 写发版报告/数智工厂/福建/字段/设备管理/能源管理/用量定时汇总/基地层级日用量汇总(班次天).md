# 基地层级日用量汇总(班次/天)

## 页面概述

- **功能说明**：按基地层级结构汇总各能源类型的日用量数据，支持按统计日期、统计周期筛选，支持手动触发和导出
- **URL**：`https://fjmms.y1b.cn:8424/#/device-manage/energy-manage/regular-summary/daily-usage-summary`

## 截图

![基地层级日用量汇总主页面](能源管理_基地层级日用量汇总_主页面_1.png)

## 筛选条件

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 统计日期 | textbox | 空 | 可选 | 日期范围选择（开始日期-结束日期） |
| 2 | 统计周期 | combobox | 空 | 可选 | 下拉选择统计周期（班次/每日） |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件搜索 |
| 3 | 手动触发 | 手动触发汇总任务 |
| 4 | 导出数据 | 导出汇总数据 |

## 列表字段

| 序号 | 字段名称 | 字段类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 统计日期 | 文本展示 | - | - | 汇总统计日期 |
| 2 | 统计周期 | 文本展示 | - | - | 如"班次"、"每日" |
| 3 | 班次 | 文本展示 | - | - | 如"夜"、"白"、"中"，每日时为"--" |
| 4 | 水用量(t) | 文本展示 | - | - | 水用量（吨） |
| 5 | 电用量(kwh) | 文本展示 | - | - | 电用量（千瓦时） |
| 6 | 蒸汽用量(t) | 文本展示 | - | - | 蒸汽用量（吨） |
| 7 | 燃气用量(m³) | 文本展示 | - | - | 燃气用量（立方米） |
