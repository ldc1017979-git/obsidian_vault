## 搜索条件

| 序号 | 字段名称 | 字段类型 | 是否必填 | 默认值 | 说明 |
|------|----------|----------|----------|--------|------|
| 1 | 任务名称 | 文本输入框 | 否 | - | placeholder: "任务名称" |
| 2 | 任务状态 | 下拉选择框 | 否 | - | 可选值：未开始、进行中、已验收、已终止 |
| 3 | 任务类型 | 下拉选择框 | 否 | - | 可选值：公司级年度重点工作、部门级年度重点工作 |
| 4 | 问题分类 | 下拉选择框 | 否 | - | 动态选项 |
| 5 | 截止时间 | 日期范围选择器 | 否 | - | 开始日期 - 结束日期 |
| 6 | 来源渠道 | 下拉选择框 | 否 | - | 可选值：巡检、设备、生产、质量、安全、其他 |
| 7 | 任务人员 | 复合选择器 | 否 | - | 包含"人员类型"下拉 + "任务人员"搜索下拉 |
| 8 | 逾期状态 | 单选框组 | 否 | 全部 | 可选值：全部(默认选中)、未逾期、已逾期 |

### 搜索按钮

| 按钮名称 | 功能说明 |
|----------|----------|
| 搜索 | 根据条件搜索任务列表 |
| 重置 | 清空所有搜索条件 |

## 操作按钮

| 序号 | 按钮名称 | 功能说明 | 截图 |
|------|----------|----------|------|
| 1 | 发布任务 | 下拉按钮，可选择发布常规任务或周期任务 | ![发布任务](../截图/任务管理_发布常规任务弹窗.png) |
| 2 | 导入任务 | 下拉按钮，支持导入任务 | - |
| 3 | 导出数据 | 导出任务数据 | - |

## 列表字段

| 序号 | 列名 | 说明 |
|------|------|------|
| 1 | 序号 | 行序号 |
| 2 | 周数 | 任务所属周数 |
| 3 | 任务编号 | 系统自动生成的任务编号 |
| 4 | 任务名称 | 任务的名称 |
| 5 | 任务状态 | 未开始/进行中/已验收/已终止 |
| 6 | 任务类型 | 任务所属类型 |
| 7 | 开始时间 | 任务开始时间 |
| 8 | 截止时间 | 任务截止时间 |
| 9 | 验收人 | 负责验收的人员 |
| 10 | 执行人 | 负责执行的人员 |
| 11 | 任务描述 | 任务的详细描述 |
| 12 | 验收时间 | 验收完成时间 |
| 13 | 解决措施 | 问题的解决措施 |
| 14 | 耗时 | 任务执行耗时 |
| 15 | 来源渠道 | 任务来源渠道 |
| 16 | 问题分类 | 问题所属分类 |
| 17 | 抄送 | 抄送人员 |
| 18 | 创建时间 | 任务创建时间 |
| 19 | 任务操作 | 任务操作记录 |
| 20 | 操作 | 编辑、删除等操作 |

## 分页控件

| 控件 | 说明 |
|------|------|
| 每页条数 | 下拉选择，默认10条/页 |
| 上一页/下一页 | 翻页按钮 |
| 页码跳转 | 输入页码直接跳转 |
