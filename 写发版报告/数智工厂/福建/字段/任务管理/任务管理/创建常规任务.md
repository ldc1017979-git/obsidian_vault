# 创建常规任务

> 入口：任务管理列表页 → 发布任务 → 常规任务
> 截图：![创建常规任务弹窗](../截图/任务管理_发布常规任务弹窗.png)

## 表单字段

| 序号 | 字段名称 | 字段类型 | 是否必填 | 默认值 | 约束条件 | 说明 |
|------|----------|----------|----------|--------|----------|------|
| 1 | 任务名称 | 文本输入框 | 是 | - | - | placeholder: "请输入任务名称" |
| 2 | 任务类型 | 下拉选择框 | 是 | - | - | 可选值：公司级年度重点工作、部门级年度重点工作 |
| 3 | 来源渠道 | 下拉选择框 | 是 | - | - | 可选值：巡检、设备、生产、质量、安全、其他 |
| 4 | 执行人 | 人员选择器 | 是 | - | - | 点击打开人员选择弹窗，支持搜索 |
| 5 | 截止时间 | 日期时间选择器 | 是 | - | - | 选择日期和时间 |
| 6 | 验收人 | 人员选择器 | 是 | - | - | 点击打开人员选择弹窗，支持搜索 |
| 7 | 抄送人 | 人员选择器 | 否 | - | - | 点击打开人员选择弹窗 |
| 8 | 任务描述 | 多行文本框 | 否 | - | - | 描述任务详情 |
| 9 | 附件上传 | 文件上传 | 否 | - | - | 支持上传附件 |

## 下拉选项详情

### 任务类型下拉选项

| 序号 | 选项值 |
|------|--------|
| 1 | 公司级年度重点工作 |
| 2 | 部门级年度重点工作 |

### 来源渠道下拉选项

| 序号 | 选项值 |
|------|--------|
| 1 | 巡检 |
| 2 | 设备 |
| 3 | 生产 |
| 4 | 质量 |
| 5 | 安全 |
| 6 | 其他 |

## 关联弹窗

### 执行人选择弹窗

> 截图：![执行人选择弹窗](../截图/任务管理_创建任务_执行人弹窗.png)

| 序号 | 字段名称 | 字段类型 | 说明 |
|------|----------|----------|------|
| 1 | 搜索框 | 文本输入框 | 支持按姓名搜索人员 |
| 2 | 部门树 | 树形控件 | 按部门层级选择人员 |
| 3 | 人员列表 | 列表 | 显示可选人员，支持多选 |

### 抄送人选择弹窗

> 截图：![抄送人选择弹窗](../截图/任务管理_创建任务_抄送人弹窗.png)

| 序号 | 字段名称 | 字段类型 | 说明 |
|------|----------|----------|------|
| 1 | 搜索框 | 文本输入框 | 支持按姓名搜索人员 |
| 2 | 部门树 | 树形控件 | 按部门层级选择人员 |
| 3 | 人员列表 | 列表 | 显示可选人员，支持多选 |

### 任务提醒设置弹窗

> 截图：![任务提醒设置弹窗](../截图/任务管理_创建任务_任务提醒弹窗.png)

| 序号 | 字段名称 | 字段类型 | 是否必填 | 默认值 | 说明 |
|------|----------|----------|----------|--------|------|
| 1 | 提醒时间 | 数字输入框 | 是 | - | 输入提醒时间数值 |
| 2 | 时间单位 | 下拉选择框 | 是 | 天 | 可选值：天、小时、分钟 |
| 3 | 提醒方式 | 复选框组 | 是 | - | 可选提醒方式 |

#### 时间单位下拉选项

| 序号 | 选项值 |
|------|--------|
| 1 | 天 |
| 2 | 小时 |
| 3 | 分钟 |

## 操作按钮

| 按钮名称 | 功能说明 |
|----------|----------|
| 取消 | 关闭弹窗，不保存 |
| 确定 | 提交创建任务 |
