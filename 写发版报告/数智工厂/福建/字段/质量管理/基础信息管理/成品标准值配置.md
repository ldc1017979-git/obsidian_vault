# 成品标准值配置

## 页面概述

- **模块路径**: 质量管理 > 基础信息管理 > 标准值配置 > 成品标准值配置
- **页面URL**: `#/quality-manage/index2/qc-standard-value-configuration/finished`
- **页面功能**: 配置成品检验的标准值，包括左侧树形分类选择和右侧检验项目列表

## 编辑检查项弹窗字段

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 检查项目 | 文本框（禁用） | 当前项目名称 | 只读，不可编辑 | 显示当前检验项目名称 |
| 2 | 标准来源 | 下拉框 | 自主配置 | 可选 | 选择标准来源，如"自主配置" |
| 3 | 状态 | 下拉框（禁用） | 未配置 | 只读，不可编辑 | 显示当前配置状态 |
| 4 | 单位 | 文本框 | 空 | 可选 | 输入计量单位 |
| 5 | 是否判定 | 下拉框 | 是 | 可选 | 选择是否需要判定，如"是"/"否" |
| 6 | 排序 | 数字输入框 | 当前排序值 | 可选 | 输入排序序号 |
| 7 | 检验类型 | 单选框组 | 文本 | 必选 | 选择检验类型，选项如下 |
| 7.1 | ┗ 区间 | 单选框 | - | - | 区间类型 |
| 7.2 | ┗ 大于 | 单选框 | - | - | 大于类型 |
| 7.3 | ┗ 大于等于 | 单选框 | - | - | 大于等于类型 |
| 7.4 | ┗ 小于 | 单选框 | - | - | 小于类型 |
| 7.5 | ┗ 小于等于 | 单选框 | - | - | 小于等于类型 |
| 7.6 | ┗ 等于 | 单选框 | - | - | 等于类型 |
| 7.7 | ┗ 是否合格 | 单选框 | - | - | 是否合格类型 |
| 7.8 | ┗ 文本 | 单选框 | - | - | 文本类型 |
| 7.9 | ┗ 上下浮动（±） | 单选框 | - | - | 上下浮动类型 |
| 8 | 标准值 | 文本框 | 当前标准值 | 根据检验类型填写 | 输入标准值 |

## 操作按钮

| 序号 | 按钮名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 编辑 | 打开编辑检查项弹窗 |
| 2 | 删除 | 删除当前检验项目 |
| 3 | 取消 | 关闭编辑弹窗 |
| 4 | 确定 | 保存编辑内容 |
