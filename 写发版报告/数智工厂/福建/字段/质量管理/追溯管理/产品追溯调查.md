# 产品追溯调查

## 页面概述
- 功能说明：追溯原材料信息及工艺过程，追溯成品信息
- URL：https://fjmms.y1b.cn:8424/#/quality-manage/traceability/investigation

## 截图
![产品追溯调查](../../../字段截图/质量管理_追溯管理_产品追溯调查_1.png)

## 追溯原材料信息及工艺过程

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 批次 | textbox | 无 | 必填 | 批次输入框 |
| 2 | 批号 | textbox | 无 | 必填 | 批号输入框 |

## 追溯成品信息

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 物料编号 | textbox | 无 | 必填 | 物料编号输入框 |
| 2 | 原厂批次 | textbox | 无 | 必填 | 原厂批次输入框 |
| 3 | 原内部批次 | textbox | 无 | 必填 | 原内部批次输入框 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 导出追溯表 | 导出追溯原材料信息及工艺过程的追溯表 |
| 2 | 导出追溯表 | 导出追溯成品信息的追溯表 |

## 交互说明
1. 输入批次和批号信息，点击"导出追溯表"可追溯原材料信息及工艺过程
2. 输入物料编号、原厂批次和原内部批次，点击"导出追溯表"可追溯成品信息
