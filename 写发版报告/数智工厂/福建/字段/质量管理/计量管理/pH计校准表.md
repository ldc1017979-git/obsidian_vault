### 搜索条件

| 序号 | 字段名称 | 输入类型 | 默认值 | 是否必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 确认状态 | select | 全部 | 否 | 下拉选择确认状态（全部/已确认/未确认） |
| 2 | 校准人 | select | 空 | 否 | 下拉选择校准人 |
| 3 | 校准日期 | date | 空 | 否 | 选择校准日期范围（开始日期 - 结束日期） |
| 4 | 使用地点 | text | 空 | 否 | 输入使用地点搜索 |

## 新增校准记录（弹窗）

![pH计校准表新建页](计量管理_pH计校准表_新建页_1.png)

### 表单字段

| 序号 | 字段名称 | 输入类型 | 默认值 | 是否必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 设备编号 | text + button | 空 | 是 | 选择设备编号（只读，点击搜索按钮选择） |
| 2 | 设备型号 | text | 空 | 否 | 设备型号（只读，选择设备后自动填充） |
| 3 | 设备名称 | text | 空 | 否 | 设备名称（只读，选择设备后自动填充） |
| 4 | 使用地点 | text | 空 | 是 | 输入使用地点 |
| 5 | 校准日期 | date | 空 | 是 | 选择校准日期 |
| 6 | 校准人 | select | 空 | 是 | 下拉选择校准人 |
| 7 | CAL1 | text | 空 | 是 | 输入校准值1 |
| 8 | CAL2 | text | 空 | 是 | 输入校准值2 |
| 9 | 斜率 | text | 空 | 是 | 输入斜率值（%） |
| 10 | 备注 | text | 空 | 否 | 输入备注信息 |

### 操作按钮

| 序号 | 按钮名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 取消 | 取消并关闭弹窗 |

| 3 | 签字确认 | 签字并确认校准记录 |
