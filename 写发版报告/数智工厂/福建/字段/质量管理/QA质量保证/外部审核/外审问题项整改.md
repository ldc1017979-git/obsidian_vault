## 处理状态流转说明

| 状态 | 说明 | 可操作 |
| :--- | :--- | :--- |
| 待整改 | 新创建的外审问题项，等待整改 | 查看详情 |
| 整改中 | 正在进行整改 | 查看详情 |
| 待验证 | 整改完成，等待验证 | 查看详情 |
| 验证通过 | 验证通过，流程结束 | 查看详情 |
| 验证不通过 | 验证不通过，需重新整改 | 查看详情 |
