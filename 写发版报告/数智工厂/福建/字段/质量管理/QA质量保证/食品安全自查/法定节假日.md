# 法定节假日

## 页面说明

![法定节假日页面](QA质量保证_法定节假日_1.png)

法定节假日页面为日历视图，用于查看和管理法定节假日信息。

### 操作按钮

| 序号 | 按钮名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 手动更新 | 手动更新节假日数据 |

### 筛选条件

| 序号 | 字段名称 | 输入类型 | 默认值 | 是否必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 年份 | select | 当前年份 | 否 | 下拉选择年份（如：2026年） |
| 2 | 月份 | select | 当前月份 | 否 | 下拉选择月份（如：6月） |

### 日历视图

| 序号 | 字段名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 星期标题 | 一、二、三、四、五、六、日 |
| 2 | 日期数字 | 显示当月日期 |
| 3 | "今"标记 | 标记当天日期 |
| 4 | "休"标记 | 标记法定节假日/休息日（如19日、20日、21日显示"休"） |
