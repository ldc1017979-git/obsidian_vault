# 公司级周排查问题清单

## 列表页

![公司级周排查问题清单列表页](QA质量保证_公司级周排查问题清单_列表页_1.png)

### 搜索条件

| 序号 | 字段名称 | 输入类型 | 默认值 | 是否必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 整改情况 | select | 空 | 否 | 下拉选择整改情况（如：已整改、整改不合格、待验证、未整改） |
| 2 | 年月份（开始） | date | 2026-01-01 | 否 | 选择开始日期 |
| 3 | 年月份（结束） | date | 2026-06-30 | 否 | 选择结束日期 |

### 操作按钮

| 序号 | 按钮名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 重置 | 重置搜索条件 |
| 2 | 搜索 | 按条件搜索 |
| 3 | 推送整改消息 | 推送整改消息通知 |

### 统计信息

| 序号 | 统计项 | 说明 |
| :--- | :--- | :--- |
| 1 | 已整改 | 显示已整改数量（如：5） |
| 2 | 整改不合格 | 显示整改不合格数量（如：0） |
| 3 | 待验证 | 显示待验证数量（如：0） |
| 4 | 未整改 | 显示未整改数量（如：0） |

| 序号 | 字段名称 | 字段类型 | 默认值 | 是否必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |

| 7 | 问题类型 | 文本展示 | - | - | 问题类型（如：问题项） |
| 8 | 问题地点 | 文本展示 | - | - | 问题地点（如：称料暂存间、称料间一更室） |
