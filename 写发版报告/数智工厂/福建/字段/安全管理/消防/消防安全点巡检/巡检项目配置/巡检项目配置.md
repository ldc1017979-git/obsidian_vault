## 新增表单字段

点击"新建"按钮打开新建页面，表单分为以下几个区域：

### 点巡检项目信息区域

| 序号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 检查内容组名 | 文本输入框 | **是** | 检查内容组名称 |
| 2 | 资产类型 | 下拉选择框 | **是** | 选择资产类型 |
| 3 | 检查目的 | 文本输入框 | 否 | 检查目的描述 |
| 4 | 备注 | 文本输入框 | 否 | 备注说明 |

### 新增检查内容区域

点击"添加检查内容"按钮弹出对话框，表单字段如下：

| 序号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 检查内容 | 文本输入框 | **是** | 检查项内容描述 |
| 2 | 检验方法 | 文本输入框 | 否 | 检验方法/工具/依据 |
| 3 | 检查标准说明 | 文本输入框 | 否 | 检查标准说明 |
| 4 | 记录方式 | 单选按钮组 | **是** | 单选/多选/数值/长文本 |
| 5 | 正常 | 动态添加 | **是** | 正常值选项，可添加多个 |
| 6 | 异常 | 动态添加 | **是** | 异常值选项，可添加多个 |
| 7 | 上限 | 数字输入框 | 否 | 数值上限（记录方式为数值时显示） |
| 8 | 下限 | 数字输入框 | 否 | 数值下限（记录方式为数值时显示） |

### 检查内容列表区域

| 序号 | 字段名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 序号 | 自动编号 |
| 2 | 检查内容 | 检查项内容 |
| 3 | 检验方法/工具/依据 | 检验方法说明 |
| 4 | 检查标准说明 | 检查标准 |
| 5 | 记录方式 | 单选/多选/数值/长文本 |
| 6 | 结果选项 | 正常/异常值列表 |
| 7 | 上限 | 数值上限 |
| 8 | 下限 | 数值下限 |
| 9 | 操作 | 编辑/删除 |

### 表单操作按钮

| 按钮名称 | 描述 |
| :--- | :--- |
| 添加检查内容 | 添加新的检查内容 |
| 返回 | 返回列表页 |
| 确定 | 保存巡检项目配置 |

### 添加检查内容弹窗操作按钮

| 按钮名称 | 描述 |
| :--- | :--- |
| + 添加正常值 | 添加正常值选项 |
| + 添加异常值 | 添加异常值选项 |
| 取消 | 关闭弹窗，不保存 |
| 确定 | 保存检查内容 |
