# 用油记录表

## 页面概述

- **功能说明**：用于管理叉车用油记录，记录叉车的加油情况
- **页面URL**：`/warehouse-manage/forklift-manage/oil`
- **所属模块**：仓储管理 > 叉车管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 登记日期 | 日期范围选择器 | 开始日期-结束日期 |
| 3 | 车牌号 | 文本框 | 输入车牌号搜索 |
| 4 | 加油人 | 文本框 | 输入加油人搜索 |
| 5 | 审核人 | 文本框 | 输入审核人搜索 |
| 6 | 单据状态 | 下拉框 | 可选择单据状态 |
| 7 | 唯一码 | 文本框 | 输入资产唯一码搜索 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新增 | 新增一条用油记录 |
| 4 | 数据导出 | 导出用油数据 |
| 5 | 关闭 | 关闭操作 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本 | 记录的唯一编号 |
| 2 | 单据状态 | 文本 | 单据当前状态 |
| 3 | 登记日期 | 日期 | 登记日期 |
| 4 | 唯一码 | 文本 | 资产唯一码 |
| 5 | 车牌号 | 文本 | 叉车车牌号 |
| 6 | 加油量(L) | 数字 | 加油量（升） |
| 7 | 加油人 | 文本 | 加油人 |
| 8 | 审核人 | 文本 | 审核人 |
| 9 | 备注 | 文本 | 备注信息 |
| 10 | 制单人 | 文本 | 创建单据的人员 |
| 11 | 创建时间 | 日期时间 | 单据创建时间 |
| 12 | 操作 | 按钮 | 操作按钮 |

## 交互说明

1. 用油记录表展示所有叉车的加油记录
2. 支持按叉车资产、登记日期等条件筛选
3. 点击操作按钮可查看用油记录详情
