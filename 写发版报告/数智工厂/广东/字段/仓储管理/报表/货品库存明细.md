# 货品库存明细

## 页面概述

- **功能说明**：用于查看货品库存明细，展示每条库存记录的详细信息
- **页面URL**：`/warehouse-manage/forms/goods-record`
- **所属模块**：仓储管理 > 报表

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 关键字 | 文本框 | 支持模糊搜索 |
| 2 | 库位 | 文本框 | 输入库位搜索 |
| 3 | 仓库 | 下拉框 | 可选择仓库 |
| 4 | 库存数 | 下拉框 | 可选择库存数量范围 |
| 5 | 所属分类 | 下拉框 | 可选择所属分类 |
| 6 | 可用状态 | 下拉框 | 可选择可用状态 |
| 7 | 入库日期 | 日期范围选择器 | 开始日期-结束日期 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 数据导出 | 导出库存明细数据 |
| 4 | 库位设置 | 设置库位信息 |
| 5 | 关闭 | 关闭操作 |

## 交互说明

1. 报表展示所有货品的库存明细，包括可用库存、库位、批次、金额等信息
2. 支持按仓库、分类、供应商等条件筛选
3. 可查看每条库存记录的SAP凭证和全生命周期管理标识
