# 仓管员交接班记录

## 页面概述

- **功能说明**：用于管理仓管员交接班记录，记录仓管员的交接班情况
- **页面URL**：`/warehouse-manage/depot-manage/daily/warehouseer-shift`
- **所属模块**：仓储管理 > 库房管理 > 日常管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 交接日期 | 日期范围选择器 | 开始日期-结束日期 |
| 3 | 班次 | 下拉框 | 可选择班次 |
| 4 | 班组 | 下拉框 | 可选择班组 |
| 5 | 交班仓管员 | 文本框 | 输入交班仓管员搜索 |
| 6 | 接班仓管员 | 文本框 | 输入接班仓管员搜索 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新增 | 新增一条交接班记录 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本 | 记录的唯一编号 |
| 2 | 单据状态 | 文本 | 单据当前状态 |
| 3 | 交接日期 | 日期 | 交接日期 |
| 4 | 班组 | 文本 | 班组 |
| 5 | 班次 | 文本 | 班次 |
| 6 | 交班仓管员 | 文本 | 交班仓管员 |
| 7 | 接班仓管员 | 文本 | 接班仓管员 |
| 8 | 接班时间 | 时间 | 接班时间 |
| 9 | 原材料入库总数 | 数字 | 原材料入库总数 |
| 10 | 原材料退库总数 | 数字 | 原材料退库总数 |
| 11 | 成品入库总数 | 数字 | 成品入库总数 |
| 12 | 制单人 | 文本 | 创建单据的人员 |
| 13 | 创建时间 | 日期时间 | 单据创建时间 |
| 14 | 操作 | 按钮 | 操作按钮 |

## 交互说明

1. 仓管员交接班记录用于记录仓管员的交接班情况
2. 支持按交接日期、班次等条件筛选
3. 记录包含原材料和成品的入库/出库总数
