# 叉车月度检查记录

## 页面概述

- **功能说明**：用于管理叉车月度检查记录，记录叉车的月度检查情况
- **页面URL**：`/warehouse-manage/depot-manage/daily/forklift-check`
- **所属模块**：仓储管理 > 库房管理 > 日常管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 检查日期 | 日期范围选择器 | 开始日期-结束日期 |
| 3 | 检查人 | 文本框 | 输入检查人搜索 |
| 4 | 单据状态 | 下拉框 | 可选择单据状态 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新增 | 新增一条叉车月度检查记录 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本 | 检查单的唯一编号 |
| 2 | 单据状态 | 文本 | 单据当前状态 |
| 3 | 检查日期 | 日期 | 检查日期 |
| 4 | 正常车辆 | 数字 | 正常车辆数 |
| 5 | 异常车辆 | 数字 | 异常车辆数 |
| 6 | 检查人 | 文本 | 检查人 |
| 7 | 制单人 | 文本 | 创建单据的人员 |
| 8 | 创建时间 | 日期时间 | 单据创建时间 |
| 9 | 操作 | 按钮 | 操作按钮 |

## 交互说明

1. 叉车月度检查记录用于记录叉车的月度安全检查情况
2. 支持按检查日期等条件筛选
3. 记录包含正常和异常车辆数量
