# 备件退库单

## 页面概述

- **功能说明**：用于管理备件退库业务，记录有价备件退回仓库的过程
- **页面URL**：`/warehouse-manage/depot-manage/integrated-manage/spare-part-return`
- **所属模块**：仓储管理 > 库房管理 > 备件与综合物资管理

![备件退库单列表页](../仓储管理截图/备件退库单_列表页.png)

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号 |
| 2 | 仓库 | 下拉框 | 可选择仓库 |
| 3 | 单据状态 | 下拉框 | 可选择状态 |
| 4 | 时间 | 日期范围选择器 | 开始日期-结束日期 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新建 | 新建一条备件退库单 |

## 提示信息

- 退料入库按领用出库单原仓库同价退回
