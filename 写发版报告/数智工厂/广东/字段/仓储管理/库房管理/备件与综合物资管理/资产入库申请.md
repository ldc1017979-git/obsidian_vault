# 资产入库申请

## 页面概述

- **功能说明**：用于管理资产入库申请业务
- **页面URL**：`/warehouse-manage/depot-manage/integrated-manage/property-in-apply`
- **所属模块**：仓储管理 > 库房管理 > 备件与综合物资管理

## 页面截图

![资产入库申请列表页](../仓储管理截图/资产入库申请_列表页.png)

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 资产名称 | 文本框 | 输入资产名称搜索 |
| 3 | 使用部门 | 文本框（只读） | 部门信息 |
| 4 | 单据状态 | 下拉框 | 可选择状态 |
| 5 | 创建日期 | 日期范围选择器 | 开始日期-结束日期 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新建 | 新建一条资产入库申请 |
