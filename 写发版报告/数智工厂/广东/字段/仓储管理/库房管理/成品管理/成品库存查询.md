# 成品库存查询

## 页面概述

- **功能说明**：用于查询成品库存信息，展示当前成品的库存状态
- **页面URL**：`/warehouse-manage/depot-manage/product-manage/product-stock/product-search`
- **所属模块**：仓储管理 > 库房管理 > 成品管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 库存工厂编码 | 文本框 | 输入工厂编码搜索 |
| 2 | 库位信息 | 文本框 | 输入库位信息搜索 |
| 3 | 成品批次 | 文本框 | 输入成品批次搜索 |
| 4 | 库存类型 | 下拉框 | 可选择库存类型 |
| 5 | 物料信息 | 文本框 | 输入物料信息搜索 |
| 6 | 物料类型 | 下拉框 | 可选择物料类型 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 库存可视化 | 查看库存可视化视图 |
| 4 | 导出 | 导出库存数据 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 序号 | 数字 | 序号 |
| 2 | 库存工厂编码 | 文本 | 库存工厂编码 |
| 3 | 库存工厂名称 | 文本 | 库存工厂名称 |
| 4 | 物料编码 | 文本 | 物料编码 |
| 5 | 库存总数 | 数字 | 库存总数量 |
| 6 | 非限制 | 数字 | 非限制库存数量 |
| 7 | 质量检查 | 数字 | 质量检查库存数量 |
| 8 | 单位 | 文本 | 计量单位 |
| 9 | 物料名称 | 文本 | 物料名称 |
| 10 | 操作 | 按钮 | 操作按钮 |

## 交互说明

1. 成品库存查询用于查看成品的实时库存情况
2. 支持按库存工厂、物料编码等条件筛选
3. 显示非限制库存和质量检查库存的分类数量
