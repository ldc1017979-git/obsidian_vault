# 成品调拨管理

## 页面概述

- **功能说明**：用于管理成品调拨，记录成品在不同工厂间的调拨
- **页面URL**：`/warehouse-manage/depot-manage/product-manage/product-stock/product_allot`
- **所属模块**：仓储管理 > 库房管理 > 成品管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 调拨单号 | 文本框 | 输入调拨单号搜索 |
| 2 | 调拨日期 | 日期范围选择器 | 开始日期-结束日期 |
| 3 | 调拨类型 | 下拉框 | 可选择调拨类型 |
| 4 | 调拨状态 | 下拉框 | 可选择调拨状态 |
| 5 | 物料信息 | 文本框 | 输入物料信息搜索 |
| 6 | 库存工厂编码 | 文本框 | 输入工厂编码搜索 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新增调拨 | 新增一条成品调拨记录 |
| 4 | 删除 | 删除调拨记录 |
| 5 | 撤回 | 撤回调拨记录 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 调拨编号 | 文本 | 调拨单的唯一编号 |
| 2 | 调拨状态 | 文本 | 调拨状态 |
| 3 | 交货工厂 | 文本 | 交货工厂 |
| 4 | 收货工厂 | 文本 | 收货工厂 |
| 5 | 调拨日期 | 日期 | 调拨日期 |
| 6 | 调拨类型 | 文本 | 调拨类型 |
| 7 | 物料编码 | 文本 | 物料编码 |
| 8 | 物料名称 | 文本 | 物料名称 |
| 9 | 调拨数量 | 数字 | 调拨数量 |
| 10 | 单位 | 文本 | 计量单位 |
| 11 | 备注信息 | 文本 | 备注信息 |
| 12 | 操作 | 按钮 | 删除/撤回按钮 |

## 交互说明

1. 成品调拨管理用于管理成品在不同工厂间的调拨
2. 支持按调拨日期、工厂等条件筛选
3. 可对调拨单进行删除或撤回操作
