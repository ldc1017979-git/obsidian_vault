# 成品库存报表

## 页面概述

- **功能说明**：用于查看成品库存报表，按期统计成品库存变动情况
- **页面URL**：`/warehouse-manage/depot-manage/product-manage/product-stock/product_inventory`
- **所属模块**：仓储管理 > 库房管理 > 成品管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 期初期末日期 | 日期范围选择器 | 选择统计期 |
| 2 | 库存工厂 | 下拉框 | 可选择库存工厂 |
| 3 | 物料信息 | 文本框 | 输入物料信息搜索 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 导出数据 | 导出报表数据 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 序号 | 数字 | 序号 |
| 2 | 物料名称 | 文本 | 物料名称 |
| 3 | 物料编码 | 文本 | 物料编码 |
| 4 | 单位 | 文本 | 计量单位 |
| 5 | 上期库存 | 数字 | 上期库存数量 |
| 6 | 本期入库 | 数字 | 本期入库数量 |
| 7 | 本期出库 | 数字 | 本期出库数量 |
| 8 | 本期末库存 | 数字 | 本期末库存数量 |
| 9 | 当前库存总数 | 数字 | 当前库存总数量 |
| 10 | 非限制 | 数字 | 非限制库存数量 |
| 11 | 质量检查 | 数字 | 质量检查库存数量 |
| 12 | 操作 | 按钮 | 操作按钮 |

## 交互说明

1. 成品库存报表展示成品的期初期末库存统计
2. 支持按时间范围、物料等条件筛选
3. 显示非限制库存和质量检查库存的分类数量
