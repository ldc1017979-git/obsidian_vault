# 贮存仓库信息

## 页面概述

- **功能说明**：用于管理危废贮存仓库信息，维护贮存设施的基础数据
- **页面URL**：`/warehouse-manage/depot-manage/auxiliary-materials/hazardous/storage-warehouse`
- **所属模块**：仓储管理 > 库房管理 > 危废管理

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 新建 | 新增一条贮存仓库信息 |
| 2 | 编辑 | 编辑贮存仓库信息 |
| 3 | 删除 | 删除贮存仓库信息 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 贮存设施编码 | 文本 | 贮存设施编码 |
| 2 | 贮存设施类型(仓库名) | 文本 | 贮存设施类型或仓库名称 |
| 3 | 操作 | 按钮 | 编辑/删除按钮 |

## 交互说明

1. 贮存仓库信息用于维护危废贮存仓库的基础配置
2. 支持新增、编辑和删除仓库记录
3. 每条记录包含贮存设施编码和类型
