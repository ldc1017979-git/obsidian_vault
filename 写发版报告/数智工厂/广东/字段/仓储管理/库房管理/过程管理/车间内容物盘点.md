# 车间内容物盘点

## 页面概述

- **功能说明**：用于管理车间内容物盘点，记录车间内物品的盘点情况
- **页面URL**：`/warehouse-manage/depot-manage/auxiliary-materials/workshop-content-check`
- **所属模块**：仓储管理 > 库房管理 > 辅助材料管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 单据状态 | 下拉框 | 可选择单据状态 |
| 3 | 制单日期 | 日期范围选择器 | 开始日期-结束日期 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新建 | 新增一条车间内容物盘点 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本 | 盘点单的唯一编号 |
| 2 | 产品类型 | 文本 | 产品类型 |
| 3 | 盘点日期 | 日期 | 盘点日期 |
| 4 | 盈/亏总数量 | 数字 | 盈亏总数量 |
| 5 | 制单人 | 文本 | 创建单据的人员 |
| 6 | 创建时间 | 日期时间 | 单据创建时间 |
| 7 | 单据状态 | 文本 | 单据当前状态 |
| 8 | 操作 | 按钮 | 操作按钮 |

## 交互说明

1. 在列表页可通过筛选条件查询车间内容物盘点
