# 原料入库检查表

## 页面概述

- **功能说明**：用于管理原料入库检查，记录原料入库时的检查情况
- **页面URL**：`/warehouse-manage/depot-manage/check/raw-in-check`
- **所属模块**：仓储管理 > 库房管理 > 原材料管理

## 交互说明

1. 在列表页可通过筛选条件查询原料入库检查表
2. 点击"详情"按钮可查看检查表详情
3. 详情页包含基本信息、入库检查明细、附件信息、单据日志四个部分
4. 可通过"导出"按钮导出数据
4. 可通过"反审"按钮反审单据
5. 数据量较大（共228条），支持分页浏览
