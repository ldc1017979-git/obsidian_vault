# 原料入库计量抽检月报

## 页面概述

- **功能说明**：用于管理原料入库计量抽检月报，按月汇总原料入库抽检数据
- **页面URL**：`/warehouse-manage/depot-manage/check/raw-monthly-spotcheck`
- **所属模块**：仓储管理 > 库房管理 > 原材料管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 抽检月份 | 日期选择器 | 选择抽检月份 |
| 3 | 报告人 | 文本框 | 输入报告人搜索 |
| 4 | 单据状态 | 下拉框 | 可选择单据状态 |
| 5 | 创建时间 | 日期范围选择器 | 开始日期-结束日期 |
| 6 | 产品大类 | 下拉框 | 可选择产品大类 |

## 交互说明

1. 在列表页可通过筛选条件查询原料入库计量抽检月报
2. 点击"详情"按钮可查看月报详情
3. 详情页包含基本信息、抽检统计明细、单据日志三个部分
4. 抽检统计明细中可点击"明细"查看各物料详细抽检数据
