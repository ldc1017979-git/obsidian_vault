# 液氮验收核对表

## 页面概述

- **功能说明**：用于管理液氮验收核对，记录液氮到货验收数据
- **页面URL**：`/warehouse-manage/depot-manage/check/liquid-nitrogen`
- **所属模块**：仓储管理 > 库房管理 > 原材料管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 到货日期 | 日期选择器 | 选择到货日期 |
| 2 | 状态 | 下拉框 | 可选择单据状态 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新增 | 新增一条液氮验收核对记录 |

| :--- | :--- | :--- | :--- |

| 2 | 到货日期 | 日期 | 液氮到货日期 |
| 3 | 到货数量(瓶) | 数字 | 到货数量（瓶） |
| 4 | 入库总重量 | 数字 | 入库总重量 |
| 5 | 出库总重量 | 数字 | 出库总重量 |
| 6 | 当天收货总重量 | 数字 | 当天收货总重量 |
| 7 | 制单人 | 文本 | 创建单据的人员 |
| 8 | 创建时间 | 日期时间 | 单据创建时间 |
| 9 | 单据状态 | 文本 | 单据当前状态 |
| 10 | 操作 | 按钮 | 操作按钮 |
