# 原料入库抽检报告

## 页面概述

- **功能说明**：用于管理原料入库抽检报告，记录原料入库的抽检情况
- **页面URL**：`/warehouse-manage/depot-manage/check/raw-inspect`
- **所属模块**：仓储管理 > 库房管理 > 原材料管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 物料名称 | 文本框 | 输入物料名称搜索 |
| 3 | 检验日期 | 日期范围选择器 | 开始日期-结束日期 |

## 交互说明

1. 在列表页可通过筛选条件查询原料入库抽检报告
2. 点击"详情"按钮可查看报告详情
3. 详情页包含基本信息（两组）、关联入库单明细、实检数据、单据日志五个部分
4. 可通过"定义检验标准"按钮配置检验标准
5. 可通过"导出"按钮导出数据
6. 数据量较大（共233条），支持分页浏览
