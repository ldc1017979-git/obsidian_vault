# 原料状态变更

## 页面概述

- **功能说明**：用于管理原料状态变更业务，记录原料在仓库中的状态变化
- **页面URL**：`/warehouse-manage/depot-manage/material-manage/raw-status-change`
- **所属模块**：仓储管理 > 库房管理 > 原材料管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 关键字 | 文本框 | 支持模糊搜索 |
| 2 | 商品名称 | 文本框 | 输入商品名称搜索 |
| 3 | 仓库 | 下拉框 | 可选择仓库 |
| 4 | 单据状态 | 下拉框 | 可选择单据状态 |
| 5 | 时间 | 日期范围选择器 | 开始时间-结束时间 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新建 | 新建一条原料状态变更单 |

| :--- | :--- | :--- | :--- |

| 2 | 仓库 | 文本 | 仓库名称 |
| 3 | 变更日期 | 日期 | 状态变更日期 |
| 4 | 商品明细 | 文本 | 变更商品明细 |
| 5 | 移动类型 | 文本 | 移动类型 |
| 6 | 变更原因 | 文本 | 状态变更原因 |
| 7 | 单据备注 | 文本 | 单据备注信息 |
| 8 | 制单人 | 文本 | 创建单据的人员 |
| 9 | 创建时间 | 日期时间 | 单据创建时间 |
| 10 | 单据状态 | 文本 | 单据当前状态 |
| 11 | 操作 | 按钮 | 详情按钮 |

## 交互说明

1. 在列表页可通过筛选条件查询原料状态变更记录
2. 点击"详情"按钮可查看变更详情
3. 详情页展示变更单的完整信息
