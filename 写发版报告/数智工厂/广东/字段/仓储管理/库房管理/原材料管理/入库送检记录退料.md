# 入库送检记录退料

## 页面概述

- **功能说明**：用于管理入库送检记录的退料业务，记录送检后退回的原料
- **页面URL**：`/warehouse-manage/depot-manage/material-manage/raw-ret-materials`
- **所属模块**：仓储管理 > 库房管理 > 原材料管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 退入仓库 | 下拉框 | 可选择退入仓库 |
| 3 | 单据状态 | 下拉框 | 可选择单据状态 |
| 4 | 创建时间 | 日期范围选择器 | 开始日期-结束日期 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新建 | 新建一条入库送检记录退料 |
