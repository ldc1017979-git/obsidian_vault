# 库房温湿度记录表

## 页面概述

- **功能说明**：用于记录库房温湿度数据，监控仓库环境条件
- **页面URL**：`/warehouse-manage/depot-manage/material-manage/warehouse-temperature`
- **所属模块**：仓储管理 > 库房管理 > 原材料管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 日期 | 日期选择器 | 选择日期 |
| 2 | 仓库名称 | 下拉框 | 可选择仓库 |
| 3 | 状态 | 下拉框 | 可选择单据状态 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新增 | 新增一条温湿度记录 |
| 4 | 温度标准配置 | 配置温度标准参数 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本 | 记录单的唯一编号 |
| 2 | 仓库名称 | 文本 | 仓库名称 |
| 3 | 日期 | 日期 | 记录日期 |
| 4 | 单据状态 | 文本 | 单据当前状态 |
| 5 | 创建时间 | 日期时间 | 单据创建时间 |
| 6 | 制单人 | 文本 | 创建单据的人员 |
| 7 | 操作 | 按钮 | 详情按钮 |

## 详情页面字段

### 单据日志

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 操作人 | 文本 | 执行操作的人员 |
| 2 | 操作类型 | 文本 | 操作类型 |
| 3 | 时间 | 日期时间 | 操作时间 |

## 交互说明

1. 在列表页可通过筛选条件查询温湿度记录
2. 点击"详情"按钮可查看温湿度记录详情
3. 详情页展示温湿度记录的编辑表单和单据日志
4. 可通过"温度标准配置"按钮配置温度标准参数
5. 数据量较大（共897条），支持分页浏览
