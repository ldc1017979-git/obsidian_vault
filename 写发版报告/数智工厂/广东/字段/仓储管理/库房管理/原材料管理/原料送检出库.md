# 原料送检出库

## 页面概述

- **功能说明**：用于管理原料送检出库业务，记录原料送检的出库过程
- **页面URL**：`/warehouse-manage/depot-manage/material-manage/send-inspect`
- **所属模块**：仓储管理 > 库房管理 > 原材料管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 关键字 | 文本框 | 支持模糊搜索 |
| 2 | 商品名称 | 文本框 | 输入商品名称搜索 |
| 3 | 仓库 | 下拉框 | 可选择仓库 |
| 4 | 状态 | 下拉框 | 可选择单据状态 |
| 5 | 时间 | 日期范围选择器 | 开始时间-结束时间 |

## 交互说明

1. 在列表页可通过筛选条件查询原料送检出库记录
2. 点击"详情"按钮可查看送检出库详情
3. 详情页包含基本信息、送检出库商品明细、单据日志三个部分
4. 数据量较大（共595条），支持分页浏览
