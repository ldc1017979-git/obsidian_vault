# 物料单号报表(辅料)模块

## 一、模块概述

物料单号报表(辅料)模块用于统计和管理辅料物料的单号信息，帮助企业跟踪辅料的采购和使用情况。

## 二、功能定位

| 功能维度 | 说明 |
| :--- | :--- |
| **核心功能** | 辅料物料单号统计管理 |
| **数据来源** | 采购系统、仓储系统 |
| **目标用户** | 仓储管理人员、采购人员 |
| **输出形式** | 物料单号报表、跟踪报告 |

## 三、页面结构

### 3.1 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│                物料单号报表(辅料)页面                       │
├─────────────────────────────────────────────────────────────┤
│  【筛选区域】                                                │
│  ├─ 时间范围选择                                            │
│  ├─ 物料类别选择                                            │
│  └─ 单号状态选择                                            │
├─────────────────────────────────────────────────────────────┤
│  【单号列表区域】                                            │
│  ├─ 物料单号列表                                           │
│  ├─ 单号状态                                               │
│  └─ 操作按钮                                               │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 主要字段

| 字段编号 | 字段名称 | 类型 | 描述 |
| :--- | :--- | :--- | :--- |
| 1 | 物料单号 | 文本 | 物料单号 |
| 2 | 物料编码 | 文本 | 物料编码 |
| 3 | 物料名称 | 文本 | 物料名称 |
| 4 | 规格型号 | 文本 | 物料规格 |
| 5 | 计量单位 | 文本 | 计量单位 |
| 6 | 数量 | 数值 | 物料数量 |
| 7 | 单价 | 数值 | 物料单价 |
| 8 | 金额 | 数值 | 物料金额 |
| 9 | 采购日期 | 日期 | 采购日期 |
| 10 | 供应商 | 文本 | 供应商名称 |
| 11 | 入库状态 | 下拉框 | 入库/未入库 |
| 12 | 使用状态 | 下拉框 | 使用中/已用完 |

## 四、交互操作

### 4.1 查询操作

1. **选择时间范围**：选择统计期间
2. **选择物料类别**：筛选特定类别
3. **选择单号状态**：筛选状态
4. **点击查询**：获取物料单号列表

### 4.2 详情查看

1. **点击单号**：查看物料单号详情
2. **跟踪状态**：查看物料流转状态
