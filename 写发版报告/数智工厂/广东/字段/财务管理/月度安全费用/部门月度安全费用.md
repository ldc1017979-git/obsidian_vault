# 部门月度安全费用模块

## 一、模块概述

部门月度安全费用模块用于统计和管理各部门的月度安全费用支出情况，确保安全费用的合理使用。

## 二、功能定位

| 功能维度 | 说明 |
| :--- | :--- |
| **核心功能** | 部门安全费用月度统计 |
| **数据来源** | 财务系统、安全管理系统 |
| **目标用户** | 安全管理人员、财务人员 |
| **输出形式** | 部门安全费用报表 |

## 三、页面结构

### 3.1 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│                部门月度安全费用页面                         │
├─────────────────────────────────────────────────────────────┤
│  【筛选区域】                                                │
│  ├─ 年月选择                                                │
│  └─ 部门选择                                                │
├─────────────────────────────────────────────────────────────┤
│  【费用列表区域】                                            │
│  ├─ 部门列表                                               │
│  ├─ 费用明细                                               │
│  └─ 费用汇总                                               │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 主要字段

| 字段编号 | 字段名称 | 类型 | 描述 |
| :--- | :--- | :--- | :--- |
| 1 | 统计年月 | 日期选择 | 统计的年月 |
| 2 | 部门名称 | 下拉框 | 部门名称 |
| 3 | 费用项目 | 文本 | 费用项目名称 |
| 4 | 预算金额 | 数值 | 预算金额 |
| 5 | 实际支出 | 数值 | 实际支出金额 |
| 6 | 支出比例 | 百分比 | 实际支出占预算比例 |
| 7 | 费用说明 | 文本 | 费用使用说明 |

## 四、交互操作

### 4.1 查询操作

1. **选择年月**：选择统计月份
2. **选择部门**：选择目标部门
3. **点击查询**：获取部门安全费用数据

### 4.2 明细查看

1. **点击部门**：查看该部门详细费用明细
2. **查看详情**：查看费用使用详情
