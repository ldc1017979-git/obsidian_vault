# 经营统计模块

## 一、模块概述

经营统计模块是财务管理模块的核心组成部分，负责对企业的经营数据进行全面统计与分析，为管理层提供决策依据。

## 二、功能定位

| 功能维度 | 说明 |
| :--- | :--- |
| **核心功能** | 企业经营数据的综合统计与分析 |
| **数据来源** | 各业务系统的经营数据汇总 |
| **目标用户** | 财务管理人员、企业决策者 |
| **输出形式** | 统计报表、图表分析、数据可视化 |

### 3.2 主要字段

| 字段编号 | 字段名称 | 类型 | 描述 |
| :--- | :--- | :--- | :--- |
| 1 | 统计周期 | 下拉框 | 年度/季度/月度统计 |
| 2 | 开始日期 | 日期选择 | 统计起始日期 |
| 3 | 结束日期 | 日期选择 | 统计结束日期 |
| 4 | 部门 | 下拉框 | 选择统计部门 |
| 5 | 产品类别 | 下拉框 | 选择产品类别 |
| 6 | 收入总额 | 数值 | 经营收入总计 |
| 7 | 成本总额 | 数值 | 经营成本总计 |
| 8 | 利润额 | 数值 | 利润总额 |
| 9 | 利润率 | 百分比 | 利润占收入比例 |
| 10 | 环比增长率 | 百分比 | 较上期增长比例 |

## 四、交互操作

### 4.1 查询操作

1. **选择时间范围**：点击日期选择框，选择统计的开始和结束日期
2. **选择部门**：从下拉框中选择目标部门
3. **选择产品类别**：从下拉框中选择产品类别（可选）
4. **点击查询**：点击查询按钮获取统计数据

### 4.2 数据导出

- 支持导出为Excel格式
- 支持导出为PDF格式

## 五、数据展示

### 5.1 指标卡片

| 指标名称 | 显示内容 | 单位 |
| :--- | :--- | :--- |
| 营业收入 | 本期营业收入金额 | 元 |
| 营业成本 | 本期营业成本金额 | 元 |
| 净利润 | 本期净利润金额 | 元 |
| 毛利率 | 毛利占收入比例 | % |

### 5.2 趋势图表

- **收入趋势图**：展示月度/季度收入变化趋势
- **成本趋势图**：展示月度/季度成本变化趋势
- **利润趋势图**：展示月度/季度利润变化趋势

### 5.3 数据表格

| 列名 | 说明 |
| :--- | :--- |
| 序号 | 记录编号 |
| 日期 | 统计日期 |
| 部门 | 所属部门 |
| 收入 | 收入金额 |
| 成本 | 成本金额 |
| 利润 | 利润金额 |
| 利润率 | 利润率百分比 |

## 七、注意事项

1. 统计数据可能存在延迟，建议在数据更新完成后进行查询
2. 日期范围跨度不宜过大，建议按月度或季度进行统计
3. 导出功能需要相应权限，请确保有足够的操作权限
