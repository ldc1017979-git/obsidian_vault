# 采购委员会评审记录模块

## 一、模块概述

采购委员会评审记录模块用于记录和管理采购委员会对供应商和采购项目的评审过程和结果，确保采购决策的透明度和公正性。

## 二、功能定位

| 功能维度 | 说明 |
| :--- | :--- |
| **核心功能** | 采购评审记录管理 |
| **数据来源** | 采购委员会评审会议 |
| **目标用户** | 采购委员会成员、采购管理人员 |
| **输出形式** | 评审记录报表、决策报告 |

## 三、页面结构

### 3.1 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│                采购委员会评审记录页面                       │
├─────────────────────────────────────────────────────────────┤
│  【筛选区域】                                                │
│  ├─ 评审日期选择                                            │
│  ├─ 评审类型选择                                            │
│  └─ 评审状态选择                                            │
├─────────────────────────────────────────────────────────────┤
│  【评审列表区域】                                            │
│  ├─ 评审记录列表                                           │
│  └─ 操作按钮                                               │
├─────────────────────────────────────────────────────────────┤
│  【评审详情区域】                                            │
│  ├─ 评审基本信息                                           │
│  ├─ 评审委员信息                                           │
│  └─ 评审结果                                               │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 主要字段

| 字段编号 | 字段名称 | 类型 | 描述 |
| :--- | :--- | :--- | :--- |
| 1 | 评审编号 | 文本 | 评审记录编号 |
| 2 | 评审类型 | 下拉框 | 供应商评审/项目评审 |
| 3 | 评审对象 | 文本 | 评审对象名称 |
| 4 | 评审日期 | 日期 | 评审会议日期 |
| 5 | 评审委员 | 文本 | 参与评审的委员名单 |
| 6 | 评审标准 | 文本 | 评审依据标准 |
| 7 | 评审结果 | 下拉框 | 通过/未通过/待复议 |
| 8 | 评审意见 | 文本 | 评审意见说明 |
| 9 | 决策结论 | 文本 | 最终决策结论 |
| 10 | 记录人 | 文本 | 记录人员 |

## 四、交互操作

### 4.1 查询操作

1. **选择日期范围**：选择评审日期范围
2. **选择评审类型**：筛选评审类型
3. **选择评审状态**：筛选评审状态
4. **点击查询**：获取评审记录列表

### 4.2 评审详情

1. **点击评审编号**：查看评审详细记录
2. **查看委员意见**：查看各委员的评审意见
3. **查看结果**：查看评审最终结果

### 4.3 新增评审记录

1. **填写评审信息**：评审对象、日期、委员等
2. **填写评审意见**：记录各委员意见
3. **填写评审结果**：记录评审结论
4. **保存提交**：保存评审记录
