# 供应商调查表模块

## 一、模块概述

供应商调查表模块用于收集和管理供应商的基本信息和资质资料，为供应商评估和选择提供依据。

## 二、功能定位

| 功能维度 | 说明 |
| :--- | :--- |
| **核心功能** | 供应商信息调查与管理 |
| **数据来源** | 供应商提交的资料 |
| **目标用户** | 采购人员、供应商管理人员 |
| **输出形式** | 供应商调查报告 |

## 四、交互操作

### 4.1 供应商查询

1. **输入供应商名称**：搜索目标供应商
2. **选择状态**：筛选供应商状态
3. **点击查询**：获取供应商列表

### 4.2 调查详情查看

1. **点击供应商名称**：查看详细调查信息
2. **查看资质**：查看供应商资质认证
3. **评估业务能力**：查看业务能力评估结果

### 4.3 新增调查

1. **填写基本信息**：录入供应商基本信息
2. **上传资质文件**：上传资质证书
3. **填写评估意见**：添加业务能力评估
4. **保存提交**：保存调查信息
