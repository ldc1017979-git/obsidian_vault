# 部门月度预算模块

## 一、模块概述

部门月度预算模块用于管理各部门的月度预算额度，跟踪月度预算执行情况，包括预算金额、执行金额和执行率，实现月度预算的精细化管理。

- **页面URL**：`#/financial-manage/operating/dept-monthly-budget`
- **完整URL**：`https://gdmms.y1b.cn:8424/#/financial-manage/operating/dept-monthly-budget`

## 二、功能定位

| 功能维度 | 说明 |
| :--- | :--- |
| **核心功能** | 部门月度预算额度管理与执行监控 |
| **数据来源** | 预算编制数据、费用报销数据 |
| **目标用户** | 财务人员、部门负责人 |
| **输出形式** | 月度预算执行报表、预算分析报告 |

## 四、新增页面结构

### 4.1 基本信息字段

| 字段编号 | 字段名称 | 类型 | 必填 | 默认值 | 描述 |
| :--- | :--- | :--- | :--- | :--- | :--- |

### 4.2 操作按钮

| 按钮名称 | 描述 |
| :--- | :--- |
| 返回 | 返回列表页面 |

| 确认费用 | 提交确认预算 |

### 4.3 预算明细表格字段

| 字段编号 | 列名 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 序号 | 数值 | 否 | 记录序号 |

## 五、交互操作

1. **搜索**：输入单据编号、选择统计月份或创建时间范围，点击"搜索"按钮查询数据
2. **重置**：点击"重置"按钮清空搜索条件
3. **新增**：点击"新增"按钮进入新建部门月度预算页面
4. **添加明细**：点击"添加"按钮新增预算明细行
5. **保存**：点击"保存"按钮保存草稿
6. **确认费用**：点击"确认费用"按钮提交确认
7. **返回**：点击"返回"按钮返回列表页面

## 七、注意事项

1. 预算年度月份为必填项，默认为当前月份
2. 执行金额和执行率由系统自动计算
3. 执行率 = 执行金额 / 预算金额 × 100%
4. 确认费用操作后单据状态将变更
