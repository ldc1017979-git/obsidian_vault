# 个人考勤记录表

## 功能定位
个人考勤记录表模块用于按员工个人维度记录和管理考勤数据，支持员工确认和按条件查询。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 单据编号 | 文本输入 | 按单据编号搜索 |
| 日期 | 日期范围 | 选择考勤日期区间 |
| 员工确认状态 | 下拉选择 | 按员工确认状态筛选 |

### 操作按钮
- 重置
- 搜索

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 单据编号 | 系统自动生成 |
| 员工确认状态 | 员工确认情况 |
| 姓名 | 员工姓名 |
| 部门 | 所属部门 |
| 日期 | 考勤日期 |
| 分部门 | 所属分部门 |
| 合计工时 | 考勤总工时 |
| 操作 | 详情/编辑等 |
