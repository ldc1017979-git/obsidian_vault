# 培训设置

## 功能定位
培训设置模块用于配置培训相关的各类参数，包含13个标签页的设置项。

## 页面结构
页面包含13个标签页：
1. 培训类别
2. 培训交付物
3. 培训课程
4. 培训教材
5. 考核方式
6. 培训时段
7. 培训形式
8. 培训方法
9. 培训内容划分
10. 培训类型
11. 考核分类
12. 培训必学
13. 培训记录月报汇总规则

### 标签页一：培训类别

#### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 培训类别 | 文本输入 | 按培训类别名称搜索 |

#### 操作按钮
- 重置
- 搜索
- 新增培训类别

#### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 培训类别 | 类别名称（如：体系知识、食品安全、职业素养技能、规章制度、岗位知识、环境类、质量类、安全健康类） |
| 状态 | 启用/禁用 |
| 显示顺序 | 排列顺序 |
| 备注信息 | 备注说明 |
| 操作 | 编辑 |

### 新增培训类别表单字段
点击"新增培训类别"按钮打开表单，表单字段如下：

| 序号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 培训类别名称 | 文本输入框 | 是 | 培训类别名称，最多20个字符 |
| 2 | 状态 | 单选框 | 否 | 启用/禁用，默认启用 |
| 3 | 显示顺序 | 数字输入 | 否 | 排列顺序 |
| 4 | 备注信息 | 多行文本 | 否 | 备注说明，最多100个字符 |

### 其他标签页
其余12个标签页（培训交付物、培训课程、培训教材、考核方式、培训时段、培训形式、培训方法、培训内容划分、培训类型、考核分类、培训必学、培训记录月报汇总规则）结构类似，均包含搜索、新增和列表管理功能。
