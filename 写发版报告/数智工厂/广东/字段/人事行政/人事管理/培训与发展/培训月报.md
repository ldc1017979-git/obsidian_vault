# 培训月报

## 功能定位
培训月报模块用于按月统计各部门的培训情况，汇总培训场数、时长等数据。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 统计年月 | 日期范围 | 选择统计月份区间 |
| 培训统计部门 | 文本输入（只读） | 按部门筛选 |
| 培训统计状态 | 下拉选择 | 按统计状态筛选 |

### 操作按钮
- 重置
- 搜索

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 统计年月 | 统计月份 |
| 培训统计部门 | 统计部门 |
| 月度总场数 | 当月培训总场次 |
| 有效总场数 | 有效培训场次 |
| 培训总时长(min) | 培训总时长 |
| 复训场数 | 重复培训场次 |
| 培训统计状态 | 统计状态 |
| 操作 | 详情等 |
