# 培训计划

## 功能定位
培训计划模块用于制定和管理企业年度/月度培训计划，支持新增计划、批量导入、批量提交和批量审核。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 培训类型 | 下拉选择 | 按培训类型筛选 |
| 时间安排 | 日期范围 | 选择培训时间区间 |
| 培训状态 | 下拉选择 | 按培训状态筛选 |
| 培训主题 | 文本输入 | 按培训主题搜索 |
| 培训人 | 文本输入 | 按培训人搜索 |
| 培训部门 | 文本输入（只读） | 按培训部门筛选 |

### 操作按钮
- 重置
- 搜索
- 新增培训计划
- 批量导入
- 批量提交
- 批量审核
- 设置延期审核人

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 培训编号 | 系统自动生成 |
| 培训类别 | 培训分类 |
| 部门 | 培训部门 |
| 培训主题 | 培训主题名称 |
| 时间安排(月) | 计划培训月份 |
| 培训方式 | 内训/外训 |
| 估算费用(元) | 预估费用 |

| 受训人 | 参训人员 |
| 培训交付物 | 培训产出 |
| 计划备注 | 备注说明 |
| 操作 | 详情/关联培训记录/组织培训 |

## 新增表单字段

点击"新增培训计划"按钮打开表单，表单字段如下：

### 基础信息
| 序号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 培训主题 | 文本输入框 | **是** | 培训主题名称 |
| 2 | 培训类别 | 下拉选择框 | **是** | 培训类别选择 |
| 3 | 培训部门 | 文本输入框 | **是** | 自动填充，不可编辑 |
| 4 | 培训人 | 点击选择 | **是** | 点击选择培训人(多选) |
| 5 | 受训人 | 点击选择 | 否 | 点击选受训人员（培训计划可不填写） |
| 6 | 提醒接收人 | 点击选择 | 否 | 点击选择提醒接收人(多选) |
| 7 | 计划备注 | 多行文本框 | 否 | 备注说明，最多500字符 |
| 8 | 附件信息 | 文件上传 | 否 | 支持jpg, png, gif, jpeg, pdf, zip, rar, docx, doc, xlsx, ppt, pptx, pptm, xls格式，不超过100M |
| 9 | 计划编号 | 文本输入框 | 否 | 自动生成，不可编辑 |
| 10 | 估算费用 | 数字输入框 | 否 | 估算费用，单位元 |
| 11 | 培训方式 | 单选按钮 | **是** | 内训/外训/公开课 |
| 12 | 时间安排 | 日期选择器 | **是** | 选择培训月份 |
| 13 | 计划提醒 | 复选框 | 否 | 截止前30天/15天/7天 |
| 14 | 创建人 | 文本输入框 | 否 | 自动填充当前用户，不可编辑 |
| 15 | 培训地点 | 文本输入框 | 否 | 培训地点 |
| 16 | 培训时长(min) | 文本输入框 | 否 | 培训时长（分钟） |
| 17 | 培训交付物 | 下拉选择框 | 否 | 培训交付物类型 |
| 18 | 培训必学 | 下拉选择框 | 否 | 是否必学 |
| 19 | 培训形式 | 下拉选择框 | 否 | 培训形式 |
| 20 | 是否有教材 | 单选按钮 | 否 | 有/无 |
| 21 | 培训教材 | 下拉选择框 | 否 | 选择培训教材 |
| 22 | 培训类型 | 下拉选择框 | 否 | 培训类型 |
| 23 | 考核方式 | 下拉选择框 | 否 | 考核方式 |

### 操作按钮
| 按钮名称 | 描述 |
| :--- | :--- |
| 取消 | 取消编辑 |
| 确定 | 提交培训计划 |
