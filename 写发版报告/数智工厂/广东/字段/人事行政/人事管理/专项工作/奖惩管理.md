# 奖惩管理

## 功能定位
奖惩管理模块用于管理员工的奖励和惩罚记录，支持新增报名申请和二维码申报。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 奖惩日期 | 日期范围 | 选择奖惩日期区间 |
| 业务状态 | 下拉选择 | 按业务状态筛选 |
| 奖惩类型 | 下拉选择 | 按奖惩类型筛选 |
| 申报类型 | 下拉选择 | 按申报类型筛选 |
| 员工信息 | 文本输入 | 按员工姓名/工号搜索 |
| 奖惩文号 | 文本输入 | 按文号搜索 |

### 操作按钮
- 重置
- 搜索
- 新增报名申请

### 其他元素
- 奖惩申报二维码

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 业务编号 | 系统自动生成 |
| 业务状态 | 当前审批状态 |
| 申报日期 | 奖惩申报日期 |
| 奖惩类型 | 奖励/惩罚分类 |
| 申报类型 | 申报类别 |
| 奖惩人员 | 受奖惩员工 |
| 奖惩金额(元) | 奖惩金额 |
| 事件描述 | 奖惩事件描述 |
| 申报原因 | 申报原因说明 |
| 奖惩文号 | 文号标识 |
| 备注信息 | 备注说明 |
| 操作 | 查看/编辑等 |
