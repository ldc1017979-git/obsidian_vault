# 内训师设置

## 功能定位
内训师设置模块用于配置内训师认证相关的参数，包括潜力自评、成就动机和内训师等级三个标签页。

## 页面结构
页面包含三个标签页：
1. 潜力自评
2. 成就动机
3. 内训师等级

### 标签页一：潜力自评

#### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 潜力自评 | 文本输入 | 按潜力自评名称搜索 |

#### 操作按钮
- 重置
- 搜索
- 新增潜力自评

#### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 潜力自评 | 潜力自评名称 |
| 状态 | 启用/禁用状态 |
| 显示顺序 | 排列顺序 |
| 备注信息 | 备注说明 |
| 操作 | 编辑/删除等 |

#### 新增/编辑潜力自评表单字段
点击"新增潜力自评"或"编辑"按钮打开表单，表单字段如下：

| 序号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 潜力自评 | 文本输入框 | 是 | 潜力自评名称 |
| 2 | 类别颜色 | 按钮选择 | 否 | 设置类别颜色 |
| 3 | 选项配置 | 表格输入 | 是 | 选项内容、状态、显示顺序 |
| 4 | 状态 | 单选框 | 否 | 启用/禁用，默认启用 |
| 5 | 显示顺序 | 数字输入 | 否 | 数值越大，越靠前 |
| 6 | 备注信息 | 多行文本 | 否 | 备注说明，最多100字符 |
