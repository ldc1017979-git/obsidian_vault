# 招聘设置

## 一、模块概述

| 属性 | 说明 |
| :--- | :--- |
| 模块名称 | 招聘设置 |
| 所属分类 | 人事管理 > 员工档案管理 |

## 五、应聘者郑重承诺说明

| 字段编号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 承诺说明内容 | 多行文本框 | 否 | 5000字符以内，默认预设内容 |
| 2 | 设置承诺说明 | 按钮 | 否 | 点击进入编辑模式 |

默认承诺内容：
1. 本人已与上家单位解除劳动关系；发生纠纷与贵公司无关。
2. 工作履历和所提供的资料真实可查。
3. 本人所提供的证件及所填写的资料完全属实，如有虚假成份，一经查实，所引起的一切后果均由本人负责，并愿接受企业无条件解雇处分。若违反上述承诺而导致劳动关系解除，公司有权要求赔偿相关招聘费用。
