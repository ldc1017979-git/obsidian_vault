# 合同管理

## 一、模块概述

| 属性 | 说明 |
| :--- | :--- |
| 模块名称 | 合同管理 |
| 所属分类 | 人事管理 > 员工档案管理 |
| 页面URL | `#/administration-manage/index10/index107/contract-management` |
| 功能定位 | 管理员工劳动合同，包括合同签订、续签、终止等全流程管理 |
