## 一、模块概述

| 属性 | 说明 |
| :--- | :--- |
| 模块名称 | 人员档案库 |
| 所属分类 | 人事管理 > 员工档案管理 |
| 页面URL | `#/administration-manage/index10/index107/library` |
| 功能定位 | 管理员工档案信息，包括个人基本信息、用工信息、标签信息等 |
