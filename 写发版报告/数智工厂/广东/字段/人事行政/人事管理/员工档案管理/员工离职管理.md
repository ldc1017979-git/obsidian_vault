# 员工离职管理

## 一、模块概述

| 属性 | 说明 |
| :--- | :--- |
| 模块名称 | 员工离职管理 |
| 所属分类 | 人事管理 > 员工档案管理 |
| 页面URL | `#/administration-manage/index10/index107/dimission` |
| 功能定位 | 管理员工离职流程，包括离职申请、审批和记录管理 |

## 三、新增页面结构

新增页面URL：`#/administration-manage/index10/index107/dimission/detail?pageType=1`

### 3.1 基础信息

| 字段编号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 离职人员 | 选择器 | **是** | 点击选择离职人员 |
| 2 | 工号 | 文本输入框 | 否 | 自动填充，不可编辑 |
| 3 | 部门 | 文本输入框 | 否 | 自动填充，不可编辑 |
| 4 | 入职日期 | 日期选择器 | 否 | 自动填充，不可编辑 |
| 5 | 职位 | 文本输入框 | 否 | 自动填充，不可编辑 |
| 6 | 用工形式 | 文本输入框 | 否 | 自动填充，不可编辑 |
| 7 | 离职类型 | 下拉选择框 | 否 | 离职类型选择 |
| 8 | 离职原因 | 下拉选择框 | **是** | 离职原因选择 |
| 9 | 离职原因备注 | 多行文本框 | 否 | 离职原因详细说明 |
| 10 | 附件信息 | 文件上传 | 否 | 最多10个，不超过100M |
| 11 | 离职编号 | 文本输入框 | 否 | 自动生成，不可编辑 |
| 12 | 申请日期 | 日期选择器 | **是** | 离职申请日期 |
| 13 | 预计离职日期 | 日期选择器 | **是** | 预计离职日期 |
| 14 | HR审批人 | 人员选择器 | **是** | 点击选择HR审批人 |
| 15 | 创建人 | 文本输入框 | 否 | 自动填充当前用户，不可编辑 |

### 3.2 操作按钮

| :--- | :--- |
| 取消 | 取消编辑 |
