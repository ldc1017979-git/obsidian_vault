# 退休管理

## 一、模块概述

| 属性 | 说明 |
| :--- | :--- |
| 模块名称 | 退休管理 |
| 所属分类 | 人事管理 > 员工档案管理 |
| 页面URL | `#/administration-manage/index10/index107/retirement` |
| 功能定位 | 管理员工退休流程，包括退休提醒、退休处理和记录管理 |

## 三、退休提醒设置对话框

### 3.1 设置项

| 字段编号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 退休提醒时间 | 动态添加 | **是** | 点击"添加退休提醒时间"添加提醒时间 |
| 2 | 提醒通知谁 | 人员选择器 | **是** | 点击选择退休到期提醒人员（支持多人） |

### 3.2 操作按钮

| 按钮名称 | 描述 |
| :--- | :--- |
| 添加退休提醒时间 | 添加退休提醒时间条件 |
| 取消 | 取消设置 |
| 确定 | 保存设置 |
