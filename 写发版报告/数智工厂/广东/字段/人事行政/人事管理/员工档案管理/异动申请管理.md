# 异动申请管理

## 一、模块概述

| 属性 | 说明 |
| :--- | :--- |
| 模块名称 | 异动申请管理 |
| 所属分类 | 人事管理 > 员工档案管理 |
| 页面URL | `#/administration-manage/index10/index107/remove-management-apply` |
| 功能定位 | 管理员工异动申请，包括平调、晋升、降职等异动类型的申请和审批 |

## 三、新增页面结构

新增页面URL：`#/administration-manage/index10/index107/remove-management-apply/detail?pageType=1`

### 3.1 异动前信息

| 字段编号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 在职员工 | 选择器 | **是** | 点击选择在职员工 |
| 2 | 工号 | 文本输入框 | 否 | 自动填充，不可编辑 |
| 3 | 异动前部门 | 文本输入框 | 否 | 自动填充，不可编辑 |
| 4 | 入职日期 | 日期选择器 | 否 | 自动填充，不可编辑 |
| 5 | 异动前职务 | 文本输入框 | 否 | 自动填充，不可编辑 |
| 6 | 职位 | 文本输入框 | 否 | 自动填充，不可编辑 |
| 7 | 单据编号 | 文本输入框 | 否 | 自动生成，不可编辑 |
| 8 | 异动前部门(数智工厂) | 文本输入框 | 否 | 自动填充，不可编辑 |
| 9 | 异动前岗位(数智工厂) | 文本输入框 | 否 | 自动填充，不可编辑 |

### 3.2 异动后信息

| 字段编号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 异动日期 | 日期选择器 | **是** | 异动执行日期 |
| 2 | 异动类型 | 下拉选择框 | **是** | 平调/晋升/降职等 |
| 3 | 异动后部门 | 文本输入框 | **是** | 异动后部门 |
| 4 | 异动后职务 | 文本输入框 | **是** | 异动后职务 |
| 5 | 异动备注 | 多行文本框 | 否 | 异动备注说明 |
| 6 | 异动附件 | 文件上传 | 否 | 最多10个，不超过100M |
| 7 | 异动后部门(数智工厂) | 文本输入框 | **是** | 数智工厂异动后部门 |
| 8 | 异动后岗位(数智工厂) | 下拉选择框 | **是** | 数智工厂异动后岗位，不可编辑 |
| 9 | 异动后部门负责人 | 下拉选择框 | **是** | 异动后部门负责人 |
| 10 | 工作地点(支持多选) | 下拉选择框 | 否 | 支持多选工作地点 |
| 11 | 计划异动定岗日期 | 日期选择器 | **是** | 计划定岗日期 |

### 3.3 操作按钮

| 按钮名称 | 描述 |
| :--- | :--- |
| 取消 | 取消编辑 |
| 确定 | 提交异动申请 |
