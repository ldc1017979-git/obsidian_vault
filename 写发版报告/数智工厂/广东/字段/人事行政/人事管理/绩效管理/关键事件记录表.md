| 属性 | 说明 |
| :--- | :--- |
| 模块名称 | 关键事件记录表 |

## 三、新增表单字段

### 3.1 员工信息

| 序号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 考核类型 | 单选框 | 否 | 单人考核/多人考核，默认单人考核 |
| 2 | 被考核员工 | 选择框 | 是 | 点击选择被考核员工 |
| 3 | 工号 | 文本输入框 | 否 | 自动填充，不可编辑 |
| 4 | 所在部门 | 文本输入框 | 否 | 自动填充，不可编辑 |
| 5 | 所在岗位 | 文本输入框 | 否 | 自动填充，不可编辑 |
| 6 | 单据编号 | 文本输入框 | 否 | 自动生成，不可编辑 |

### 3.2 关键事件记录

| 序号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 记录日期 | 日期选择框 | 是 | 事件发生日期 |
| 2 | 依据考核细则 | 文本输入框 | 是 | 依据的考核细则，不可编辑 |
| 3 | 绩效行为记录 | 多行文本 | 是 | 绩效行为描述（最多500字） |
| 4 | 记录附件 | 文件上传 | 否 | 最多支持10个文件，大小不超过100M |
| 5 | 分数标准 | 文本输入框 | 否 | 自动显示，不可编辑 |
| 6 | 结果分数 | 下拉选择/手动输入 | 是 | 考核分数 |
| 7 | 处理方案 | 下拉选择框 | 否 | 处理方案选择 |

### 3.3 操作按钮

| 按钮名称 | 描述 |
| :--- | :--- |
| 返回列表 | 返回列表页面 |
| 保存 | 保存记录 |
| 考核人提交签字 | 提交并签字确认 |
