# 车辆保养时间记录

## 功能定位
车辆保养时间记录模块用于记录每次车辆保养的时间和项目信息。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 车牌号 | 下拉选择 | 按车牌号筛选 |
| 保养日期 | 日期范围 | 选择保养日期区间 |

### 操作按钮
- 重置
- 搜索
- 新增

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 车牌号 | 车辆牌照号码 |
| 保养日期 | 保养日期 |
| 保养项目 | 保养项目名称 |
| 保养费用(元) | 保养费用 |
| 下次保养时间 | 下次保养日期 |
| 操作 | 详情/编辑 |
