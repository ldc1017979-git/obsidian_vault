# 车辆月油耗统计表

## 功能定位
车辆月油耗统计表模块用于按月统计各车辆的油耗数据，包括加油量和加油费用。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 车牌号 | 下拉选择 | 按车牌号筛选 |
| 统计月份 | 月份选择 | 选择统计月份 |

### 操作按钮
- 重置
- 搜索
- 导出

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 车牌号 | 车辆牌照号码 |
| 品牌 | 车辆品牌 |
| 加油量(升) | 当月加油总量 |
| 加油金额(元) | 当月加油总费用 |
| 行驶里程(km) | 当月行驶总里程 |
| 百公里油耗(L) | 百公里油耗 |
| 操作 | 详情 |
