# 车辆档案

## 功能定位
车辆档案模块用于管理企业所有车辆的基本信息，包括车牌号、品牌、购置信息、使用性质等。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 车牌号 | 下拉选择 | 按车牌号筛选 |
| 品牌 | 文本输入 | 按品牌搜索 |
| 档案状态 | 下拉选择 | 按档案状态筛选 |

### 操作按钮
- 重置
- 搜索
- 新增
- 导入
- 导出数据
- 消息通知人

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 车牌号 | 车辆牌照号码 |
| 品牌 | 车辆品牌 |
| 档案状态 | 生效中/已归档 |
| 车辆图片 | 车辆照片 |
| 购置日期 | 购买日期 |
| 购置价(裸车) | 裸车价格 |
| 使用性质 | 使用性质 |
| 车辆识别码 | VIN码 |
| 排量 | 发动机排量 |
| 变速箱 | 手动档/自动档 |
| 车审到期时间 | 年审到期日 |
| 下次保养时间 | 下次保养日期 |
| 报废信息 | 报废相关信息 |
| 操作 | 详情/编辑/归档 |
