# 车辆保险记录

## 功能定位
车辆保险记录模块用于记录每次车辆保险的详细信息，包括保险类型、保费等。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 车牌号 | 下拉选择 | 按车牌号筛选 |
| 保险日期 | 日期范围 | 选择保险日期区间 |

### 操作按钮
- 重置
- 搜索
- 新增

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 车牌号 | 车辆牌照号码 |
| 保险类型 | 保险类型 |
| 保险公司 | 保险公司名称 |
| 保险费用(元) | 保险费用 |
| 保险起期 | 保险起始日期 |
| 保险止期 | 保险到期日期 |
| 操作 | 详情/编辑 |
