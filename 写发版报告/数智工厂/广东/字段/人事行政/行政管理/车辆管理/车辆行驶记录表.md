# 车辆行驶记录表

## 功能定位
车辆行驶记录表模块用于记录每次车辆出行的详细信息，包括出发地、目的地、里程等。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 车牌号 | 下拉选择 | 按车牌号筛选 |
| 行驶日期 | 日期范围 | 选择行驶日期区间 |

### 操作按钮
- 重置
- 搜索
- 新增

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 车牌号 | 车辆牌照号码 |
| 行驶日期 | 行驶日期 |
| 出发地 | 出发地点 |
| 目的地 | 目的地点 |
| 行驶里程(km) | 行驶公里数 |
| 驾驶人 | 驾驶员姓名 |
| 操作 | 详情/编辑 |
