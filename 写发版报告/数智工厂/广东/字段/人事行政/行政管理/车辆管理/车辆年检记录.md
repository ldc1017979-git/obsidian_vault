# 车辆年检记录

## 功能定位
车辆年检记录模块用于记录每次车辆年检的详细信息。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 车牌号 | 下拉选择 | 按车牌号筛选 |
| 年检日期 | 日期范围 | 选择年检日期区间 |

### 操作按钮
- 重置
- 搜索
- 新增

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 车牌号 | 车辆牌照号码 |
| 年检日期 | 年检日期 |
| 年检结果 | 合格/不合格 |
| 下次年检时间 | 下次年检日期 |
| 操作 | 详情/编辑 |
