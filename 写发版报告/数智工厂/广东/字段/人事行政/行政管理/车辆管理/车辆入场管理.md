# 车辆入场管理

## 功能定位
车辆入场管理模块用于管理外来车辆的入场登记和审批流程。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 车牌号 | 文本输入 | 按车牌号搜索 |
| 入场日期 | 日期范围 | 选择入场日期区间 |
| 状态 | 下拉选择 | 按入场状态筛选 |

### 操作按钮
- 重置
- 搜索
- 新增

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 车牌号 | 车辆牌照号码 |
| 驾驶人 | 驾驶员姓名 |
| 入场日期 | 入场日期 |
| 入场事由 | 入场原因 |
| 预计离场时间 | 预计离场时间 |
| 状态 | 入场状态 |
| 操作 | 详情/编辑 |
