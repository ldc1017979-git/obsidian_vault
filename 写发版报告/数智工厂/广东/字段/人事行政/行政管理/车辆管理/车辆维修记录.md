# 车辆维修记录

## 功能定位
车辆维修记录模块用于记录每次车辆维修的详细信息，包括维修项目、费用等。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 车牌号 | 下拉选择 | 按车牌号筛选 |
| 维修日期 | 日期范围 | 选择维修日期区间 |

### 操作按钮
- 重置
- 搜索
- 新增

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 车牌号 | 车辆牌照号码 |
| 维修日期 | 维修日期 |
| 维修项目 | 维修项目名称 |
| 维修费用(元) | 维修费用 |
| 维修厂商 | 维修厂商名称 |
| 操作 | 详情/编辑 |
