# 车辆购置

## 功能定位
车辆购置模块用于管理企业新车辆的购置申请和审批流程。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 车牌号 | 下拉选择 | 按车牌号筛选 |
| 品牌 | 文本输入 | 按品牌搜索 |
| 状态 | 下拉选择 | 按购置状态筛选 |

### 操作按钮
- 重置
- 搜索
- 新增

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 车牌号 | 车辆牌照号码 |
| 品牌 | 车辆品牌 |
| 购置日期 | 购买日期 |
| 购置价(裸车) | 裸车价格 |
| 使用性质 | 使用性质 |
| 状态 | 购置状态 |
| 操作 | 详情/编辑 |
