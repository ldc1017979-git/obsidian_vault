# 车辆事故记录

## 功能定位
车辆事故记录模块用于记录每次车辆事故的详细信息，包括事故原因、责任认定等。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 车牌号 | 下拉选择 | 按车牌号筛选 |
| 事故日期 | 日期范围 | 选择事故日期区间 |

### 操作按钮
- 重置
- 搜索
- 新增

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 车牌号 | 车辆牌照号码 |
| 事故日期 | 事故发生日期 |
| 事故类型 | 事故类型 |
| 事故描述 | 事故详细描述 |
| 责任认定 | 责任认定结果 |
| 操作 | 详情/编辑 |
