# 员工职业证照

## 功能定位
员工职业证照模块用于管理员工职业证件照和资质信息，支持批量导入和审核。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 员工 | 下拉选择 | 按员工筛选 |
| 部门 | 文本输入 | 按部门搜索 |
| 证件名称 | 下拉选择 | 按证件名称筛选 |
| 证件状态 | 下拉选择 | 按证件状态筛选 |
| 临期 | 单选 | 筛选临期证件 |

### 操作按钮
- 重置
- 搜索
- 新增
- 设置通知接收人
- 导入员工证照
- 导出数据
- 批量通过
- 批量驳回
- 批量导入图片

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 证照状态 | 证照审核状态 |
| 员工姓名 | 员工姓名 |
| 部门 | 所属部门 |
| 岗位 | 岗位 |
| 证件名称 | 证件名称 |
| 证件是否临期 | 是否临期 |
| 证件编码 | 证件编码 |
| 是否长期有效 | 是否长期有效 |
| 资质有效期止 | 有效期截止日期 |
| 上传时间 | 上传时间 |
| 是否归档 | 是否归档 |
| 创建时间 | 创建时间 |
| 操作 | 详情/编辑/提交验收/作废 |
