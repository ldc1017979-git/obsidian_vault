# 证照借阅/查阅提报申请

## 功能定位
证照借阅/查阅提报申请模块用于管理证照的借阅和查阅申请，支持申请审批流程。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 单据编号 | 文本输入 | 按单据编号搜索 |
| 证照名称 | 文本输入 | 按证照名称搜索 |
| 证照类型 | 下拉选择 | 按证照类型筛选 |
| 文件类型 | 下拉选择 | 按文件类型筛选 |
| 申请类型 | 下拉选择 | 按申请类型筛选 |
| 申请日期 | 日期范围 | 选择申请日期区间 |

### 操作按钮
- 重置
- 搜索
- 展开
- 新增
- 档案管理人员

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 单据编号 | 系统编号 |
| 单据状态 | 单据状态 |
| 证照级别 | 证照级别 |
| 证照名称 | 证照名称 |
| 证照类型 | 证照类型 |
| 文件类型 | 文件类型 |
| 申请类型 | 申请类型 |
| 申请人 | 申请人姓名 |
| 申请时间 | 申请时间 |

| 申请归还时间 | 申请归还时间 |
| 确认归还时间 | 确认归还时间 |
| 操作 | 详情/编辑 |
