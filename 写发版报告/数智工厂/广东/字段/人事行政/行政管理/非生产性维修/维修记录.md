# 维修记录

## 功能定位
维修记录模块用于管理非生产性维修的记录信息，包括维修区域、内容、费用等。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 关键词 | 文本输入 | 按关键词搜索 |
| 维修区域 | 下拉选择 | 按维修区域筛选 |
| 维修状态 | 下拉选择 | 按维修状态筛选 |
| 维修时间 | 日期范围 | 选择维修时间区间 |
| 维修项目 | 下拉选择 | 按维修项目筛选 |

### 操作按钮
- 重置
- 搜索
- 创建维修记录

### 统计汇总
- 维修费用合计(元)

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 维修单号 | 系统编号 |
| 维修状态 | 维修状态 |
| 维修时间 | 维修时间 |
| 维修区域 | 维修区域 |
| 维修地点 | 维修地点 |
| 维修内容 | 维修内容描述 |
| 维修项目 | 维修项目名称 |
| 维修前图片 | 维修前照片 |
| 维修后图片 | 维修后照片 |
| 维修费用（元） | 维修费用 |
| 人工费（元） | 人工费用 |
| 材料费（元） | 材料费用 |
| 创建人 | 创建人姓名 |
| 操作 | 详情/编辑 |
