# 宿舍入住申请表

## 功能定位
宿舍入住申请表模块用于员工提交宿舍入住申请，支持审批流程和宿舍分派。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 单据编号 | 文本输入 | 按单据编号搜索 |
| 申请人 | 下拉选择 | 按申请人筛选 |
| 申请入住时间 | 日期范围 | 选择申请入住时间区间 |
| 单据状态 | 下拉选择 | 按单据状态筛选 |

### 操作按钮
- 重置
- 搜索
- 创建单据
- 宿舍分派员
- 宿舍综合业务二维码

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 单据编号 | 系统编号 |
| 单据状态 | 单据状态 |
| 补充状态 | 补充状态 |
| 申请人 | 申请人姓名 |
| 所在部门 | 所属部门 |
| 职位 | 职位 |
| 申请入住时间 | 申请入住时间 |
| 申请原因 | 入住原因 |
| 批准入住时间 | 批准入住时间 |
| 安排房间 | 安排房间 |
| 操作 | 详情/编辑 |
