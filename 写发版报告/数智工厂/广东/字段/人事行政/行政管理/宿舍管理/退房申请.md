# 宿舍退租申请表

## 功能定位
宿舍退租申请表模块用于已入住员工提交退租申请，支持审批流程和检查人员设置。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 单据编号 | 文本输入 | 按单据编号搜索 |
| 申请人 | 下拉选择 | 按申请人筛选 |
| 申请退租时间 | 日期范围 | 选择申请退租时间区间 |
| 单据状态 | 下拉选择 | 按单据状态筛选 |

### 操作按钮
- 重置
- 搜索
- 创建单据
- 设置检查人员

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 单据编号 | 系统编号 |
| 单据状态 | 单据状态 |
| 检查状态 | 检查状态 |
| 申请人 | 申请人姓名 |
| 所在部门 | 所属部门 |
| 宿舍号 | 宿舍号 |
| 入职时间 | 入职时间 |
| 申请退租时间 | 申请退租时间 |
| 操作 | 详情/编辑 |
