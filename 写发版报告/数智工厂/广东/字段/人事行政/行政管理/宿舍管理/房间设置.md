# 客房设置

## 功能定位
客房设置模块用于管理宿舍客房的布草、易耗品和客房价格设置。

## 页面结构

### 标签页
- 布草
- 易耗品
- 客房价格

### 布草标签页

#### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 布草名称 | 文本输入 | 按布草名称搜索 |

#### 操作按钮
- 重置
- 搜索
- 新增布草

#### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 布草名称 | 布草名称 |
| 新购单据(元) | 新购单价 |
| 单位 | 计量单位 |
| 状态 | 启用/禁用 |
| 显示顺序 | 排序号 |
| 备注信息 | 备注信息 |
| 操作 | 编辑 |
