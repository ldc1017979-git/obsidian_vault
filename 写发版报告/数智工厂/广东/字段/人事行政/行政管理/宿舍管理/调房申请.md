# 宿舍人员调动申请表

## 功能定位
宿舍人员调动申请表模块用于已入住员工提交调换房间申请，支持审批流程。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 单据编号 | 文本输入 | 按单据编号搜索 |
| 申请人 | 下拉选择 | 按申请人筛选 |
| 单据状态 | 下拉选择 | 按单据状态筛选 |

### 操作按钮
- 重置
- 搜索
- 新增

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 单据编号 | 系统编号 |
| 单据状态 | 单据状态 |
| 补充状态 | 补充状态 |
| 申请人 | 申请人姓名 |
| 所在部门 | 所属部门 |
| 职位 | 职位 |
| 现居住宿舍房间 | 当前房间 |
| 调整后宿舍房间 | 调往房间 |
| 调整原因 | 调房原因 |
| 操作 | 详情/编辑 |
