# 宿舍客房安全卫生检查清单

## 功能定位
宿舍客房安全卫生检查清单模块用于管理宿舍客房的安全卫生检查记录，支持检查内容维护。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 单据编号 | 文本输入 | 按单据编号搜索 |
| 门牌号 | 文本输入 | 按门牌号搜索 |
| 检查人 | 下拉选择 | 按检查人筛选 |
| 检查日期 | 日期范围 | 选择检查日期区间 |
| 单据状态 | 下拉选择 | 按单据状态筛选 |

### 操作按钮
- 重置
- 搜索
- 新增
- 维护检查内容

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 单据编号 | 系统编号 |
| 单据状态 | 单据状态 |
| 门牌号 | 房间门牌号 |
| 检查人 | 检查人姓名 |
| 实住人数 | 实际入住人数 |
| 检查日期 | 检查日期 |
| 检查结果 | 检查结果 |
| 检查说明 | 检查说明 |
| 操作 | 详情/编辑 |
