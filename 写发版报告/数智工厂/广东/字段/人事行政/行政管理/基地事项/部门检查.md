# 部门安全检查管理

## 功能定位
部门安全检查管理模块用于管理各部门的安全检查记录和评分。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 检查年月 | 日期范围 | 选择检查年月区间 |
| 业务状态 | 下拉选择 | 按业务状态筛选 |
| 卫生检查结果 | 下拉选择 | 按检查结果筛选 |
| 业务日期 | 日期范围 | 选择业务日期区间 |
| 员工部门 | 文本输入 | 按部门搜索 |
| 员工岗位 | 下拉选择 | 按岗位筛选 |

### 操作按钮
- 重置
- 搜索
- 新增部门安全检查
- 部门安全检查二维码

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 业务编号 | 系统编号 |
| 业务状态 | 业务状态 |
| 检查日期 | 检查日期 |
| 检查结果 | 检查结果 |
| 检查部门 | 被检查部门 |
| 检查人 | 检查人姓名 |
| 创建时间 | 创建时间 |
| 备注信息 | 备注信息 |
| 操作 | 详情/编辑 |
