# 活动设置

## 功能定位
活动设置模块用于配置活动类别，包含活动类别标签页。

## 页面结构

### 标签页
- 活动类别

### 活动类别标签页

#### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 活动类别 | 文本输入 | 按活动类别搜索 |

#### 操作按钮
- 重置
- 搜索
- 新增活动类别

#### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 活动类别 | 活动类别名称 |
| 状态 | 启用/禁用 |
| 显示顺序 | 排序号 |
| 备注信息 | 备注信息 |
| 操作 | 编辑/删除 |
