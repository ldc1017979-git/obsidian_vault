# 监控设备设置

## 功能定位
监控设备设置模块用于配置监控设备名称和外部维护单位信息。

## 页面结构

### 标签页
- 监控设备名称
- 外部维护单位

### 监控设备名称标签页

#### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 监控设备名称 | 文本输入 | 按设备名称搜索 |

#### 操作按钮
- 重置
- 搜索
- 新增监控设备名称

#### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 监控设备名称 | 设备名称 |
| 数量 | 设备数量 |
| 所属维护类型 | 维护类型 |
| 状态 | 启用/禁用 |
| 显示顺序 | 排序号 |
| 备注信息 | 备注信息 |
| 操作 | 编辑/删除 |

### 外部维护单位标签页

#### 操作按钮
- 新增外部维护单位

#### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 单位名称 | 维护单位名称 |
| 联系人 | 联系人 |
| 联系电话 | 联系电话 |
| 地址 | 单位地址 |
| 状态 | 启用/禁用 |
| 操作 | 编辑/删除 |
