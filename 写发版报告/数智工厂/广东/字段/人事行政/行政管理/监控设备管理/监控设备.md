# 监控系统设备巡检维修

## 功能定位
监控系统设备巡检维修模块用于管理企业监控设备的巡检和维修记录。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 单据编号 | 文本输入 | 按单据编号搜索 |
| 维护人/单位 | 文本输入 | 按维护人或单位搜索 |
| 巡检维修日期 | 日期范围 | 选择巡检维修日期区间 |
| 状态 | 下拉选择 | 按状态筛选 |

### 操作按钮
- 重置
- 搜索
- 新增

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 单据编号 | 系统编号 |
| 巡检维修日期 | 巡检维修日期 |
| 维护类型 | 维护类型 |
| 维护人/单位 | 维护人或单位 |
| 联系人 | 联系人 |
| 状况 | 设备状况 |
| 制单人 | 制单人 |
| 创建时间 | 创建时间 |
| 签字状态 | 签字状态 |
| 单据状态 | 单据状态 |
| 操作 | 详情/编辑 |
