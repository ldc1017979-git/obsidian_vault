# 蒸汽表抄表明细

## 页面概述

- **功能说明**：查看蒸汽表的采集抄表数据明细，支持按分组树和采集时间筛选，包含质量累计流量、热量累计流量、温度、压力、蒸汽密度等蒸汽专用参数
- **URL**：`https://gdmms.y1b.cn:8424/#/device-manage/energy-manage/meter-data/steam-meter-reading`

## 左侧分组树

- **功能**：按分组层级选择蒸汽表，点击树节点可筛选对应蒸汽表的抄表数据
- **树形结构示例**：
  - 物流门总表
    - 一车间生产线
    - 一车间化糖
    - 一车间热水
    - 二车间生产线
    - 二车间化糖
    - 二车间热水
    - 三车间生产线
    - 三车间化糖
    - 三车间热水
    - 糖厂

## 交互说明

1. 左侧为分组树，点击树节点可筛选对应蒸汽表的抄表数据
2. 支持按采集时间范围和采集表名进行筛选
3. 蒸汽表特有字段：质量累计流量、热量累计/瞬时流量、温度、压力、蒸汽密度
4. 表格数据按采集时间倒序排列
5. 每行支持编辑操作
