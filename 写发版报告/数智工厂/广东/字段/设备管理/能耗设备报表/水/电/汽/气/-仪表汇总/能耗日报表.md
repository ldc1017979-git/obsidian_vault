# 能耗日报表

## 页面概述

能耗日报表用于查看每日能源消耗情况，支持按电表、水表、蒸汽表、燃气表分类查看，展示各仪表的起始/截止读数和用量统计。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/device/report-forms/energy/direct-statement/energy-consumption`
- **所属模块**: 能耗/设备报表 > 能源直报报表

## 交互说明

1. 通过Tab切换不同能源类型（电表/水表/蒸汽表/燃气表）
2. 支持按能源层级类型、抄表日期、采集表名、所属分组和统计用量筛选
3. 支持导出数据
4. 用量 = (止码读数 - 起码读数) × 倍率
