# 能源层级统计报表

## 页面概述

能源层级统计报表用于按能源层级（基地总表/区域分表/车间子表/位置仪表）统计能源消耗，支持电表、水表、蒸汽表、燃气表分类查看，展示各层级的用电量和电损量。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/device/report-forms/energy/direct-statement/hierarchy-statistics`
- **所属模块**: 能耗/设备报表 > 能源直报报表

| 序号 | Tab名称 | 说明 |

| 4 | 燃气表 | 燃气层级统计 |

## 搜索字段

| 序号 | 字段名称 | 输入类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 能源层级类型 | 下拉选择 | 能源层级分类筛选 |
| 2 | 分组名称 | 文本输入 | 分组名称搜索 |
| 3 | 抄表日期 | 日期范围 | 开始日期-结束日期 |
| 4 | 参与核算 | 开关 | 是否参与核算 |

## 交互说明

1. 通过Tab切换不同能源类型
2. 支持按能源层级类型、分组名称、抄表日期范围和参与核算筛选
3. 支持导出数据
4. 用于分析各层级能源消耗和电损情况
