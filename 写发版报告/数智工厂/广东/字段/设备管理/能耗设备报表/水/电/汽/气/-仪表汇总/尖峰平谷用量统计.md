# 尖峰平谷用量统计

## 页面概述

尖峰平谷用量统计用于按电价时段（尖/峰/平/谷）统计电力消耗，支持正向有功和反向有功两种统计维度，展示各电表在不同电价时段的读数和用量。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/device/report-forms/energy/direct-statement/spfv-dosage`
- **所属模块**: 能耗/设备报表 > 能源直报报表

## 交互说明

1. 通过Tab切换正向有功/反向有功统计维度
2. 支持按能源层级类型、采集表名、抄表日期范围筛选
3. 支持导出数据
4. 尖/峰/平/谷对应不同电价时段，用于电费成本分析
