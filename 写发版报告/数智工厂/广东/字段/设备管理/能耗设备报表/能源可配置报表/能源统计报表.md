# 能源统计报表

## 页面概述

能源统计报表用于按已配置的统计方案查看能源消耗数据，支持水表、电表分类查看，展示仪表层级、采集表名、起止读数和用量。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/device/report-forms/Energy-configurable-report/scheme-design-monthly`
- **所属模块**: 能耗/设备报表 > 能源可配置报表

## 页面截图

![能源统计报表](../../设备管理截图/能源统计报表.jpeg)

## 能源类型Tab

| 序号 | Tab名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 水表 | 水资源统计（默认） |
| 2 | 电表 | 电能统计 |

## 搜索字段

| 序号 | 字段名称 | 输入类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 能源统计方案 | 下拉选择 | 必填，选择已配置的统计方案 |
| 2 | 抄表日期 | 日期范围 | 开始日期-结束日期 |

## 操作按钮

| 序号 | 按钮名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 重置 | 重置搜索条件 |
| 2 | 搜索 | 按条件搜索 |
| 3 | 导出数据 | 导出报表数据 |

## 表格列信息（水表）

| 序号 | 列名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 仪表层级 | 仪表层级分类 |
| 2 | 采集表名 | 采集仪表名称 |
| 3 | 水表编号 | 水表编号 |
| 4 | 起码读数 | 起始读数 |
| 5 | 止码读数 | 截止读数 |
| 6 | 用水量 | 实际用水量 |

## 数据示例

当前页面暂无数据，需先选择统计方案和日期范围后查询。

## 交互说明

1. 需先选择能源统计方案（必填），再选择抄表日期范围
2. 通过Tab切换水表/电表视图
3. 支持导出数据
4. 统计方案需在"能源统计报表-配置方案"页面预先配置
