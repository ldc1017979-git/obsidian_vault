# 能源统计报表-配置方案

## 页面概述

能源统计报表-配置方案用于配置可自定义的能源统计报表方案，支持按不同维度（按天/按月）和仪表类型（电表/水表/蒸汽表/燃气表）创建统计方案，供能源统计报表页面使用。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/device/report-forms/Energy-configurable-report/scheme-design`
- **所属模块**: 能耗/设备报表 > 能源可配置报表

## 搜索字段

| 序号 | 字段名称 | 输入类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 方案名称 | 文本输入 | 报表方案名称搜索 |
| 2 | 统计维度 | 下拉选择 | 统计维度筛选（按天统计/按月统计等） |
| 3 | 统计仪表类型 | 下拉选择 | 仪表类型筛选（电表/水表/蒸汽表/燃气表） |

## 交互说明

1. 支持新增、编辑、删除报表方案
2. 方案配置后可在"能源统计报表"页面选择使用
3. 统计维度支持按天统计和按月统计
4. 统计仪表类型支持电表、水表、蒸汽表、燃气表
