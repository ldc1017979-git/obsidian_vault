# 各项能源分组统计表

## 页面概述

各项能源分组统计表用于按车间/项目分组统计水、电、蒸汽、天然气等各项能源消耗量，支持周期统计和班次统计两种维度，展示各分组的仪表数量和用量。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/device/report-forms/Energy-configurable-report/base-statistics`
- **所属模块**: 能耗/设备报表 > 能源可配置报表

## 页面截图

![各项能源分组统计表](../../设备管理截图/各项能源分组统计表.jpeg)

## 统计维度Tab

| 序号 | Tab名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 周期统计 | 按时间周期统计（默认） |
| 2 | 班次统计 | 按班次统计 |

## 搜索字段

| 序号 | 字段名称 | 输入类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 抄表日期 | 日期范围 | 开始日期-结束日期 |

## 操作按钮

| 序号 | 按钮名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 重置 | 重置搜索条件 |
| 2 | 搜索 | 按条件搜索 |
| 3 | 导出数据 | 导出报表数据 |
| 4 | 设定统计方案 | 配置分组统计方案 |

## 表格列信息

| 序号 | 列名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 车间/项目 | 分组名称 |
| 2 | 水-水表 | 水表数量 |
| 3 | 水-用量(t) | 用水量（吨） |
| 4 | 电-电表 | 电表数量 |
| 5 | 电-用量(kWh) | 用电量（千瓦时） |
| 6 | 蒸汽-蒸汽表 | 蒸汽表数量 |
| 7 | 蒸汽-用量(t) | 蒸汽用量（吨） |
| 8 | 天然气-燃气表 | 燃气表数量 |
| 9 | 天然气-用量(m³) | 天然气用量（立方米） |

## 数据示例

当前页面暂无数据，需先设定统计方案后选择日期范围查询。

## 交互说明

1. 支持周期统计和班次统计两种维度切换
2. 需先通过"设定统计方案"配置分组方案
3. 选择抄表日期范围后搜索
4. 支持导出数据
5. 综合展示水、电、蒸汽、天然气四类能源的分组用量
