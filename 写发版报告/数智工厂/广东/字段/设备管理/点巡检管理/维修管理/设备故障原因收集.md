# 设备故障原因收集

## 页面概述

设备故障原因收集页面用于维护设备故障原因的基础数据字典，支持新增、编辑和删除故障原因，为维修管理和故障分析提供标准化的故障原因分类。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/device/inspection-deivce/inspection-deivce/cause`
- **所属模块**: 点巡检管理 > 维修管理

| 序号 | 列名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 故障原因 | 故障原因名称 |
| 2 | 备注 | 故障原因备注说明（适用设备范围） |
| 3 | 操作 | 编辑、删除 |

## 新增/编辑弹窗字段

| 序号 | 字段名称 | 数据类型 | 输入类型 | 长度限制 | 是否必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 故障原因 | String | 文本输入 | 50 | 是 | 故障原因名称 |
| 2 | 备注 | String | 文本域 | 500 | 否 | 故障原因备注说明（适用设备范围） |

## 交互说明

1. 点击"新增故障原因"按钮可添加新的故障原因
2. 点击"编辑"按钮可修改已有故障原因
3. 点击"删除"按钮可删除故障原因
4. 故障原因数据用于维修管理和故障分析中的标准化分类
