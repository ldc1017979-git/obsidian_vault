# CIP清洁点巡检记录

## 页面概述

- **功能说明**：记录CIP清洁点巡检的执行结果，包括检查单号、检查情况、审批签字等
- **URL**：`https://gdmms.y1b.cn:8424/#/device-manage/device/inspection-deivce/point-inspection/cip-record`

## 左侧树形导航

- 支持按计划组分类的树形导航筛选

## 交互说明

1. 左侧为树形导航，可按计划组分类筛选
2. 支持多维度筛选：关键字、资产类型、单据状态、执行人、时间范围、周期
3. 支持展开更多筛选条件
4. 支持批量审批通过操作
5. 每条记录支持查看详情
6. 记录包含两级审批签字流程
