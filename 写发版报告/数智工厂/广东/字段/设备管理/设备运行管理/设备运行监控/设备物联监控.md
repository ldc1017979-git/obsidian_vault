# 设备物联监控

## 页面概述

设备物联监控页面用于实时监控设备运行状态，通过物联网技术采集设备数据，以卡片形式展示各产线设备的资产类型、设备台账和所属岗位等信息。支持按设备类型和产线筛选。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/equipment-operate/Operation-monitoring/iot-monitoring`
- **所属模块**: 设备运行管理 > 设备运行监控

| 序号 | 字段名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 设备名称 | 设备名称（如"一线码垛机"） |
| 2 | 资产类型 | 资产分类路径（如"生产设备>一车间>一线>码垛工序"） |
| 3 | 设备台账 | 对应设备台账名称（如"一车间码垛机组一线"） |
| 4 | 所属岗位 | 设备所属岗位（如"码垛"） |

## 交互说明

1. 通过单选按钮切换设备类型（生产设备/检测设备/辅助设备）
2. 通过Tab标签切换不同产线
3. 点击设备卡片可进入设备物联监控详情页面
4. 详情页面展示设备的实时运行数据和状态信息
