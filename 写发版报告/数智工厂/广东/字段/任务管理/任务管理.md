# 任务管理

## 模块概述

- **功能说明**：用于管理系统任务的创建、分配、跟踪和验收
- **所属模块**：任务管理
- **页面URL**：`https://gdmms.y1b.cn:8424/#/taskCenter/taskManagement`

## 框架结构

```
任务管理
├── 任务管理（业务单据主页面）
│   ├── 搜索表单
│   ├── 数据列表
│   └── 发布任务（常规任务、父子级任务）
├── 任务设置
│   ├── 任务类型
│   ├── 来源渠道
│   ├── 问题分类
│   ├── 重复/相似类型
│   └── 默认抄送人
└── 任务分析（仪表盘）
```

#### 仪表盘说明

该页面是任务管理数据分析的核心展示页面，包含以下特点：

1. **数据可视化**：通过图表和数字卡片直观展示任务数据
2. **时间筛选**：支持按日期范围筛选数据
3. **多维度分析**：从任务状态、类型、来源、部门等多个维度进行分析
4. **逾期预警**：提供即将逾期任务的提醒功能
5. **趋势分析**：展示任务完成和发布的趋势变化
