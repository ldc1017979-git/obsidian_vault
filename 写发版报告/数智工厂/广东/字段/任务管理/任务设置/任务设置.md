# 任务设置

## 页面概述

- **功能说明**：配置任务相关的基础数据，包括任务类型、来源渠道、问题分类等
- **所属模块**：任务管理 > 任务设置
- **页面URL**：`https://gdmms.y1b.cn:8424/#/taskCenter/taskSetUp`

## 标签页结构

| 序号 | 标签名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 任务类型 | 管理任务的分类类型（如集团层级、基地层级、部门层级、班组层级） |
| 2 | 来源渠道 | 管理任务的来源渠道（如集团、基地） |
| 3 | 问题分类 | 管理任务涉及的问题分类 |
| 4 | 重复/相似类型 | 管理重复任务和相似任务的类型配置 |
| 5 | 默认抄送人 | 设置任务创建时的默认抄送范围 |

### 标签页五：默认抄送人

#### 功能说明

设置任务创建时的默认抄送范围，设置后在创建所有任务时会自动默认添加至抄送。

#### 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 点击选择默认抄送范围 | 选择需要默认抄送的人员或部门 |

#### 说明文字

- "设置后在创建所有的任务时会自动默认添加至抄送"
