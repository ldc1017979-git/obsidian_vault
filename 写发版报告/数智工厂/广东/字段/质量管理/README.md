# 质量管理模块

## 模块概述

质量管理模块主要负责产品质量的检测、控制和追溯工作，确保生产过程中的质量符合标准要求。

## 模块结构

### QC质量控制
- 原材料复检单
- 空罐检验
  - 红牛空罐信息确认单
  - 内涂膜检验报告
  - 空罐卷封检验报告
  - 标签标识检验报告
  - 空罐进货检验报告
  - 顶盖/底盖检验报告
  - 热缩膜检验报告
  - 纸皮进货检验报告
  - 战马空罐送检信息表
  - 战马空罐质量检验报告
  - 战马标签标识检验报告
- 原材料使用通知单
- 内容物留样记录
- 内容物信息及使用通知单
- 原料质量异常处置
- VB12管理
  - VB12称量人编号
  - VB12入库检测单
  - VB12异常库存控制

### QA质量保证
- 法定节假日
- 食安计划安排
- 日自查任务
- 自查项目配置
- 品管部每日自查记录
- 生产部每日自查记录
- 储运部每日自查记录
- 每日食品安全检查总表
- 日自查问题清单

### 计量管理
- 职业病因素检测
- 环境因素检测
- 生产现场人员辐射检测
- 成品外检
- 内容物外检
- 检测仪器外检

### 基础信息管理
- 打码取样信息表
- 基地红牛生产工艺流程图

### 追溯管理
- 产品追溯调查

## 文件说明

- 所有表单均以Markdown格式保存
- 截图保存在"质量管理截图"文件夹中
- 每个表单文件包含：字段信息、操作按钮、业务说明等
