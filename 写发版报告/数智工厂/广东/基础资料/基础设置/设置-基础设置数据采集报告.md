## 基础设置概述

**页面路径**: `设置 > 基础设置`

基础设置模块是数智工厂系统的核心配置中心，负责管理系统运行所需的基础数据。该模块包含以下6个主要功能子模块：

| 子模块 | 功能描述 |
| :--- | :--- |
| **货品分类** | 管理物料组编码、分类名称及描述信息 |
| **计量单位** | 管理系统中使用的各种计量单位 |
| **部门管理** | 管理公司组织架构中的部门信息 |
| **使用地点** | 管理厂区内各使用地点及其负责人 |
| **移动类型** | 定义库存移动的类型（如入库、出库、移库等） |
| **领料类型** | 定义领料申请的类型（如维修、保养、清洁等） |
