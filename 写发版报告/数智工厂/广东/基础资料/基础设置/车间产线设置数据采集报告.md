## 概述

**页面路径**: `设置 > 车间产线设置`

**功能描述**: 管理工厂车间和产线的基础配置，支持车间和产线的新增、编辑、删除操作。

**数据采集时间**: 2026年5月6日

**数据来源**: `https://gdmms.y1b.cn:8424/#/setting/production-line`

**车间数量**: 3个车间（一车间、二车间、三车间）

**产线数量**: 6条产线（一线至六线）

## 车间管理

### 车间列表

| 序号 | 车间名称 | 操作 |
| :--- | :--- | :--- |
| 1 | 一车间 | 编辑 / 删除 |
| 2 | 二车间 | 编辑 / 删除 |
| 3 | 三车间 | 编辑 / 删除 |

### 车间管理说明

- 系统支持三个车间的管理：一车间、二车间、三车间
- 每个车间可以独立配置和管理
- 支持对车间进行编辑和删除操作

## 新增表单字段说明

### 新增车间表单

| 字段名称 | 必填 | 说明 |
| :--- | :--- | :--- |
| 车间名称 | ✅ 是 | 车间的名称标识 |

### 新增产线表单

| 字段名称 | 必填 | 说明 |
| :--- | :--- | :--- |
| 产线名称 | ✅ 是 | 产线的名称标识 |
| 车间 | ✅ 是 | 产线所属的车间（下拉选择） |

## 操作功能说明

### 车间管理操作

| 操作按钮 | 功能说明 |
| :--- | :--- |
| 新增车间 | 弹出新增车间对话框，添加新的车间 |
| 编辑 | 修改已存在的车间信息 |
| 删除 | 删除指定的车间记录 |

### 产线管理操作

| 操作按钮 | 功能说明 |
| :--- | :--- |
| 新增产线 | 弹出新增产线对话框，添加新的产线 |
| 编辑 | 修改已存在的产线信息 |
| 删除 | 删除指定的产线记录 |

### 弹窗操作

| 操作按钮 | 功能说明 |
| :--- | :--- |
| 确定 | 保存新增或修改的信息并关闭弹窗 |
| 取消 | 取消操作并关闭弹窗 |
