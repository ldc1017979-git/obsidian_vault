## 概述

**页面路径**: `设置 > 设置工作台`

**功能描述**: 管理系统中个性化工作台的配置，支持根据部门、岗位、人员设置不同的工作台布局，实现个性化的系统首页展示。

**数据采集时间**: 2026年5月6日

**数据来源**: `https://gdmms.y1b.cn:8424/#/setting/workbench-set`

**配置总数**: 1个（系统预置通用工作台）

**系统说明**: 通过个性化工作台，可以根据具体的部门、岗位、人员进行配置工作台，如果没有配置的，将会直接进入到系统默认工作台中。

## 新建/编辑工作台表单

### 第一步：填写基础信息

#### 表单字段说明

| 字段名称 | 必填 | 说明 |
| :--- | :--- | :--- |
| 工作台名称 | ✅ 是 | 工作台的显示名称 |
| 工作台状态 | ✅ 是 | 选择启用或禁用该工作台 |
| 显示顺序 | ✅ 是 | 数值越大，工作台越靠前显示 |
| 工作台描述 | ❌ 否 | 对工作台的描述说明 |
| 使用对象 | ✅ 是 | 点击选择工作台适用的部门/岗位/人员 |

#### 工作台状态选项

| 选项 | 说明 |
| :--- | :--- |
| 启用 | 工作台可被使用 |
| 禁用 | 工作台不可被使用 |

#### 显示顺序说明

> 数值越大，越靠前

## 工作台组件说明

### 工作流控中心

包含以下子模块：

| 子模块 | 说明 |
| :--- | :--- |
| 我的待办 | 待处理的工作任务 |
| 我发起的 | 我发起的工作流程 |
| 我处理的 | 已处理的工作流程 |
| 抄送我的 | 抄送我的任务 |

### 公告通知

展示内容：
- 公告标题
- 公告类型（如：公司公告）
- 发布时间

示例公告：
- 2025年度总结暨表彰会以及2026年元宵晚会的通知（2026-02-26）
- 2026年春节假期安全告知书（2026-02-06）
- 关于公司2026年元旦放假安排的通知（2025-12-29）

### 生产系统达成概况

展示的生产数据指标：
- 年度完成进度（百分比）
- 累计产量 / 计划产量（万罐）
- 上月完成进度（百分比）
- 实际产量 / 计划产量（万罐）

### 安/质/环风险预警台

安全、质量、环保指标展示：
- 批质量无事故天数
- 重大环保无事故天数
- 重大安全无事故天数
- 无1-7级工伤天数
- 市场投诉小于10的天数

## 操作功能说明
