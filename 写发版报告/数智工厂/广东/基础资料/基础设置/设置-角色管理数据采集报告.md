## 角色管理概述

**页面路径**: `设置 > 角色管理`

角色管理模块是数智工厂系统的权限管理核心，负责管理系统中的角色定义、权限分配和成员管理。该模块包含以下核心功能：

| 功能项 | 描述 |
| :--- | :--- |
| **角色列表** | 展示所有角色，支持搜索、筛选和排序 |
| **新建角色** | 创建新的角色并配置权限 |
| **编辑角色** | 修改角色信息和权限配置 |
| **删除角色** | 删除不再需要的角色 |
| **角色架构图** | 可视化展示角色层级关系 |

## 角色编辑配置

### 基础信息配置

**页面路径**: `设置 > 角色管理 > 编辑角色 > 基础信息`

**功能描述**: 配置角色的基本信息，包括角色名称、所属部门、数据权限和状态。

**页面截图**:

![编辑角色-基础信息](截图/设置-角色管理-编辑角色-基础信息.png)

**配置项说明**:

| 配置项 | 类型 | 说明 |
| :--- | :--- | :--- |
| **角色名称** | 必填文本 | 角色的唯一标识名称 |
| **所属部门** | 文本 | 角色所属的部门（可选） |
| **数据权限** | 单选 | 个人/全部数据权限范围 |
| **状态** | 单选 | 启用/停用角色 |
| **角色备注** | 文本 | 角色的备注说明（可选） |

**示例配置（特种设备审批人员）**:
- 角色名称：特种设备审批人员
- 所属部门：安全管理部
- 数据权限：全部
- 状态：启用
- 角色备注：（空）
