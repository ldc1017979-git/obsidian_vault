## 概述

**页面路径**: `设置 > 仓库设置`

**功能描述**: 管理厂区内各仓库的配置信息，包括仓库编码、SAP工厂编码、所属部门、仓管员权限等。

**数据采集时间**: 2026年5月6日

**数据来源**: `https://gdmms.y1b.cn:8424/#/setting/warehouse-manage`

**仓库总数**: 45个

## 操作功能说明

### 搜索与筛选

| 功能 | 说明 |
| :--- | :--- |
| 部门选择 | 通过树形结构选择所属部门进行筛选 |
| 仓库名称搜索 | 支持按仓库名称模糊搜索 |
| 仓库编码搜索 | 支持按仓库编码精确搜索 |
| SAP工厂编码搜索 | 支持按SAP工厂编码搜索 |
| 仓管员权限筛选 | 支持按仓管员权限筛选 |
| 查看仓库权限筛选 | 支持按查看仓库权限筛选 |

### 操作按钮

| 按钮 | 功能说明 |
| :--- | :--- |
| 重置 | 清空所有搜索条件，恢复默认状态 |
| 搜索 | 根据输入条件查询仓库列表 |
| 新增仓库 | 创建新的仓库记录 |
| 编辑 | 修改现有仓库信息 |
