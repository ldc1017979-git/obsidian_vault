## 配置表单说明

### 新增/编辑配置表单字段

| 字段名称 | 必填 | 说明 |
| :--- | :--- | :--- |
| 计划组名称 | ✅ 是 | 点巡检计划组的名称标识 |
| 备注 | ❌ 否 | 对该计划组的补充说明 |
| 关联图示 | ❌ 否 | 支持上传png/jpg/jpeg格式图片，最多6张 |
| 关联检查项 | ❌ 否 | 关联相关的检查项目 |

### 关联检查项字段

| 字段名称 | 说明 |
| :--- | :--- |
| 检查内容组名 | 检查项的分组名称 |
| 检查目的 | 该检查项的目的描述 |
| 备注 | 补充说明信息 |
| 检查项总数 | 该计划组包含的检查项数量 |

## 操作功能说明

### 主页面操作

| 操作按钮 | 功能说明 |
| :--- | :--- |
| 新增配置 | 打开新增点巡检计划组配置表单 |
| 编辑 | 编辑选中的点巡检计划组配置 |

### 配置表单操作

| 操作按钮 | 功能说明 |
| :--- | :--- |
| 关联检查项 | 打开检查项选择弹窗，关联检查项目 |
| 关闭 | 关闭表单，返回主页面 |
| 确定 | 保存配置信息 |

### 检查项选择弹窗操作

| 操作按钮 | 功能说明 |
| :--- | :--- |
| 重置 | 重置搜索条件 |
| 搜索 | 根据条件搜索检查项 |
| 关闭 | 关闭弹窗 |

### 检查项详情操作

| 操作按钮 | 功能说明 |
| :--- | :--- |
| 详情 | 查看检查项详细信息 |
| 删除 | 从计划组中移除该检查项 |
| 关闭 | 关闭详情弹窗 |
