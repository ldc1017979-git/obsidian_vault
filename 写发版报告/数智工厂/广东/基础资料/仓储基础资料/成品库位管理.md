# 成品库位管理

## 页面概述

- **功能说明**：用于管理成品库位信息，包括库位编码、所属工厂等
- **页面URL**：`/warehouse-manage/base-info/product-wscode`
- **所属模块**：仓储管理 > 基础信息

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 库存工厂编码 | 文本框 | 输入工厂编码搜索 |
| 2 | 库位信息 | 文本框 | 输入库位信息搜索 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新增库位 | 新增一个库位 |
| 4 | 导入库位 | 批量导入库位 |
| 5 | 编辑 | 编辑库位信息 |
| 6 | 删除 | 删除库位 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 序号 | 数字 | 序号 |
| 2 | 库存名称 | 文本 | 库存名称 |
| 3 | 库位编码 | 文本 | 库位编码 |
| 4 | 所属库存工厂编码 | 文本 | 所属库存工厂编码 |
| 5 | 备注信息 | 文本 | 备注信息 |
| 6 | 操作 | 按钮 | 编辑/删除按钮 |

## 交互说明

1. 在列表页可通过筛选条件查询库位信息
2. 数据量较大（共393条），支持分页浏览
