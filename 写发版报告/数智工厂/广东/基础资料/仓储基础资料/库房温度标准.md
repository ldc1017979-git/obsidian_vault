# 库房温度标准

## 页面概述

- **功能说明**：用于管理库房温度标准设置，配置各库房的适宜温度和湿度标准
- **页面URL**：`/warehouse-manage/base-info/warehouse-temperature-standard`
- **所属模块**：仓储管理 > 基础信息

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 新增库房温湿度标准 | 新增一条温湿度标准 |
| 2 | 编辑 | 编辑温湿度标准 |
| 3 | 删除 | 删除温湿度标准 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 库房区域名称 | 文本 | 库房区域名称 |
| 2 | 适宜温度标准 | 文本 | 适宜温度范围 |
| 3 | 适宜湿度标准 | 文本 | 适宜湿度范围 |
| 4 | 操作 | 按钮 | 编辑/删除按钮 |

## 交互说明

1. 库房温度标准用于配置各库房的温度标准信息
2. 支持新增、编辑和删除温度标准记录
3. 共8条记录
