# 原厂批次编码规则

## 页面概述

- **功能说明**：用于配置原厂批次编码规则，定义原料入库时的批次编码生成规则
- **页面URL**：`/warehouse-manage/base-info/ylrk/batch-code-rule`
- **所属模块**：仓储管理 > 基础信息 > 原料入库配置

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 新建 | 新增一条编码规则 |
| 2 | 编辑 | 编辑编码规则 |
| 3 | 删除 | 删除编码规则 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 条码 | 文本 | 物料条码（多个以逗号分隔） |
| 2 | 物料名称 | 文本 | 物料名称（多个以逗号分隔） |
| 3 | 供应商 | 文本 | 供应商名称 |
| 4 | 厂商 | 文本 | 厂商名称 |
| 5 | 批次规则 | 文本 | 批次编码生成规则 |
| 6 | 备注 | 文本 | 备注信息 |

## 交互说明

1. 在列表页可通过筛选条件查询批次编码规则
2. 数据量共35条
