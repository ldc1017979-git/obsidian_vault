# 供应商管理

## 功能定位
供应商管理模块用于管理仓储系统中所有供应商的基础信息，包括原材料、备件、综合物资、服务商、其他等分类的供应商数据维护。

## 页面结构

### 标签页分类
| 序号 | 标签名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 全部 | 显示所有类别供应商 |
| 2 | 原材料 | 原材料类供应商 |
| 3 | 备件 | 备件类供应商 |
| 4 | 综合物资 | 综合物资类供应商 |
| 5 | 服务商 | 服务商类供应商 |
| 6 | 其他 | 其他类供应商 |
