# 原料抽检标准

## 页面概述

- **功能说明**：用于配置原料抽检标准，定义原料入库时的抽检规则
- **页面URL**：`/warehouse-manage/base-info/ylrk/standard-config`
- **所属模块**：仓储管理 > 基础信息 > 原料入库配置

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 新建 | 新增一条抽检标准 |
| 2 | 编辑 | 编辑抽检标准 |
| 3 | 删除 | 删除抽检标准 |
| 4 | 关闭 | 关闭操作 |
| 5 | 保存 | 保存配置 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 条码 | 文本 | 物料条码（多个以逗号分隔） |
| 2 | 物料名称 | 文本 | 物料名称（多个以逗号分隔） |
| 3 | 抽检方式 | 文本 | 抽检方式（按比例抽检/固定抽检） |
| 4 | 检验标准描述 | 文本 | 检验标准描述 |
| 5 | 抽检阈值 | 数字 | 抽检阈值（带单位） |
| 6 | 应抽检数 | 数字 | 应抽检数量（带单位） |

## 交互说明

1. 共7条原料抽检标准记录
2. 可通过"新建"按钮新增抽检标准配置
