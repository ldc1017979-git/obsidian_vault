# 纸皮版本信息

## 功能定位
纸皮版本信息模块用于管理纸皮的版本信息，包括版本名称、物料编号、纸皮版本类型、纸皮图片等。

## 页面结构

### 搜索条件
| 序号 | 字段名称 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 版本名 | 文本输入 | 按版本名搜索 |
| 2 | 物料编号 | 文本输入 | 按物料编号搜索 |
| 3 | 产品类别 | 下拉选择 | 按产品类别筛选 |
| 4 | 可用状态 | 下拉选择 | 按可用状态筛选 |
| 5 | 版本类型 | 下拉选择 | 按版本类型筛选 |
| 6 | 创建时间 | 日期范围 | 按创建时间范围筛选 |

### Tab切换
| Tab名称 | 说明 |
| :--- | :--- |
| 红牛纸皮 | 红牛品牌纸皮版本信息 |
| 战马纸皮 | 战马品牌纸皮版本信息 |

### 操作按钮
| 按钮名称 | 描述 |
| :--- | :--- |
| 重置 | 重置搜索条件 |
| 搜索 | 执行搜索 |
| 新建 | 打开新增纸皮版本信息页面 |

### 列表字段
| 序号 | 字段名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 序号 | 自动编号 |
| 2 | 版本名称 | 版本名称描述 |
| 3 | 纸皮版本 | 促销版/非促销版 |
| 4 | 物料编号 | 物料编号 |
| 5 | 可用状态 | 开关控件，启用/禁用 |
| 6 | 纸皮图片 | 纸皮图片预览 |
| 7 | 创建人 | 创建人姓名 |
| 8 | 创建时间 | 创建时间 |
| 9 | 更新人 | 更新人姓名 |
| 10 | 更新时间 | 更新时间 |
| 11 | 操作 | 编辑 |

## 新增表单字段

点击"新建"按钮跳转至新增页面，页面包含以下区域：

### Tab页
| Tab名称 | 说明 |
| :--- | :--- |
| 详情信息 | 版本详情信息（默认选中） |

### 基础信息区域
| 序号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 产品大类 | 下拉选择框（禁用） | 否 | 默认"红牛" |
| 2 | 产品类型 | 下拉选择框 | **是** | 选择产品类型 |
| 3 | 产品类别 | 下拉选择框 | **是** | 选择产品类别 |
| 4 | 版本名称 | 文本输入框 | **是** | 版本名称描述 |
| 5 | 物料编号 | 文本输入框 | **是** | 物料编号 |
| 6 | 纸皮版本 | 单选按钮 | **是** | 促销版/非促销版 |
| 7 | 是否启用 | 开关控件 | **是** | 启用/禁用（默认启用） |
| 8 | 备注 | 文本输入框 | 否 | 备注说明 |

### 纸皮图片区域
| 序号 | 字段名称 | 类型 | 描述 |
| :--- | :--- | :--- | :--- |
| 1 | 纸皮图片 | 图片上传 | 仅支持png/jpg/jpeg格式，最多上传2张 |

### 操作按钮
| 按钮名称 | 描述 |
| :--- | :--- |
| 返回 | 返回列表页 |
| 保存 | 保存版本信息 |
