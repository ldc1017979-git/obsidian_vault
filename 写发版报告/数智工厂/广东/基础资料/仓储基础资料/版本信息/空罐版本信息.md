# 空罐版本信息

## 功能定位
空罐版本信息模块用于管理空罐的版本信息，包括版本号、版本名称、空罐物料编号、顶盖物料编号、版本类型、空罐图片等。

## 页面结构

### 搜索条件
| 序号 | 字段名称 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 版本号 | 文本输入 | 按版本号搜索 |
| 2 | 版本名 | 文本输入 | 按版本名搜索 |
| 3 | 空罐物料编号 | 文本输入 | 按空罐物料编号搜索 |
| 4 | 顶盖物料编号 | 文本输入 | 按顶盖物料编号搜索 |
| 5 | 可用状态 | 下拉选择 | 按可用状态筛选 |
| 6 | 版本类型 | 下拉选择 | 按版本类型筛选 |
| 7 | 创建时间 | 日期范围 | 按创建时间范围筛选 |

### Tab切换
| Tab名称 | 说明 |
| :--- | :--- |
| 红牛空罐 | 红牛品牌空罐版本信息 |
| 战马空罐 | 战马品牌空罐版本信息 |

### 操作按钮
| 按钮名称 | 描述 |
| :--- | :--- |
| 重置 | 重置搜索条件 |
| 搜索 | 执行搜索 |
| 新建 | 打开新增空罐版本信息页面 |

## 新增表单字段

点击"新建"按钮跳转至新增页面，页面包含Tab切换和以下区域：

### Tab页
| Tab名称 | 说明 |
| :--- | :--- |
| 详情信息 | 版本详情信息（默认选中） |

### 基础信息区域
| 序号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 产品大类 | 下拉选择框（禁用） | 否 | 默认"红牛" |
| 2 | 产品类型 | 下拉选择框 | **是** | 选择产品类型 |
| 3 | 版本号 | 文本输入框 | **是** | 版本编号 |
| 4 | 版本名称 | 文本输入框 | **是** | 版本名称描述 |
| 5 | 空罐物料编号 | 文本输入框 | **是** | 空罐物料编号 |
| 6 | 顶盖物料编号 | 文本输入框 | **是** | 顶盖物料编号 |
| 7 | 版本类型 | 单选按钮 | **是** | 促销版/非促销版 |
| 8 | 是否启用 | 开关控件 | **是** | 启用/禁用（默认启用） |
| 9 | 备注 | 文本输入框 | 否 | 备注说明 |

### 空罐图片区域
| 序号 | 字段名称 | 类型 | 描述 |
| :--- | :--- | :--- | :--- |
| 1 | 顶盖图片 | 图片上传 | 支持png/jpg/jpeg/gif格式 |
| 2 | 罐身图片 | 图片上传 | 支持png/jpg/jpeg/gif格式 |
| 3 | 底盖图片 | 图片上传 | 支持png/jpg/jpeg/gif格式 |

### 操作按钮
| 按钮名称 | 描述 |
| :--- | :--- |
| 返回 | 返回列表页 |
| 保存 | 保存版本信息 |
