# 计量报废申请单

## 页面概述

- **所属模块**: 数据录入端 > 质量管理 > 计量管理
- **页面URL**: `#/quality-manage/index13/measure/measure-scrap`
- **页面类型**: 列表页面（支持搜索/筛选/新建）

![计量报废申请单_主页面](../质量管理截图/计量管理_计量报废申请单_主页面.png)

## 筛选条件字段

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 申请日期 | 日期范围选择器 | 空 | 可选 | 按申请日期范围筛选 |
| 2 | 仪器名称 | 文本框 | 空 | 可选 | 按仪器名称模糊搜索 |
| 3 | 单据状态 | 下拉框 | 全部 | 可选 | 按单据状态筛选 |

## 表格列字段

| 序号 | 字段名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 序号 | 自动编号 |
| 2 | 报废单号 | 报废申请单号 |
| 3 | 仪器名称 | 报废仪器名称 |
| 4 | 仪器编号 | 内部管理编号 |
| 5 | 固资编号 | 固定资产编号 |
| 6 | 型号规格 | 仪器型号 |
| 7 | 使用部门 | 所属部门 |
| 8 | 报废原因 | 报废原因说明 |
| 9 | 申请日期 | 申请时间 |
| 10 | 申请人 | 申请人姓名 |
| 11 | 审批状态 | 待审批/已批准/已驳回 |
| 12 | 操作 | 编辑/查看/删除 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空筛选条件 |
| 2 | 搜索 | 执行筛选查询 |
| 3 | 新建 | 新建报废申请 |
| 4 | 编辑 | 编辑选中记录 |
| 5 | 签字提交 | 提交审批 |
