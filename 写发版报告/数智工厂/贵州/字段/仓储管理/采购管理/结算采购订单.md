# 结算采购订单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 采购管理 → 原料/备件与综合物资 → 结算采购订单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/buy/settle`
- **功能说明**: 管理采购订单的结算操作，记录结算原因、结算日期等信息

## 交互说明

1. 进入页面后默认显示所有结算采购订单列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的结算订单
4. 点击"详情"按钮可查看结算订单详细信息
5. 新建时需选择采购订单类型、填写结算日期和结算原因
6. 通过"选择采购单"按钮选择需要结算的采购订单
7. 详情页包含"结算采购订单详情"、"单据日志"、"审批流程"三个标签页
