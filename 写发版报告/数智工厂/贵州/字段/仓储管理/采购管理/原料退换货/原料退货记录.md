# 原料退货记录

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 采购管理 → 原料/备件与综合物资 → 原料退换货 → 原料退货记录
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/buy/Returns/raw-return-record`
- **功能说明**: 记录和管理原料退货信息，包括退库单的创建、审核和跟踪

## 交互说明

1. 进入页面后默认显示所有原料退货记录列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的退货记录
4. 点击"详情"按钮可查看退货记录详细信息
5. 新建时需先选择"退到采购单"，系统自动填充产品大类和供应商
6. 详情页包含"原料退货记录详情"、"单据日志"、"审批流程"三个标签页
