# 原料采购单

## 页面概述

- **功能模块**: 仓储管理 → 采购管理 → 原料/备件与综合物资 → 原料采购单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/buy/routine-purchase/order-copy/raw`
- **功能说明**: 管理原材料类采购订单，包括原料的采购、入库、退货等全流程管理

## 交互说明

1. 进入页面后默认显示原料类采购订单列表
2. 支持多条件组合搜索筛选
3. 点击"详情"按钮可查看采购订单详细信息
4. 待入库状态的订单可点击"确认入库"进行入库操作
5. 与全部采购订单相比，增加了产品大类、物料条码、换货数量等字段
6. 详情页包含采购单详情、退货信息、冲销信息、入库信息、单据日志、审批流程等Tab标签
7. 新建原料采购单时需先填写基本信息（需求月份、供应商等），再添加商品明细
