# 原料入库检查表

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原料到货验收 → 原料入库检查表
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/check/raw-in-check`
- **功能说明**: 管理原料入库检查记录，记录入库检验信息

## 交互说明

1. 进入页面后默认显示所有原料入库检查表列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的检查表
4. 点击"详情"按钮可查看检查表详细信息
