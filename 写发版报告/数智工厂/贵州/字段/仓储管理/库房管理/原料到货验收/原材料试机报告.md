# 原材料试机报告

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原料到货验收 → 原材料试机报告
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/check/test-report`
- **功能说明**: 记录原材料试机检验报告，管理试机送样和检验信息

## 交互说明

1. 进入页面后默认显示所有原材料试机报告列表
2. 支持多条件组合搜索筛选
3. 点击"新增"按钮可创建新的试机报告
4. 点击"详情"按钮可查看试机报告详细信息
