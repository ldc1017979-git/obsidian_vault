# 成品质量检查

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 成品管理 → 成品质量检查
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/product-manage/product-stock/product-check`
- **功能说明**: 管理成品质量检查，支持解除库存限制和查看操作日志

## 交互说明

1. 进入页面后默认显示所有成品质量检查记录列表
2. 支持多条件组合搜索筛选
3. 点击"解除限制"可解除库存使用限制
4. 点击"日志"可查看操作日志

## 备注

> 本页面为质量检查记录管理页面，无"详情"和"新建"功能。支持解除限制和查看日志操作。
