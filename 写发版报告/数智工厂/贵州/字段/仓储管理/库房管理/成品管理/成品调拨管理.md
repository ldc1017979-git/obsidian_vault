# 成品调拨管理

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 成品管理 → 成品调拨管理
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/product-manage/product-stock/product_allot`
- **功能说明**: 管理成品调拨操作，记录交货工厂和收货工厂之间的调拨信息

## 交互说明

1. 进入页面后默认显示所有成品调拨记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增调拨"按钮可创建新的调拨单
4. 支持"提交签字"和"撤回"操作
5. 点击"详情"按钮可查看调拨记录详细信息
