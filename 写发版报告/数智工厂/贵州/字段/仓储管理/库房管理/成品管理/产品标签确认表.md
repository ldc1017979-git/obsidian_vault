# 产品标签确认表

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 成品管理 → 产品标签确认表
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/product-manage/product-label-confirm-form`
- **功能说明**: 管理产品标签确认记录，确认产品标签信息的准确性

## 交互说明

1. 进入页面后默认显示所有产品标签确认记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增"按钮可创建新的产品标签确认记录
4. 支持"签字提交"和"报告导出"操作
5. 点击"详情"按钮可查看标签确认记录详细信息
