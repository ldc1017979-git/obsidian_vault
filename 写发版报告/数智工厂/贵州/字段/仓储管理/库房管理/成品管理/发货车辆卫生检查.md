# 发货车辆卫生检查

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 成品管理 → 发货车辆卫生检查
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/product-manage/car-sanitary-inspection`
- **功能说明**: 管理发货车辆卫生检查记录，确保运输车辆符合装车卫生要求

## 交互说明

1. 进入页面后默认显示所有车辆卫生检查记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增"按钮可创建新的车辆卫生检查记录
4. 点击"详情"按钮可查看检查记录详细信息
5. 支持"反审"操作
