# 成品入库管理

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 成品管理 → 成品入库管理
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/product-manage/product-stock/product-in`
- **功能说明**: 管理成品入库操作，支持手动入库和自动入库

## 交互说明

1. 进入页面后默认显示所有成品入库记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增手动入库"按钮可手动创建入库单
4. 支持编辑、删除、审核、反审等操作
5. 点击"详情"按钮可查看入库记录详细信息
