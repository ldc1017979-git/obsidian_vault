# 成品出库管理

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 成品管理 → 成品出库管理
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/product-manage/product-stock/product_out`
- **功能说明**: 管理成品出库操作，支持手动出库和自动出库

## 交互说明

1. 进入页面后默认显示所有成品出库记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增手动出库"按钮可手动创建出库单
4. 点击"详情"按钮可查看出库记录详细信息
