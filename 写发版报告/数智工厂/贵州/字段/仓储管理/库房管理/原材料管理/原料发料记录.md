# 原料发料记录

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原材料管理 → 原料发料记录
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/material-manage/contents-give-out`
- **功能说明**: 记录原料的发料操作，关联需求单进行发料
