# 仓库原料移库单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原材料管理 → 仓库原料移库单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/material-manage/warehouse-raw-move`
- **功能说明**: 管理仓库间原料的移库操作，记录移出/移入仓库和数量信息

## 交互说明

1. 进入页面后默认显示所有仓库原料移库单列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的移库单
4. 点击"详情"按钮可查看移库单详细信息
