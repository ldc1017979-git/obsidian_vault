# 原料送检出库

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原材料管理 → 原料送检出库
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/material-manage/send-inspect`
- **功能说明**: 管理原料送检出库操作，记录送检信息和出库详情

## 交互说明

1. 进入页面后默认显示所有原料送检出库单列表
2. 支持多条件组合搜索筛选
3. 点击"新增送检出库"按钮可创建新的送检出库单
4. 点击"详情"按钮可查看送检出库单详细信息
