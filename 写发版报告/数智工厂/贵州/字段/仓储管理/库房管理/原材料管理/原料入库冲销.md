# 原料入库冲销

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原材料管理 → 原料入库冲销
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/material-manage/raw-write-off`
- **功能说明**: 管理原料入库单的冲销操作，记录冲销原因、冲销数量等信息
