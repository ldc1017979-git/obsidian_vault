# 入库送检记录退料

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原材料管理 → 入库送检记录退料
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/material-manage/raw-ret-materials`
- **功能说明**: 管理入库送检记录的退料操作，关联送检单进行退料

## 交互说明

1. 进入页面后默认显示所有入库送检记录退料列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的退料单
4. 点击"详情"按钮可查看退料记录详细信息
