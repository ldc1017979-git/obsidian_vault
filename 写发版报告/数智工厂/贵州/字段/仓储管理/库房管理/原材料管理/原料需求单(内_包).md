# 原料需求单(内/包)

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原材料管理 → 原料需求单(内/包)
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/material-manage/content-requirements`
- **功能说明**: 管理内容物/包装物原料的需求申请，记录需求信息和发料状态

## 交互说明

1. 进入页面后默认显示所有原料需求单列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的需求单
4. 点击"详情"按钮可查看需求单详细信息
