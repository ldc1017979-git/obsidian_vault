# 原料入库单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原材料管理 → 原料入库单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/material-manage/take-goods`
- **功能说明**: 管理原料的入库操作，记录原料入库、送检等信息

## 交互说明

1. 进入页面后默认显示所有原料入库单列表
2. 支持多条件组合搜索筛选
3. 点击"新建原料入库单"按钮可创建新的入库单
4. 点击"详情"按钮可查看入库单详细信息
5. 支持"冲销"操作进行入库冲销
