# 其他出库单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 备件与综合物资管理 → 其他出库单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/integrated-manage/ret-goods`
- **功能说明**: 管理非领料途径的出库操作，如退货出库、其他出库等

## 交互说明

1. 进入页面后默认显示所有其他出库单列表
2. 支持多条件组合搜索筛选
3. 点击"新建其他出库单"按钮可创建新的出库单
4. 点击"详情"按钮可查看出库单详细信息
5. 新建时需选择出库仓库
6. 可通过"添加"或"批量添加"选择出库商品
7. 详情页包含"出库单详情"、"单据日志"、"审批流程"三个标签页
