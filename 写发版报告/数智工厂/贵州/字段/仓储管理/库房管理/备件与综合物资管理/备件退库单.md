# 备件退库单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 备件与综合物资管理 → 备件退库单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/integrated-manage/spare-part-return`
- **功能说明**: 管理备件的退库操作，关联备件领用单进行退库

## 交互说明

1. 进入页面后默认显示所有备件退库单列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的退库单
4. 点击"详情"按钮可查看退库单详细信息
5. 新建退库单需先选择关联的备件领用单号，再添加退库商品
6. 退料入库按领用出库单原仓库同价退回
