# 资产入库申请

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 备件与综合物资管理 → 资产入库申请
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/integrated-manage/property-in-apply`
- **功能说明**: 管理资产入库申请，记录资产入库申请信息

## 交互说明

1. 进入页面后默认显示所有资产入库申请列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的入库申请
4. 点击"详情"按钮可查看入库申请详细信息
