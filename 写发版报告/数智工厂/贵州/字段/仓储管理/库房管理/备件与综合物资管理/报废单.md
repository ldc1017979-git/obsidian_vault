# 报废单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 备件与综合物资管理 → 报废单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/integrated-manage/scrap`
- **功能说明**: 管理备件与综合物资的报废操作，记录报废原因和报废商品信息

## 交互说明

1. 进入页面后默认显示所有报废单列表
2. 支持多条件组合搜索筛选
3. 点击"新建报废单"按钮可创建新的报废单
4. 点击"详情"按钮可查看报废单详细信息
