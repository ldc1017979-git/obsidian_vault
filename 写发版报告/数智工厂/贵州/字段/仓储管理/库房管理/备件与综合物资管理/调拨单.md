# 调拨单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 备件与综合物资管理 → 调拨单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/integrated-manage/allot`
- **功能说明**: 管理备件与综合物资的仓库间调拨操作

## 交互说明

1. 进入页面后默认显示所有调拨单列表
2. 支持多条件组合搜索筛选
3. 点击"新建调拨单"按钮可创建新的调拨单
4. 点击"详情"按钮可查看调拨单详细信息
5. 新建时需选择调出仓库和调入仓库
6. 可通过"添加"、"批量添加"或"导入"选择调拨商品
7. 详情页包含"调拨单详情"、"单据日志"、"审批流程"三个标签页
