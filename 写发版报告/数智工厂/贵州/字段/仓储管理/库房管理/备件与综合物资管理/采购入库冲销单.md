# 采购入库冲销单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 备件与综合物资管理 → 采购入库冲销单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/integrated-manage/buy-in-off`
- **功能说明**: 管理采购入库单的冲销操作，记录冲销原因、冲销数量等信息

## 交互说明

1. 进入页面后默认显示所有采购入库冲销单列表
2. 支持多条件组合搜索筛选
3. 点击"详情"按钮可查看冲销单详细信息
4. 新建时需通过"选择冲销物料"选择需要冲销的入库物料
5. 冲销数量不能超过可冲销数
6. 详情页包含"冲销信息"、"单据日志"、"审批流程"三个标签页
