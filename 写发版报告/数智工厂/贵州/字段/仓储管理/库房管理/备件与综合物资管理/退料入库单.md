# 退料入库单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 备件与综合物资管理 → 退料入库单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/integrated-manage/ret-supplier`
- **功能说明**: 管理领料出库后的退料入库操作，记录退料信息

## 交互说明

1. 进入页面后默认显示所有退料入库单列表
2. 支持多条件组合搜索筛选
3. 点击"新建退料入库单"按钮可创建新的退料入库单
4. 点击"详情"按钮可查看退料入库单详细信息
5. 新建时需先选择关联的领料出库单
6. 通过"选择商品"按钮选择退料商品
7. 详情页包含"退料入库单详情"、"单据日志"、"审批流程"三个标签页
