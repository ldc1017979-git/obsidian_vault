# 其他入库单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 备件与综合物资管理 → 其他入库单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/integrated-manage/other-in`
- **功能说明**: 管理非采购途径的入库操作，如赠送、调拨入库等

## 交互说明

1. 进入页面后默认显示所有其他入库单列表
2. 支持多条件组合搜索筛选
3. 点击"新建其他入库单"按钮可创建新的入库单
4. 点击"详情"按钮可查看入库单详细信息
5. 支持"打印全部条码"操作
6. 新建时需选择入库仓库
7. 可通过"添加"、"批量添加"或"导入货品"添加入库商品
8. 详情页包含"入库单详情"、"单据日志"、"审批流程"三个标签页
