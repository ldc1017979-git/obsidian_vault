# 危废库存明细

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 过程管理 → 危废管理 → 危废库存明细
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/auxiliary-materials/hazardous/inventory-details`
- **功能说明**: 查看危废库存明细，展示危废物品的当前库存信息

## 交互说明

1. 进入页面后默认显示所有危废库存明细列表
2. 支持多条件组合搜索筛选
3. 点击"贮存仓库信息"可查看仓库详细信息
4. 本页面为查看页面，数据由入库/出库操作自动更新
