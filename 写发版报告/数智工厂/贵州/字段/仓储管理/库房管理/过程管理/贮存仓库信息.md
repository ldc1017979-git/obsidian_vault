# 贮存仓库信息

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 过程管理 → 贮存仓库信息
- **页面URL**: `待填写`
- **功能说明**: 管理贮存仓库信息，记录仓库的基本信息、位置、容量等

## 交互说明

1. 进入页面后默认显示所有贮存仓库信息列表
2. 支持关键字和仓库名称搜索筛选
3. 点击"新增"按钮可创建新的贮存仓库记录
4. 点击"详情"按钮可查看贮存仓库详细信息
5. 支持编辑和删除操作
