# 危废基础资料

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 过程管理 → 危废管理 → 危废基础资料
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/auxiliary-materials/hazardous/hazardous-waste`
- **功能说明**: 管理危废基础资料信息，维护危废物品的基本属性和分类信息

## 交互说明

1. 进入页面后默认显示所有危废基础资料列表
2. 支持多条件组合搜索筛选
3. 点击"新增"按钮可创建新的危废基础资料
4. 支持"打印选中标签"操作
5. 点击"编辑"或"删除"可修改或删除记录
