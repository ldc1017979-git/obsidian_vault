# 粘鼠板使用记录

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 过程管理 → 粘鼠板使用记录
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/auxiliary-materials/rodent_glue_board_usage`
- **功能说明**: 记录粘鼠板使用情况，管理仓库防鼠措施

## 交互说明

1. 进入页面后默认显示所有粘鼠板使用记录列表
2. 支持按日期和状态搜索筛选
3. 点击"新增"按钮可创建新的使用记录
4. 支持"提交确认"操作
5. 点击"详情"按钮可查看使用记录详细信息
