# 库位产线变更单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 过程管理 → 库位产线变更单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/auxiliary-materials/line-change`
- **功能说明**: 管理库位产线变更记录，记录物料库位和产线的变更信息

## 交互说明

1. 进入页面后默认显示所有库位产线变更记录列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的库位产线变更单
4. 点击"详情"按钮可查看变更记录详细信息
