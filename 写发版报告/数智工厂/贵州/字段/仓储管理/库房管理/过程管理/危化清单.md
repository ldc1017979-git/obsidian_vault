# 危化清单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 过程管理 → 危险化学品管理 → 危化清单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/auxiliary-materials/hazardous/hazard-list`
- **功能说明**: 管理危险化学品清单，记录危化品的基本信息和危险特性

## 交互说明

1. 进入页面后默认显示所有危险化学品清单列表
2. 支持关键字和物料名称搜索筛选
3. 点击"新增危化品"按钮可创建新的危化品记录
4. 点击"详情"按钮可查看危化品详细信息
5. 支持编辑和删除操作
