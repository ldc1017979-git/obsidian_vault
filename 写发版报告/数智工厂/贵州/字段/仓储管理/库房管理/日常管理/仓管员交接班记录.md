# 仓管员交接班记录

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 日常管理 → 仓管员交接班记录
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/daily/warehouseer-shift`
- **功能说明**: 记录仓管员交接班情况，包括出入库统计和交接信息

## 交互说明

1. 进入页面后默认显示所有仓管员交接班记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增"按钮可创建新的交接班记录
4. 支持"提审"和"导出报告"操作
5. 点击"详情"按钮可查看交接班记录详细信息
