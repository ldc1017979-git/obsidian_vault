# 成品托盘记录表

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 成品管理 → 成品托盘记录表
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/daily/tray-record`
- **功能说明**: 记录成品托盘的使用情况，包括出厂、返厂和未还数量

## 交互说明

1. 进入页面后默认显示所有成品托盘记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增"按钮可创建新的托盘记录
4. 点击"详情"按钮可查看托盘记录详细信息
