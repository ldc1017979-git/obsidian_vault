# 补码申请单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 日常管理 → 补码申请单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/daily/code-apply`
- **功能说明**: 管理补码申请单，记录产品补码申请和审批流程

## 交互说明

1. 进入页面后默认显示所有补码申请记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增"按钮可创建新的补码申请单
4. 支持"导出报告"操作
5. 点击"详情"按钮可查看补码申请详细信息
