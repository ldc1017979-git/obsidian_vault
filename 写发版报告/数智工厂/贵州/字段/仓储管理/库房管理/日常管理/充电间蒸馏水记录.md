# 充电间蒸馏水记录

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 日常管理 → 充电间蒸馏水记录
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/daily/distilled_water_record`
- **功能说明**: 记录充电间蒸馏水使用情况，追踪入库、领用和结余量

## 交互说明

1. 进入页面后默认显示所有蒸馏水记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增"按钮可创建新的蒸馏水记录
4. 支持"确认提交"、"撤回"和"作废"操作
5. 支持"报告导出"操作
