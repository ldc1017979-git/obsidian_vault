# 叉车月度检查记录

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 日常管理 → 叉车月度检查记录
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/daily/forklift-check`
- **功能说明**: 记录叉车月度检查情况，统计正常和异常车辆数

![叉车月度检查记录主页面](../仓储管理截图/库房管理_叉车月度检查记录_主页面_01.png)

## 交互说明

1. 进入页面后默认显示所有叉车月度检查记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增"按钮可创建新的月度检查记录
4. 点击"详情"按钮可查看检查记录详细信息
