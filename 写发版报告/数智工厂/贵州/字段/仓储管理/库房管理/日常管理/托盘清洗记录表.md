# 托盘清洗记录表

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 日常管理 → 托盘清洗记录表
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/daily/pallet_cleaning_record`
- **功能说明**: 记录托盘清洗情况，追踪清洗数量和清洗人员信息

## 交互说明

1. 进入页面后默认显示所有托盘清洗记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增"按钮可创建新的清洗记录
4. 支持"确认提交"、"撤回"和"作废"操作
5. 支持"报告导出"操作
