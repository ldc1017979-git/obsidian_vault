# 货品库存明细

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 报表 → 货品库存明细
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/forms/goods-record`
- **功能说明**: 查看货品库存明细，展示每条入库记录的详细库存信息

## 交互说明

1. 进入页面后默认显示所有货品库存明细列表
2. 支持多条件组合搜索筛选
3. 支持"数据导出"操作
4. 支持"库位设置"和"查看标签"功能
