# 保养项目

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 叉车管理 → 叉车维保记录 → 保养项目
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/forklift-manage/storage-others/maintain/project`
- **功能说明**: 管理叉车保养项目配置，定义保养部位和保养标准

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 搜索 | 根据关键字查询保养项目 |

| 3 | 新增 | 新增保养项目 |
| 4 | 编辑 | 编辑保养项目 |
| 5 | 删除 | 删除保养项目 |

## 交互说明

1. 进入页面后默认显示所有保养项目列表
2. 支持关键字搜索筛选
3. 点击"新增"按钮可创建新的保养项目
4. 支持编辑和删除操作
