# 叉车里程

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 叉车管理 → 叉车里程
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/forklift-manage/mileage`
- **功能说明**: 记录叉车里程使用情况，追踪行驶里程和司机信息

## 交互说明

1. 进入页面后默认显示所有叉车里程记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增里程记录"按钮可创建新的里程记录
4. 点击"详情"按钮可查看里程记录详细信息
