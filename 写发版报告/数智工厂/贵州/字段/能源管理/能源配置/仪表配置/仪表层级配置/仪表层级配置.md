# 仪表层级配置

## 页面基本信息

- **页面名称**: 仪表层级配置
- **所属模块**: 能源管理 > 能源配置 > 仪表配置
- **页面URL**: `#/energy-management/energy-manage/meter-configurine/group`
- **页面描述**: 配置水表、电表、蒸汽表、燃气表的层级分组结构

## 页面结构

### Tab页签

| Tab名称 | 说明 |
|---------|------|
| 水表分组 | 配置水表的层级分组 |
| 电表分组 | 配置电表的层级分组 |
| 蒸汽表分组 | 配置蒸汽表的层级分组 |
| 燃气表分组 | 配置燃气表的层级分组 |

### 列表表格

#### 表格列

| 列名 | 说明 |
|------|------|
| 分组名称 | 分组的名称 |
| 层级类型 | 仪表的层级类型 |
| 生产车间 | 所属的生产车间 |
| 所属产线 | 所属的生产线别 |
| 所属区域 | 所属的区域类型 |
| 操作 | 操作按钮 |

### 操作按钮

| 按钮名称 | 功能说明 |
|----------|----------|
| 新增分组 | 新增一个仪表分组 |
| 全部展开 | 展开所有分组节点 |
| 全部折叠 | 折叠所有分组节点 |
| 新增子分组 | 在当前分组下新增子分组 |
| 编辑 | 编辑当前分组信息 |
| 删除 | 删除当前分组 |

## 表单字段

### 新增/编辑分组表单

| 字段名称 | 字段类型 | 是否必填 | 说明 |
|----------|----------|----------|------|
| 分组名称 | 文本输入框 | 是 | 分组的名称 |
| 层级类型 | 下拉选择框 | 是 | 仪表的层级类型 |
| 所属车间 | 下拉选择框 | 否 | 所属的生产车间 |
| 所属线别 | 下拉选择框 | 否 | 所属的生产线别 |
| 所属区域 | 单选按钮组 | 否 | 所属的区域类型 |

### 层级类型选项

- 基地总表
- 区域分表
- 车间子表
- 产线仪表
- 位置仪表
- 设备仪表
- 一车间
- 一线
- 二线

### 所属区域选项

- 生产区
- 生活区
- 办公区
