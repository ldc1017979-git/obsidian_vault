# 物料库存总表

## 页面概述

- **功能模块**: 数据录入端 → 生产管理 → 生产库存报表 → 物料库存总表
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/product-package/report-form/inventory-summary`
- **功能说明**: 查看物料库存总表，汇总展示各物料的库存总量信息

## 搜索字段

| 序号 | 字段名称 | 字段类型 | 说明             |
| :- | :--- | :--- | :------------- |
| 1  | 关键字  | 文本输入 | 关键字搜索          |
| 2  | 仓库   | 下拉选择 | 仓库筛选           |
| 3  | 所属分类 | 下拉选择 | 所属分类筛选         |
| 4  | 库存数量 | 下拉选择 | 库存数量筛选（默认：大于0） |
| 5  | 预警类型 | 下拉选择 | 预警类型筛选         |
| 6  | 供货大类 | 下拉选择 | 供货大类筛选         |
