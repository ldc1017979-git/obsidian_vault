# 物料库存明细

## 页面概述
- **功能模块**: 数据录入端 → 生产管理 → 生产库存报表 → 物料库存明细
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/product-package/report-form/inventory-detail`
- **功能说明**: 查看物料库存明细，展示各物料的批次库存详细信息
