# 生产日历

## 页面概述
- **功能模块**: 数据录入端 → 生产管理 → 生产基础信息 → 生产日历
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/production-baseinfo/produce_calendar`
- **功能说明**: 管理生产日历基础数据，维护月份与产线的日历配置
