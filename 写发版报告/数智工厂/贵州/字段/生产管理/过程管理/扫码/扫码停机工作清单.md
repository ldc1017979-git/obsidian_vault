### 检查清单项目
| 序号 | 工作内容 |
| :--- | :--- |
| 1 | 水处理：上班后和主管确认停机时间，截止批次缸号，并和上个班扫码确认订单是否有误。 |
| 2 | 提前核对本生产周期SAP系统生产订单，原材料投入，成品入库等信息是否有误，并和仓库确认对数 |
| 3 | 停机前和仓库确认当班原材投入数量，做好对接和沟通 |
| 4 | 停机后确认剩余退库原辅料，包材数量，和仓管做好数量确认和对接，确保系统和实物账物相符。 |
| 5 | 排空操作：对本生产周期后的物料物资进行盘点，确认是否账物相符 |
| 6 | 收集和整理，计算当班生产报表并做出这个周期的物料平衡表 |
| 7 | 审查和整理本生产周期批记录，装订归档 |
| 8 | 检查确认辅助物资出库记录，盘点辅房物资是否账物相符 |
| 9 | 做好办公室用品整理，保管工作，并且数量及是否完好 |
| 10 | 协助和配合岗位员领取卫生清洁用品用具，并做好出入库记录 |
