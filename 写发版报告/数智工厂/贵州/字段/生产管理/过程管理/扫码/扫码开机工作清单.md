### 检查清单项目
| 序号 | 工作内容 |
| :--- | :--- |
| 1 | 感官检查：开机前若有试机试水，与仓库对数，所有原材料是否需要计数，计数则按照领用的实数来投试机试水，若不计数那无需投系统，和仓管做好对接。 |
| 1（续） | 协助岗位员工领取卫生清洁用品，用具，辅助物资。 |
| 2 | 确认岗位报表记录是否齐全，劳保是否发放到位 |
| 3 | 开机前与统计员、主管确认生产订单号、第一缸缸号、产品类型、和仓管确认原材料版型。 |
| 4 | 通知仓管员确认原材料版型，空罐，顶盖使用线别，原材料叉到线上的时间。 |
| 5 | 先查询0005库配方是否够扫，不够则转，若：（长期停机后开机，第一时间按称料给的配方转到0005库里）方便配料扫码。 |
| 6 | 把各岗位的工作清单打出来给各岗位人员。 |
| 7 | 开机清洗的柠檬酸数量确认是否投系统试机试水。 |
| 8 | 根据本班的缸号给下一个班打印一二线的订单号，订单号和缸号确认无误后在交给下班配料人员进行扫码。 |
