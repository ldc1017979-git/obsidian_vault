# 维保计划

## 页面概述
- **功能模块**: 数据录入端 → 生产管理 → 过程管理 → 扫码 → 维保计划
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/index55/saoma/maintenance_plan`
- **功能说明**: 管理维保计划配置，包括维保项目、循环周期、负责人、到期提醒等信息

## 页面截图
- [主页面截图](../生产管理截图/过程管理_扫码_维保计划_主页面.jpeg)

## 搜索区域字段
| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 维保类型 | 文本框 | 空 | 可选 | 输入维保类型 |
| 2 | 维保项目 | 文本框 | 空 | 可选 | 输入维保项目名称 |
| 3 | 状态 | 下拉框 | 空 | 可选 | 选择计划状态 |

## 操作按钮
| 序号 | 按钮名称 | 功能说明 |
| :--- | :--- | :--- |
| 1 | 搜索 | 根据搜索条件查询数据 |
| 2 | 重置 | 清空所有搜索条件 |
| 3 | 新增 | 新增维保计划 |

## 列表字段
| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 维保项目 | 文本 | 维保项目名称（车间环境消杀/污水车间/厂房外围清洁等） |
| 2 | 维保类型 | 文本 | 维保类型（清洁类/更换维护/清洗类/更换维保类/配料余热换热板交清洁等） |
| 3 | 产线 | 文本 | 所属产线（一线等） |
| 4 | 岗位 | 文本 | 岗位名称（灌装/配料/制水/保洁/污水处理员等） |
| 5 | 循环周期 | 数字 | 维保循环周期（天） |
| 6 | 负责人 | 文本 | 维保负责人 |
| 7 | 上次实施时间 | 日期时间 | 上次维保实施时间 |
| 8 | 到期时间 | 日期时间 | 维保到期时间 |
| 9 | 提醒时间 | 数字 | 到期前提醒天数 |
| 10 | 创建人 | 文本 | 创建人姓名 |
| 11 | 创建时间 | 日期时间 | 创建时间 |
| 12 | 状态 | 开关 | 启用/禁用状态 |
| 13 | 操作 | 按钮 | 编辑/删除 |

## 详情页面字段

> 此页面为配置管理页面，无详情页。列表行操作仅有"编辑"和"删除"按钮，点击"编辑"弹出编辑弹窗修改维保计划配置。
