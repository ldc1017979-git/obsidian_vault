# 维保记录

## 页面概述
- **功能模块**: 数据录入端 → 生产管理 → 过程管理 → 扫码 → 维保记录
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/index55/saoma/maintenance_record`
- **功能说明**: 记录设备维保执行情况，包括清洁类、更换维保类等维保项目的实施与到期管理
