# 停机检查

## 页面概述
- **功能模块**: 数据录入端 → 生产管理 → 过程管理 → 主管 → 停机检查
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/index55/zhuguan/shutdown-inspection`
- **功能说明**: 记录生产线停机后的各项检查项目，包括各岗位清洁、设备关闭、物料退库等检查内容
