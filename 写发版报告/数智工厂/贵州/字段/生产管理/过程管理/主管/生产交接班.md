# 生产交接班

## 页面概述
- **功能模块**: 数据录入端 → 生产管理 → 过程管理 → 主管 → 生产交接班
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/index55/zhuguan/product-shift-handover-gz`
