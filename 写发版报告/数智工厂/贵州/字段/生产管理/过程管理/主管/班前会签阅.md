# 班前会签阅

## 页面概述
- **功能模块**: 数据录入端 → 生产管理 → 过程管理 → 主管 → 班前会签阅
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/index55/zhuguan/pre_shift_meeting_sign_record`
