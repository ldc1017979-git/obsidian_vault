# 物料称量记录

## 页面概述
- **功能模块**: 数据录入端 → 生产管理 → 过程管理 → 称料 → 物料称量记录
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/index55/product-package/weight-feed-process/material-weight-record`
