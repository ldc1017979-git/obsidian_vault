# 清场记录-开机

## 页面概述
- **功能模块**: 数据录入端 → 生产管理 → 过程管理 → 巡检 → 清场记录-开机
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/index55/inspectionp/clear-records-on`

| 序号 | 指令内容 |
| :--- | :--- |
| 1 | 各工序在更换产品类型或在设备试机以及开机时，进行清场 |
| 2 | 将本批的中间产品、废弃物、剩余物料及与生产无关的工艺文件等清离现场，无遗留 |
| 3 | 按设备清洁标准操作程序清洁生产设备，做到设备内外无油污、无浆块、无物料遗物，设备见本色 |
| 4 | 按生产用工具、容器清洁标准操作程序清洗或清扫工具、容器，达到清洁、无异物、无物料遗留物 |
| 5 | 按清场操作程序清洁地面、门窗、天花板、地漏、设备表面等，做到无积水、无积尘、无料液、无粉渣 |
| 6 | 按清洁工具清洁标准操作程序清洗清洁工具，做到干净、无遗留物，置于规定干燥位置 |
