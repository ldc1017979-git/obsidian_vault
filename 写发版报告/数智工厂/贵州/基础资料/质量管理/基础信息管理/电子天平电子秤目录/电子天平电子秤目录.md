## 1. 页面概述

| 属性 | 说明 |
|------|------|
| 所属模块 | 质量管理 > 基础信息管理 |
| 页面名称 | 电子天平电子秤目录 |
| 路由地址 | `/quality-manage/index2/index195/electronic-scale` |
| API端点 | `POST /qlty/Scaledevice/getScaledeviceList` |
| 数据总量 | 11条记录 |
| 主要功能 | 管理电子天平和电子秤的基础信息，包括使用地点、型号、出厂编号、规格（Max/e/d）、砝码重量等 |

## 2. 页面布局与功能说明

### 2.1 搜索区域

页面顶部提供两个搜索条件：

| 搜索项 | 类型 | 说明 |
|--------|------|------|
| 名称 | 文本输入框 | 支持模糊搜索，占位符"名称:" |
| 型号 | 文本输入框 | 支持模糊搜索，占位符"型号:" |

搜索区域按钮：
- **重置**：清空所有搜索条件
- **搜索**：按条件筛选数据

### 2.2 功能按钮

| 按钮名称 | 功能说明 |
|----------|----------|
| 新建 | 打开新增电子天平/电子秤对话框 |

### 2.3 数据列表

列表展示以下字段：

| 序号 | 字段名 | 说明 |
|------|--------|------|
| 1 | 排序编号 | 排序序号 |
| 2 | 使用地点 | 天平/秤的使用位置 |
| 3 | 名称 | 仪器名称（关联仪器管理） |
| 4 | 仪器编号 | 仪器编码 |
| 5 | 型号 | 仪器型号 |
| 6 | 出厂编号 | 出厂编号 |
| 7 | 规格 | 包含Max、e、d三个参数 |
| 8 | Max | 最大称量值及单位 |
| 9 | e | 检定分度值及单位 |
| 10 | d | 实际分度值及单位 |
| 11 | 砝码重量 | 校准砝码重量及单位 |
| 12 | 创建人 | 创建记录的用户 |
| 13 | 创建时间 | 记录创建时间 |
| 14 | 更新人 | 最后更新用户 |
| 15 | 操作 | 编辑、删除按钮 |

## 3. 新增电子天平/电子秤

点击"新建"按钮，弹出"新增"对话框。

### 表单字段

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| 排序号 | 文本输入框 | 是 | 标记为必填(*)，数字排序 |
| 使用地点 | 文本输入框 | 是 | 标记为必填(*)，天平/秤的使用位置 |
| 名称 | 下拉选择框 | 是 | 标记为必填(*)，关联仪器管理中的仪器列表 |
| 仪器编号 | 文本输入框 | 否 | 选择名称后自动填充（禁用编辑） |
| 出厂编号 | 文本输入框 | 是 | 标记为必填(*)，选择名称后自动填充（禁用编辑） |
| 型号 | 文本输入框 | 是 | 标记为必填(*)，选择名称后自动填充（禁用编辑） |
| Max | 文本输入框 + 单位选择 | 是 | 标记为必填(*)，最大称量值，需输入数值并选择单位 |
| e | 文本输入框 + 单位选择 | 是 | 标记为必填(*)，检定分度值，需输入数值并选择单位 |
| d | 文本输入框 + 单位选择 | 是 | 标记为必填(*)，实际分度值，需输入数值并选择单位 |
| 砝码重量 | 文本输入框 + 单位选择 | 是 | 标记为必填(*)，校准砝码重量，需输入数值并选择单位 |
