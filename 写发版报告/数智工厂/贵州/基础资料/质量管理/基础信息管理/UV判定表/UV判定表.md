## 1. 页面概述

- **页面路径**：质量管理 → 基础信息管理 → UV判定表
- **路由地址**：`/quality-manage/index2/uv-config`
- **页面功能**：管理UV（紫外分光光度法）判定数据，记录每批次产品的可溶性固形物、pH值、ABS吸光度等检测指标，用于产品质量判定
- **数据总量**：共 20 条记录
- **产品类型**：红牛-普通型（ND1-1）

![列表页](截图/UV判定表-列表页.png)

## 2. 页面布局

页面分为以下区域：

### 2.1 Tab标签区域

| Tab名称 | 产品编码 | 说明 |
|---------|---------|------|
| 红牛-普通型 | ND1-1 | 红牛维生素功能饮料（普通型） |

- Tab标签位于页面顶部，以左侧排列方式展示
- 当前仅有1个产品类型Tab

### 2.2 搜索筛选区域

位于Tab标签下方，提供多条件组合搜索。

### 2.3 数据列表区域

位于页面中央，展示UV判定数据列表，支持分页浏览。

## 6. 新建表单

新建对话框标题：**新增UV信息—红牛-普通型**

| 字段名 | 控件类型 | 是否必填 | 说明 |
|--------|----------|----------|------|
| 生产日期 | 日期选择器 | 是 | 产品生产日期 |
| 时间 | 时间选择器 | 是 | 检测时间 |
| 批次 | 文本输入框 | 是 | 生产批次号 |
| 批号 | 文本输入框 | 是 | 产品批号 |
| 可溶性固形物 | 数字输入框 | 是 | Brix值 |
| pH | 数字输入框 | 是 | pH值 |
| ABS | 数字输入框 | 是 | ABS吸光度值 |
| nm | 数字输入框 | 是 | 波长值，默认271.5 |
| 备注 | 多行文本框 | 否 | 备注信息 |

- 操作按钮：取消、确定
