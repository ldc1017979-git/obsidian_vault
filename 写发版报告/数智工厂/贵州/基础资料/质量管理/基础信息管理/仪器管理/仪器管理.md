## 1. 页面概述

| 属性 | 说明 |
|------|------|
| 所属模块 | 质量管理 > 基础信息管理 |
| 页面名称 | 仪器管理 |
| 路由地址 | `/quality-manage/index2/index195/instrument` |
| API端点 | `POST /qlty/Inst/getInstList` |
| 数据总量 | 58条记录 |
| 主要功能 | 管理检测仪器的基础信息，包括仪器编码、名称、型号、品牌、类型、可用状态等 |

## 2. 页面布局与功能说明

### 2.1 搜索区域

页面顶部提供三个搜索条件：

| 搜索项 | 类型 | 说明 |
|--------|------|------|
| 仪器名称 | 文本输入框 | 支持模糊搜索，占位符"仪器名称:" |
| 可用状态 | 下拉选择框 | 选项：可用、禁用 |
| 仪器类型 | 下拉选择框 | 选项：分析天平、恒温箱、pH计、酶标仪、生化培养箱、紫外分光光度计 |

搜索区域按钮：
- **重置**：清空所有搜索条件
- **搜索**：按条件筛选数据

## 3. 新增检测仪器

点击"新建"按钮，弹出"新增检测仪器"对话框。

### 表单字段

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| 仪器编码 | 文本输入框 | 是 | 标记为必填(*) |
| 仪器名称 | 文本输入框 | 是 | 标记为必填(*) |
| 出厂编号 | 文本输入框 | 是 | 标记为必填(*) |
| 仪器型号 | 文本输入框 | 是 | 标记为必填(*) |
| 仪器品牌 | 文本输入框 | 是 | 标记为必填(*) |
| 仪器类型 | 下拉选择框 | 是 | 标记为必填(*)，选项：分析天平、恒温箱、pH计、酶标仪、生化培养箱、紫外分光光度计 |
| 可用状态 | 开关控件 | 否 | 默认关闭 |

### 仪器类型选项

| 序号 | 类型名称 |
|------|----------|
| 1 | 分析天平 |
| 2 | 恒温箱 |
| 3 | pH计 |
| 4 | 酶标仪 |
| 5 | 生化培养箱 |
| 6 | 紫外分光光度计 |

### 操作按钮

| 按钮 | 说明 |
|------|------|
| 取消 | 关闭对话框 |
| 确定 | 提交新增数据 |
