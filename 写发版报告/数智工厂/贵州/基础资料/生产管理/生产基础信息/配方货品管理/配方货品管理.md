## 1. 模块概述

配方货品管理模块用于管理生产配方相关的货品信息，包括货品条码、名称、规格型号、分类、计量单位等基本信息。支持新建、编辑、删除、导入货品以及打印标签等操作。

## 2. 页面路径

生产管理 → 生产基础信息 → 配方货品管理

URL: `https://gzmms.y1b.cn:8424/#/product/production-baseinfo/index156/recipe-goods`

## 7. 新建货品表单

点击"新建货品"按钮后，打开批量新建表单页面。

### 表单字段

| 字段名 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| 序号 | 自动生成 | 否 | 行序号 |
| 条码 | 文本输入 | 否 | 空白时系统自动生成 |
| 名称 | 文本输入 | 是 | 货品名称 |
| 品牌 | 文本输入 | 否 | 品牌信息 |
| 自定义类别 | 文本输入 | 否 | 自定义分类 |
| 规格型号 | 文本输入 | 否 | 规格型号 |
| 计量单位 | 下拉选择 | 是 | 计量单位 |
| 分类 | 下拉选择 | 是 | 货品分类 |
| 默认价格 | 数字输入 | 否 | 默认价格 |
| 保质期(天) | 数字输入 | 否 | 保质期天数 |
| 保质期预警(天) | 数字输入 | 否 | 保质期预警天数 |
| 保留小数 | 数字输入 | 否 | 保留小数位数 |
| 税率(%) | 数字输入 | 否 | 税率百分比 |

### 功能按钮

| 按钮名称 | 功能说明 |
| --- | --- |
| 检查重复条码 | 检查已输入的条码是否重复 |
| 添加 | 添加一行新的货品输入行 |
| 取消 | 取消新建操作 |
| 保存 | 保存所有新建货品 |

### 特殊说明

- 连接扫描枪后，在此页面扫描商品条码可自动添加一行
- 条码为空时系统自动生成

## 9. 导入货品

点击"导入货品"按钮后，弹出导入对话框。

### 导入功能说明

| 项目 | 说明 |
| --- | --- |
| 模板下载 | 点击"点击下载"按钮下载导入模板 |
| 文件上传 | 支持拖拽上传或点击上传 |
| 文件格式 | .xls 或 .xlsx 标准格式 |
| 文件大小 | 最大20M |
