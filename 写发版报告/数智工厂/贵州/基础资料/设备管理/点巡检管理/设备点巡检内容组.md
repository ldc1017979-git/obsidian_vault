## 1. 页面概览

**系统地址：** https://gzmms.y1b.cn:8424/#/dashboard

**导航路径：** 设备管理 → 点巡检管理 → 设备点巡检内容组

**页面功能：** 管理设备点巡检内容组，包括内容组的新增、查看详情、编辑等操作。每个内容组包含多个检查项目，定义了巡检的项目、内容、方法、标准、周期、是否区分线别及记录方式等。

## 2. 页面功能说明

### 2.1 列表页功能

| 功能按钮 | 说明 |
|---------|------|
| 新增 | 新建点巡检内容组 |
| 详情 | 查看选中内容组的详细信息 |
| 编辑 | 编辑选中内容组的配置 |

### 2.2 新增/编辑页面字段说明

| 字段名 | 说明 | 输入方式 |
|--------|------|---------|
| 点巡检内容组名称 | 内容组的名称标识 | 文本输入 |
| 资产类型 | 关联的设备资产类型 | 下拉选择（生产设备、污水、自动查罐系统等） |
| 巡检目的 | 巡检的目的说明 | 文本输入 |
| 备注 | 补充说明信息 | 文本输入 |

### 2.3 检查内容行字段说明

| 字段名 | 说明 | 输入方式 |
|--------|------|---------|
| 项目 | 巡检项目名称 | 文本输入 |
| 内容 | 具体检查内容描述 | 文本输入 |
| 方法 | 检查方法 | 文本输入 |
| 标准说明 | 检查标准及判定依据 | 文本输入 |
| 点巡检周期 | 巡检执行周期 | 下拉选择（按班次/每天/按CIP/每月） |
| 是否区分线别 | 是否按产线区分 | 下拉选择（是/否） |
| 记录方式 | 巡检结果记录方式 | 下拉选择（单选/文本） |
| 正常值 | 单选记录方式下的正常选项值 | 文本输入 |
| 异常值 | 单选记录方式下的异常选项值 | 文本输入 |
