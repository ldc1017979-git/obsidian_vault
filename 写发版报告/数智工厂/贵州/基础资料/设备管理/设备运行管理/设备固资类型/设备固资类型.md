## 1. 页面概述

- **页面路径**：设备管理 → 设备运行管理 → 固资管理 → 设备固资类型
- **页面URL**：`https://gzmms.y1b.cn:8424/#/device-manage/equipment-operate/Fixed-asset-management/equipment-ledger-type`
- **页面功能**：管理设备固资类型的层级分类，支持树形结构的资产类型管理，包含顶级类型和子类型的增删改查操作

![设备固资类型-列表页](截图/设备固资类型-列表页.png)

## 2. 页面功能按钮

| 按钮名称 | 功能说明 |
|---------|---------|
| 搜索 | 根据关键字搜索资产类型 |

## 4. 弹窗表单说明

### 4.1 新增设备固资类型

点击"新建资产类型"按钮后弹出，用于新增顶级资产类型。

![新建资产类型](截图/设备固资类型-新建资产类型.png)

| 字段名称 | 字段类型 | 是否必填 | 说明 |
|---------|---------|---------|------|
| 资产类型名称 | 文本输入框 | 是（*） | 输入资产类型名称 |
| 排序 | 数字输入框 | 否 | 控制显示顺序，默认值为0 |
| 状态 | 单选按钮 | 否 | 启用/停用，默认选中"启用" |
| 备注 | 文本输入框 | 否 | 填写备注信息 |

**操作按钮**：取消、确定

### 4.2 编辑设备固资类型

点击某行的"编辑"按钮后弹出，用于修改已有资产类型信息。

![编辑生产设备](截图/设备固资类型-编辑生产设备.png)

![编辑辅助设施](截图/设备固资类型-编辑辅助设施.png)

| 字段名称 | 字段类型 | 是否必填 | 说明 |
|---------|---------|---------|------|
| 上级类型 | 下拉选择框 | 否 | 选择上级类型，选项包括：顶级类型、生产设备、辅助设施 |
| 资产类型名称 | 文本输入框 | 是（*） | 输入资产类型名称 |
| 排序 | 数字输入框 | 否 | 控制显示顺序 |
| 状态 | 单选按钮 | 否 | 启用/停用 |
| 备注 | 文本输入框 | 否 | 填写备注信息 |

**上级类型下拉选项**：
- 顶级类型（默认，表示该类型为顶级节点）
- 生产设备
- 辅助设施

![上级类型下拉](截图/设备固资类型-编辑生产设备-上级类型下拉.png)

**操作按钮**：取消、确定

### 4.3 新增子设备固资类型

点击某行的"新增子类型"按钮后弹出，用于在当前类型下新增子类型。

![新增子类型](截图/设备固资类型-新增子类型.png)

| 字段名称 | 字段类型 | 是否必填 | 说明 |
|---------|---------|---------|------|
| 上级类型 | 下拉选择框 | 否 | 自动填充为当前父类型（如"生产设备"），可修改 |
| 资产类型名称 | 文本输入框 | 是（*） | 输入子类型名称 |
| 排序 | 数字输入框 | 否 | 控制显示顺序，默认值为0 |
| 状态 | 单选按钮 | 否 | 启用/停用，默认选中"启用" |
| 备注 | 文本输入框 | 否 | 填写备注信息 |

**操作按钮**：取消、确定

### 4.4 删除确认

点击某行的"删除"按钮后弹出确认弹窗。

![删除确认](截图/设备固资类型-删除确认.png)
