# dianjian-yhl-skills 团队安装说明

## 这个 skill 解决什么问题

用于根据市场活动规则、需求资料、历史模板或知识库内容，生成可打印、可执行、按后端配置人员和前端业务验证拆分的上线点检表，目标是减少系统配置项遗漏和线上验收漏检。

## 安装方式

1. 复制本文件夹内的 `dianjian-yhl-skills` 文件夹。
2. 放到团队成员本机的 Codex skills 目录：

```text
C:\Users\你的用户名\.codex\skills\dianjian-yhl-skills
```

3. 重启 Codex 或新开一个任务后使用。

## 使用方式示例

```text
使用 dianjian-yhl-skills，根据这份活动规则生成上线点检表。
要求拆成后端配置确认和前端业务验证两份打印填写版。
```

## 交付口径

- 默认只显示 `打印填写版` 一个页签，其他校验页隐藏。
- 结果列和备注列保持空白，方便打印后手写。
- 主责只使用 `后端配置人员` 和 `前端业务验证`。
- 点检项按一次性验证场景连续排列，避免执行人员来回跳项。
