# 看板工作流来源说明

## 1. 来源项目

本包结合了两个真实看板项目的经验：

1. BI留存分析项目
2. 门店动销热力图项目

本包只抽象通用方法，不固化具体品牌、行业和项目名称。

## 2. 从BI留存分析项目吸收的方法

- 首次行为作为T0。
- 按7/15/30天窗口观察第二次、第三次行为。
- 同一天多次行为不算复购。
- 非目标身份排除出主分析，但单独汇总。
- 输出用户级底表、周期汇总表、生命周期摘要、转移矩阵、路径表。
- 用测试用例验证口径。

## 3. 从门店动销热力图项目吸收的方法

- 先定义明细数据粒度。
- 通过中间表计算门店归属。
- 同一天多个首次事件合并。
- 用中位数代表门店常态间隔。
- 一个门店只落一个热力图格子。
- 0值和无行为对象单独分析。
- 点击热力图层级后下钻到明细。

## 4. 最终沉淀原则

看板项目必须先证明数据可信，再证明页面好看。

```text
业务问题
-> 字段粒度
-> 指标口径
-> 数据验证
-> 输出数据集
-> 看板页面
-> 浏览器验证
```
