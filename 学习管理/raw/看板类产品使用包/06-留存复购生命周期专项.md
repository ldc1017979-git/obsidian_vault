# 留存复购生命周期专项

## 1. 适用问题

- 用户是否复购。
- 新客是否留下来。
- 首次行为后多久发生第二次、第三次行为。
- 哪些用户需要运营跟进。

## 2. 推荐口径

- 以用户第一次有效行为作为T0。
- 观察T0后7天、15天、30天、30天后。
- 同一天多次行为默认不算复购，只算集中行为。
- 非目标身份不进入主分析，但要单独汇总。
- 保留用户级底表，便于运营筛选。

## 3. 推荐输出数据集

| 数据集 | 用途 |
|---|---|
| 用户周期状态表 | 每周/每日用户状态 |
| 用户最新明细表 | 运营筛选 |
| 生命周期摘要表 | 首次、二次、三次行为 |
| 第二次行为窗口分布 | 看快慢复购 |
| 第三次行为窗口分布 | 看持续性 |
| 生命周期转移矩阵 | 看第N次到第N+1次 |
| 路径汇总表 | 看行为路径 |
| 非目标身份汇总表 | 看排除数据 |

## 4. 必测用例

| 用例 | 预期 |
|---|---|
| 同一用户同一天多次行为 | 不算复购 |
| 同一用户不同日期第二次行为 | 算二次行为 |
| 一个用户没有第二次行为 | 进入无二次行为分桶 |
| 非目标身份 | 不进入主分析 |
| 分桶合计 | 等于用户基数 |
| 转移矩阵 | 下一阶段基数等于上一阶段转化人数 |
