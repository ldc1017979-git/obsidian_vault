## 3. 产品经理提供的目标页面特征

### 3.1 系统与页面壳

- 系统：数智工厂测试版。
- 顶部业务域：生产管理处于选中状态。
- 左侧菜单：过程管理处于选中状态。
- Tags-View：工作台、消息中心、大批次查询。
- 页面名称：大批次查询。
- 页面风格：数智工厂后台工具型页面，中高密度。

### 3.2 查询区

目标页面的查询条件为：

| 字段 | 控件 | 是否必填 | 备注 |
|---|---|---|---|
| 大批次号 | 输入框 | 是 | 示例值：JS26D015 |
| 生产日期 | 日期选择 | 否 | 单个日期，不是起止范围 |
| 班次 | 下拉框 | 否 | 占位：请选择班次 |
| 产线 | 下拉框 | 否 | 示例值：四线 |
| 班组 | 下拉框 | 否 | 占位：请选择班组 |

查询区按钮：

- 搜索：蓝色主按钮。
- 重置：次按钮。

### 3.3 查询结果区

目标页面采用单表格平铺展示，不做表单名称分组折叠。

表格上方有查询摘要：

- 当前查询：大批次号 JS26D015，产线 四线，共 42 条记录。

表格字段为：

| 字段 | 说明 |
|---|---|
| 工序/表单名称 | 原系统表单或工序名称 |
| 单据号 | 原表单单据编号 |
| 大批次号 | 查询命中的大批次号 |
| 产线 | 表单所属产线 |
| 班次 | 表单所属班次 |
| 班组 | 表单所属班组 |
| 原状态 | 原表单当前状态 |
| 生产日期 | 表单生产日期 |
| 操作人 | 表单操作人 |
| 提交时间 | 表单提交时间 |
| 操作 | 查看 |

状态标签示例：

- 已审核：绿色标签。
- 已提交：蓝色标签。
- 填写中：橙色标签。

操作列：

- 文案为“查看”。
- 点击后进入原表单详情页。

目标页面右下角存在“开发备注”浮动按钮。该入口适合保留在开发实现原型中，用于研发查看字段说明、逻辑说明和待确认事项。

## 5. 需要产品经理确认的关键冲突

### 5.1 生产日期是单日期还是日期范围

当前最新口径曾要求增加“生产日期范围”，但目标图中是单个“生产日期”。

可选方案：

A. 按目标图改为单个生产日期。  
适合：页面与目标交互完全一致。

B. 保留生产日期范围。  
适合：业务需要按时间段查批次相关表单。

C. 单日期为默认，展开高级筛选后支持日期范围。  
适合：兼顾目标图简洁性和业务扩展。

待确认结论：待产品经理确认。

### 5.2 查询结果是否继续分组

当前 PRD 曾确认“按表单名称分组/折叠”，目标图为单表格平铺。

可选方案：

A. 改为单表格平铺。  
适合：完全贴合目标图，表格查询效率高。

B. 保留表单名称分组。  
适合：表单类型很多时按表单聚合更清晰。

C. 默认平铺，支持按工序/表单名称筛选或排序。  
适合：兼顾目标图和查询效率。

建议：改为 A 或 C。

待确认结论：待产品经理确认。

### 5.3 页面入口名称

当前 PRD：生产管理 / 批次查询。  
目标图：生产管理 / 过程管理 / 大批次查询。

建议：以目标图为准，更新为“生产管理 / 过程管理 / 大批次查询”。

待确认结论：待产品经理确认。

## 7. 建议保留的业务规则

以下规则与目标页面不冲突，建议保留：

- 大批次号必填。
- 大批次号精确匹配。
- 查询范围覆盖系统内所有包含该大批次号的表单记录。
- 数据来源为系统表单，不是图片、附件或本地文件。
- 点击“查看”进入原表单详情页。
- 查看权限继承原表单权限。
- 无权限时是否展示行记录、是否置灰“查看”，仍需结合目标页面补充权限态。
- 无结果时显示空态提示。
- 重置清空查询条件和结果区。
