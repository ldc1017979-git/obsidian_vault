# 大批次表单查询 PRD/页面说明

## 1. 项目基本信息

| 项目 | 内容 |
|---|---|
| 项目名称 | 大批次表单查询 |
| 端口/业务域 | 工厂端 |
| 承载系统 | 数智工厂现有系统 |
| 需求类型 | 现有系统新增查询能力 |
| 菜单入口 | 生产管理 / 批次查询 |
| 协作模式 | 详细引导版 |
| 原型用途 | 产品确认原型、开发实现 HTML 原型、最终 UI 视觉稿 |

## 2. 背景与目标

当前红牛普通型的大批次号会出现在系统内多类生产、质量、物料、清场、放行等表单中。业务需要一个统一查询入口，输入完整大批次号后，能聚合查到所有系统表单中填写过该大批次号的记录，并能跳转回原表单详情页。

目标不是查询本地图片、附件或截图，而是查询系统内已填写的表单记录。

## 3. 一期范围

- 支持在数智工厂现有系统中新增“大批次表单查询”页面。
- 支持按大批次号精确查询。
- 支持产线、班组、班次、生产日期范围作为选填筛选条件。
- 查询所有状态的表单记录，包括草稿、已提交、已驳回、已作废、已完成等。
- 查询结果按表单名称分组，默认全部展开。
- 同一表单内出现多条同大批次记录时全部展示。
- 点击详情后，通过 Tags-View 打开原系统对应表单详情页。
- 一期以红牛普通型跑通，页面和字段结构预留后续扩展其他产品类型。

## 4. 一期不做范围

- 不做导出。
- 不做缺失表单/未填写表单判断。
- 不做 OCR。
- 不查询本地图片、附件或扫描件。
- 不重做各表单详情页，只跳转原表单详情。
- 不新增统一表单详情页。

## 5. 用户角色

| 角色 | 使用目的 |
|---|---|
| 生产人员 | 按大批次号快速查看生产相关表单记录 |
| 质量/QA 人员 | 查看该大批次关联的质检、放行、追溯相关表单 |
| 管理/追溯人员 | 跨表单查看批次相关记录、状态、提交人和提交时间 |

## 6. 查询条件

| 字段 | 类型 | 必填 | 规则 |
|---|---|---|---|
| 大批次号 | 输入框 | 是 | 精确匹配，不能为空 |
| 产线 | 下拉选择 | 否 | 用于缩小查询范围 |
| 班组 | 下拉选择 | 否 | 用于缩小查询范围 |
| 班次 | 下拉选择 | 否 | 用于缩小查询范围 |
| 生产日期范围 | 日期范围 | 否 | 用于按生产日期缩小查询范围 |

## 7. 查询结果字段

| 字段 | 说明 | 来源 |
|---|---|---|
| 表单名称 | 原系统表单名称 | 原表单/表单配置 |
| 大批次号 | 表单中填写的大批次号 | 原表单字段 |
| 订单号 | 表单关联订单号 | 原表单字段 |
| 状态 | 原表单当前状态 | 原表单状态 |
| 提交人 | 表单提交人 | 原表单提交信息 |
| 提交时间 | 表单提交时间 | 原表单提交信息 |
| 班组 | 表单填写班组 | 原表单字段 |
| 班次 | 表单填写班次 | 原表单字段 |
| 产线 | 表单填写产线 | 原表单字段 |
| 生产日期 | 表单生产日期 | 原表单字段 |
| 操作 | 详情 | 权限控制 |

## 8. 展示规则

- 查询结果按表单名称分组/折叠展示。
- 默认全部展开。
- 分组标题展示“表单名称 + 记录数量”，例如“灌装工序记录（3）”。
- 分组内记录按提交时间倒序。
- 整体按表单名称排序。
- 分页暂按整体分页，后续研发结合数据量确认最终实现。

## 9. 权限规则

- 查询页继承数智工厂现有权限体系。
- 记录详情权限继承原表单权限。
- 用户具备对应原表单详情权限时，“详情”按钮可点击。
- 用户无对应原表单详情权限时，该记录仍展示，“详情”按钮置灰，提示“无该表单查看权限”。
- 无权限记录的基础字段是否全部可见，需业务和研发进一步确认。

## 10. 操作规则

| 操作 | 触发条件 | 结果 |
|---|---|---|
| 查询 | 大批次号已填写 | 刷新结果区，按表单名称分组并默认展开 |
| 查询 | 大批次号为空 | 阻止查询，提示“请输入大批次号” |
| 重置 | 点击重置 | 清空大批次号、产线、班组、班次、生产日期范围，并清空结果区 |
| 展开分组 | 点击分组标题 | 展示该表单下所有匹配记录 |
| 收起分组 | 点击分组标题 | 隐藏该表单下记录 |
| 查看详情 | 有原表单详情权限 | 在 Tags-View 打开原表单详情页 |
| 查看详情 | 无原表单详情权限 | 按钮置灰，提示“无该表单查看权限” |

## 11. 异常与空态

| 场景 | 页面反馈 |
|---|---|
| 未输入大批次号点击查询 | 请输入大批次号 |
| 查询无结果 | 未查询到该大批次号相关表单记录，请检查大批次号是否输入正确 |
| 无详情权限 | 无该表单查看权限 |
| 同一表单多条记录 | 全部展示，不合并为最新一条 |

## 12. 页面结构

| 区域 | 内容 |
|---|---|
| 系统壳 | 顶部业务域导航、左侧菜单、Tags-View |
| 查询区 | 大批次号、产线、班组、班次、生产日期范围、查询、重置 |
| 结果区 | 表单名称分组、记录表格、整体分页 |
| 行操作 | 详情 |

## 13. 视觉基准

- 继承数智工厂现有系统壳。
- 保留顶部业务域导航、左侧菜单、Tags-View。
- 内容区使用白色背景。
- 使用后台工具型页面密度。
- 控件接近 Element Plus 风格：输入框、下拉框、按钮、表格、分页、状态标签。
- 主按钮为系统蓝色，重置为次按钮。
- 必填项使用红色星号。
- 不做营销页、大屏、暗色科技风、装饰插画。

## 15. 待研发确认

1. 各系统表单是否都能按大批次号统一检索。
2. 不同表单的大批次号字段是否字段名一致，或是否需要字段映射表。
3. 查询所有状态时，草稿、驳回、作废等数据来源和权限策略是否一致。
4. 无权限记录的基础字段是否允许完整展示。
5. 查询性能、索引方案、分页方式。
6. Tags-View 打开原表单详情页所需路由参数。
7. 产线、班组、班次筛选项的数据字典来源。
8. 生产日期范围筛选对应原表单中的哪个日期字段，以及不同表单日期字段是否需要映射。

## 16. 验收标准

- 未输入大批次号时不能查询，并提示“请输入大批次号”。
- 输入有效大批次号后，能返回所有包含该大批次号的系统表单记录。
- 结果按表单名称分组，默认全部展开。
- 同一表单多条记录全部展示。
- 重置后清空查询条件和结果区。
- 生产日期范围为选填；填写后仅返回生产日期落在该范围内的记录。
- 有详情权限的记录可打开原表单详情页。
- 无详情权限的记录详情按钮置灰，并提示“无该表单查看权限”。
- 无结果时展示指定空态文案。
- 页面风格符合数智工厂现有系统壳和后台工具型页面规范。
