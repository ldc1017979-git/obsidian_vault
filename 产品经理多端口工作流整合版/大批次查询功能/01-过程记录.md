# 大批次查询功能过程记录

## 1. 原始需求

用户一句话需求：新增大批次查询功能。

补充说明：会根据批次号，查询出不同工序表单，例如拆包工序、灌装工序等。

## 2. 资料清单与资料审计

已提供资料：

- 现有页面截图：华彬快消品制造中心中的批生产记录/大批次首页页面截图。

截图中明确可见：

- 系统名称：华彬快消品制造中心。
- 页面入口：首页 / 批生产记录 / 大批次首页。
- 查询条件：批次号、生产日期、班次、批次。
- 示例批次号：JS26D015。
- 查询按钮：查询、重置。
- 查询结果包含不同工序/表单记录。
- 表单/记录示例：大批次首页、批生产指令、包装材料物料平衡计算表、原辅料物料平衡计算表、生产主管、拆包记录、灌装封口记录、打码记录、热缩记录。
- 行数据示例：编号 100286729、4线、2026-06-26、A2班、早班。
- 每行右侧有“查看”操作。

资料可信度：

- 截图可用于业务理解和参考页面结构。
- 用户已确认最终承载系统是另一个工厂系统，因此该截图不能直接作为最终 UI 风格基线。

## 3. 当前协作模式

协作模式：详细引导版。

模式说明：

- 每轮只确认 1-3 个关键产品判断。
- Codex 提供选项、解释、推荐理由和影响。
- 用户通过选项确认、组合或修正。

## 4. 启动三轮漏斗结论

### 第一轮：端口分流

已确认：工厂端。

判断依据：

- 核心对象是批号。
- 查询结果是拆包、灌装等工序表单。
- 使用场景属于生产、工序、批次记录和追溯核查。

### 第二轮：资料来源盘点

已确认：

- 已有现有页面截图。

暂定：

- 目标承载系统资料尚未提供。
- 当前截图仅作为业务参考。

### 第三轮：需求类型和承载系统

已确认：

- 需求变化类型：现有系统新增模块。
- 系统承载关系：放到另一个工厂系统。
- 主要解决问题：查询入口、结果聚合、查看路径、异常提示都要。

影响：

- 需要继承目标工厂系统的菜单、页面框架、组件交互、权限体系和 UI 风格。
- 在目标系统资料未提供前，不能生成最终 UI 风格 HTML 原型。

## 5. 关键产品决策记录

### 5.1 使用角色

已确认：

- 生产现场人员可以使用。
- 多角色按权限控制数据范围。

暂定角色范围：

- 生产现场人员。
- 生产主管。
- 工艺人员。
- 质量人员。

影响：

- 不同角色看到的数据范围可能不同。
- 无权限记录不展示。

### 5.2 一期结果展示范围

已确认一期先做：

- 展示该批号有哪些工序表单。
- 展示各工序表单原状态。
- 展示关键字段摘要。

暂不做：

- 缺失工序判断。

原因：

- 缺失判断需要目标系统标准工序清单和应生成表单规则。

### 5.3 查询方式

已确认：

- 支持精确批号查询。
- 支持扫码/粘贴批号。

### 5.4 状态展示

已确认：

- 直接展示各工序表单原状态。
- 一期不做统一状态映射。

待研发确认：

- 各工序表单是否都有状态字段。
- 各表单状态字段名称是否一致。

### 5.5 查看路径

已确认：

- 点击“查看”进入原工序表单详情页。
- 详情页为只读查看。

### 5.6 查询条件

已确认：

- 批号：必填。
- 生产日期：选填。
- 班次：选填。
- 产线：选填。

批号校验：

- 必填。
- 不限制格式。

### 5.7 结果排序

已确认：

- 按工序生产顺序展示。

待研发确认：

- 工序生产顺序由配置提供、后端返回，还是前端固定枚举。

### 5.8 结果表列

已确认：

- 批号。
- 产线。
- 工序/表单名称。
- 原状态。
- 生产日期。
- 班次。
- 操作人。
- 提交时间。
- 查看。

### 5.9 工序范围

已确认：

- 按目标工厂系统已有工序表单清单来。

待补资料：

- 目标工厂系统已有工序表单清单。

### 5.10 异常与空态

用户确认：

- 查询不到记录时提示：“未查询到该批号关联的工序表单，请检查批号是否正确”。

Codex 建议加入的基础规则：

- 批号为空时提示：“请输入批号”。

说明：

- 批号为空提示属于查询页基础校验，不属于范围扩张。

### 5.11 权限规则

已确认：

- 多角色使用，按权限控制数据范围。
- 有权限的表单显示“查看”。
- 无权限记录不展示该行。

待研发确认：

- 无权限记录由后端过滤，还是前端根据权限过滤。

### 5.12 页面结构

已确认：

- 一期只有一个列表查询页。
- 查询区 + 查询条件摘要 + 结果表 + 查看入口。
- 不增加统一批次概览页。

### 5.13 查询摘要

已确认：

- 查询后显示本次查询条件摘要。

示例：

- 当前查询批号 JS26D015，生产日期 2026-06-26，共查询到 8 条记录。

### 5.14 导出

已确认：

- 一期不做导出。

### 5.15 重置

已确认：

- 点击重置后清空查询条件，结果表回到空态。

## 6. 当前一期最小闭环

用户输入、扫码或粘贴批号，生产日期/班次/产线可选，点击查询后系统按批号查询该用户有权限访问的工序表单记录，按工序生产顺序展示结果。结果表展示批号、产线、工序/表单名称、原状态、生产日期、班次、操作人、提交时间和查看入口。点击查看进入原工序表单只读详情页。查询不到记录时给出明确提示。

- 各工序表单关键字段是否一致。
- 工序生产顺序来源。
- 目标系统工序表单清单来源。
- 原工序表单详情页路由。
- 详情页只读控制方式。
- 数据权限过滤方式。
- 查询性能和分页是否需要。
