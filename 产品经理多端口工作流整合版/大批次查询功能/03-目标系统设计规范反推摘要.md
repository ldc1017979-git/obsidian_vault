# 目标系统设计规范反推摘要

## 1. 设计规范来源

来源类型：现有系统截图反推。

来源系统：数智工厂（测试版）。

来源页面：

- 登录页。
- 登录后的工作台/生产管理模块页面截图。

覆盖情况：

- 已覆盖：系统壳、顶部一级导航、左侧菜单、工作台标签、模块入口面板、搜索框、用户区、图标按钮、页面密度。
- 未覆盖：标准列表页、标准表单页、详情页、弹窗、抽屉、分页、状态标签、只读详情页。

结论：

- 当前截图可以作为“大批次查询页”的系统壳和总体视觉基线参考。
- 由于还缺标准列表页和详情页截图，表格、分页、状态标签和详情页样式仍需在原型中标记为基于现有后台风格推断。

## 2. 页面明确可见

### 2.1 系统壳

- 左侧固定主菜单栏，宽度约 186px。
- 左上角为系统品牌区，蓝色背景，显示建筑图标和“数智工厂（测试版）”。
- 顶部横向一级业务域导航，包含：运营中心、仓储管理、生产管理、质量管理、设备管理、安全管理、人事行政管理、财务管理、数据中心、数据统计、综合管理、数据看板、设置。
- 当前一级导航为“生产管理”，使用蓝色文字和下划线标识激活态。
- 左侧当前菜单为“过程管理”，使用浅蓝底色和蓝色文字标识激活态。
- 顶部右侧有搜索框、通知、云图标、全屏图标、用户头像和账号下拉。

### 2.2 页面层级

- 顶部一级业务域导航用于切换系统大模块。
- 左侧菜单用于切换当前业务域下的功能组。
- 顶部下方有页签/工作台标签，当前可见“工作台”标签。
- 页面主体区域为浅灰背景。
- 当前展开的是一个生产管理功能入口面板，按工序/业务类别多列展示。

### 2.3 功能入口组织

页面主体中的入口面板按业务类别分组：

- 生产管理。
- 称料。
- 配料。
- 拆包。
- 灌装。
- 扫码。

每组下面是多个文本型功能入口，整体呈高密度后台工具型布局。

与本项目相关的可见入口示例：

- 批生产指令。
- 生产订单。
- 清场记录。
- 包装材料物料平衡表。
- 原辅料物料平衡表。
- 拆包工序。
- 灌装工序。
- 灌装封口记录。
- 打码相关记录。

## 3. Codex 基于页面推断

### 3.1 页面风格

推断内容：

- 目标系统属于典型后台管理系统，不是大屏、营销页或低密度展示页。
- 新增“大批次查询”应保留系统壳，放在生产管理域下，左侧过程管理或相关生产记录菜单中。

推断依据：

- 顶部生产管理为激活态。
- 左侧过程管理为激活态。
- 页面主体集中展示生产过程、称料、配料、拆包、灌装、扫码等入口。

可信度：高。

### 3.2 组件风格

推断内容：

- 查询页应使用浅灰页面背景 + 白色内容容器。
- 查询区应采用中高密度表单布局。
- 主按钮使用系统蓝色。
- 表格应采用后台管理常见的紧凑型表格。
- 激活态使用蓝色文字、蓝色下划线或浅蓝底色。

推断依据：

- 当前系统壳和入口页已经呈现蓝色主色、浅灰背景、白色/浅色内容面板和高密度入口布局。

可信度：中高。

### 3.3 页面打开方式

推断内容：

- 大批次查询应作为一个独立列表查询页打开。
- 点击查看后进入原工序表单只读详情页。
- 不建议做营销式说明页或独立大屏。

推断依据：

- 系统已有工作台标签和菜单结构。
- 项目需求已确认一期是一个列表查询页。

可信度：中高。

## 4. 拟作为本项目 UI 基线的规则

### 4.1 必须继承

- 左侧系统品牌栏。
- 顶部一级业务域导航。
- 左侧功能菜单。
- 工作台/页签区域。
- 浅灰页面背景。
- 白色内容区域。
- 蓝色主色和激活态。
- 中高密度后台工具型布局。
- 查询、重置、查看等后台操作按钮语义。

### 4.2 大批次查询页建议位置

建议承载位置：

- 一级业务域：生产管理。
- 左侧菜单：过程管理。
- 页面名称：大批次查询。

说明：

- 这是基于当前截图推断，最终菜单位置仍需产品确认。

### 4.3 大批次查询页布局建议

页面结构：

- 顶部保留系统导航和页签。
- 主体区域使用白色内容容器。
- 上方为查询区。
- 查询区字段：批号、生产日期、班次、产线。
- 查询区操作：查询、重置。
- 查询后显示查询摘要。
- 下方为结果表。
- 结果表列：批号、产线、工序/表单名称、原状态、生产日期、班次、操作人、提交时间、查看。

### 4.4 不应出现

- 大 hero。
- 深色科技大屏。
- 装饰性插画。
- 营销式介绍页。
- 与生产管理无关的示例字段。
- 未确认的导出、编辑、审批操作。
