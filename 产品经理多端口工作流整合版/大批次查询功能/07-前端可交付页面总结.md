## 2. 需求目标

根据大批次号查询该批次关联的多个工序/表单记录，并展示在列表下。

页面需要支持：

- 同一个大批次号下查询全部关联表单。
- 同一个工序/表单名称可能出现多条记录。
- 不同记录可能由不同班次、不同班组创建。
- 产线固定展示。
- 每条表单有独立单据号。
- 点击查看进入只读详情。

## 3. 当前产品口径

端口：工厂端。

承载系统：数智工厂现有后台系统。

页面位置建议：

- 一级导航：生产管理。
- 左侧菜单：过程管理。
- 页签：大批次查询。

页面类型：列表查询页。

一期不做：

- 新增。
- 编辑。
- 删除。
- 导出。
- 批量提交。
- 批量审核。
- 缺失工序判断。
- 统一状态映射。

## 4. 查询条件

| 字段 | 是否必填 | 当前规则 |
|---|---|---|
| 大批次号 | 是 | 支持手输、扫码、粘贴 |
| 生产日期 | 否 | 用于筛选某一天的表单 |
| 班次 | 否 | 早 / 中 / 晚 |
| 产线 | 否 | 当前 mock 固定为四线 |
| 班组 | 否 | A / B / C / D / E |

默认状态：

- 大批次号默认示例为 `JS26D015`。
- 生产日期默认不选，便于展示该大批次号下全部记录。

## 7. 页面交互

### 搜索

用户输入大批次号后点击搜索。

系统行为：

- 大批次号为空时提示“请输入大批次号”。
- 根据大批次号筛选记录。
- 如果选择生产日期、班次、产线、班组，则叠加筛选。
- 查询成功后刷新结果列表和查询摘要。

### 重置

点击重置后：

- 清空查询条件。
- 结果表回到空态。

### 查看

点击列表中的“查看”：

- 打开右侧只读详情抽屉。
- 展示单据号、大批次号、工序表单、产线、班次、班组、生产日期、原状态、操作人、提交时间。
- 当前为 Mock 详情，正式实现应跳转或打开原工序表单只读详情页。

### 开发备注

页面右下角保留“开发备注”入口。

用途：

- 给研发查看字段、权限、状态、数据来源和待确认事项。
- 不替代 PRD 和接口文档。

## 8. UI 基线

页面沿用数智工厂后台风格：

- 左侧蓝色品牌栏。
- 顶部一级导航。
- 左侧菜单。
- Tags-View 页签。
- 浅灰页面背景。
- 白色查询卡片。
- 蓝色搜索按钮。
- 浅色重置按钮。
- 浅蓝灰表头。
- 高密度表格。
- 右侧文本链接操作列。

已按用户提供的目标系统截图反推：

- 生产管理高亮。
- 过程管理高亮。
- 页面保持后台工具型密度。
- 不做大屏、营销页或说明页。
