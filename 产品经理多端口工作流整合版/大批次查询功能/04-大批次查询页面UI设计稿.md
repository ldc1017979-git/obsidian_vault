# 大批次查询页面 UI 设计稿

## 1. 设计基线

采用目标系统“数智工厂（测试版）”现有后台风格。

已参考页面：

- 登录页。
- 生产管理工作台入口页。
- 生产订单标准列表页。

页面风格关键词：

- 浅灰背景。
- 白色内容容器。
- 蓝色主色。
- 中高密度后台工具型布局。
- 顶部业务域导航。
- 左侧功能菜单。
- Tags-View 页签。
- 查询区卡片。
- 高密度表格。
- 右侧文本链接操作列。

## 2. 页面定位

页面名称：大批次查询。

建议菜单位置：

- 一级业务域：生产管理。
- 左侧菜单：过程管理。
- 页签名称：大批次查询。

页面用途：

- 通过批号查询该批号关联的不同工序表单记录。
- 支持生产现场人员、生产主管、工艺人员、质量人员按权限查看。
- 点击查看进入原工序表单只读详情页。

## 3. 页面整体结构

页面从上到下分为：

1. 系统壳。
2. Tags-View 页签。
3. 查询区卡片。
4. 查询结果摘要区。
5. 结果表格。
6. 空态或查询提示。

## 4. 系统壳

沿用目标系统：

- 左侧蓝色品牌区：数智工厂（测试版）。
- 左侧菜单：过程管理为当前高亮。
- 顶部一级导航：生产管理为当前高亮。
- 顶部右侧：搜索框、通知、云图标、全屏、用户头像。
- Tags-View：显示“工作台”和“大批次查询”，当前“大批次查询”高亮。

## 5. 查询区设计

查询区使用白色卡片，布局参考生产订单列表页。

字段布局建议为两行四列：

| 字段 | 控件 | 规则 |
|---|---|---|
| 批号 | 输入框 | 必填，支持手输/扫码/粘贴，不限制格式 |
| 生产日期 | 日期选择器 | 选填 |
| 班次 | 下拉选择 | 选填 |
| 产线 | 下拉选择 | 选填 |

操作区：

| 按钮 | 样式 | 行为 |
|---|---|---|
| 搜索 | 蓝色主按钮，带搜索图标 | 校验批号并刷新结果 |
| 重置 | 浅色描边按钮，带重置图标 | 清空查询条件，结果表回到空态 |

交互规则：

- 批号为空点击搜索，提示“请输入批号”。
- 批号输入框支持扫码枪连续输入和粘贴。
- 生产日期、班次、产线不必填，只作为辅助筛选。

## 6. 查询摘要区

查询成功后，在结果表上方显示一行摘要。

样式：

- 放在表格上方左侧。
- 使用轻量文本，不做醒目大卡片。
- 数字可使用蓝色强调。

示例：

```text
当前查询：批号 JS26D015，生产日期 2026-06-26，班次 A2班，产线 4线，共 8 条记录
```

如果某个筛选条件为空，不展示该条件。

## 7. 表格设计

表格样式参考生产订单列表页：

- 表头浅蓝灰背景。
- 细边框分隔。
- 中高密度行高。
- 左侧不显示勾选框，因为一期不做批量操作。
- 右侧操作列固定。

表格列：

| 列名 | 宽度建议 | 说明 |
|---|---:|---|
| 批号 | 140 | 查询关联批号 |
| 产线 | 90 | 如一线、四线 |
| 工序/表单名称 | 220 | 如拆包记录、灌装封口记录 |
| 原状态 | 110 | 展示各工序表单原状态 |
| 生产日期 | 120 | yyyy-mm-dd |
| 班次 | 100 | 如 A2班 |
| 操作人 | 120 | 表单操作人 |
| 提交时间 | 170 | yyyy-mm-dd hh:mm |
| 操作 | 90 | 查看 |

排序：

- 默认按工序生产顺序展示。
- 暂不提供前端排序控件，避免与工序顺序冲突。

操作列：

- “查看”为蓝色文本链接。
- 点击进入原工序表单只读详情页。
- 无权限记录不返回、不展示。

## 8. 状态展示

一期展示各工序表单原状态，不做统一状态映射。

建议样式：

- 若目标系统已有状态标签颜色，后续按系统规则对齐。
- 当前页面设计稿可先使用普通文本或轻量标签。

待研发确认：

- 各工序表单状态字段来源。
- 是否需要状态颜色映射。

## 9. 空态与异常

初始空态：

```text
请输入批号后点击搜索，查询关联工序表单
```

批号为空：

```text
请输入批号
```

查询不到：

```text
未查询到该批号关联的工序表单，请检查批号是否正确
```

接口失败待研发补充：

```text
查询失败，请稍后重试
```

## 10. 一期不出现的内容

不出现：

- 新增。
- 导入。
- 批量提交。
- 批量审核。
- 导出。
- 编辑。
- 删除。
- 审批。
- 统一批次概览页。
- 大屏图表。
- 说明型欢迎页。

原因：

- 本模块一期定位是查询和只读查看，不参与原工序表单的创建、编辑、提交、审批。
