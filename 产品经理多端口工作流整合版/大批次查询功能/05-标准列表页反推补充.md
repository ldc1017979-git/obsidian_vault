# 标准列表页反推补充

## 1. 来源

来源截图：数智工厂（测试版）生产管理下的“生产订单”标准列表页。

用途：

- 补齐“大批次查询功能”列表页 UI 基线。
- 作为查询区、表格、操作列和按钮样式参考。

## 2. 页面明确可见

### 2.1 系统壳

- 左侧为蓝色品牌区，显示“数智工厂（测试版）”。
- 顶部一级导航中“生产管理”高亮。
- 左侧菜单中“过程管理”高亮。
- 顶部 Tags-View 中有“工作台”“消息中心”“生产订单”等标签。
- 当前页签“生产订单”使用蓝色边框/浅蓝底高亮。

### 2.2 查询区

查询区为白色卡片，置于页面主体顶部。

可见字段：

- 生产订单号。
- 产线。
- 班组。
- 班次。
- 产品名称。
- 产品类型。
- 生产日期。
- 订单日期。
- 制单时间。
- 状态。

布局规则：

- 多列栅格布局。
- 标签在左，控件在右。
- 输入框、下拉框、日期选择器高度统一。
- 日期区间采用“开始时间 - 结束时间”结构。
- 搜索和重置按钮位于查询区右下。

按钮规则：

- 搜索：蓝色主按钮，带搜索图标。
- 重置：浅色描边按钮，带重置图标。

### 2.3 表格区

表格区域位于查询区下方。

可见规则：

- 表格外层为白色内容区。
- 表头背景为浅蓝灰。
- 表格行高偏紧凑。
- 单元格有浅色边框。
- 左侧有复选框列。
- 右侧操作列固定。
- 操作以彩色文本链接形式展示。

可见操作示例：

- 详情。
- 修改订单。
- 销毁。
- 报告导出。
- 冲销。
- 编辑。
- 确认提交。
- 删除。
- 撤回。

### 2.4 工具栏

表格上方左侧有操作按钮：

- 新建生产单。
- 导入生产订单。
- 批量提交。
- 批量审核。

表格上方右侧有小图标工具：

- 刷新。
- 密度/列设置类图标。
- 设置图标。

## 3. 对大批次查询页的适配规则

### 3.1 应继承

- 系统壳。
- 顶部生产管理激活态。
- 左侧过程管理菜单激活态。
- Tags-View 页签打开方式。
- 白色查询区卡片。
- 多列查询表单布局。
- 蓝色搜索按钮。
- 浅色重置按钮。
- 浅蓝灰表头。
- 紧凑表格行高。
- 右侧文本链接操作列。

### 3.2 不应照搬

生产订单页中的以下操作不适用于大批次查询一期：

- 新建。
- 导入。
- 批量提交。
- 批量审核。
- 修改。
- 销毁。
- 删除。
- 撤回。
- 冲销。
- 报告导出。

原因：

- 大批次查询一期定位是查询和只读查看。
- 不参与原工序表单的创建、编辑、提交、审批或导出。

### 3.3 大批次查询页建议

查询区：

- 批号。
- 生产日期。
- 班次。
- 产线。
- 搜索。
- 重置。

表格区：

- 不展示批量操作按钮。
- 可保留右上角刷新/设置类图标，但不作为一期核心能力。
- 操作列只保留“查看”。
