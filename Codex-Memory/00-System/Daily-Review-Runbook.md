# 每日复盘流程

## 运行时段

- 17:00：复盘当日 00:00 至运行时刻的记录，增量写入当日日志。

## 处理流程

1. 获取目标时间段内的 Codex 任务列表与可用摘要。
2. 提取完成事项、未完成事项、关键决策、偏好变化、工作流改进、项目状态与后续承诺。
3. 过滤秘密、敏感凭据、临时聊天和重复内容；推断必须标记 `待确认`。
4. 创建或增量更新 `05-Daily/YYYY-MM-DD.md`，保留来源任务标题或 ID。
5. 将耐久信息同步到对应的偏好、规划、工作流、决策或项目文件；历史只追加或显式标记废弃。
6. 按日期、来源和内容去重；没有新增记录时如实注明，不得编造内容。
