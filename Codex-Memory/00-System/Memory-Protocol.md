# 记忆协议

## 任务开始

1. 阅读 [[../Home]]、[[../01-Profile/Preferences]]、[[../01-Profile/Long-Term-Plans]] 和 [[../02-Workflows/Workflows]]。
2. 按任务关键词搜索 `03-Decisions`、`04-Projects` 与最近 14 天的 `05-Daily`。
3. 只把相关记忆带入当前任务，避免无关上下文干扰。
4. 当前用户明确指令与历史记忆冲突时，以当前指令为准，并记录变更。

## 写入标准

写入：稳定偏好、长期目标、可复用流程、重要决策及理由、项目关键状态、承诺、反复出现的问题和有效经验。

不写入：临时闲聊、一次性细节、未经确认的推测、可轻易重新获得的日志、密码、密钥、令牌、Cookie 或不必要的敏感个人信息。

每条新增记忆应包含日期、主题、内容、适用范围、来源；不确定内容标记为 `待确认`，过时内容标记为 `已废弃`，不得悄悄删除历史。
