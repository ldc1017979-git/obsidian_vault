# Obsidian Memory

Use `D:/Obsidian Vault/Codex-Memory` as the canonical durable-memory store.

## Before a task

1. Read `Home.md` and `00-System/Memory-Protocol.md`.
2. Read preferences, long-term plans, and workflows.
3. Search decisions, projects, and recent daily notes for relevant context.
4. Treat explicit current user instructions as authoritative when they conflict with memory.

## After a task

1. Save only durable preferences, plans, workflows, decisions, project state, commitments, and reusable lessons.
2. Append rather than rewrite history. Add ISO dates and source task titles or IDs when available.
3. Update the canonical topic file and add a short entry to the current daily note.
4. Never store passwords, API keys, tokens, private keys, cookies, or unnecessary sensitive data.
5. Mark uncertain inferences as `待确认`; never convert guesses into facts.

## Daily review

Follow `00-System/Daily-Review-Runbook.md`. Consolidate duplicates, preserve decision history, and link project notes with Obsidian wikilinks.
