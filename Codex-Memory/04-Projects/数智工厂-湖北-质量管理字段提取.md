# 数智工厂-湖北-质量管理字段提取

## 目标

使用 Chrome DevTools MCP，按 `字段和基础资料/数智工厂/SKILL.md` 提取湖北基地质量管理模块表单字段，输出到 Obsidian Vault。

```
基础信息管理/
├── 打码取样信息表
```

## 关键决策

- 菜单名带「﹥」的项存盘文件名去掉「﹥」
- 截图命名：`质量管理_{表单名}_{页面类型}_{序号}.png`
- 子目录 md 截图相对路径用 `../../截图/`
- 水质菜单文件名必须用「水质检测点位（新）」与湖北侧栏一致

## 湖北相对贵州差异（已确认）

- 水质菜单：湖北「水质检测点位（新）」；贵州「水质检测点位」+「广东-水质检测点位」
- 工序标准值配置树含「湖北-开机确认单」「湖北-停机确认单」「水质检测报告」
- 计量标准值配置湖北可交互（1 条标志块标准值）
- 浮游菌测点列名「浓度标准」
