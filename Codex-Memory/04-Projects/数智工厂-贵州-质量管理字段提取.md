# 数智工厂-贵州-质量管理字段提取

## 目标

使用 Chrome DevTools MCP，按 `字段和基础资料/数智工厂/SKILL.md` 提取贵州基地质量管理模块表单字段，输出到 Obsidian Vault。

## 当前状态

- **基础信息管理**：主表单、标准值配置（21项）与仪器信息（2项）已全部完成
- **输出目录**：`字段和基础资料/数智工厂/贵州/字段/质量管理/基础信息管理`
- **截图目录**：`字段和基础资料/数智工厂/贵州/字段/质量管理/截图`
- **系统地址**：`https://gzmms.y1b.cn:8424`

## 框架结构（与网页侧栏一致）

```
基础信息管理/
├── 打码取样信息表
├── UV判定表
├── 标准值配置/（21 个子表单）
├── 检验依据
├── 定量项目
└── 仪器信息/（仪器管理、电子天平电子秤目录）
```

## 关键决策

- 菜单名带「﹥」的项（UV判定表、检验依据、定量项目）存盘文件名去掉「﹥」
- 截图命名：`质量管理_{表单名}_{页面类型}_{序号}.png`
- 子目录 md 截图相对路径用 `../../截图/`
- 贵州侧栏较广东多「计量标准值配置」「水质检测点位」两项
