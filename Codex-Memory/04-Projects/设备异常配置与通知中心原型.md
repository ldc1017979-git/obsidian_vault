# 设备异常配置与通知中心原型

- 目标：设计设备异常配置与异常通知中心的可交互 HTML 原型。
- 当前状态：已完成可预览原型。配置页只保留“设备点位表”和“通知接收人”；通知中心只展示异常处理所需字段。
- 关键决策：通知接收人支持多选和模糊搜索；已配置设备点位不可重复选择，保存时再次校验；通知中心不展示电表、水表、蒸汽表、燃气表分类及“连接异常”按钮。
- 通知字段：设备异常通知、时间、设备数据异常提示、前往查看、设备点位表名称、采集数据、单位、上限值、下限值。
- 已完成验证：旧字段和无关按钮无残留；设备重复选择禁用逻辑存在；导航保持单一高亮。
- 下一步：等待用户对原型进行业务验收或提出后续调整。
