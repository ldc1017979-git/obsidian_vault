# 04-Codex 整理 GitHub 仓库提示词

## 1. 仓库体检提示词

```text
请读取当前仓库，按“GitHub文件管理包”的规范做一次仓库体检。

请重点检查：
1. 顶层目录是否清晰
2. README 是否能说明项目用途、运行方式和使用方式
3. .gitignore 是否覆盖常见临时文件、依赖目录、构建产物和敏感配置
4. 文件命名是否清楚
5. 是否有疑似密钥、Token、账号、Cookie、私有配置
6. 是否有不该进入 GitHub 的大文件、缓存文件、导出文件
7. 是否有重复、过期、无人维护的文件

请输出：
1. 当前问题清单
2. 风险等级
3. 建议目录结构
4. 需要移动、重命名、删除或补充的文件
5. 可以直接执行的整理步骤
```

## 2. 生成 README 提示词

```text
请根据当前仓库内容生成或更新 README.md。

README 需要包含：
1. 项目名称
2. 项目用途
3. 目录结构说明
4. 安装或运行方式
5. 常用命令
6. 使用说明
7. 协作规则
8. 注意事项

要求简洁、准确，不要写无法从仓库确认的信息。
```

## 3. 生成 .gitignore 提示词

```text
请根据当前项目技术栈生成或更新 .gitignore。

请覆盖：
1. 依赖目录
2. 构建产物
3. 缓存文件
4. 本地环境变量
5. 系统文件
6. 编辑器配置中不需要共享的内容
7. 日志文件

不要忽略必须进入仓库的示例配置文件，例如 .env.example。
```

## 4. 整理文件提示词

```text
请帮我整理当前仓库文件。

整理原则：
1. 不删除用户资料，除非我明确确认
2. 先给移动和重命名方案
3. 说明每个文件为什么移动
4. 保留 README、docs、src、assets、data、scripts、tests 等清晰结构
5. 检查是否会破坏引用路径

请先输出方案，等我确认后再执行。
```
