# 开始这里：GitHub 文件管理只看这个

## 1. 你只需要记住一件事

GitHub 仓库不是网盘，而是一个可追踪变更的项目工作区。

每个文件都应该回答三个问题：

```text
这个文件是什么？
它应该放在哪里？
它为什么需要被提交？
```

## 2. 新建仓库时先放这些文件

```text
README.md        项目说明入口
.gitignore       忽略不该上传的文件
docs/            文档
src/             源代码
assets/          图片、图标、演示素材
data/            样例数据或公开数据
scripts/         工具脚本
tests/           测试文件
CHANGELOG.md     版本变更记录
```

## 3. 每次提交前做 5 个检查

- 这次提交只做了一类事情吗？
- 文件名是否能看懂？
- 有没有误传账号、密钥、Token、Cookie？
- 有没有误传临时文件、缓存文件、大文件？
- 提交说明是否能让别人知道你改了什么？

## 4. 推荐的日常流程

```text
同步最新代码
-> 新建或切换分支
-> 修改文件
-> 本地检查
-> 提交 commit
-> 推送到 GitHub
-> 创建 Pull Request
-> 合并后删除临时分支
```

## 5. 给 Codex 的一句话

```text
请读取当前项目里的“GitHub文件管理包”，帮我检查这个仓库的目录结构、文件命名、.gitignore、README、提交规范和风险文件，并给出可执行的整理方案。
```
