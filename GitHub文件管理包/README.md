# GitHub 文件管理包

## 1. 这个包解决什么问题

用于管理一个 GitHub 仓库里的文件、目录、分支、提交和协作规则，避免出现这些问题：

- 文件不知道放哪里
- 文件名随意，后续找不到
- README、文档、代码、素材混在一起
- 每次提交说明不清楚
- 分支多人乱改，难以合并
- 大文件、临时文件、账号密钥误传到 GitHub

## 2. 推荐使用顺序

1. 先看 `开始这里-GitHub文件管理只看这个.md`
2. 新建仓库前，看 `01-仓库目录结构规范.md`
3. 每天提交代码或资料前，看 `02-提交与分支管理SOP.md`
4. 需要多人协作时，看 `03-协作与权限规范.md`
5. 要让 Codex 帮你整理仓库时，复制 `04-Codex整理GitHub仓库提示词.md`
6. 每周或发版前，用 `05-GitHub文件管理检查清单.md` 做检查

## 3. 默认仓库结构

```text
project-name/
├─ README.md
├─ docs/
├─ src/
├─ assets/
├─ data/
├─ scripts/
├─ tests/
├─ .gitignore
└─ CHANGELOG.md
```

## 4. 质量红线

- 不上传密码、密钥、Token、Cookie、私有配置
- 不上传无说明的大文件
- 不把临时文件、导出文件、缓存文件直接提交
- 不用 `final-final-v2` 这类文件名
- 不在主分支直接做高风险修改
- 不提交无法说明目的的改动
