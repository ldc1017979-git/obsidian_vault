# 05-GitHub 文件管理检查清单

## 1. 仓库入口

- [ ] 有 `README.md`
- [ ] README 说明项目是什么
- [ ] README 说明如何运行或使用
- [ ] README 说明目录结构
- [ ] 有 `.gitignore`
- [ ] 有必要时包含 `CHANGELOG.md`

## 2. 目录结构

- [ ] 顶层目录不混乱
- [ ] 文档放在 `docs/`
- [ ] 代码放在 `src/`
- [ ] 素材放在 `assets/`
- [ ] 数据放在 `data/`
- [ ] 脚本放在 `scripts/`
- [ ] 测试放在 `tests/`

## 3. 文件命名

- [ ] 文件名能看懂
- [ ] 没有 `最终版`、`新建文档`、`final-final` 这类名称
- [ ] 同类文件命名风格一致
- [ ] 日期文件使用统一格式，例如 `2026-06-22`

## 4. 安全风险

- [ ] 没有密码
- [ ] 没有 Token
- [ ] 没有私钥
- [ ] 没有 Cookie
- [ ] 没有真实 `.env`
- [ ] 没有内部账号配置

## 5. 垃圾文件

- [ ] 没有 `node_modules/`
- [ ] 没有无必要的 `dist/` 或 `build/`
- [ ] 没有系统缓存文件
- [ ] 没有临时导出文件
- [ ] 没有无说明的大文件

## 6. 协作流程

- [ ] 分支命名清楚
- [ ] 提交说明清楚
- [ ] 一次提交只做一类事情
- [ ] Pull Request 写明变更内容
- [ ] 合并前检查风险文件
