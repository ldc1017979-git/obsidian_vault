## 1. 页面概述

- **页面路径**: 安全管理 → 现场管理 → 特种设备台账
- **页面URL**: `https://fjmms.y1b.cn:8424/#/safety-manage/onsite/special-EQP/special-equipment`
- **数据来源说明**: 数据来源：资产档案或设备台账，辅助分类【特种设备】
- **资产类型树**: 特种设备（id=5，系统大类，归属安全管理部）

## 5. API数据采集结果

### API接口信息

- **接口地址**: `https://fjmms.y1b.cn:8424/mro/equipment_special/equipment`
- **请求方法**: POST
- **Content-Type**: application/json;charset=UTF-8

### 请求参数

```json
{
  "page": 1,
  "size": 10,
  "equipment_type": "5",
  "keyword": null,
  "save_addr": null,
  "use_dept_id": null,
  "use_duty_user": null,
  "open_date_start": null,
  "open_date_end": null
}
```

### 采集结果

| 项目 | 值 |
|------|------|
| 数据总量 | **0条** |
| 当前页 | 1 |
| 每页条数 | 10 |
| 状态 | 当前特种设备台账暂无数据 |

> **说明**: 特种设备类型（id=5）为系统大类，归属安全管理部，当前系统中尚未录入任何特种设备台账数据。

### 资产类型树接口

- **接口地址**: `https://fjmms.y1b.cn:8424/mro/Post/getEqipmentTypeSelect`
- **请求参数**: `{"is_special": 1}`

返回结果：

| 字段 | 值 |
|------|------|
| id | 5 |
| name | 特种设备 |
| pid | 0 |
| rank | 0 |
| status | 1 |
| module_type | 1 |
| dept | 安全管理部 |
| note | 系统大类 |
| 子类型 | 无 |
