## 1. 页面概述

- **页面名称**：UV判定表
- **所属模块**：质量管理 → 基础信息管理
- **页面URL**：`https://fjmms.y1b.cn:8424/#/quality-manage/index2/uv-config`
- **功能说明**：用于管理UV（紫外分光光度法）检测判定标准数据，记录不同批次产品的可溶性固形物、pH值、牛磺酸、咖啡因、nm等关键检测指标。

![列表页初始状态](截图/UV判定表-列表页-初始状态.png)

---

## 2. 页面导航路径

1. 登录系统：`https://fjmms.y1b.cn:8424/#/dashboard`
2. 点击左侧菜单「质量管理」展开子菜单
3. 点击「基础信息管理」展开子菜单
4. 点击「UV判定表」进入页面

---

## 3. 列表页功能说明

### 3.1 产品类型Tab

页面顶部有产品类型Tab选项卡，当前系统仅有一个类型：

| Tab名称 | 产品编码 | 产品全称 |
|---------|---------|---------|
| 红牛-普通型 | ND1-1 | 红牛维生素功能饮料 |

### 3.2 搜索筛选区域

| 筛选项 | 类型 | 说明 |
|-------|------|------|
| 启用日期 | 日期范围选择器 | 包含"开始日期"和"结束日期"两个输入框 |
| 批次 | 文本输入框 | 按批次号筛选 |
| 批号 | 文本输入框 | 按批号筛选 |
| 重置 | 按钮 | 清空所有筛选条件 |
| 搜索 | 按钮 | 执行搜索查询 |

### 3.3 操作按钮区域

| 按钮 | 说明 |
|------|------|
| 新建 | 打开新增UV信息对话框 |
| 列设置（齿轮图标） | 设置表格密度（宽松/默认/紧凑） |
| 列筛选（图标） | 设置显示/隐藏列 |

### 3.4 列表表格

表格列定义如下：

| 列名 | 字段名 | 说明 |
|------|--------|------|
| 启用状态 | status | 1=启用，0=停用 |
| 启用时间 | open_time | UV判定启用的时间 |
| 截止时间 | end_time | UV判定截止的时间 |
| 生产日期 | pro_date | 产品生产日期 |
| 时间 | check_time | 检测时间 |
| 批次 | batch_no | 生产批次编号 |
| 批号 | batch_number | 检测批号 |
| 可溶性固形物 | soluble_solid_val | 可溶性固形物含量 |
| pH | ph_val | pH值 |
| 牛磺酸 | taurine_val | 牛磺酸含量 |
| 咖啡因 | caffeine_val | 咖啡因含量 |
| nm | nm_val | nm值（默认271.5） |
| 创建时间 | create_time | 记录创建时间 |
| 创建人 | ct_name | 记录创建人 |
| 备注 | note | 备注信息 |

### 3.5 分页功能

- 每页条数选择：10条/页（可选）
- 总记录数：10条
- 页码：共1页
- 支持跳转到指定页

## 4. 新建表单详情

点击「新建」按钮后弹出对话框，标题为"新增UV信息—红牛-普通型"。

![新建表单对话框](截图/UV判定表-新建-表单对话框.png)

表单字段说明：

| 字段名 | 类型 | 是否必填 | 默认值 | 说明 |
|--------|------|---------|--------|------|
| 生产日期 | 日期选择器 | 是（*） | - | 产品生产日期 |
| 时间 | 时间选择器 | 是（*） | - | 检测时间 |
| 批次 | 文本输入框 | 是（*） | - | 生产批次编号 |
| 批号 | 文本输入框 | 是（*） | - | 检测批号 |
| 可溶性固形物 | 文本输入框 | 是（*） | - | 可溶性固形物含量 |
| pH | 文本输入框 | 是（*） | - | pH值 |
| 牛磺酸 | 文本输入框 | 是（*） | - | 牛磺酸含量 |
| 咖啡因 | 文本输入框 | 是（*） | - | 咖啡因含量 |
| nm | 文本输入框 | 是（*） | 271.5 | nm值，默认271.5 |
| 备注 | 多行文本框 | 否 | - | 备注信息 |

操作按钮：
- **取消**：关闭对话框
- **确定**：提交表单

## 5. 列设置功能

点击列设置齿轮图标后，弹出密度设置菜单：

![列设置密度选项](截图/UV判定表-列设置-密度选项.png)

| 选项 | 说明 |
|------|------|
| 宽松 | 表格行间距较大 |
| 默认 | 表格行间距适中 |
| 紧凑 | 表格行间距较小 |
