## 3. 搜索区域功能

| 筛选项 | 类型 | 说明 |

## 4. 列表页功能

### 表格列定义

| 列名 | 说明 |
|------|------|
| 序号 | 自动编号 |
| 仪器编码 | 仪器唯一编码，如C-QC-A10 |
| 仪器名称 | 仪器的名称 |
| 出厂编号 | 仪器出厂时的编号 |
| 仪器型号 | 仪器的型号规格 |
| 所属品牌 | 仪器的品牌/制造商 |
| 仪器类型 | 仪器的分类类型（如恒温箱） |
| 可用状态 | 开关控件，启用/禁用状态 |
| 创建人 | 创建该记录的用户 |
| 创建时间 | 记录创建的时间 |
| 更新人 | 最后更新该记录的用户 |
| 更新时间 | 最后更新的时间 |
| 操作 | 编辑、删除按钮 |

### 操作列按钮

| 按钮 | 功能说明 |
|------|----------|
| 编辑 | 打开编辑检测仪器对话框，表单预填充当前数据 |
| 删除 | 弹出确认对话框，确认后删除该条记录 |

### 可用状态开关

每行记录的"可用状态"列包含一个开关控件（Switch），用于快速切换仪器的启用/禁用状态。

### 分页功能

| 功能 | 说明 |
|------|------|
| 每页条数 | 可选10/20/40/50条/页 |
| 页码导航 | 支持点击页码跳转，当前共4页 |
| 上一页/下一页 | 翻页按钮 |
| 前往 | 输入页码直接跳转 |

## 9. API数据接口

### 接口信息

| 项目 | 内容 |
|------|------|
| 接口地址 | `https://fjmms.y1b.cn:8424/qlty/Inst/getInstList` |
| 请求方式 | POST |
| Content-Type | application/json;charset=UTF-8 |
| 认证方式 | Authorization请求头 |

### 请求参数

```json
{
  "page": 1,
  "size": 10,
  "name": null,
  "is_open": null
}
```

| 参数 | 类型 | 说明 |
|------|------|------|
| page | Integer | 页码，从1开始 |
| size | Integer | 每页条数 |
| name | String | 仪器名称筛选，null表示不筛选 |
| is_open | Integer | 可用状态筛选，null表示不筛选 |

### 响应数据结构

```json
{
  "code": "1",
  "data": {
    "total": 32,
    "per_page": "10",
    "current_page": 1,
    "last_page": 4,
    "data": [...]
  },
  "msg": "success",
  "time": 0.02641010284423828
}
```

### 数据字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer | 记录唯一标识 |
| is_open | Integer | 可用状态（1=启用，0=禁用） |
| code | String | 仪器编码 |
| name | String | 仪器名称 |
| productserial_no | String | 出厂编号 |
| inst_type_no | String | 仪器型号 |
| brand | String | 所属品牌 |
| type | String | 仪器类型（null表示未分类） |
| create_time | String | 创建时间 |
| update_time | String | 更新时间 |
| ct_uid | Integer | 创建人ID |
| ct_name | String | 创建人姓名 |
| up_uid | Integer | 更新人ID |
| up_name | String | 更新人姓名 |
