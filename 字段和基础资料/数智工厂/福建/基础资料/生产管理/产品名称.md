## 1. 页面概述

产品名称页面用于管理生产系统中的产品基础信息，包括产品名称、单罐规格、包装规格、产品大类、产品小类、状态、工艺规程等关键配置项。页面支持搜索、新增、编辑、禁用等操作功能。

## 2. 搜索功能

页面顶部提供搜索区域，包含以下搜索条件：

## 5. 新增产品信息对话框

点击"新增"按钮，右侧弹出抽屉式"新增产品信息"对话框，包含以下表单字段：

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 产品名称 | 下拉选择 | 是（*） | 选择产品名称，下拉选项包含物料分类及具体产品名称 |
| 单罐规格 | 数字输入 | 是（*） | 输入单罐容量，单位为ml/罐，最小值1 |
| 包装规格 | 文本输入 | 是（*） | 输入包装规格描述（如"24罐/箱"） |
| 产品大类 | 单选按钮 | 是（*） | 红牛 / 战马 |
| 产品小类 | 下拉选择 | 是（*） | 选择产品小类 |
| 产品状态 | 单选按钮 | 是（*） | 启用 / 禁用 |
| 工艺规程 | 多行文本 | 是（*） | 输入工艺规程描述，最大500字符 |
| 备注信息 | 文本输入 | 否 | 输入备注说明 |

```

3、各岗位依据产品《生产工艺流程》、《工序质量预控计划》及作业指导书等标准规范生产，按时保质保量完成生产计划产量，具体工艺执行如下：
```
