## 1. 页面概述

产线工序页面用于管理生产线上的工序基础信息，包括工序名称、更新人、更新时间、制单人、创建时间、状态等关键信息。页面支持搜索、新增、编辑、禁用等操作功能。

![产线工序-列表页第1页](截图/产线工序-列表页-第1页.png)

---

## 2. 搜索功能

页面顶部提供搜索区域，包含以下搜索条件：

| 搜索字段 | 类型 | 说明 |
|----------|------|------|
| 工序 | 文本输入 | 输入工序名称关键字进行搜索 |
| 状态 | 下拉选择 | 按状态筛选，选项：可用、禁用、启用 |

搜索区域按钮：

| 按钮 | 功能 |
|------|------|
| 重置 | 清空搜索条件，恢复默认列表 |
| 搜索 | 按输入条件搜索工序 |

状态下拉选项：

| 选项 | 说明 |
|------|------|
| 可用 | 筛选可用状态的工序 |
| 禁用 | 筛选禁用状态的工序 |
| 启用 | 筛选启用状态的工序 |

![状态下拉选项](截图/产线工序-状态下拉选项.png)

## 4. 列设置选项

点击表格右上角的列设置按钮，可配置表格显示的列。可配置的列包括：

| 列名 | 是否默认显示 |
|------|-------------|
| 序号 | 否 |
| 产品名称 | 否 |
| 单罐规格 | 否 |
| 包装规格 | 否 |
| 产品大类 | 否 |
| 产品小类 | 否 |
| 备注信息 | 否 |
| 创建人 | 否 |
| 创建时间 | 是 |
| 更新人 | 是 |
| 更新时间 | 是 |
| 生产班组 | 否 |
| 可用状态 | 否 |
| 工序 | 是 |
| 制单人 | 是 |

## 5. 新增产线工序对话框

点击"新增"按钮，弹出"新增产线工序"对话框，包含以下表单字段：

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 工序 | 文本输入 | 是（*） | 输入工序名称 |
| 状态 | 单选按钮 | 是（*） | 选项：启用（默认选中）、禁用 |

对话框按钮：取消 / 确认

![新增对话框](截图/产线工序-新增对话框.png)

---

## 6. 编辑产线工序对话框

点击列表中某条记录的"编辑"按钮，弹出"编辑产线工序"对话框。表单结构与新增对话框相同，字段会预填充当前记录的数据。

### 编辑状态下的字段

| 字段 | 预填充值 |
|------|----------|
| 工序 | 当前工序名称 |
| 状态 | 当前状态（启用/禁用） |

对话框按钮：取消 / 确认

![编辑对话框](截图/产线工序-编辑对话框.png)

---

## 7. 禁用确认对话框

点击列表中某条记录的"禁用"按钮，弹出确认对话框：

- **标题**：提示
- **内容**：确定禁用吗？
- **按钮**：取消 / 确定
