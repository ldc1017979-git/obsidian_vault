## 1. 页面概述

员工岗位管理页面用于管理企业内各岗位的基础信息，包括岗位名称、所属部门、建议薪酬、任职条件、岗位职责、工作地点、工作内容、岗位标配人数、工作班制、岗位作业类型、工作班时间等。页面支持搜索、新增岗位、批量导入、导出数据等操作功能。

当前页面数据状态：已加载数据，共39条岗位记录（9个部门，全部启用）。

## 5. 新增岗位对话框

点击"新增岗位名称"按钮，弹出"岗位名称"对话框，包含以下表单字段：

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 岗位名称 | 文本输入 | 是（*） | 输入岗位名称 |
| 所属部门 | 文本输入 | 是（*） | 输入所属部门 |
| 建议薪酬 | 文本输入 | 否 | 输入薪酬范围（两个输入框，中间"——"分隔） |
| 任职条件 | 多行文本 | 否 | 输入任职条件（最多100字） |
| 岗位状态 | 单选按钮 | 否 | 选项：启用（默认）、禁用 |
| 显示顺序 | 数字输入 | 否 | 输入排序值，默认为0 |
| 岗位职责 | 多行文本 | 否 | 输入岗位职责（最多100字） |
| 工作地点 | 文本输入 | 否 | 输入工作地点 |
| 工作内容 | 文本输入 | 否 | 输入工作内容 |
| 岗位标配人数 | 文本输入 | 否 | 输入标配人数 |
| 工作班制 | 下拉选择 | 否 | 选择工作班制 |
| 岗位作业类型 | 下拉选择 | 否 | 选择岗位作业类型 |
| 工作班时间 | 复合输入 | 否 | 输入天制 + 小时/天 |

### 岗位状态选项

| 选项 | 说明 |
|------|------|
| 启用 | 岗位处于启用状态（默认） |
| 禁用 | 岗位处于禁用状态 |

### 工作班时间输入

工作班时间由两个输入框组成：

| 输入框 | 单位 | 说明 |
|--------|------|------|
| 第一个输入框 | 天制 | 输入工作天数 |
| 第二个输入框 | 小时/天 | 输入每天工作小时数 |

对话框按钮：取消 / 确定
