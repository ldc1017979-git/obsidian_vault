# 经济数据指标﹥

## 页面概述

- **功能说明**：经济数据指标数据分析看板，以可视化图表形式展示生产概况、KPI考核指标、一般考核指标等经济数据
- **URL**：`https://fjmms.y1b.cn:8424/#/operating-center/economic-data-indicators`
- **所属模块**：运营中心
- **页面类型**：嵌入式BI看板（iframe嵌入，来源：bigdata.y1b.cn）

## 交互说明

1. 该页面为嵌入式BI看板，数据来源于bigdata.y1b.cn
2. 可通过时间范围和数据类型切换查看不同维度的数据
3. 点击"查询"按钮刷新看板数据
4. 各指标图表支持交互查看详细数值
5. 达标率以百分比形式展示，0.00%表示未达标
