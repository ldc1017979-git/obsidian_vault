# 成品标准值配置

## 页面概述

- **功能说明**：配置成品检验的标准值；支持按左侧检验分类与品牌 Tab 维护各检验项目的初检/复检标准，标准可来自「自主配置」或「集团标准」，并支持修约方式配置
- **页面URL**：`https://fjmms.y1b.cn:8424/#/quality-manage/index2/qc-standard-value-configuration/finished`
- **编辑页URL**：`https://fjmms.y1b.cn:8424/#/quality-manage/index2/qc-standard-value-configuration/finished/add?id={id}&pageType=2`
- **所属模块**：质量管理 > 基础信息管理 > 标准值配置 > 成品标准值配置
- **实机核对**：福建基地 `fjmms.y1b.cn:8424`，2026-07-28

## 交互说明

1. 左侧为树形配置分类，点击分类切换右侧检验项目列表；可用「配置名称」搜索分类。
2. 顶部品牌 Tab（红牛 / 战马 / 红牛-普通型 / 红牛-强化型）切换产品维度。
3. 列表操作由原先的「编辑/删除」改为 **配置标准**，进入独立编辑页（非弹窗）。
4. **标准来源 = 自主配置**：可编辑单位、检验类型（弹窗）、是否判定、小数保留位数、**修约方式**。
5. **标准来源 = 集团标准**：展示集团主键ID、版本及集团标准只读字段（含品牌、计算方式、检测频率、修约方式、样本来源等）。
6. 成品相对原材料：列表与自主配置均多出 **修约方式**；集团标准字段结构侧重「品牌/物料大类」而非「物料品类/物料归属」。
7. 编辑页支持「详情信息」「单据日志」页签；保存使用顶部 **确认执行**。
