# RO水检测记录表

## 页面概述

- **功能说明**：管理 RO 水检测记录，按时间点录入电导率、pH、余氯（可选检）、外观等检验明细；支持新建、签字完成、导出与自定义报告
- **列表页URL**：`https://fjmms.y1b.cn:8424/#/quality-manage/qc-quality-control/water-quality-monitoring/ro-water-test`
- **新建页URL**：`https://fjmms.y1b.cn:8424/#/quality-manage/qc-quality-control/water-quality-monitoring/ro-water-test/add?pageType=1`
- **详情页URL**：`https://fjmms.y1b.cn:8424/#/quality-manage/qc-quality-control/water-quality-monitoring/ro-water-test/add?pageType=3&id={id}`
- **所属模块**：质量管理 > QC质量控制 > 监视与测量 > 水质监测 > RO水检测记录表
- **实机核对**：福建基地 `fjmms.y1b.cn:8424`，2026-07-28
- **列表数据量**：共 506 条（实机；单据可含多条检测时间明细行）

### 检验信息（明细表）

| 序号 | 字段名称 | 说明 |
| :--- | :--- | :--- |
| 1 | # | 序号 |
| 2 | 检验时间 | 四位时间，如 `02:50` |
| 3 | 检测控制温度（℃） | 可填 `/` 表示未检 |
| 4 | 电导率 (0.00~2.99)μS/cm | 数值；标准由旧「≤3.0 us/cm」调整为区间 **0.00~2.99 μS/cm** |
| 5 | pH (5.20~6.80) | 数值 |
| 6 | 检余氯否 (不检) | 下拉；实机见「不检」；替代旧「二氧化氯」单一项 |
| 7 | 余氯 (~)ppm | 检余氯时录入；不检时显示 `-` |
| 8 | 外观 | **新增**；实机见「清澈/无异味」 |
| 9 | 检验结论 | 如：合格 |
| 10 | 备注 | 行备注 |

> 旧明细列「二氧化氯(<0.20)ppm」已不在实机表头中；现为「检余氯否 + 余氯」。

## 变更摘要（相对旧版字段文档）

| 变更点 | 旧 | 新（2026-07-28 实机） |

| 基础信息 | 无复检结果 | **新增复检结果** |
| 详情页签 | 未写复检 | **详情信息、复检信息** |
