### 检验信息 · 检测批列

列头：`检测批数` + **第一批～第八批**（每批可开关；第八批等可启用）。

| 行项目（左侧） | 类型/选项 | 说明 |
| :--- | :--- | :--- |
| 批号 | 文本 | 各批批号 |
| 罐底码时间 | 时间文本 | 如 `08:00` |
| 理化检测 / 可溶性固形物 / 样品检测温度（℃） | 数值 | 各批温度 |
| 检测值（12.1~12.6 %） | 数值 | 可溶性固形物检测值（标准随配置） |
| pH（3.40~3.55 ） | 数值 | pH（标准随产品/配置） |
| 感官（滋味、气味、纯净度） | 正常 / 异常 | 单选 |
| 罐内压（-0.0200~0.0100 MPa） | 数值 | 罐内压 |
| 液位（≥245.0 mL） | 数值 | 液位 |
| 平均液位（mL）（≥250.0 mL） | 只读汇总 | 自动计算 |
| 液位≥250ml占比率（≥250.0 mL） | 只读汇总 | 自动计算，如 `100.00%` |
