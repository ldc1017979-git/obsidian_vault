# 仪器更换记录

## 列表页

### 搜索条件

| 序号 | 字段名称 | 输入类型 | 默认值 | 是否必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 确认状态 | select | 空 | 否 | 下拉选择确认状态 |
| 2 | 更换人 | select | 空 | 否 | 下拉选择更换人 |
| 3 | 更换时间 | date | 空 | 否 | 选择更换时间范围（开始日期 - 结束日期） |

### 操作按钮

| 序号 | 按钮名称 | 说明 |
| :--- | :--- | :--- |

| 3 | 新建 | 新增更换记录（弹窗） |
| 4 | 导出数据 | 导出数据 |

## 新增更换记录（弹窗）

### 表单字段

| 序号 | 字段名称 | 输入类型 | 默认值 | 是否必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 仪器名称 | button | 空 | 是 | 点击"点击选择仪器"按钮选择仪器 |
| 2 | 更换时间 | datetime | 空 | 是 | 选择更换时间 |
| 3 | 更换配件 | text | 空 | 是 | 输入更换配件名称 |
| 4 | 更换人 | text | 当前用户 | 否 | 更换人（只读，默认当前登录用户） |
| 5 | 更换原因 | textarea | 空 | 是 | 输入更换原因 |
| 6 | 备注 | textarea | 空 | 否 | 输入备注信息 |

### 操作按钮

| 序号 | 按钮名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 取消 | 取消并关闭弹窗 |
| 2 | 保存 | 保存当前记录 |
| 3 | 签字确认 | 签字并确认记录 |
