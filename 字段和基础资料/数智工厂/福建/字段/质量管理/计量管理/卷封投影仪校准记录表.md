## 新增校准记录（弹窗）

![卷封投影仪校准记录表新建页](计量管理_卷封投影仪校准记录表_新建页_1.png)

### 表单字段

| 序号 | 字段名称 | 输入类型 | 默认值 | 是否必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 仪器编号 | text + button | 空 | 是 | 选择仪器编号（只读，点击搜索按钮选择） |
| 2 | 仪器型号 | text | 空 | 否 | 仪器型号（只读，选择仪器后自动填充） |
| 3 | 仪器名称 | text | 空 | 否 | 仪器名称（只读，选择仪器后自动填充） |
| 4 | 使用地点 | text | 空 | 是 | 输入使用地点 |
| 5 | 车间 | select | 空 | 是 | 下拉选择车间 |
| 6 | 校准日期 | date | 空 | 是 | 选择校准日期 |
| 7 | 校准时间 | time | 空 | 是 | 选择校准时间 |
| 8 | 标准块标准值(mm) | number | 空 | 是 | 输入标准块标准值（单位：mm） |
| 9 | 校准人 | text | 当前用户 | 否 | 校准人（只读，默认当前登录用户） |
| 10 | 备注 | text | 空 | 否 | 输入备注信息 |
| 11 | 测量值(mm) - X | text | 空 | 是 | 输入X方向测量值（单位：mm） |
| 12 | 测量值(mm) - Y | text | 空 | 否 | 输入Y方向测量值（单位：mm） |
| 13 | 误差值(mm) - X | text | 空 | 是 | 输入X方向误差值（单位：mm） |
| 14 | 误差值(mm) - Y | text | 空 | 否 | 输入Y方向误差值（单位：mm） |

### 操作按钮

| :--- | :--- | :--- |

| 3 | 签字确认 | 签字并确认校准记录 |
