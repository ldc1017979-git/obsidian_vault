## 新增表单字段

点击"新增配置"按钮打开新建页面，表单字段如下：

| 序号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 计划组名称 | 文本输入框 | **是** | 点巡检计划组名称 |
| 2 | 备注 | 文本输入框 | 否 | 备注说明 |
| 3 | 关联图示 | 图片上传 | 否 | 仅能上传png/jpg/jpeg格式，最多6张 |

### 关联检查项区域

点击"关联检查项"按钮可选择关联的检查项：

| 字段名称 | 说明 |
| :--- | :--- |
| 检查内容组名 | 检查内容组名称 |
| 检查目的 | 检查目的描述 |
| 备注 | 备注说明 |
| 检查项总数 | 检查项数量 |

### 表单操作按钮

| 按钮名称 | 描述 |
| :--- | :--- |
| 关联检查项 | 关联检查项目 |
