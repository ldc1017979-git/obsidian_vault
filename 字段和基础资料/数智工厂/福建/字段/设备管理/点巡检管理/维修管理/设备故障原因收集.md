# 设备故障原因收集

## 页面概述

- **功能说明**：管理设备故障原因的收集，维护故障原因字典数据，支持新增、编辑、删除故障原因
- **URL**：`https://fjmms.y1b.cn:8424/#/device-manage/device/inspection-deivce/inspection-deivce/cause`

| 序号 | 字段名称 | 字段类型 | 默认值 | 约束条件 | 说明 |
