# 能源层级统计报表

## 页面概述

- **功能说明**：展示能源层级统计数据，按能源层级类型、分组名称、抄表日期、参与核算筛选，支持导出数据
- **URL**：`https://fjmms.y1b.cn:8424/#/device-manage/statements/energy/direct-statement/hierarchy-statistics`
