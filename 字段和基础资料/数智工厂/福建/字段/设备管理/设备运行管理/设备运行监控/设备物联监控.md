# 设备物联监控

## 页面概述

- **功能说明**：设备物联监控看板，以卡片形式展示各设备的实时监控信息，支持按设备类型（生产设备、检测设备、辅助设备）和线别（一线、二线）切换查看，展示设备资产类型、设备台账、所属岗位等信息
- **URL**：`https://fjmms.y1b.cn:8424/#/device-manage/equipment-operate/Operation-monitoring/iot-monitoring`

## 筛选条件

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 设备类型 | radio | 生产设备 | 可选 | 单选切换：生产设备、检测设备、辅助设备 |
| 2 | 线别 | tab | 一线 | 可选 | 标签页切换：一线、二线 |

## 操作按钮

无

## 设备卡片信息

| 序号 | 字段名称 | 字段类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 设备名称 | 文本展示 | - | - | 如"一线注氮机"、"一线码垛机"、"一线纸箱包装机"等 |
| 2 | 资产类型 | 文本展示 | - | - | 如"生产设备>一线>一线灌装岗" |
| 3 | 设备台账 | 文本展示 | - | - | 如"检验设备-注氮机"、"码垛系统-码垛机器人" |
| 4 | 所属岗位 | 文本展示 | - | - | 如"灌装岗"、"码垛岗"、"包装岗"等 |

## 分页信息

- 无分页（卡片式展示）
