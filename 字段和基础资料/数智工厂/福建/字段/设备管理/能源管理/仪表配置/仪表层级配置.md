# 仪表层级配置

## 页面概述

- **功能说明**：配置能源仪表的分组层级结构，支持水表、电表、蒸汽表、燃气表四种类型的分组管理
- **URL**：`https://fjmms.y1b.cn:8424/#/device-manage/energy-manage/meter-configurine/group`

## 页签（Tab）

| 序号 | 页签名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 水表分组 | 水表仪表层级分组配置（默认选中） |
| 2 | 电表分组 | 电表仪表层级分组配置 |
| 3 | 蒸汽表分组 | 蒸汽表仪表层级分组配置 |
| 4 | 燃气表分组 | 燃气表仪表层级分组配置 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 新增分组 | 新增一个顶级分组 |
| 2 | 全部展开 | 展开所有分组的子级 |
| 3 | 全部折叠 | 折叠所有分组的子级 |
| 4 | 新增子分组 | 在当前分组下新增子分组（行操作） |
| 5 | 编辑 | 编辑当前分组信息（行操作） |
| 6 | 删除 | 删除当前分组（行操作） |

## 列表字段

| 序号 | 字段名称 | 字段类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 分组名称 | 文本展示 | - | - | 分组的名称 |
| 2 | 层级类型 | 文本展示 | - | - | 如"基地总表" |
| 3 | 生产车间 | 文本展示 | -- | - | 所属生产车间 |
| 4 | 所属产线 | 文本展示 | -- | - | 所属产线 |
| 5 | 所属区域 | 文本展示 | -- | - | 所属区域 |

## 新增分组弹窗字段

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 分组名称 | textbox | 空 | 必填（*） | 输入分组名称 |
| 2 | 层级类型 | combobox | 空 | 必填（*） | 下拉选择层级类型 |
| 3 | 所属车间 | combobox | 空 | 可选 | 下拉选择所属车间 |
| 4 | 所属线别 | combobox | 空 | 可选 | 下拉选择所属线别 |
| 5 | 所属区域 | radio | 空 | 可选 | 单选：生产区/生活区/办公区 |

## 弹窗操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 取消 | 关闭弹窗，不保存 |
| 2 | 确定 | 保存分组信息 |
