# 基地层级统计方案

## 页面概述

- **功能说明**：配置基地各层级的能源统计方案，支持综合能耗按基地>区域>车间>产线>具体位置的层级结构进行统计
- **URL**：`https://fjmms.y1b.cn:8424/#/device-manage/energy-manage/meter-configurine/statistical-project`

## 截图

![基地层级统计方案主页面](能源管理_基地层级统计方案_主页面_1.png)

## 层级结构

| 层级 | 名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 综合能耗 | 顶级节点 |
| 2 | 基地 | 基地级别 |
| 3 | 区域 | 区域级别 |
| 4 | 车间 | 车间级别 |
| 5 | 产线 | 产线级别 |
| 6 | 具体位置 | 最细粒度 |

## 设定统计方案

### 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 新增 | 新增一个统计方案节点 |
| 2 | 保存 | 保存所有统计方案配置 |

### 能源类型列

| 序号 | 列名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 水 | 水表统计方案 |
| 2 | 电 | 电表统计方案 |
| 3 | 蒸汽 | 蒸汽表统计方案 |
| 4 | 燃气 | 燃气表统计方案 |

### 行操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 新增 | 在当前节点下新增子节点 |
| 2 | 删除 | 删除当前节点 |
| 3 | 添加仪表 | 为当前节点添加仪表 |
| 4 | 使用公式 | 使用公式计算当前节点的统计值 |

### 统计方案配置示例

| 层级 | 水 | 电 | 蒸汽 | 燃气 |
| :--- | :--- | :--- | :--- | :--- |
| 基地 | 自来水总表（添加仪表） | 光伏9,光伏4,光伏5,光伏6,光伏7,高压计量表,办公楼,办公室中央空调,宿舍楼（添加仪表） | 蒸汽总表（添加仪表） | - |
| 区域 | - | 生产用电（使用公式） | - | - |

### 公式示例

- 生产用电公式：`【光伏4-正向】+【光伏5-正向】+【光伏6-正向】+【光伏7-正向】+【光伏9-正向】+(【高压计量表-正向】-【高压计量表-反向】)-【宿舍楼-正向】-【办公室中央空调-正向】-【办公楼-正向】`
