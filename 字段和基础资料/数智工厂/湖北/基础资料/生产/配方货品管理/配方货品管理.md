## 1. 页面概述

- **所属模块**：生产管理 > 生产基础信息
- **页面名称**：配方货品管理
- **页面路由**：`/product/production-baseinfo/index156/recipe-goods`
- **完整URL**：`https://hbmms.y1b.cn:8424/#/product/production-baseinfo/index156/recipe-goods`
- **数据总量**：共 19 条记录，分 2 页显示（每页 10 条）
- **页面功能**：管理配方相关的货品信息，包括货品的新建、编辑、删除、导入、打印标签等操作

## 5. 新建货品

点击"新建货品"按钮，弹出新建货品对话框，支持批量添加货品。

### 5.1 新建货品表单

新建货品对话框包含以下内容：

- **标题**：新建货品
- **功能按钮**：检查重复条码
- **提示信息**：注：连接扫描枪后，在此页面扫描商品条码可自动添加一行
- **数据表格**：可编辑的表格，初始为空（暂无数据）
- **操作按钮**：添加、取消、保存

![新建货品对话框](截图/配方货品管理-新建货品对话框.png)

### 5.2 新建货品表单字段说明

点击"添加"按钮后，表格新增一行可编辑行，包含以下字段：

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| 序号 | 自动生成 | - | 行序号，自动递增 |
| 条码 | 文本输入框 | 否 | 货品条码，空白时系统自动生成 |
| 名称 | 下拉搜索框 | 是 | 货品名称，支持搜索选择 |
| 品牌 | 文本输入框 | 否 | 货品品牌 |
| 自定义类别 | 文本输入框 | 否 | 用户自定义类别 |
| 规格型号 | 文本输入框 | 否 | 货品规格型号 |
| 计量单位 | 下拉选择框 | 是 | 计量单位，从预设列表选择 |
| 分类 | 下拉选择框 | 是 | 货品分类，从预设列表选择 |

## 13. API接口信息

### 13.1 货品列表

- **接口地址**：`POST /produce/goods/list`
- **请求参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| keyword | string | 搜索关键字 |
| class_name | string | 分类名称 |
| page | number | 页码 |
| size | number | 每页条数 |
| barcode | array | 条码数组 |

- **请求示例**：
```json
{
  "keyword": null,
  "class_name": null,
  "page": 1,
  "size": 10,
  "barcode": []
}
```

- **响应数据字段说明**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | number | 货品ID |
| title | string | 货品名称 |
| spec | string | 规格型号 |
| barcode | string | 条码 |
| brand | string | 品牌 |
| company | string | 公司 |
| price | number | 默认价格 |
| img_url | string | 图片URL |
| class_name | string | 分类名称 |
| measure_name | string | 计量单位 |
| goods_class | string | 自定义类别 |
| exp_day | number | 保质期(天) |
| reserve_decimal | number | 保留小数 |
| exp_warning_day | number | 保质期预警(天) |
| is_stop_using | number | 是否停用（0=启用，1=停用） |
| is_raw_mat | number | 是否原材料（2=是） |
| tax_rate | number | 税率(%) |
| available_status | number | 可用状态（1=可用） |
| socure_type | number | 来源类型（1=系统） |
| create_time | string | 创建时间 |

### 13.2 货品详情

- **接口地址**：`POST /produce/goods/detail`
- **请求参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| id | number | 货品ID |

- **请求示例**：
```json
{
  "id": 1363
}
```

- **响应额外字段**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| img_info | array | 图片信息数组 |
| split_goods | array | 拆分货品数组 |
| split_quantity | number | 拆分数量 |

### 13.3 分类列表

- **接口地址**：`GET /apios/get/goodsclasslist`
- **请求参数**：无
- **响应数据**：返回所有货品分类列表，包含 id、name、group_name、name_two 等字段

### 13.4 计量单位列表

- **接口地址**：`GET /apios/get/measurelist`
- **请求参数**：无
- **响应数据**：返回所有计量单位列表，包含 id、name 字段

### 13.5 操作日志
