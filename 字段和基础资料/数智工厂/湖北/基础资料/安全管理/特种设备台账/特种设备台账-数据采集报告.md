## 1. 页面概述

### 页面路径
安全管理 → 现场管理 → 特种设备管理 → 特种设备台账

### 系统地址
`https://hbmms.y1b.cn:8424/#/safety-manage/onsite/special-EQP/special-equipment`

### 主要功能
特种设备台账模块用于管理企业内所有特种设备的基本信息、使用登记信息、检定记录等，确保特种设备的安全合规管理。数据来源为资产档案或设备台账，辅助分类为【特种设备】。

### 左侧资产类型树
- 特种设备（当前选中分类）

## 2. 搜索和筛选功能

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 关键字 | 文本输入 | 支持模糊查询资产名称、编码等 |
| 使用位置 | 文本输入 | 按设备使用位置筛选 |
| 使用部门 | 文本输入 | 按使用部门筛选 |
| 使用负责人 | 下拉选择 | 选择使用负责人进行筛选 |
| 启用日期 | 日期范围 | 选择启用日期区间（开始日期-结束日期） |
| 使用状态 | 下拉选择 | 按使用状态筛选（正常/停用/报废等） |
| 点巡检状态 | 下拉选择 | 按点巡检状态筛选（无记录/正常/异常等） |
| 点巡检配置 | 下拉选择 | 按点巡检配置筛选（未配置/已配置等） |

### 操作按钮
- **搜索**: 根据条件查询设备数据
- **重置**: 清空所有搜索条件

## 8. 字段说明

### 8.1 资产基本信息
- **唯一码**: 系统自动生成的设备唯一标识码，如"5010000016"
- **资产名称**: 设备的完整名称，如"电瓶叉车-（海斯特）J3.0UT（鄂L02684）"
- **资产类型**: 设备分类，统一为"特种设备"
- **资产编码**: 设备的资产编码，如"14000169"
- **资产条码**: 设备的条形码标识

### 8.2 使用登记信息
- **设备注册代码**: 特种设备在监管部门的注册代码，如"51104212022025093007"
- **使用证编号**: 特种设备使用证的编号，如"车11鄂L30230(25)"
- **产品(出厂)编号**: 设备出厂时的编号，如"A3C4A07208Z"
- **登记状态**: 注册登记状态（未登记/已登记/已注销）
- **使用截止日期**: 使用证的有效截止日期
- **下次检验日期**: 下次需要检验的日期

### 8.3 设备使用信息
- **使用状态**: 设备当前状态（正常/停用/报废）
- **使用位置**: 设备所在的具体位置
- **使用部门**: 使用该设备的部门
- **使用负责人**: 设备的日常使用负责人
- **责任部门**: 设备管理的责任部门

### 8.4 费用信息
- **维修费用(元)**: 设备累计维修费用
- **保养费用(元)**: 设备累计保养费用

### 8.5 点巡检信息
- **点巡检配置**: 是否已配置点巡检（未配置/已配置）
- **点巡检状态**: 点巡检执行状态（无记录/正常/异常）

### 8.6 特种设备分类
- **特种设备种类**: 如"厂内车辆"
- **特种设备类别**: 如"场(厂)内专用机动车辆-电瓶"

## 9. 数据统计

### 统计信息
- **总记录数**: 34条
- **总页数**: 4页
- **每页显示**: 10条
- **数据文件**: [特种设备台账-数据.csv](特种设备台账-数据.csv)（包含55条完整数据记录，含重复行）

### 数据文件说明
CSV文件包含以下25个字段的完整数据：
- 使用状态、资产名称、资产类型、唯一码、资产编码
- 使用位置、资本化日期、维修费用(元)、保养费用(元)
- 责任部门、使用部门、使用负责人
- 点巡检配置、点巡检状态
- 设备注册代码、证书编号、产品(出厂)编号
- 登记状态、使用截止日期、检定日期、下次检验日期
- 使用证、使用标志、检验单位、维保单位

### 设备类型分布
根据采集数据，特种设备主要包括：
- 电瓶叉车（海斯特品牌）
- 内燃平衡重式柴油叉车（海斯特品牌）
- 蓄电池平衡重式电叉车
- 杂物电梯
- 储气罐

### 使用部门分布
- 储运采购部：叉车类设备
- 生产部：储气罐类设备
- 人事行政部：电梯类设备
