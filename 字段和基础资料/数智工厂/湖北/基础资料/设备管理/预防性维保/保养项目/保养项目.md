## 1. 页面概述

- **所属模块**：设备管理 > 预防性维保
- **页面名称**：保养项目
- **页面路由**：`/device-manage/device/maintain/maintenance/project`
- **路由名称**：`deviceMaintainProject`
- **API端点**：
  - 列表：`POST /mro/maintenance_project/list`
  - 资产类型选项：`POST /mro/Post/getEqipmentTypeSelect`
- **请求参数**：`{ "page": 1, "size": 10, "keyword": null }`

页面用于管理设备保养项目信息，包含保养内容组、资产类型、保养部位、保养项目、保养要求/标准、保养方法、保养工具/物品、设备状态、备注等配置。支持新增、编辑和删除操作。

## 4. 操作功能

### 4.1 搜索功能

页面顶部提供搜索区域，支持以下搜索条件：
- **关键字**：文本输入框，输入关键词后点击"搜索"按钮
- **重置**：清空搜索条件，恢复默认列表

### 4.2 新增保养项目

点击"新增"按钮后，弹出"新增保养项目"对话框：

![新增对话框](截图/保养项目-新增对话框.png)

#### 表单字段

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 项目标准名称 | 文本输入 | 是 | 输入保养项目标准名称 |
| 资产类型 | 下拉选择（级联） | 是 | 树形结构选择，详见下方 |
| 添加明细 | 按钮 | -- | 点击后展开明细表格行 |

#### 添加明细表格字段

点击"添加明细"后，展开一行明细输入：

![添加明细行](截图/保养项目-新增-添加明细行.png)

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 保养部位 | 文本输入 | 是 | 输入保养部位 |
| 保养项目 | 文本输入 | 是 | 输入保养项目名称 |
| 保养要求/标准 | 文本输入 | 是 | 输入保养要求或标准 |
| 保养方法 | 文本输入 | 否 | 输入保养方法 |
| 保养工具/物品 | 文本输入 | 否 | 输入所需工具或物品 |
| 设备状态 | 下拉选择 | 否 | 选项：静态、动态 |
| 备注 | 文本输入 | 否 | 备注说明 |
| 操作 | 删除按钮 | -- | 删除该行明细 |

  - 配料间
  - 空压机房
  - 蒸汽间
- 三车间

### 4.4 删除保养项目

点击表格行中的"删除"按钮后，弹出确认对话框：

![删除确认对话框](截图/保养项目-删除确认对话框.png)

确认对话框内容：**"确认要删除：【热缩岗位-自主保养-缩膜机-在刻度线以上】的该条内容吗?"**

- **取消**：放弃删除操作
- **确定**：确认删除该条保养项目记录
