## 字段说明

| 字段名    | 说明             |
| ------ | -------------- |
| 检验项目   | 检验项目名称         |
| 条码     | 关联物料条码，多个以逗号分隔 |
| 物料名称   | 关联物料名称，多个以逗号分隔 |
| 抽检方式   | 固定抽检/按比例抽检     |
| 检验标准描述 | 抽检标准详细描述       |
| 抽检阈值   | 按比例抽检时的阈值（KG）  |
| 应抽检数   | 每批/每阈值应抽检的数量   |

## 抽检方式说明

| 抽检方式  | 说明                     |
| ----- | ---------------------- |
| 固定抽检  | 每批次固定抽检数量，不受入库量影响      |
| 按比例抽检 | 根据入库量按比例抽检，达到阈值后抽检固定数量 |
