# 原料入库配置

## 截图

![原料入库配置-列表](../仓储基础资料截图/原料入库配置-列表.png)

## 数据概览

- 总条数：若干条

## 列表字段

| 字段名 | 说明 |
|--------|------|
| 物料条码 | 原料物料条码 |
| 物料名称 | 原料物料名称 |
| 入库仓库 | 默认入库仓库 |
| 库位 | 默认入库库位 |
| 是否需要检验 | 入库是否需要质量检验 |
| 检验方式 | 全检/抽检 |
| 是否需要送检报告 | 入库是否需要提交送检报告 |
| 创建时间 | 创建时间 |

## 配置说明

原料入库配置用于定义原材料入库时的默认规则，包括：
- 默认入库仓库和库位
- 是否需要进行质量检验
- 检验方式（全检/抽检）
- 是否需要提交送检报告（COA报告/卫生证书等）
