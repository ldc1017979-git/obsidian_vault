## 1. 页面概述

电子天平电子秤目录页面用于管理质量检测中使用的电子天平和电子秤设备的详细参数信息，包括使用地点、名称、型号、出厂编号、Max（最大称量值）、e（检定分度值）、d（实际分度值）、砝码重量等计量参数。页面路径为：质量管理 → 基础信息管理 → 电子天平电子秤目录。

![电子天平电子秤目录-列表页](电子天平电子秤目录-列表页.png)

---

## 2. 搜索/筛选功能

页面顶部提供以下搜索/筛选条件：

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 名称 | 文本输入框 | 支持模糊搜索 |
| 型号 | 文本输入框 | 支持模糊搜索 |

操作按钮：
- **搜索**：根据筛选条件查询数据
- **重置**：清空所有筛选条件

## 3. 功能按钮

| 按钮 | 位置 | 功能说明 |
|------|------|----------|

## 4. 新建对话框

点击"新建"按钮弹出"新增"对话框，包含以下字段：

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 排序号 | 数字输入 | 是 | 排序编号 |
| 使用地点 | 文本输入 | 是 | 仪器使用地点 |
| 名称 | 下拉选择 | 是 | 关联仪器管理中的仪器名称，选择后自动填充仪器编号、出厂编号、型号 |
| 仪器编号 | 文本 | 自动 | 选择名称后自动填充，不可编辑 |
| 出厂编号 | 文本 | 自动 | 选择名称后自动填充，不可编辑 |
| 型号 | 文本 | 自动 | 选择名称后自动填充，不可编辑 |
| Max | 数字输入 + 单位下拉 | 是 | 最大称量值，单位可选（g、kg、mg等） |
| e | 数字输入 + 单位下拉 | 是 | 检定分度值，单位可选 |
| d | 数字输入 + 单位下拉 | 是 | 实际分度值，单位可选 |
| 砝码重量 | 数字输入 + 单位下拉 | 是 | 校准砝码重量，单位可选 |

### 名称下拉选项

关联仪器管理中的所有仪器名称，包括：分析天平、电子秤、恒温箱、pH计、高效液相色谱仪、酶标仪、气相色谱仪、氨基酸分析仪、双道原子荧光光度计、近红外线检测仪、生化培养箱、糖酸一体机、自动旋光仪、紫外分光光度计等。

### 单位下拉选项

可选单位包括：托、g/L、ug/L、mg/L、厘米、本、顶、PC、mg、立方米、TIA、PAC、米-2、D米、项目、CAR、平方米、只、升、KG、g、台、个、支、罐、片、瓶、箱、组、条、桶、张、双、卷、件、盒、包、米、块、套、把、根、袋、副等。

## 8. 字段说明

| 字段名 | 类型 | 是否必填 | 说明 |
|--------|------|----------|------|
| 排序编号 | 数字 | 是 | 系统排序编号 |
| 使用地点 | 文本 | 是 | 仪器使用地点，如"一化验/试剂室"、"二化验/主化验室"等 |
| 名称 | 下拉选择 | 是 | 关联仪器管理中的仪器名称，选择后自动填充仪器编号、出厂编号、型号 |
| 仪器编号 | 文本 | 自动 | 由名称关联自动填充，不可手动编辑 |
| 型号 | 文本 | 自动 | 由名称关联自动填充，不可手动编辑 |
| 出厂编号 | 文本 | 自动 | 由名称关联自动填充，不可手动编辑 |
| Max | 数字+单位 | 是 | 最大称量值（Maximum capacity），天平/秤的最大称量范围 |
| e | 数字+单位 | 是 | 检定分度值（Verification scale interval），用于检定的分度值 |
| d | 数字+单位 | 是 | 实际分度值（Actual scale interval），天平/秤的实际读数分度值 |
| 砝码重量 | 数字+单位 | 是 | 校准用砝码的重量值 |
| 创建人 | 文本 | 自动 | 创建该记录的用户 |
| 创建时间 | 日期时间 | 自动 | 创建时间 |
| 更新人 | 文本 | 自动 | 最后更新该记录的用户 |
