## 1. 页面概述

### 页面路径
质量管理 → 基础信息管理 → 检验依据

### 系统地址
`https://hbmms.y1b.cn:8424/#/quality-manage/index2/inspection`

### 主要功能
检验依据模块用于管理产品检验所依据的标准文件信息，包括国家标准、行业标准、客户标准和企业标准。每条记录包含检验依据编号、说明、标准类型、可用状态等信息，用于质量检验过程中引用对应的检验标准。

## 2. 搜索和筛选功能

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 检验依据 | 文本输入 | 按检验依据编号/名称筛选 |
| 可用状态 | 下拉选择 | 可选：可用/禁用 |

### 操作按钮
- **重置**: 清空所有搜索条件
- **搜索**: 根据条件查询检验依据数据

## 3. 功能按钮说明

### 3.1 新建
点击打开新建检验依据对话框，创建新的检验依据记录。

![检验依据-新建对话框](检验依据-截图/检验依据-新建对话框.png)

### 3.2 刷新
刷新当前列表数据（图标按钮）。

### 3.3 密度设置
设置表格行间距，可选：宽松、默认、紧凑。

### 3.4 列表内操作
每行数据提供以下操作按钮：
- **编辑**: 打开编辑对话框，修改检验依据信息
- **删除**: 删除该条检验依据记录（需确认）
- **可用状态开关**: 直接在列表中切换启用/禁用状态

## 4. 新建检验依据

### 对话框标题
**新增检验依据**

### 表单字段

| 字段名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 检验依据 | 文本输入 | 是 | - | 检验依据编号或名称，如GB1886.220-2016 |
| 说明 | 多行文本 | 否 | - | 检验依据的说明描述，如"胭脂红" |
| 标准类型 | 下拉选择 | 是 | - | 可选：国家标准、行业标准、客户标准、企业标准 |
| 可用状态 | 开关 | 否 | 默认开启 | 启用/禁用该检验依据 |

### 标准类型下拉选项
![检验依据-标准类型下拉选项](检验依据-截图/检验依据-标准类型下拉选项.png)

| 选项 | 说明 |
|------|------|
| 国家标准 | 以GB开头的国家标准文件 |
| 行业标准 | 行业相关标准文件 |
| 客户标准 | 客户指定的检验标准 |
| 企业标准 | 企业内部制定的检验标准，如Q/HRRBD |

### 底部按钮
- **取消**: 关闭对话框
- **确定**: 保存检验依据数据

## 8. 字段说明

### 8.1 序号
- **类型**: 数字
- **说明**: 数据记录的序号，每页从1开始

### 8.2 检验依据
- **类型**: 文本
- **必填**: 是
- **说明**: 检验依据的标准编号或名称，如GB1886.220-2016、Q/HRRBD 0001J等

### 8.3 说明
- **类型**: 文本
- **必填**: 否
- **说明**: 检验依据的简要说明，描述该标准对应的检测项目，如"胭脂红"、"牛磺酸"等

### 8.4 标准类型
- **类型**: 下拉选择
- **必填**: 是
- **可选值**: 国家标准、行业标准、客户标准、企业标准
- **说明**: 检验依据所属的标准类型分类

### 8.5 可用状态
- **类型**: 开关
- **说明**: 控制该检验依据是否可用，可直接在列表中切换

### 8.6 创建人
- **类型**: 文本
- **说明**: 创建该记录的操作人员

### 8.7 创建时间
- **类型**: 日期时间
- **格式**: YYYY-MM-DD HH:mm:ss
- **说明**: 记录创建时间

### 8.8 更新人
- **类型**: 文本
- **说明**: 最后更新该记录的操作人员

### 8.9 更新时间
- **类型**: 日期时间
- **格式**: YYYY-MM-DD HH:mm:ss
- **说明**: 记录最后更新时间
