## 1. 页面概述

### 页面路径
质量管理 → 基础信息管理 → UV判定表

### 系统地址
`https://hbmms.y1b.cn:8424/#/quality-manage/index2/uv-config`

### 主要功能
UV判定表模块用于管理红牛产品的UV检测数据，记录每批次产品的可溶性固形物、pH值、ABS吸光度、nm波长等关键质量指标，用于产品质量判定和追溯。

## 5. 新建UV信息

新建对话框标题根据当前标签页自动变化：
- 红牛-普通型标签页：**新增UV信息—红牛-普通型**
- 红牛-强化型标签页：**新增UV信息—红牛-强化型**

### 表单字段

| 字段名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| 生产日期 | 日期选择 | 是 | - | 产品生产日期 |
| 时间 | 时间选择 | 是 | - | 生产时间 |
| 批次 | 文本输入 | 是 | - | 生产批次号，如HB26E009 |
| 批号 | 文本输入 | 是 | - | 批次编号，如908ZE |
| 可溶性固形物 | 数字输入 | 是 | - | 可溶性固形物含量（Brix值） |
| pH | 数字输入 | 是 | - | pH酸碱度值 |
| ABS | 数字输入 | 是 | - | ABS吸光度值 |
| nm | 数字输入 | 是 | 271.5 | 波长（纳米），默认271.5nm |
| 备注 | 多行文本 | 否 | - | 备注信息 |

### 底部按钮
- **取消**: 关闭对话框
- **确定**: 保存UV检测数据

## 7. 字段说明

### 7.1 启用状态
- **类型**: 标签显示
- **取值**: 启用（绿色标签）/ 停用（红色标签）
- **说明**: 当前UV检测记录是否处于启用状态。每新增一条记录，上一条记录自动变为停用。

### 7.2 启用时间
- **类型**: 日期时间
- **格式**: YYYY-MM-DD HH:mm:ss
- **说明**: 该UV检测记录的启用时间

### 7.3 截止时间
- **类型**: 日期时间
- **格式**: YYYY-MM-DD HH:mm:ss
- **说明**: 该UV检测记录的停用时间，即下一条记录启用的时间

### 7.4 生产日期
- **类型**: 日期
- **格式**: YYYY-MM-DD
- **说明**: 产品生产日期

### 7.5 时间
- **类型**: 时间
- **格式**: HH:mm
- **说明**: 生产具体时间

### 7.6 批次
- **类型**: 文本
- **格式**: HB + 年份标识 + 序号（如HB26E009）
- **说明**: 生产批次号，HB代表湖北基地

### 7.7 批号
- **类型**: 文本
- **格式**: 数字+字母组合（如908ZE）
- **说明**: 批次内部编号

### 7.8 可溶性固形物
- **类型**: 数字
- **单位**: Brix（白利糖度）
- **普通型参考值**: 约12.3-12.4
- **强化型参考值**: 约15.2-15.4
- **说明**: 产品的可溶性固形物含量，反映产品浓度

### 7.9 pH
- **类型**: 数字
- **普通型参考值**: 约3.48-3.51
- **强化型参考值**: 约3.34-3.38
- **说明**: 产品的酸碱度值

### 7.10 ABS
- **类型**: 数字
- **参考值**: 约0.340-0.354
- **说明**: UV吸光度值（Absorbance），用于判断产品成分含量

### 7.11 nm
- **类型**: 数字
- **默认值**: 271.5
- **单位**: 纳米
- **说明**: UV检测波长，固定为271.5nm

### 7.12 创建时间
- **类型**: 日期时间
- **格式**: YYYY-MM-DD HH:mm:ss
- **说明**: 记录创建时间

### 7.13 创建人
- **类型**: 文本
- **说明**: 创建该记录的操作人员

### 7.14 备注
- **类型**: 文本
- **说明**: 备注信息
