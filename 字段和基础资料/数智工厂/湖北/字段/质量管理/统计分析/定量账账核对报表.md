# 定量账账核对报表

## 页面概述
- **模块**: 质量管理 > 统计分析 > 定量账账核对报表
- **URL**: `https://hbmms.y1b.cn:8424/#/quality-manage/statistic-analysis/ration-statement`
- **功能说明**: 定量包装产品的账账核对报表，按生产线别汇总展示定量检测数据

---

## 一、搜索筛选字段（2个）

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | Placeholder |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 产品名称 | 下拉框(combobox) | 红牛维生素功能饮料 | 可选 | 请选择产品名称 |
| 2 | 年月日 | 日期范围选择器 | 空 | 可选 | 开始日期 ~ 结束日期 |

---

## 二、数据报表内容

### 2.1 产品定量检验报告 — 抽样检测

| 统计项目 | 单位 | 说明 |
| :--- | :--- | :--- |
| 月度检测量 | 批 | 各线月度检测批次数 |
| 涉及大批次 | 个 | 各线涉及的大批次数量 |

- 按产品（如红牛-普通型）和生产线别（一线~六线+总计）统计

### 2.2 定量测定原始记录 — 检测项目

| 检测指标 | 单位 | 统计维度 | 说明 |
| :--- | :--- | :--- | :--- |
| 牛磺酸 | mg/L | 最大值/最小值/均值 | 各线牛磺酸含量统计 |
| 赖氨酸 | - | 最大值/最小值/均值 | 各线赖氨酸含量统计 |
| 肌醇 | - | 最大值/最小值/均值 | 各线肌醇含量统计 |
| 烟酰胺 | - | 最大值/最小值/均值 | 各线烟酰胺含量统计 |
| VB6 | - | 最大值/最小值/均值 | 各线VB6含量统计 |
| VB12 | μg/L | 最大值/最小值/均值 | 各线VB12含量统计 |
| 咖啡因 | mg/L | 最大值/最小值/均值 | 各线咖啡因含量统计 |
| 柠檬黄 | - | 最大值/最小值/均值 | 各线柠檬黄含量统计 |

- 每个检测指标按生产线别（一线~六线+总计）展示最大值、最小值、均值

---

## 三、操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空搜索条件 |
| 2 | 搜索 | 根据产品名称和日期查询 |

---

## 四、交互说明

1. 选择产品名称和日期范围后点击"搜索"刷新数据
2. 数据按生产线别（一线~六线）和总计列展示
3. 数据来源包括：产品定量检验报告、定量测定原始记录
4. 各检测指标以最大值/最小值/均值三个维度展示
5. 只读统计报表，无新建/编辑功能
