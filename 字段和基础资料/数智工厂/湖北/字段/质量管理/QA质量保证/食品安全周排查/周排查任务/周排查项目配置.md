# 周排查项目配置

## 页面概述
- **模块**: 质量管理 > QA质量保证 > 食品安全周排查 > 周排查任务 > 周排查项目配置
- **URL**: `https://hbmms.y1b.cn:8424/#/quality-manage/index3/index38/qa-zhoupaicharenwu/week-item-config`
- **功能说明**: 配置食品安全周排查的检查项目，支持公司级和部门级切换

## 一、列表页

### 1.1 级别切换

| 序号 | 选项 | 说明 |
| :--- | :--- | :--- |
| 1 | 公司级 | 默认选中，显示公司级排查项目 |
| 2 | 部门级 | 显示部门级排查项目 |

### 1.2 操作按钮

| 按钮 | 功能 |
| :--- | :--- |
| 配置自查项目 | 新增/编辑排查项目配置 |
| 添加周排期 | 添加周排查排期 |
| 手动推送周排查 | 手动推送周排查任务 |

### 1.3 数据表格列

| 序号 | 列名 | 说明 |
| :--- | :--- | :--- |
| 1 | 配置编码 | 配置唯一编码，如ZC250906001 |
| 2 | 推送标识 | 推送标识，如A/B |
| 3 | 项目组 | 项目组分类，如一、二、三...十四 |
| 4 | 风险项目 | 风险项目名称，如"组织机构与人员管理" |
| 5 | 创建人 | 创建者 |
| 6 | 创建时间 | 创建时间 |
| 7 | 操作 | 编辑 |

---

## 二、编辑弹窗

> 点击"编辑"按钮打开编辑弹窗

| 序号 | 字段名称 | 输入类型 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 配置编码 | 文本框 | 只读 | 系统生成 |
| 2 | 推送标识 | 下拉框 | 必选 | A/B |
| 3 | 项目组 | 下拉框 | 必选 | 项目组分类 |
| 4 | 风险项目 | 文本框 | 必填 | 风险项目名称 |

## 三、交互说明

1. 支持公司级/部门级切换，切换后显示对应级别的排查项目
2. 推送标识A对应生产类项目，B对应餐饮类项目
3. 手动推送周排查功能可主动触发排查任务
4. 添加周排期用于设置周期性排查计划
