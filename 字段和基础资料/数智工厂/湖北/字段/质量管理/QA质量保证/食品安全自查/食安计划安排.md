# 食安计划安排

## 页面概述
- **模块**: 质量管理 > QA质量保证 > 食品安全自查 > 食安计划安排
- **URL**: `https://hbmms.y1b.cn:8424/#/quality-manage/index3/index37/production-plan`
- **功能说明**: 管理食品安全自查计划安排，支持**日自查计划**和**周排查计划**两种计划类型的增删改查，两种计划类型通过单选按钮切换，表格列和新增表单字段随切换动态变化

## 操作按钮（公共）

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有搜索筛选条件 |
| 2 | 搜索 | 根据单据编号筛选条件查询计划列表 |
| 3 | 新增 | 根据当前选中的计划类型弹出对应的新增表单弹窗 |
| 4 | 编辑 | 表格操作列，对已有记录进行编辑 |
| 5 | 列设置 | 工具栏中调整表格列的显示/隐藏 |

## 交互说明

1. 进入页面默认显示"日自查计划"视图
2. 通过"日自查计划"/"周排查计划"单选按钮切换不同计划类型，表格列头和新增表单随之动态切换
3. 点击"新增"按钮弹出与当前计划类型对应的设置弹窗
4. 日自查计划弹窗仅包含自查开始日和自查结束日两个日期字段
5. 周排查计划弹窗包含排查发起日、排查周期、排查月份、当月周数、排查人1、排查人2共6个字段
6. 点击"重置"清空搜索条件，点击"搜索"执行筛选
7. 表格支持分页浏览、每页条数调整和页码跳转
8. 周排查计划表格支持水平滚动查看隐藏列（开始日、结束日、排查人等）
