# 每日食品安全检查总表

## 页面概述
- **模块**: 质量管理 > QA质量保证 > 食品安全自查 > 日自查任务 > 每日食品安全检查总表
- **URL**: `https://hbmms.y1b.cn:8424/#/quality-manage/index3/index37/qa-rizicharenwu/daily-summary`
- **功能说明**: 汇总各部门每日食品安全自查结果的汇总总表

## 一、列表页

### 1.1 搜索筛选字段

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框(textbox) | 空 | 可选 | 按单据编号搜索，如ZCZ260531001 |
| 2 | 检验结果 | 下拉框(combobox) | 空 | 可选 | 筛选检验结果 |
| 3 | 单据状态 | 下拉框(combobox) | 空 | 可选 | 筛选单据状态 |
| 4 | 检验日期 | 日期范围选择器 | 空 | 可选 | 开始日期-结束日期 |

### 1.2 数据表格列

| 序号 | 列名 | 说明 |
| :--- | :--- | :--- |
| 1 | 单据编号 | 总表单据编号，如ZCZ260531001 |
| 2 | 检查日期 | 检查执行日期 |
| 3 | 检验结果 | 合格/部分合格 |
| 4 | 自查进度 | 完成部门数/总部门数，如0/4或4/4 |
| 5 | 单据状态 | 暂存/已审核 |
| 6 | 检查人 | 检查人姓名 |
| 7 | 创建时间 | 创建时间 |
| 8 | 操作 | 编辑+作废+详情（暂存）/作废+详情（已审核） |

---

## 二、详情页面

> **入口**: 点击"详情"按钮，查看汇总明细

详情页面展示各部门自查结果汇总，包含每个部门各检查项的合规状态对照，以及审核操作日志。

---

## 三、操作按钮

| 按钮 | 位置 | 功能 |
| :--- | :--- | :--- |
| 重置 | 搜索区 | 清空搜索条件 |
| 搜索 | 搜索区 | 查询记录 |
| 编辑 | 操作列 | 编辑暂存状态记录 |
| 作废 | 操作列 | 作废记录 |
| 详情 | 操作列 | 查看汇总详情 |
