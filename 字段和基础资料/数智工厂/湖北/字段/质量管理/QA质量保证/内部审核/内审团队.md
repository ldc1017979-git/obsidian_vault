# 内审团队

## 页面概述
- **模块**: 质量管理 > QA质量保证 > 内部审核 > 内审团队
- **功能说明**: 管理内部审核团队成员配置

## 一、列表页

### 1.1 搜索筛选字段

| 序号 | 字段名称 | 输入类型 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 人员名称 | 文本框(textbox) | 可选 | 搜索人员名称 |

### 1.2 数据表格列

| 序号 | 列名 | 说明 |
| :--- | :--- | :--- |
| 1 | 序号 | 行号 |
| 2 | 人员名称 | 内审人员姓名 |
| 3 | 所属部门 | 人员所属部门 |
| 4 | 操作 | 编辑/删除 |

## 二、新增/编辑弹窗

| 序号 | 字段名称 | 输入类型 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 人员名称 | 下拉框(combobox) | 必选 | 选择人员 |
| 2 | 所属部门 | 文本框 | 自动填充(只读) | 根据人员自动带出 |

## 三、操作按钮

| 按钮 | 功能 |
| :--- | :--- |
| 新增 | 添加内审人员 |
| 编辑 | 编辑人员信息 |
| 删除 | 删除人员 |

## 四、交互说明

1. 内审团队用于内审任务的分配
2. 选择人员后自动带出所属部门
3. 支持增删改操作
