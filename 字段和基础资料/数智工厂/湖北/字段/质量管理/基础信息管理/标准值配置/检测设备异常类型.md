## 顶部标签与切换

| 序号 | 标签组 | 可选项 |
| :--- | :--- | :--- |

## 列表表格字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 检测设备 | 文本 | 如卷封外观检测、顶盖外观检测仪、产品离线外观检测 |
| 2 | 异常类型 | 文本 | 单值展示，如卷封垂唇、翻边缺口盖、缩颈不良 |
| 3 | 操作 | 按钮组 | 编辑、删除 |

> 湖北列表每行展示「检测设备 + 单个异常类型」的组合（同一设备多个异常类型分多行展示），贵州参考文档记为「多值展示」，实际编辑/新增弹窗结构一致（异常类型仍为可增删的动态行）。

## 列表页操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 新增 | 打开新增异常类型弹窗 |

## 新建弹窗字段（新增异常类型）

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 检测设备 | 文本框 | 空 | 必填(*) | 设备名称 |
| 2 | 异常类型行 | 动态行文本框 | 初始空（暂无数据） | 可增删 | 字段名为「异常类型名称」 |
| 3 | 新增一行 | 按钮 | - | - | 增加一条异常类型输入行 |
| 4 | 删除 | 按钮 | - | - | 删除对应异常类型行 |

## 编辑弹窗字段（编辑异常类型）

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 检测设备 | 文本框 | 如卷封外观检测 | 必填(*) | 可编辑 |
| 2 | 异常类型行 | 动态行文本框 | 如卷封垂唇 | 可增删 | 支持逐行维护 |
| 3 | 新增一行 | 按钮 | - | - | 追加异常类型行 |
| 4 | 删除 | 按钮 | - | - | 删除该行 |
