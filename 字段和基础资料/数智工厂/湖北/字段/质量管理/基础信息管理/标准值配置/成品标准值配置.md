# 成品标准值配置

## 页面概述

- **功能说明**：按成品配置分类维护检验标准，支持初检/复检、标准来源切换与修约方式
- **页面URL**：`https://hbmms.y1b.cn:8424/#/quality-manage/index2/qc-standard-value-configuration/finished`
- **编辑页URL**：`https://hbmms.y1b.cn:8424/#/quality-manage/index2/qc-standard-value-configuration/finished/add?id={id}&pageType=2`
- **所属模块**：质量管理 > 基础信息管理 > 标准值配置 > 成品标准值配置
- **实机核对**：湖北基地 `hbmms.y1b.cn:8424`，2026-07-29；已逐一点击左侧全部配置分类提取明细

## 列表表格字段（各节点通用）

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 检验项目 | 文本 | 检测项目名称 |
| 2 | 初检/复检 | 文本 | 初检或复检 |
| 3 | 标准来源 | 文本 | 集团标准 / 自主配置 |
| 4 | 状态 | 文本 | 正常使用 / 未配置 等 |
| 5 | 集团主键ID | 文本 | 集团标准主键；自主配置为 `-` |
| 6 | 检测类型 | 文本 | 区间 / 大于等于 / 小于等于 / 等于 / 是否合格 / 文本 等 |
| 7 | 标准值 | 文本 | 阈值或文本标准 |
| 8 | 单位 | 文本 | 单位；无数据显示 `-` 或空 |
| 9 | 是否判定 | 文本 | 是 / 否 |
| 10 | 小数精确位数 | 数值 | 小数位；无数据显示 `-` |
| 11 | 修约方式 | 文本 | 如「四舍六入五成双」 |
| 12 | 更新时间 | 日期时间 | 最后更新时间 |
| 13 | 操作 | 按钮 | 配置标准 |
