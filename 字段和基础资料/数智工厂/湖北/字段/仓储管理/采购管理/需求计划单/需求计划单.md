## 搜索表单

| 序号 | 字段名称 | 字段类型 | 默认值 | 约束条件 | 说明 |
|------|----------|----------|--------|----------|------|
| 1 | 单号 | 文本输入框 | - | - | 需求计划单编号 |
| 2 | 商品名称 | 文本输入框 | - | - | 商品名称关键词 |
| 3 | 单据状态 | 下拉选择框 | - | 可展开列表 | 单据状态筛选 |
| 4 | 采购状态 | 下拉选择框 | - | 可展开列表 | 采购状态筛选 |
| 5 | 需求月份 | 日期范围选择器 | - | 开始月份-结束月份 | 需求月份范围 |
| 6 | 需求部门 | 文本输入框(只读) | - | readonly | 需求部门选择 |
| 7 | 创建日期 | 日期范围选择器 | - | 开始日期-结束日期 | 展开后显示 |
