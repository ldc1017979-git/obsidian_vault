## 详情页 - 清场记录

| 序号 | 列名 | 说明 |
| :--- | :--- | :--- |
| 1 | 控制内容 | 清场控制内容（跨2列） |
| 2 | 执行情况 | 执行情况（是/否） |
| 3 | 备注 | 备注信息 |

清场记录按设备区域分组，包含以下区域：
- 顶（底）盖包材分类退库
  1. 链道至冷却机入口上的成品已排空
  2. 已拆包的合格在用盖用缠绕膜完好包裹，用相应的物料标识单标识清楚；所有合格盖已通知扫码员核对数量、叉车司机叉运退回仓库
  3. 下盖间的牛皮纸袋、掉落的不合格盖、废弃物塑料桶已清空
  4. 不合格盖已集中放在不合格品放置区隔离、退库处理
- 灌装机进口区域
  1. 洗罐槽掀开盖板检查已清空，无空罐遗留
  2. 洗罐槽下部及翻转器内部已用压缩空气吹扫（或专用工具清理），目视无遗留空罐
  3. 接水盘、地面无遗留空罐
  4. 灌装机进罐螺杆入口无遗留的空罐，地面无掉落的成品
- 净化间灌装机区域
  1. 灌装机内部链道无遗留空罐、成品
  2. 净化间内设施、工具箱、取样框容器、设备上、地面无遗留罐、盖、成品
- 净化间封口机区域
  1. 下盖间平台与地面无遗留散落的盖
  2. 封口机下盖槽、机器顶部无遗留剩余盖
