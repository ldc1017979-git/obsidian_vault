# KPI指标

## 页面概述

- **功能说明**: KPI指标管理，用于查看和统计生产关键绩效指标数据
- **URL**: `https://hbmms.y1b.cn:8424/#/product/public/report/kpiIndexReport`
- **所属模块**: 生产管理 → 公有内容 → 统计管理
