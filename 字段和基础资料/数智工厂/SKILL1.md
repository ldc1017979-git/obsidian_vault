# 模块基础配置全量提取 Skill

## 🎯 功能概述

本技能使用Chrome DevTools Memory Control Protocol (MCP) 功能，对系统模块基础配置进行系统化、自动化的数据采集。核心能力包括：页面导航、按钮交互、内容展开、高分辨率截图、文本提取和结构化Markdown文档生成。

---

## 📋 使用场景

- **系统配置文档自动生成**：将系统设置页面自动转换为结构化文档
- **配置变更审计**：定期采集配置页面内容，追踪配置变化
- **知识库建设**：为运维团队提供完整的配置参考文档
- **系统迁移支持**：提取现有系统配置，辅助新系统配置迁移

---

## 🛠️ 核心能力

### 1. 智能页面导航
- 支持指定URL导航
- 验证页面加载完成（DOM元素加载 + 网络请求稳定）
- 自动等待机制（3-5秒重试）

### 2. 自动化交互操作
- 识别所有可交互按钮元素
- 验证元素可点击状态
- 程序化点击展开子菜单和内容区域
- 自动滚动展示完整内容

### 3. 高分辨率截图捕获
- 覆盖整个视口的完整截图
- 确保无内容截断
- 按规范命名（设置类别-子类别-操作步骤）

### 4. 结构化文档生成
- Markdown格式输出
- 层级化组织（标题、子标题、内容说明）
- 目录索引支持
- 截图与文本内容关联

## 🔄 执行流程

### Phase 1: 初始化配置
1. **目标地址设置**：确认系统登录地址和目标页面路径
2. **输出目录配置**：指定截图和文档输出路径
3. **操作参数配置**：设置等待时间、重试次数等

### Phase 2: 页面导航与加载验证
1. **导航至目标页面**：使用MCP导航到指定URL
2. **加载状态检测**：
   - 等待DOMContentLoaded事件
   - 检测网络请求是否稳定（5秒内无新请求）
   - 验证关键元素是否存在
3. **异常处理**：加载超时自动重试（最多3次）

### Phase 3: 交互元素识别与操作
1. **按钮元素识别**：使用CSS选择器定位所有可交互按钮
2. **可点击状态验证**：检查元素disabled属性和visibility状态
3. **程序化点击**：
   - 按层级顺序点击按钮
   - 点击后等待内容展开（1-2秒）
   - 记录操作日志

### Phase 4: 内容滚动与截图
1. **自动滚动**：对可滚动区域实施自动滚动
2. **完整截图**：
   - 捕获整个视口内容
   - 确保所有设置项可见
   - 按命名规范保存截图

### Phase 5: 文本内容提取
1. **页面文本解析**：提取所有可见文本内容
2. **结构化整理**：按页面层级组织文本
3. **内容关联**：将文本与对应截图关联

### Phase 6: Markdown文档生成
1. **目录索引创建**：生成可跳转的目录结构
2. **内容组织**：按设置类别层级化展示
3. **截图嵌入**：将截图链接插入文档对应位置
4. **文档保存**：输出完整的Markdown文件

## ⚙️ 配置参数

| 参数名称 | 类型 | 默认值 | 说明 |
|----------|------|--------|------|
| target_url | string | - | 目标系统登录地址 |
| output_dir | string | ./output | 输出目录路径 |
| wait_timeout | number | 5000 | 页面加载等待时间（毫秒） |
| retry_count | number | 3 | 操作失败重试次数 |
| retry_interval | number | 3000 | 重试间隔时间（毫秒） |
| screenshot_format | string | png | 截图格式（png/jpeg/webp） |
| screenshot_quality | number | 90 | 截图质量（0-100） |

## ⚠️ 注意事项

1. **权限要求**：确保访问的页面有足够的权限，避免403/401错误
2. **网络稳定**：建议在网络稳定的环境下执行，避免因网络波动导致失败
3. **页面结构**：依赖页面具有标准的HTML结构（按钮、菜单等使用标准标签）
4. **性能影响**：大量截图可能占用较多存储空间，建议定期清理
5. **并发限制**：避免短时间内频繁操作，给服务器适当的响应时间

## 🛡️ 异常处理机制

| 异常类型 | 处理策略 | 重试机制 |
|----------|----------|----------|
| 页面加载超时 | 等待后重试 | 最多3次，间隔3秒 |
| 元素不可点击 | 检查元素状态 | 等待1秒后重试 |
| 网络请求失败 | 重新导航 | 最多3次 |
| 截图失败 | 重新捕获 | 最多2次 |
| 未知错误 | 记录日志并跳过 | 继续后续操作 |
