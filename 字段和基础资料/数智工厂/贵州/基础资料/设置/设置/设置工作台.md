# 设置工作台

## 功能概述

设置工作台是系统个性化工作台的配置管理页面，用于根据部门、岗位、人员配置不同的工作台。如果没有配置个性化工作台，用户将直接进入系统默认工作台。

## 页面结构

### 1. 项目配置

项目配置区域包含系统基础显示设置：

| 配置项 | 当前状态 | 说明 |
|--------|----------|------|
| 开启 Tags-View | ✅ 开启 | 标签页视图功能，支持多标签页浏览 |
| 固定 Header | ✅ 开启 | 顶部导航栏固定显示，不随滚动隐藏 |
| 侧边栏 Logo | ✅ 开启 | 侧边栏显示系统Logo标识 |
| 关闭页签时弹窗提示 | ✅ 开启 | 关闭页签前弹出确认提示 |
| 开启deepSeek | ❌ 关闭 | AI辅助功能开关 |
| 主题 | ❌ 关闭 | 深色/浅色主题切换功能 |

### 2. 个性化工作台设置

个性化工作台允许根据部门、岗位、人员进行差异化配置：

| 设置项 | 当前状态 | 说明 |
|--------|----------|------|
| 允许员工设置自己的工作台首页 | ❌ 关闭 | 允许员工自定义个人工作台首页 |

**操作按钮**：
- **新建个性化工作台**：创建新的个性化工作台配置

### 3. 工作台列表

#### 查询条件
- **工作台信息**：按工作台名称、描述等模糊搜索
- **重置**：清空搜索条件
- **搜索**：执行搜索

#### 列表字段

| 字段 | 说明 |
|------|------|
| 工作台名称 | 工作台的名称标识 |
| 使用对象 | 适用的部门、岗位或人员 |
| 描述 | 工作台的详细说明 |
| 创建者 | 创建该工作台的用户 |
| 状态 | 工作台状态（启用/禁用） |
| 操作 | 编辑、删除等操作按钮 |

#### 工作台列表数据

| 工作台名称 | 使用对象 | 描述 | 创建者 | 状态 |
|------------|----------|------|--------|------|
| 通用工作台 | -- | 系统通用的工作台，适用于公司全员 | 系统 | 默认 |

## 功能说明

### 个性化工作台配置流程

1. **新建配置**：点击「新建个性化工作台」按钮
2. **设置使用对象**：选择适用的部门、岗位或具体人员
3. **配置工作台内容**：自定义工作台显示的组件和布局
4. **保存生效**：保存配置后，对应对象登录时将显示个性化工作台

### 优先级规则

1. **人员级配置**：优先匹配针对具体人员的配置
2. **岗位级配置**：其次匹配岗位配置
3. **部门级配置**：再次匹配部门配置
4. **通用配置**：以上都不匹配时使用通用工作台
