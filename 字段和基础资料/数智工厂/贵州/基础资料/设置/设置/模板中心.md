# 模板中心

## 功能概述

模板中心是系统表单模板的管理模块，用于管理各类业务表单的模板配置。

## 模块统计

| 分类 | 数量 |
|------|------|
| 设备管理 | 28 |
| 质量管理 | 47 |
| 生产管理 | 96 |
| 物料管理 | 21 |
| 人事行政管理 | 38 |
| 安全管理 | 12 |

## 查询条件

- **表单名称**：按表单名称模糊搜索
- **模板设置状态**：按状态筛选（下拉选择）

## 列表字段

| 字段 | 说明 |
|------|------|
| 表单名称 | 模板对应的表单名称 |
| 模板设置状态 | 模板当前配置状态 |
| 模板更新时间 | 最后更新时间 |
| 更新人 | 最后更新操作人 |
| 操作 | 编辑、删除等操作按钮 |
