## 5. 仓库设置详情

### 5.1 搜索筛选条件

系统提供以下搜索筛选字段：

| 字段名称 | 字段类型 | 说明 |
|----------|----------|------|
| 仓库名称 | 文本输入 | 仓库的名称 |
| 仓库编码 | 文本输入 | 仓库编码(SAP库位) |
| SAP工厂编码 | 文本输入 | SAP系统工厂编码 |
| 仓管员权限 | 下拉选择 | 仓库管理员权限设置 |
| 查看仓库权限 | 下拉选择 | 仓库查看权限设置 |

### 5.2 操作按钮

- **重置**: 清空搜索条件
- **搜索**: 执行搜索操作
- **新增仓库**: 添加新的仓库
