## 1. 页面概览

外部账号管理页面位于系统设置模块下，主要用于管理系统外部用户账号信息。页面包含两个主要标签页：**账号管理**和**角色配置**。

### 页面布局

- **顶部区域**：系统导航菜单和用户信息
- **主内容区**：包含账号管理和角色配置两个标签页
- **账号管理标签**：提供外部账号列表展示、查询和新建功能
- **角色配置标签**：提供外部账号角色权限配置

### 查询条件

- **关键字**：按账号或手机号模糊查询
- **所属外部机构**：按外部机构筛选

### 列表操作

- **查询**：根据条件筛选账号
- **重置**：清空查询条件
- **新建账号**：创建新的外部账号
- **机构信息**：查看/管理外部机构信息

***

## 2. 账号管理

### 功能说明

账号管理标签页用于管理系统外部账号，包括账号列表展示、查询和基本操作。

### 列表字段

| 字段     | 说明             |
| ------ | -------------- |
| 勾选列    | 用于批量选择账号       |
| ID     | 账号唯一标识         |
| 手机/账号  | 用户登录账号（通常为手机号） |
| 绑定微信   | 微信绑定状态         |
| 所属外部机构 | 账号所属的外部机构      |
| 操作     | 编辑、删除等操作按钮     |

### 搜索功能

- **关键字搜索**：支持按账号或手机号进行模糊搜索
- **机构筛选**：支持按所属外部机构进行筛选

## 3. 角色配置

### 功能说明

角色配置标签页用于为外部账号配置角色权限，管理外部用户的系统访问权限。

### 配置内容

- **角色列表**：显示可分配给外部账号的角色
- **角色权限**：每个角色对应的权限范围
- **角色分配**：为外部账号分配角色

***

## 4. 新建账号

### 功能说明

点击"新建账号"按钮弹出新建账号对话框，用于创建外部系统用户账号。

### 表单字段

根据页面截图分析，新建账号表单包含以下字段：

- **账号**：用户登录账号
- **姓名**：用户姓名
- **手机号**：联系电话
- **所属机构**：外部机构选择
- **角色**：角色权限配置

## 5. 机构信息

### 功能说明

点击"机构信息"按钮弹出机构信息管理对话框，用于管理外部机构信息。

### 管理功能

- **机构列表**：显示所有已注册的外部机构
- **机构信息**：机构名称、联系人、联系方式等
- **操作**：添加、编辑、删除机构
