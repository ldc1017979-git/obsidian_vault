## 1. 页面概述

- **页面路径**：质量管理 → 基础信息管理 → 定量项目
- **路由地址**：`/quality-manage/index2/quantify`
- **页面功能**：管理定量检测项目，配置各产品大类对应的检测项目名称、检验依据（按产品类型区分）和检测仪器，用于质量检测过程中的项目引用
- **数据总量**：共 13 条记录

![列表页第1页](截图/定量项目-列表页-第1页.png)

---

## 2. 页面布局

页面分为以下区域：

### 2.1 搜索筛选区域

位于页面顶部，提供多条件组合搜索。

### 2.2 数据列表区域

位于页面中央，展示定量项目数据列表，支持分页浏览。每行数据包含操作按钮（编辑、删除）。

## 7. 编辑表单

编辑对话框标题：**编辑定量项目**

表单字段与新建表单基本一致，区别在于：

| 字段名 | 编辑模式说明 |
|--------|-------------|
| 产品大类 | 不可编辑（灰色禁用状态），显示已选中的产品大类标签 |
| 项目名称 | 可编辑，预填充当前值 |
| 普通型检验依据 | 可编辑，下拉框显示当前选中值 |
| 强化型检验依据 | 可编辑，下拉框显示当前选中值 |
| 战马罐装检验依据 | 可编辑，下拉框显示当前选中值 |
| 检测仪器 | 可编辑，下拉框显示当前选中值 |
| 可用状态 | 可切换，显示当前状态及"启用"文字标签 |

- 产品大类：红牛（不可编辑）
- 项目名称：总砷

- 强化型检验依据：（空）
- 战马罐装检验依据：（空）
- 检测仪器：液相色谱
- 可用状态：启用
