## 1. 页面概述

- **页面路径**：质量管理 → 基础信息管理 → 检验依据
- **路由地址**：`/quality-manage/index2/inspection`
- **页面功能**：管理检验依据信息，维护各检测项目对应的国家标准、行业标准、客户标准和企业标准，用于质量检测过程中的标准引用
- **数据总量**：共 23 条记录

![列表页第1页](截图/检验依据-列表页-第1页.png)

---

## 2. 页面布局

页面分为以下区域：

### 2.1 搜索筛选区域

位于页面顶部，提供多条件组合搜索。

### 2.2 数据列表区域

位于页面中央，展示检验依据数据列表，支持分页浏览。每行数据包含操作按钮（编辑、删除）。

## 6. 新建表单

新建对话框标题：**新增检验依据**

| 字段名 | 控件类型 | 是否必填 | 说明 |
|--------|----------|----------|------|
| 检验依据 | 文本输入框 | 是 | 标准/规范名称及编号 |
| 说明 | 多行文本框 | 否 | 检验依据的简要说明 |
| 标准类型 | 下拉选择框 | 是 | 可选项：国家标准、行业标准、客户标准、企业标准 |
| 可用状态 | 开关控件 | 否 | 默认关闭（禁用状态） |

- 操作按钮：取消、确定

![新建对话框](截图/检验依据-新建对话框.png)

### 6.1 标准类型选项

| 选项值 | 说明 |
|--------|------|
| 国家标准 | GB/GB/T系列国家标准 |
| 行业标准 | 行业相关标准 |
| 客户标准 | 客户指定的检验标准 |
| 企业标准 | 企业内部标准（如Q/HRRBD系列） |

![标准类型下拉](截图/检验依据-新建-标准类型下拉.png)

## 7. 编辑表单

编辑对话框标题：**编辑检验依据**

表单字段与新建表单一致，区别在于：
- 各字段预填充当前记录的数据
- 检验依据字段显示当前值（如"GB 30616-2020 食品安全国家标准 食品用香精"）
- 说明字段显示当前值（如"香精"）
- 标准类型下拉框显示当前选中值
- 可用状态开关显示当前状态
