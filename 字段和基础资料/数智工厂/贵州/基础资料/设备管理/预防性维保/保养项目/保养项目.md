## 页面概述

- **页面路径**: 设备管理 → 预防性维保 → 保养项目
- **页面URL**: `https://gzmms.y1b.cn:8424/#/device-manage/device/maintain/maintenance/project`
- **数据总量**: 共 203 条保养项目记录
- **主要功能**: 保养项目的增删改查管理，支持按关键字搜索、重置、列设置等操作

### 列表字段说明

| 字段名 | 说明 |
|--------|------|
| 保养内容组 | 保养内容的分组名称，通常包含编号和描述 |
| 资产类型 | 设备所属资产类型分类 |
| 保养部位 | 具体需要保养的设备部位 |
| 保养项目 | 具体的保养项目名称 |
| 保养要求/标准 | 保养执行的标准或周期要求 |
| 保养方法 | 保养实施的具体方法 |
| 保养工具/物品 | 保养所需的工具或物品 |
| 设备状态 | 设备当前状态（动态/静态） |
| 备注 | 补充说明信息 |
| 操作 | 编辑、删除按钮 |

## 页面功能截图

### 列表页

![保养项目-列表页](截图/保养项目-列表页.png)

列表页展示所有保养项目数据，支持分页浏览（每页10条，共21页），提供关键字搜索、重置、新增功能。

### 新增对话框

![保养项目-新增对话框](截图/保养项目-新增对话框.png)

新增保养项目对话框包含以下字段：保养内容组、资产类型（下拉选择）、保养部位、保养项目、保养要求/标准、保养方法、保养工具/物品、设备状态（动态/静态）、备注，以及可添加多行保养明细。

![保养项目-新增-资产类型下拉选项](截图/保养项目-新增-资产类型下拉选项.png)

![保养项目-新增-添加明细行](截图/保养项目-新增-添加明细行.png)

### 编辑对话框

![保养项目-编辑对话框](截图/保养项目-编辑对话框.png)

编辑对话框与新增对话框字段一致，预填充已有数据，支持修改后保存。

### 删除确认对话框

![保养项目-删除确认对话框](截图/保养项目-删除确认对话框.png)

删除操作会弹出确认对话框，提示"确定删除此记录？"，确认后执行删除。

### 列设置

![保养项目-列设置](截图/保养项目-列设置.png)

列设置功能允许用户自定义表格显示的列，可勾选/取消勾选需要显示的列字段。
