## 1. 页面概述

- **页面路径**：安全管理 → 消防 → 消防器械台账
- **路由地址**：`/safety-manage/fire/fire-equipment`
- **页面功能**：管理消防器材台账信息，包括消防栓、灭火器、应急物资柜等消防设备的登记、查询、编辑和点巡检管理
- **数据总量**：共 186 条记录

![列表页](截图/消防器械台账-列表页.png)

## 2. 页面布局

页面分为三个区域：

### 2.1 左侧资产类型树

| 层级 | 类型名称 |
|------|----------|
| 一级 | 消防器材 |
| 二级 | 室内消防栓 |
| 二级 | 室内干粉灭火器 |
| 二级 | 室内二氧化碳灭火器 |
| 二级 | 室外干粉灭火器 |
| 二级 | 应急物资柜 |

- 支持搜索过滤资产类型
- 点击类型节点可筛选对应类型的设备列表

### 2.2 搜索筛选区域

位于页面上方，提供多条件组合搜索。

### 2.3 数据列表区域

位于页面中央，展示设备台账列表数据，支持分页浏览。
