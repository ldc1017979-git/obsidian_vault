## 1. 页面概述

- **页面路径**: 生产管理 > 生产基础信息 > 产品名称
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/production-baseinfo/index156/name`
- **功能说明**: 管理产品名称信息，包括产品名称、单罐规格、包装规格、产品大类、产品小类、状态、工艺规程等。支持新增、编辑、禁用/启用操作。

## 6. 新增产品信息表单

点击"新增"按钮后从右侧弹出"新增产品信息"抽屉，包含以下表单字段：

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 产品名称 | 下拉选择 | 是 | 选择产品名称 |
| 单罐规格 | 数字输入 | 是 | 输入单罐容量，单位为ml/罐，最小值1，默认1 |
| 包装规格 | 文本输入 | 是 | 输入包装规格，如"2*12罐/箱" |
| 产品大类 | 单选 | 是 | 可选"红牛"或"战马" |
| 产品小类 | 下拉选择 | 是 | 根据产品大类选择对应的小类 |
| 产品状态 | 单选 | 是 | 可选"启用"或"禁用" |
| 工艺规程 | 多行文本 | 是 | 输入工艺规程内容，最大500字符 |
| 备注信息 | 文本输入 | 否 | 输入备注信息 |
