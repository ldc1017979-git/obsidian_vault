## 1. 页面概述

- **页面路径**: 生产管理 > 生产基础信息 > 维保项目
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/production-baseinfo/maintenance_project`
- **功能说明**: 管理维保项目信息，包括维保类型、维保项目和维保内容。支持新增、编辑、删除操作。用于定义设备维保计划中的各类维保项目及其内容。

---

## 2. 搜索条件

| 搜索项 | 类型 | 说明 |
|--------|------|------|
| 维保类型 | 文本输入 | 按维保类型搜索（如清洁类、更换维护类、清洗类等） |
| 维保项目 | 文本输入 | 按维保项目名称搜索 |

搜索按钮：重置、搜索

## 3. 列表字段说明

| 字段名 | 说明 |
|--------|------|
| 维保类型 | 维保项目的分类，如"清洁类"、"更换维护类"、"更换维保类"、"清洗类"等 |
| 维保项目 | 维保项目的名称，如"车间环境消杀"、"时间校准"等 |
| 维保内容 | 维保项目的具体内容描述 |
| 创建人 | 创建该记录的用户 |
| 创建时间 | 创建时间 |
| 操作 | 编辑、删除 |

## 5. 可交互按钮与操作

### 5.1 页面顶部按钮

| 按钮 | 说明 |
|------|------|
| 重置 | 重置搜索条件 |
| 搜索 | 按条件搜索 |
| 新增 | 打开新增维保项目对话框 |
| 列设置 | 打开列展示设置面板 |

### 5.2 行内按钮

| 按钮 | 说明 |
|------|------|
| 编辑 | 打开编辑维保项目对话框，可修改维保类型、维保项目和维保内容 |
| 删除 | 弹出删除确认对话框，确认后删除该条记录 |

## 6. 新增对话框

点击"新增"按钮后弹出"新增维保项目"对话框，包含以下表单字段：

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 维保类型 | 文本输入 | 是 | 输入维保类型分类 |
| 维保项目 | 文本输入 | 是 | 输入维保项目名称 |
| 维保内容 | 多行文本 | 否 | 输入维保项目的具体内容描述 |

- ![新增对话框](../../截图/维保项目-新增对话框.png)

---

## 7. 编辑对话框

点击行操作"编辑"按钮后弹出"编辑维保项目"对话框，表单字段与新增相同，但会预填充当前行的数据。

以"保安过滤器"为例的编辑表单数据：

| 字段 | 值 |
|------|-----|
| 维保类型 | 更换维护类 |
| 维保项目 | 保安过滤器 |
| 维保内容 | 制水车间 |

- ![编辑对话框](../../截图/维保项目-编辑对话框.png)

---

## 8. 删除确认对话框

点击行操作"删除"按钮后弹出确认对话框：

- **类型**: 提示
- **内容**: 确认删除吗？
- **按钮**: 取消 / 确定
