## 1. 页面概述

- **页面路径**: 生产管理 > 生产基础信息 > 配方BOM清单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/production-baseinfo/index156/bom-detailed-list`
- **功能说明**: 管理配方BOM（Bill of Materials）清单，包括物料的称重标准、标准值、标准范围等信息。支持按产品分类（普通红牛、强化红牛、战马）查看和管理。

## 3. 列表字段说明

| 字段名 | 说明 |
|--------|------|
| 条码 | 物料条码，格式为"编号-PF"或"编号-PFP" |
| 名称 | 物料名称编号 |
| 规格型号 | 物料规格，如"6kg/桶"、"14.4g/袋" |
| 分类 | 物料分类，当前均为"配方" |
| 计量单位 | 计量单位，如"桶"、"袋" |
| 保留小数 | 数值保留小数位数 |
| 标准值 | 称重标准值 |
| 标准范围 | 称重允许的标准范围，格式为"最小值~最大值" |
| 称重单位 | 称重使用的单位，如"kg"、"g" |
| 称重保留小数 | 称重数值保留小数位数 |
| 单据类型 | 关联的单据类型，如"复合香精记录"、"盛料桶记录表" |
| 单据序号 | 单据序号 |
| 操作 | 编辑、删除 |

## 8. 新增标准表单

点击"新增"按钮后弹出"新增标准"对话框，包含以下表单字段：

### 8.1 物料条码信息

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 名称 | 下拉选择 | 是 | 选择物料名称，选择后自动填充条码、规格型号、分类、计量单位、品牌、保留小数 |
| 条码 | 文本（自动） | 否 | 根据名称自动生成 |
| 规格型号 | 文本（自动） | 否 | 根据名称自动填充 |
| 分类 | 文本（自动） | 否 | 根据名称自动填充 |
| 计量单位 | 文本（自动） | 否 | 根据名称自动填充 |
| 品牌 | 文本（自动） | 否 | 根据名称自动填充 |
| 保留小数 | 数字（自动） | 否 | 根据名称自动填充，默认0 |

### 8.2 物料称重标准

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 称重单位 | 下拉选择 | 是 | 选择称重使用的单位（如kg、g） |
| 称重保留小数 | 数字输入 | 是 | 称重数值保留小数位数，范围0-4，默认0 |
| 标准值 | 数字输入 | 是 | 称重标准值 |
| 标准范围 | 数字输入 | 否 | 两个数字输入框，格式为"最小值-最大值" |
| 单据类型 | 单选 | 否 | 可选"盛料桶记录表"或"复合香精记录"，支持"取消选择" |
| 单据序号 | 文本输入 | 否 | 输入单据序号 |
