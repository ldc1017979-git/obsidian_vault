## 1. 页面概述

- **页面路径**: 生产管理 > 生产基础信息 > 生产班组
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/production-baseinfo/production-team`
- **功能说明**: 管理生产班组信息，包括班组名称和可用状态。支持新增、编辑、删除操作，以及通过开关直接切换班组的可用状态。

---

## 2. 搜索条件

| 搜索项 | 类型 | 说明 |
|--------|------|------|
| 生产班组 | 文本输入 | 按班组名称搜索 |
| 可用状态 | 下拉选择 | 可选"可用"或"禁用" |

搜索按钮：重置、搜索

## 3. 列表字段说明

| 字段名 | 说明 |
|--------|------|
| 生产班组 | 班组名称，如"A"、"B"、"C" |
| 可用状态 | 开关控件，可切换"启用"/"禁用"状态 |
| 创建人 | 创建该记录的用户 |
| 创建时间 | 创建时间 |
| 更新人 | 最后更新该记录的用户 |
| 更新时间 | 最后更新时间 |
| 操作 | 编辑、删除 |

## 5. 可交互按钮与操作

### 5.1 页面顶部按钮

| 按钮 | 说明 |
|------|------|
| 重置 | 重置搜索条件 |
| 搜索 | 按条件搜索 |
| 新建 | 打开新增班组对话框 |
| 列设置 | 打开列展示设置面板 |

### 5.2 行内控件与按钮

| 控件/按钮 | 说明 |
|-----------|------|
| 可用状态开关 | 直接切换班组的启用/禁用状态 |
| 编辑 | 打开编辑班组对话框，可修改班组名称和可用状态 |
| 删除 | 弹出删除确认对话框，确认后删除该条记录 |

---

## 6. 新增对话框

点击"新建"按钮后弹出"新增"对话框，包含以下表单字段：

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 生产班组 | 文本输入 | 是 | 输入班组名称 |
| 可用状态 | 开关 | 否 | 切换启用/禁用状态，默认关闭 |

- ![新增对话框](../../截图/生产班组-新增对话框.png)

---

## 7. 编辑对话框

点击行操作"编辑"按钮后弹出"编辑"对话框，表单字段与新增相同，但会预填充当前行的数据。

以班组"A"为例的编辑表单数据：

| 字段 | 值 |
|------|-----|
| 生产班组 | A |
| 可用状态 | 启用（开关已打开） |

- ![编辑对话框](../../截图/生产班组-编辑对话框.png)

---

## 8. 删除确认对话框

点击行操作"删除"按钮后弹出确认对话框：

- **类型**: 警告
- **内容**: 确认要删除生产班组为：【A】的该条内容吗?
- **按钮**: 取消 / 确定

- ![删除确认对话框](../../截图/生产班组-删除确认对话框.png)
