# 出入库明细报表

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 报表 → 出入库明细报表
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/forms/inout-record`
- **功能说明**: 查看出入库明细报表，记录所有出入库业务流水

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 搜索 | 根据筛选条件查询出入库明细 |
| 2 | 重置 | 清空搜索条件 |
| 3 | 数据导出 | 导出出入库明细数据 |
| 4 | 打印 | 打印报表 |

## 交互说明

1. 进入页面后默认显示所有出入库明细记录
2. 支持多条件组合搜索筛选
3. 支持"数据导出"和"打印"操作
