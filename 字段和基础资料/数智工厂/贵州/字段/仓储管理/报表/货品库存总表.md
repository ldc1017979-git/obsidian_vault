# 货品库存总表

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 报表 → 货品库存总表
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/forms/goods-stock`
- **功能说明**: 查看货品库存总表，汇总展示各仓库物料库存情况

## 交互说明

1. 进入页面后默认显示所有货品库存汇总数据
2. 支持多条件组合搜索筛选
3. 支持"数据导出"操作
4. 支持"库存预警"和"订货预警"功能
5. 可查看月消耗量统计
