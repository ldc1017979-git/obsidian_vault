# 保养工单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 叉车管理 → 叉车维保记录 → 保养工单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/forklift-manage/storage-others/maintain/work-order`
- **功能说明**: 管理叉车保养工单，记录保养执行情况和费用

## 交互说明

1. 进入页面后默认显示所有保养工单列表
2. 支持多条件组合搜索筛选
3. 点击"详情"按钮可查看保养工单详细信息
4. 工单由保养计划执行后自动生成
