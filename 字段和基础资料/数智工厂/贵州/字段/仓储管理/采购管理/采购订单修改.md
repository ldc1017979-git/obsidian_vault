# 采购订单修改

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 采购管理 → 原料/备件与综合物资 → 采购订单修改
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/buy/order-modification`
- **功能说明**: 管理采购订单的修改申请，记录修改原因、修改内容等信息

## 交互说明

1. 进入页面后默认显示所有采购订单修改记录列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的修改申请
4. 点击"详情"按钮可查看修改详情
5. 新建时需先选择采购订单类型，再选择采购单号
6. 修改原因类型支持新增、修改、删除、修改删除等选项
7. 通过"选择采购单商品"按钮选择需要修改的商品
8. 详情页包含"采购订单修改详情"、"单据日志"、"审批流程"三个标签页
