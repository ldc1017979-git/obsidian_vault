# 供应商调查表

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 采购管理 → 仓储SRM → 供应商调查表
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/buy/cangchu/supplier-survey`
- **功能说明**: 管理供应商调查表，记录供应商资质、能力等调查信息

## 交互说明

1. 进入页面后默认显示所有供应商调查表列表
2. 支持按填表日期和状态筛选
3. 点击"新增"按钮可创建新的供应商调查表
4. 点击"详情"按钮可查看调查表详细信息
5. 新建表单包含7个折叠区域：基本信息、供应商基本信息、公司概况、人员信息、生产技术设备信息、产品信息、财务信息
6. 详情页与新建页字段一致，但所有字段为只读状态
7. 签字功能支持电子签名，填表人和公司负责人均需签字
