# 需求计划单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 采购管理 → 需求计划单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/buy/demand-plan`
- **功能说明**: 用于创建和管理物料需求计划单，包括需求计划的创建、审核、采购跟踪等

## 交互说明

1. 进入页面后默认显示所有需求计划单列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的需求计划单
4. 点击"详情"按钮可查看需求计划单详细信息
5. 点击"导出"按钮可导出数据
6. 新建需求计划单时需填写需求月份，添加商品明细行并填写申请部门、部门仓库、物料信息等
7. 新建页面支持保存草稿和提交审核两种操作
