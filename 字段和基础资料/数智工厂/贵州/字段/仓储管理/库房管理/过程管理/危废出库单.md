# 危废出库单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 过程管理 → 危废管理 → 危废出库单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/auxiliary-materials/hazardous/hazardous-out`
- **功能说明**: 管理危废物品出库记录，记录废物去向和出库信息

## 交互说明

1. 进入页面后默认显示所有危废出库记录列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的危废出库单
4. 点击"详情"按钮可查看出库记录详细信息
