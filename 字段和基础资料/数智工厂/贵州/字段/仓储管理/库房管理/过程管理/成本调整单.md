# 成本调整单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 过程管理 → 成本调整单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/auxiliary-materials/cost-adjustment`
- **功能说明**: 管理库存成本调整记录，调整仓库物料的成本信息

## 交互说明

1. 进入页面后默认显示所有成本调整记录列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的成本调整单
4. 点击"详情"按钮可查看调整记录详细信息
