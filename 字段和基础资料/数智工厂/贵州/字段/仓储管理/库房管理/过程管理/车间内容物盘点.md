# 车间内容物盘点

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 过程管理 → 车间内容物盘点
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/auxiliary-materials/workshop-content-check`
- **功能说明**: 管理车间内容物盘点记录，记录盘点盈亏情况

## 交互说明

1. 进入页面后默认显示所有车间内容物盘点记录列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的盘点单
4. 点击"详情"按钮可查看盘点记录详细信息
