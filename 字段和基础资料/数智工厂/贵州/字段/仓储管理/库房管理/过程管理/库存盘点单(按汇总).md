# 库存盘点单(按汇总)

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 过程管理 → 库存盘点单(按汇总)
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/auxiliary-materials/inventory-check`
- **功能说明**: 管理库存盘点单按汇总方式记录，统计盘点盈亏情况

## 交互说明

1. 进入页面后默认显示所有库存盘点记录列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的库存盘点单
4. 点击"详情"按钮可查看盘点记录详细信息
5. 支持"导出"操作导出盘点数据
