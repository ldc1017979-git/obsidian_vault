# 原料库存日报

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原材料管理 → 原料库存日报
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/material-manage/warehouse-raw-inventory`
- **功能说明**: 管理原料库存日报的生成和查看，记录每日库存数据

## 交互说明

1. 进入页面后默认显示所有原料库存日报列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的库存日报
4. 点击"详情"按钮可查看日报详细信息
