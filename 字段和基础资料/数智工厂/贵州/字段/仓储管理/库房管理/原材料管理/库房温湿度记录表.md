# 库房温湿度记录表

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原材料管理 → 库房温湿度记录表
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/material-manage/warehouse-temperature`
- **功能说明**: 记录库房温湿度数据，确保仓储环境符合标准

## 交互说明

1. 进入页面后默认显示所有库房温湿度记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增"按钮可创建新的温湿度记录
4. 点击"温度标准配置"可设置温湿度标准值
5. 点击"详情"按钮可查看温湿度记录详细信息
