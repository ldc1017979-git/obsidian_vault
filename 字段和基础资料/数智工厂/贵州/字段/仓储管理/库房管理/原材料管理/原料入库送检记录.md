# 原料入库送检记录

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原材料管理 → 原料入库送检记录
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/material-manage/raw-check-record`
- **功能说明**: 记录原料入库后的送检信息，关联品质检验单号
