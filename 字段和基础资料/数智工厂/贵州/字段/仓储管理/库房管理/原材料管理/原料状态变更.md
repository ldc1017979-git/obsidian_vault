# 原料状态变更

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原材料管理 → 原料状态变更
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/material-manage/raw-status-change`
- **功能说明**: 管理原料状态的变更操作，记录变更原因和变更详情

## 交互说明

1. 进入页面后默认显示所有原料状态变更记录列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的状态变更单
4. 点击"详情"按钮可查看变更记录详细信息
