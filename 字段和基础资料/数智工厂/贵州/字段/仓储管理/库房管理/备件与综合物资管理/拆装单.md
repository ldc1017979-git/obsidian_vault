# 拆装单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 备件与综合物资管理 → 拆装单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/integrated-manage/split`
- **功能说明**: 管理备件的拆装操作，将一个备件拆分为多个或组装为一个

## 交互说明

1. 进入页面后默认显示所有拆装单列表
2. 支持多条件组合搜索筛选
3. 点击"新建拆装单"按钮可创建新的拆装单
4. 点击"详情"按钮可查看拆装单详细信息
