# 战略备件入库单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 备件与综合物资管理 → 战略备件入库单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/integrated-manage/strategy-in`
- **功能说明**: 管理战略备件的入库操作，记录战略备件入库信息

## 交互说明

1. 进入页面后默认显示所有战略备件入库单列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的入库单
4. 点击"详情"按钮可查看入库单详细信息
