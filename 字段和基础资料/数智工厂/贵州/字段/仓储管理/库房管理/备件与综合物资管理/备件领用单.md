# 备件领用单

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 备件与综合物资管理 → 备件领用单
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/integrated-manage/spare-part-receive`
- **功能说明**: 管理备件的领用出库操作，记录领用人、维修类型等信息

## 交互说明

1. 进入页面后默认显示所有备件领用单列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的领用单
4. 点击"详情"按钮可查看领用单详细信息
5. 新建领用单需选择维修类型、出库仓库、领用人等基本信息
6. 支持单条添加和批量添加领用商品
