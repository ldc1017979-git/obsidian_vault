# 到货计划跟进

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原料到货验收 → 到货计划跟进
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/check/delivery-plan`
- **功能说明**: 管理原料到货计划的跟进，记录预计到货和实际到货信息

## 交互说明

1. 进入页面后默认显示所有到货计划跟进列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的到货计划
4. 点击"确认到货"可确认物料已到货
5. 点击"详情"按钮可查看到货计划详细信息
