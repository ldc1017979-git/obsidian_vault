# 原料入库抽检报告

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原料到货验收 → 原料入库抽检报告
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/check/raw-inspect`
- **功能说明**: 记录原料入库抽检报告，管理抽检标准、抽检率和合格率等信息

## 交互说明

1. 进入页面后默认显示所有原料入库抽检报告列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的抽检报告
4. 点击"定义检验标准"可配置抽检标准
5. 点击"详情"按钮可查看抽检报告详细信息
