# 原料入库计量抽检月报

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原料到货验收 → 原料入库计量抽检月报
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/check/raw-monthly-spotcheck`
- **功能说明**: 管理原料入库计量抽检月报，汇总每月抽检数据

## 交互说明

1. 进入页面后默认显示所有原料入库计量抽检月报列表
2. 支持多条件组合搜索筛选
3. 点击"新建"按钮可创建新的月报
4. 点击"详情"按钮可查看月报详细信息
