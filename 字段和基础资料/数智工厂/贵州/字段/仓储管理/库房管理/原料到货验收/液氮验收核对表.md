# 液氮验收核对表

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 原料到货验收 → 液氮验收核对表
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/check/liquid-nitrogen`
- **功能说明**: 管理液氮验收核对记录，记录到货数量、入库/出库重量等信息

## 交互说明

1. 进入页面后默认显示所有液氮验收核对记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增"按钮可创建新的核对记录
4. 点击"详情"按钮可查看核对记录详细信息
