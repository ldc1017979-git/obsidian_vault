# 货物出门条

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 日常管理 → 货物出门条
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/daily/goods_out_pass_record`
- **功能说明**: 管理货物出门条，记录货物出厂审批信息

## 交互说明

1. 进入页面后默认显示所有货物出门条记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增"按钮可创建新的货物出门条
4. 支持"确认提交"、"撤回"和"作废"操作
5. 点击"详情"按钮可查看出门条详细信息
