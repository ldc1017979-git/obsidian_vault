# 咖啡因存料账卡记录

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 日常管理 → 咖啡因存料账卡记录
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/daily/caffeine-record`
- **功能说明**: 记录咖啡因存料账卡，追踪咖啡因的进货、出货和库存明细

## 交互说明

1. 进入页面后默认显示所有咖啡因存料账卡记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增"按钮可创建新的存料账卡记录
4. 支持"数据导出"操作
5. 点击"详情"按钮可查看账卡记录详细信息
