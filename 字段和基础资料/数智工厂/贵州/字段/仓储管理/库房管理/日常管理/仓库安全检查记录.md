# 仓库安全检查记录

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 日常管理 → 仓库安全检查记录
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/daily/warehouse-safety`
- **功能说明**: 管理仓库安全检查记录，记录检查内容和结果

## 交互说明

1. 进入页面后默认显示所有仓库安全检查记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增"按钮可创建新的安全检查记录
4. 点击"检查项目配置"可配置检查项目
5. 支持"导出报告"操作
