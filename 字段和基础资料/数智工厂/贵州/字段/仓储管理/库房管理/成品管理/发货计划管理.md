# 发货计划管理

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 成品管理 → 发货计划管理
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/product-manage/shipments-plan`
- **功能说明**: 管理成品发货计划，记录发运计划数和实际发运数

## 交互说明

1. 进入页面后默认显示所有发货计划列表
2. 本页面为发货计划查看页面
3. 显示发运计划数与实际发运数的对比信息

## 备注

> 本页面为发货计划查看页面，无"详情"和"新建"功能。仅支持搜索和查看计划信息。
