# 库位移动管理

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 成品管理 → 库位移动管理
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/product-manage/product-stock/product_change`
- **功能说明**: 管理成品库位移动操作，记录物料在不同库位之间的移动信息

## 交互说明

1. 进入页面后默认显示所有库位移动记录列表
2. 支持多条件组合搜索筛选
3. 点击"新增库位移动"按钮可创建新的库位移动单
4. 支持"提交签字"和"完成移库"操作
5. 点击"详情"按钮可查看库位移动记录详细信息
