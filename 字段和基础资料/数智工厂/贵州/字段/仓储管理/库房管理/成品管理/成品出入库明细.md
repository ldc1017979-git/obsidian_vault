# 成品出入库明细

## 页面概述

- **功能模块**: 数据录入端 → 仓储管理 → 库房管理 → 成品管理 → 成品出入库明细
- **页面URL**: `https://gzmms.y1b.cn:8424/#/warehouse-manage/depot-manage/product-manage/product-stock/inventory-details`
- **功能说明**: 查看成品出入库明细记录，记录每次出入库操作的详细信息

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 搜索 | 根据筛选条件查询出入库明细 |
| 2 | 重置 | 清空所有筛选条件 |
| 3 | 去供应链系统 | 跳转至供应链系统 |
| 4 | 导出数据 | 导出出入库明细数据 |

## 交互说明

1. 进入页面后默认显示所有成品出入库明细列表
2. 支持多条件组合搜索筛选
3. 点击"导出数据"可导出出入库明细
4. 点击"去供应链系统"可跳转至供应链系统

## 备注

> 本页面为出入库明细查看页面，无"详情"和"新建"功能。仅支持搜索、查看和导出数据。
