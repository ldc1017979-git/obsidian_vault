# 当班误时信息登记表

## 页面概述
- **功能模块**: 数据录入端 → 生产管理 → 过程管理 → 主管 → 当班误时信息登记表
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/index55/zhuguan/delays-info-record`
- **功能说明**: 登记当班各类误时信息，包括设备误时、原材料误时、运维误时、人员误时、工艺误时和其他误时
