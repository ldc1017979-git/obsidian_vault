# 开机检查

## 页面概述
- **功能模块**: 数据录入端 → 生产管理 → 过程管理 → 主管 → 开机检查
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/index55/zhuguan/power-inspection`
- **功能说明**: 记录生产线开机前的各项检查项目，包括人员到岗、设备运行、环境卫生等检查内容
