# 班前会记录

## 页面概述
- **功能模块**: 数据录入端 → 生产管理 → 过程管理 → 扫码 → 班前会记录
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/index55/saoma/gd_class_meeting_record`
- **功能说明**: 记录每日班前会内容，包括班组、班次、会议状态等信息
