# 原辅料物料平衡表

## 页面概述
- **功能模块**: 数据录入端 → 生产管理 → 过程管理 → 扫码 → 原辅料物料平衡表
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/index55/saoma/raw-material-balance-sheet`
- **功能说明**: 记录原辅料物料使用平衡情况，包括配方量、配料缸数、理论产量、实际产量、废品量及物料平衡率计算
