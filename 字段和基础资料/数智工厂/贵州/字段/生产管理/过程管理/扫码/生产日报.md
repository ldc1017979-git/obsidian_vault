# 生产日报

## 页面概述
- **功能模块**: 数据录入端 → 生产管理 → 过程管理 → 扫码 → 生产日报
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/index55/saoma/daily_paper`
- **功能说明**: 记录每日生产数据，包括各产品类型的当日产量和出货量
