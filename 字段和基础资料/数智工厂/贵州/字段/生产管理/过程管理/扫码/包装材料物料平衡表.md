# 包装材料物料平衡表

## 页面概述
- **功能模块**: 数据录入端 → 生产管理 → 过程管理 → 扫码 → 包装材料物料平衡表
- **页面URL**: `https://gzmms.y1b.cn:8424/#/product/index55/saoma/packag-materials-balance-sheet`
- **功能说明**: 记录包装材料使用平衡情况，包括空罐、顶盖、纸皮、热缩膜、热熔胶等材料的入库量、退库量、报废量、取样量及物料平衡率计算

### 物料平衡情况
计算公式：物料平衡 = （成品入库量 + 原材料退库量 + 成品报废量 + 成品取样量）/ 原材料领用量
