# 证明开具字段表

---

## 功能业务介绍

证明开具模块用于管理员工申请开具各类证明的业务流程。员工可以通过系统提交证明开具申请，选择证明类型并填写申请原因，经审核通过后完成证明开具。支持工作证明等多种证明类型，记录完整的申请、审核和领取流程。

---

## 业务流程

```mermaid
flowchart TD
    A[创建证明开具申请] --> B[待提交]
    B --> C[待审核]
    C --> D{是否通过}
    D -->|是| E[已完成]
    D -->|否| B
    E --> F[反审核]
    F --> B
```

```mermaid
sequenceDiagram
    participant Employee as 员工
    participant System as 系统
    participant Approver as 审批人

    Employee->>System: 创建证明开具申请
    System->>System: 自动带出员工信息(工号/部门/岗位等)
    Employee->>System: 选择证明类型
    Employee->>System: 填写申请原因
    Employee->>System: 提交申请
    System->>System: 生成业务编号
    System->>Approver: 推送审批通知
    
    Approver->>System: 审核申请
    alt 审核通过
        System->>System: 更新状态为"已完成"
        System->>Employee: 通知审核通过
        Employee->>System: 领取证明资料
        System->>System: 记录领取日期时间
    else 审核不通过
        System->>System: 更新状态为"待提交"
        System->>Employee: 通知审核结果
    end
    
    alt 反审核
        Approver->>System: 执行反审核
        System->>System: 更新状态为"待提交"
    end
```

## 业务规则

### R01 - 员工信息规则
- 员工名称为必填字段，最大长度50字符
- 工号、部门、入职日期、岗位由系统从员工档案自动带出，不可手动修改

### R02 - 业务编号规则
- 业务编号由系统自动生成，格式为"ZM + 年份后两位 + 月份 + 日期 + 流水号"
- 例如：ZM260331001（2026年3月31日第1号证明开具单）

### R03 - 申请信息规则
- 申请日期为必填字段，默认为系统当前日期
- 申请原因为必填字段，最大长度1000字符
- 证明类型为下拉选择，支持扩展多种类型

### R04 - 状态流转规则
- 状态流转顺序：待提交 → 待审核 → 已完成
- 待提交状态可进行编辑和提交操作
- 待审核状态仅审批人可操作（通过/拒绝）
- 已完成状态支持反审核操作退回待提交

### R05 - 附件规则
- 支持的文件格式：jpg、png、gif、jpeg、pdf、zip、rar、docx、doc、xlsx、ppt、pptx、pptm、xls
- 单个文件大小不超过100MB
- 最多支持上传10个附件

## 业务状态

| 状态名称 | 说明 | 触发条件 | 可执行操作 |
|---------|------|---------|-----------|
| 待提交 | 申请信息已填写但未提交 | 创建申请后 | 编辑、提交、删除 |
| 待审核 | 申请已提交，等待审批 | 员工提交申请 | 审核通过、审核拒绝 |
| 已完成 | 审核通过，证明已开具 | 审批人审核通过 | 查看详情、反审核、记录领取日期 |
