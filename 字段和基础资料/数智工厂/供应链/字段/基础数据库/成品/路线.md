# 路线

> 模块路径: 基础数据库 > 成品 > 路线
> 页面URL: https://txcscm.y1b.cn/#/jichushuku/finishedproduct/lines

---

## 页面概述

路线页面展示运输线路信息列表，记录起运地、目的地、发运方式、线路编码等。

---

## 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 搜索 | 搜索筛选条件 |
| 重置 | 重置筛选条件 |
| 新增线路 | 新增运输线路 |
| 导入线路 | 导入线路数据 |
| 编辑 | 编辑线路信息 |
| 删除 | 删除线路 |

---

## 筛选条件

### 列表筛选字段

| 条件名称 | 字段类型 | 说明 |
|---------|---------|------|
| 关键词 | 下拉+文本 | 关键词搜索（全部） |
| 发运方式 | 下拉选择 | 发运方式筛选 |

---

## 列表字段

| 字段名称 | 字段类型 | 示例值 | 说明 |
|---------|---------|--------|------|
| 序号 | 数值 | 1 | 行序号 |
| 操作 | 按钮组 | 编辑/删除 | 操作按钮 |
| 起运地 | 文本 | 咸宁 | 起运地名称 |
| 目的地 | 文本 | 泉州 | 目的地名称 |
| 起-止 | 文本 | 咸宁~泉州 | 起止地点组合 |
| 发运方式 | 文本 | 汽运 | 发运方式（如汽运、华庭直配、会议直配） |
| 线路 | 文本 | ZZ0180 | 线路编码 |
| 卸载方式 | 文本 | 1 | 卸载方式 |

---

## 编辑页字段（点击「编辑」按钮进入）

### 路线编辑表单

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 起运地 | 文本输入 | 起运地名称 |
| 目的地 | 文本输入 | 目的地名称 |
| 路线 | 文本输入 | 线路编码（如ZZ0180、Z09073） |
| 装卸方式 | 文本输入 | 装卸方式 |
| 发运方式 | 下拉选择 | 发运方式（如汽运、华庭直配、会议直配） |
