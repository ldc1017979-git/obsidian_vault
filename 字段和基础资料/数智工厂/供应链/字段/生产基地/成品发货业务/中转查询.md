# 中转查询

> 模块路径: 生产基地 > 成品发货业务 > 中转查询
> 页面URL: https://txcscm.y1b.cn/#/base/chenpinfahuo/transWaybill

## 页面概述

中转查询页面以列表形式展示运单信息，支持按单号、日期、运输状态等条件筛选，可查看运单详情。

---

## 列表页

### 筛选条件

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 单号信息 | 下拉选择+文本输入 | 单号筛选（默认"全部"） |
| 发运日期 | 日期范围 | 开始时间-结束时间 |
| 运输状态 | 下拉选择 | 运输状态 |
| 发货地 | 下拉选择 | 发货地 |
| 仓库 | 下拉选择 | 仓库 |
| 商品信息 | 下拉选择+文本输入 | 商品筛选（默认"全部"） |
