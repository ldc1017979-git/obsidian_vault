# 库存查询

> 模块路径: 生产基地 > 成品发货业务 > 库存查询
> 页面URL: https://txcscm.y1b.cn/#/base/chenpinfahuo/productStockProductSearch

## 页面概述

库存查询页面以列表形式展示成品库存信息，支持按工厂、库位、批次等条件筛选。查询前需先选择库存工厂/仓库。

## 筛选条件

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 库存工厂编码 | 下拉选择 | 库存工厂编码 |
| 库位信息 | 文本输入 | 库位信息 |
| 成品批次 | 文本输入 | 成品批次 |
| 库存类型 | 下拉选择 | 库存类型 |
| 物料信息 | 下拉选择+文本输入 | 物料搜索 |
| 成品批次 | 下拉选择 | 成品批次选择 |

## 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 搜索 | 按条件搜索 |
| 重置 | 重置筛选条件 |
| 合并 | 合并库存记录 |
| 库存可视化 | 库存可视化展示 |

## 统计信息

| 字段名称 | 说明 |
|---------|------|
| 库存总数 | 库存总数 |
| 非限制 | 非限制库存数 |
| 质量检查 | 质量检查库存数 |

## 列表字段

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 序号 | 数值 | 行序号 |
| 库存工厂编码 | 文本 | 库存工厂编码 |
| 库存工厂名称 | 文本 | 库存工厂名称 |
| 物料编码 | 文本 | 物料编码 |
| 库存总数 | 数值 | 库存总数 |
| 非限制 | 数值 | 非限制库存数 |
| 质量检查 | 数值 | 质量检查库存数 |
| 单位 | 文本 | 单位 |
| 物料名称 | 文本 | 物料名称 |
| 操作 | 按钮组 | 操作按钮 |

## 提示信息

查询前需先选择库存工厂/仓库，系统会弹出温馨提示对话框。
