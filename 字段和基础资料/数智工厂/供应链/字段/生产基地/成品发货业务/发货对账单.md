# 发货对账单

> 模块路径: 生产基地 > 成品发货业务 > 发货对账单
> 页面URL: https://txcscm.y1b.cn/#/base/chenpinfahuo/baseDispatchStatements

## 页面概述

发货对账单页面以交叉表形式展示发货对账数据，支持多条件筛选和导出Excel。

## 筛选条件

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 发货工厂 | 下拉选择 | 发货工厂 |
| 仓库 | 下拉选择 | 仓库 |
| 统计日期 | 日期范围 | 开始时间-结束时间（默认当月1日至当天） |
| 商品信息 | 下拉选择+文本输入 | 商品筛选（默认"全部"） |
| 运输方式 | 下拉选择 | 运输方式 |
| 库存工厂 | 下拉选择 | 库存工厂 |
| 订单号 | 文本输入 | 订单号搜索 |

## 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 搜索 | 按条件搜索 |
| 重置 | 重置筛选条件 |
| 合并 | 合并统计 |
| 导出统计Excel | 导出统计数据 |

## 统计汇总

| 字段名称 | 说明 |
|---------|------|
| 统计日期 | 统计日期范围 |
| 发货合计 | 发货总数 |
