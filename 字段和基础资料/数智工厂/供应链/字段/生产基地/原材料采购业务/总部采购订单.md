# 总部采购订单

> 模块路径: 生产基地 > 原材料采购业务 > 总部采购订单
> 页面URL: https://txcscm.y1b.cn/#/base/yuancailiaocaigou/basePurchaseOrder

## 页面概述

总部采购订单页面以列表形式展示基地视角的采购订单信息，支持列表筛选和查看详情。

## 筛选条件

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 采购订单号 | 文本输入 | 输入采购订单号搜索 |
| SAP采购订单号 | 文本输入 | 输入SAP采购订单号搜索 |
| 供应商名称 | 文本输入 | 输入供应商名称搜索 |
| 供应商编码 | 文本输入 | 输入供应商编码搜索 |
| 运输商名称 | 文本输入 | 输入运输商名称搜索 |
| 运输商编码 | 文本输入 | 输入运输商编码搜索 |
| 采购方名称 | 文本输入 | 输入采购方名称搜索 |
| 采购方销售组织代码 | 文本输入 | 输入采购方销售组织代码搜索 |
| 采购方收货工厂 | 文本输入 | 输入采购方收货工厂搜索 |
| 采购方收货工厂代码 | 文本输入 | 输入采购方收货工厂代码搜索 |

| 采购方收货库位 | 文本输入 | 输入采购方收货库位搜索 |
| 采购订单状态 | 下拉选择 | 选择采购订单状态筛选（如"待要货"） |
| 订单创建人 | 文本输入 | 输入订单创建人搜索 |
| 订单创建时间 | 日期范围 | 选择订单创建时间范围 |

## 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 列表筛选 | 展开/收起筛选条件 |
| 详情 | 查看订单详情 |
| N项 | 物料信息项数展示（可点击展开物料明细） |
