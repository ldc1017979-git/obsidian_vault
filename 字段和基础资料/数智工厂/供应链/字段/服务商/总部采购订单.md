## 列表页

### 页面概述

总部采购订单页面展示服务商视角的采购订单列表，支持列表筛选和查看详情操作。

### 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 列表筛选 | 打开列表筛选面板 |
| 详情 | 查看采购订单详情 |

## 详情页（点击「详情」按钮进入）

### 页面结构

详情页面通过 **6 个外层 Tab** 展示不同内容，各 Tab 的主要信息如下：

| Tab 名称 | 内容形式 | 说明 |
|---------|---------|------|
| 原料采购订单详情 | 表单 + 表格 | 核心详情页：展示采购订单基础信息（表单）及物料明细（表格） |
| 单据内容 | 表单 + 表格 | 与原料采购订单详情结构相同，展示单据基础信息及物料明细 |
| 单据日志 | 表格 | 展示单据操作日志信息 |
| 审批流程 | 文本/流程 | 展示审批流程信息（待处理/已通过节点提示） |
| 业务单据串联 | 表格 | 展示关联业务单据列表 |
| 总部采购订单 | 表格 | 返回列表视图 |

### 2. 单据内容

与「原料采购订单详情」Tab 结构相同，包含：
- **基础信息**：采购订单号、SAP采购订单号、供应商信息、运输商信息、采购方信息、采购订单状态、订单创建人、订单创建时间等字段
- **物料明细**：28列表格，字段同上（序号、物料名称、物料编码、SAP物料编码、采购订单量、基地要货数量、供应商生产计划量、供应商已生产数量、供应商已发货数量、到货合格数量、基地质检合格数、基地已入库数量、采购单位、采购单价、采购金额等）

### 4. 审批流程

展示审批流程信息，典型内容：
- 审批节点列表（待处理/已通过/已拒绝）

- 无审批记录时显示暂无数据提示
