# 生产订单

> 模块路径: 供应商 > 生产厂商 > 生产订单

## 列表页

### 页面概述

生产订单页面展示生产厂商视角的生产订单列表，支持列表筛选、查看详情和去打标操作。

### 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 列表筛选 | 打开列表筛选面板 |
| 详情 | 查看生产订单详情 |
| 去打标 | 跳转打标页面 |

### 列表筛选字段

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 生产计划单号 | 文本输入 | 按生产计划单号筛选 |
| 生产计划状态 | 下拉选择 | 按生产计划状态筛选（待生产/生产中/已生产） |
| 物料名称 | 文本输入 | 按物料名称筛选 |
| 物料编码 | 文本输入 | 按物料编码筛选 |

| 线上促销 | 下拉选择 | 按是否线上促销筛选（是/否） |
| 生产厂商 | 文本输入 | 按生产厂商名称筛选 |
| 计划完成时间 | 日期输入 | 按计划完成时间筛选 |
| 码源处理状态 | 下拉选择 | 按码源处理状态筛选（待申请/已完成） |
| 要货计划单号 | 文本输入 | 按关联要货计划单号筛选 |
| 采购订单号 | 文本输入 | 按关联采购订单号筛选 |

## 详情页（点击「详情」按钮进入）

### 页面结构

详情页面通过 2 个外层 Tab 展示不同内容，底部提供「关闭」操作按钮。

| Tab 名称 | 内容形式 | 说明 |
|---------|---------|------|
| 基础信息 | 表格 | 包含 2 个信息表格：关联单据信息（12列）、物料信息（11列） |
| 需求物料 | 表格 | 展示需求物料分配信息，无数据时显示「暂无分配数据」 |
