## 列表页

### 页面概述

生产计划页面展示供应商视角的生产计划列表，支持查看详情、打标、合格证、变更等操作。

### 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 提前备货 | 对生产计划进行提前备货 |
| 列表筛选 | 展开/收起筛选条件 |
| 详情 | 查看生产计划详情 |
| 去打标 | 进入打标操作 |
| 合格证 | 管理合格证相关操作 |
| 申请码源 | 申请活动码源 |
| 变更 | 变更生产计划 |

## 详情页（点击「详情」按钮进入）

### 页面结构

详情页面通过「基础信息」和「需求物料」两个切换按钮展示不同模块内容。

| 切换按钮 | 内容形式 | 说明 |
|---------|---------|------|
| 基础信息 | 表格（横向 label-value） | 展示生产计划关联的基础信息（单号、双方公司/客户信息） |
| 需求物料 | 表格 | 展示生产计划的详细物料需求信息 |
| 关闭 | 按钮 | 关闭详情弹窗 |
