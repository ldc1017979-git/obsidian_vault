## 列表页

### 页面概述

异常处置单-生产页面展示供应商视角的生产异常记录列表，支持列表筛选、查看详情、提审等操作。

### 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 列表筛选 | 打开列表筛选面板 |
| 详情 | 查看异常处置单详情 |
| 提审 | 提交审批 |

### 列表筛选字段

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| 异常记录单号 | 文本输入 | 按异常记录单号筛选 |
| 异常类型 | 下拉选择 | 按异常类型筛选（如作废） |
| 审批状态 | 下拉选择 | 按审批状态筛选（如待提审） |
| 生产计划单号 | 文本输入 | 按关联生产计划单号筛选 |
| 物料名称 | 文本输入 | 按物料名称筛选 |
| 物料编码 | 文本输入 | 按物料编码筛选 |
| 生产厂商 | 文本输入 | 按生产厂商名称筛选 |
| 要货计划单号 | 文本输入 | 按关联要货计划单号筛选 |
| 采购订单号 | 文本输入 | 按关联采购订单号筛选 |
| SAP物料编码 | 文本输入 | 按SAP系统物料编码筛选 |
| 申请日期 | 日期区间 | 按申请日期区间筛选 |
| 申请人 | 文本输入 | 按申请人筛选 |

## 详情页（点击「详情」按钮进入）

### 页面结构

| Tab 名称 | 内容形式 | 说明 |
|---------|---------|------|
| 单据内容 | 表格 | 展示关联生产计划单据详情（18列表格） |
| 单据日志 | 表格 | 展示单据操作日志（6列表格） |
