# 账号管理

> 模块路径: 系统设置 > 账号管理
> 页面URL: https://txcscm.y1b.cn/#/setUp/user

## 页面概述

账号管理页面展示系统用户账号配置列表，记录用户姓名、手机号、所属角色、所属组织等信息，支持账号的增删改查及密码重置。

## 筛选条件

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| **审批状态** | **下拉** | **原文档缺失** - 按审批状态筛选 |
| **姓名** | **文本框** | **原文档缺失** - 按姓名搜索 |
| **手机号** | **文本框** | **原文档缺失** - 按手机号搜索 |
| **IP白名单** | **下拉** | **原文档缺失** - 按是否设置IP白名单筛选 |
| **创建时间** | **日期选择** | **原文档缺失** - 按创建时间筛选 |
| **所属角色** | **下拉** | **原文档缺失** - 按所属角色筛选 |
| **所属组织** | **下拉** | **原文档缺失** - 按所属组织筛选 |
