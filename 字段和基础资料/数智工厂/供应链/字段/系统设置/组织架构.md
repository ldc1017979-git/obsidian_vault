# 组织架构

> 模块路径: 系统设置 > 组织架构
> 页面URL: https://txcscm.y1b.cn/#/setUp/organization

## 页面概述

组织架构页面展示系统组织架构配置，以树状结构展示组织层级关系，支持新增、编辑、删除组织节点。

## 筛选条件

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 审批状态 | 下拉 | 审批状态筛选 |
| 组织类型 | 下拉 | 组织类型筛选 |
| 组织名称 | 文本框 | 组织名称搜索 |
| 组织代码 | 文本框 | 组织代码搜索 |

## 操作按钮

| 按钮名称 | 说明 |
|---------|------|
| 搜索 | 按条件搜索 |
| 重置 | 重置筛选条件 |
| 合并 | 合并组织 |
| 批量导入 | 批量导入组织数据 |
| 新增 | 新增子组织（树节点操作） |
| 编辑 | 编辑组织（树节点操作） |
| 删除 | 删除组织（树节点操作） |

## 列表字段

| 字段名称 | 字段类型 | 说明 | 示例值 |
|---------|---------|------|--------|
| 序号 | 数值 | 行序号 | 1 |
| 操作 | 按钮组 | 新增/编辑/删除 | 新增、编辑、删除 |
| 组织类型 | 文本 | 组织类型 | 集团总部 |
| 组织名称 | 文本 | 组织名称 | 华彬快速消费品集团 |
| 组织代码 | 文本 | 组织代码 | 0001 |
| 备注 | 文本 | 备注信息 | - |
| 审批状态 | 文本 | 审批状态 | 已通过 |

## 新增/编辑表单字段

点击新增或编辑按钮后弹出的表单包含以下字段：

| 字段名称 | 字段类型 | 说明 |
|---------|---------|------|
| **上级组织** | **下拉** | **原文档缺失** - 选择上级组织 |
| 组织类型 | 下拉 | 选择组织类型 |
| 组织名称 | 文本框 | 输入组织名称 |
| 组织代码 | 文本框 | 输入组织代码 |
| 备注 | 文本框 | 输入备注信息 |

## 审批状态枚举

| 状态值 | 说明 |
|--------|------|
| 已通过 | 审批已通过 |
