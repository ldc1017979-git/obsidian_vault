# 要货计划

## 概述

要货计划页面用于管理和维护各生产基地的原材料要货计划，记录各基地对原材料的需求情况。支持要货计划的创建、查询、修改等操作。

## 业务说明

1. 要货计划是生产基地向总部提交的原材料需求计划
2. 要货计划经审批后可转化为原料采购订单
3. 要货计划状态反映了需求的处理进度（待发货、签收中、临期、已作废）
4. 要货计划与采购配额、原料采购订单、供应商生产记录、供应商到货记录等模块关联
5. 每个要货计划可包含多条物料明细，记录详细的要货数量、到货日期、生产/发货/入库状态等信息
6. 物料明细字段完整记录了从生产到入库的全流程状态，便于追踪物料流转情况
7. 支持打印要货计划单据，用于存档和审批流程
