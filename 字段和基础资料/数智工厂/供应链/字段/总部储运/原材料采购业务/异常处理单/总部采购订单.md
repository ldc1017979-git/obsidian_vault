# 异常处理单 - 总部采购订单

## 页面概述

总部采购订单异常子模块用于管理和追踪与总部采购订单相关的各类异常情况，如延迟到货、数量不符、质量问题等。

---

## 一、列表页

### 筛选条件

| 筛选字段 | 类型 | 必填 | 说明 |
|----------|------|------|------|
| 异常记录单号 | 文本输入 | 否 | 按异常记录单号搜索 |
| 异常类型 | 下拉选择 | 否 | 按异常类型筛选 |
| 审批状态 | 下拉选择 | 否 | 按审批状态筛选 |
| 采购订单号 | 文本输入 | 否 | 按采购订单号搜索 |
| SAP采购订单号 | 文本输入 | 否 | 按SAP采购订单号搜索 |
| 申请日期 | 日期范围选择 | 否 | 按申请日期范围筛选（开始时间 - 结束时间） |
| 申请人 | 文本输入 | 否 | 按申请人搜索 |

### 操作按钮

| 按钮名称 | 功能说明 |
|----------|----------|
| 列表筛选 | 展开/收起筛选条件 |
| 搜索 | 按条件搜索采购订单异常 |
| 重置 | 重置筛选条件 |
| 列设置 | 自定义表格列显示、列宽和排序 |
| 详情 | 查看异常单详细信息 |

### 列表字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 序号 | 整数 | 行号 |
| 操作 | 按钮列 | 操作按钮列（详情） |
| 异常记录单号 | 文本 | 异常记录单据编号 |
| 异常类型 | 枚举 | 异常类型 |
| 审批状态 | 枚举 | 审批状态 |
| 采购订单号 | 文本 | 关联的采购订单号 |
| SAP采购订单号 | 文本 | 关联的SAP采购订单号 |
| 物料信息 | 文本 | 物料相关信息 |
| 订单总数量 | 数值 | 采购订单总数量 |
| 订单总金额 | 数值 | 采购订单总金额 |
| 申请日期 | 日期 | 异常申请日期 |
| 申请人 | 文本 | 申请人姓名 |

### 行操作按钮

| 按钮名称 | 功能说明 |
|----------|----------|
| 详情 | 查看采购订单异常单详细信息 |

## 三、列设置功能

| 设置项 | 说明 |
|--------|------|
| 列名 | 表格列名称（异常记录单号、异常类型、审批状态、采购订单号、SAP采购订单号、物料信息、订单总数量、订单总金额、申请日期、申请人） |
| 列宽 | 自定义每列宽度（像素） |
| 显示 | 开关控制该列是否显示 |
| 排序 | 开关控制该列是否可排序 |

---

## 业务说明

1. 总部采购订单异常专用于追踪采购订单相关的业务异常
2. 异常单需关联对应的采购订单号，便于追溯
3. 异常类型涵盖延迟、数量、质量、需求等多个维度
4. 异常记录包含订单数量和金额等关键业务指标
5. 支持通过列设置自定义表格显示方式
