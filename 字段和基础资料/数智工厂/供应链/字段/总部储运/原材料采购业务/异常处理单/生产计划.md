# 异常处理单 - 生产计划

## 页面概述

生产计划异常子模块用于管理和追踪与生产计划相关的各类异常情况，如产能不足、生产延迟、物料短缺、设备故障等。

## 操作按钮

| 按钮名称 | 功能说明 |
|----------|----------|
| 搜索 | 按条件搜索生产计划异常 |
| 重置 | 重置筛选条件 |
| 列表筛选 | 展开/收起筛选条件 |
| 详情 | 查看异常单详细信息 |
| 新建 | 创建新的生产计划异常单 |
| 处理 | 处理选中的异常单 |

## 列表字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 序号 | 整数 | 行号 |
| 操作 | 按钮 | 操作按钮列 |

| 异常类型 | 枚举 | 异常类型（产能不足/生产延迟/物料短缺/设备故障/计划变更/质量问题等） |
| 异常状态 | 枚举 | 异常状态（新建/处理中/已解决/已关闭） |
| 生产计划单号 | 文本 | 关联的生产计划单号 |
| 采购订单号 | 文本 | 关联的采购订单号 |
| 供应商名称 | 文本 | 供应商/生产厂商名称 |
| 物料名称 | 文本 | 物料名称 |
| 异常发生时间 | 日期时间 | 异常发生时间 |

| 处理时限 | 日期 | 异常处理截止时间 |
| 影响数量 | 数值 | 异常影响的数量 |

## 业务说明

1. 生产计划异常专用于追踪供应商端生产过程中的业务异常
2. 异常单需关联对应的生产计划单号，便于追溯
3. 异常类型涵盖产能、进度、物料、设备等多个维度
4. 每个异常单指定责任人并设定处理时限
5. 异常处理完成后需记录解决方案和处理结果
