# 排产计划

## 概述

排产计划页面用于管理和查看原材料采购的排产计划，支持"总览"日历视图和"排产"表格视图两种展示方式。

## 标签页结构

| 标签页名称 | 说明 |
|------------|------|
| 总览 | 以日历形式展示每日排产计划，包含月份选择器、基地筛选器、商品产量汇总 |
| 排产 | 以表格形式展示按基地/车间/产线维度的排产数据，支持每日编辑 |

---

## 一、总览视图（日历）

### 筛选条件

| 筛选字段 | 类型 | 说明 |
|----------|------|------|
| 月份： | 月份选择器 | 选择要查看的月份（格式：YYYY-MM） |
| 基地筛选 | 下拉选择 | 按基地筛选，默认"全部基地" |

### 操作按钮

| 按钮名称 | 功能说明 |
|----------|----------|
| 上个月 | 切换到上一个月的日历视图 |
| 当前月 | 回到当前月份 |
| 下个月 | 切换到下一个月的日历视图 |
| 查询 | 按条件查询排产数据 |
| 重置 | 重置筛选条件 |

### 日历视图表头字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 日 | 文本 | 星期日列 |
| 一 | 文本 | 星期一列 |
| 二 | 文本 | 星期二列 |
| 三 | 文本 | 星期三列 |
| 四 | 文本 | 星期四列 |
| 五 | 文本 | 星期五列 |
| 六 | 文本 | 星期六列 |

### 日历视图内容字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 日期（01-31） | 文本 | 当月每日日期 |
| 实际产量 | 标题 | 每日产量汇总区域 |
| 商品名称（多条） | 文本 | 各商品物料名称（如：红牛/250ML/24/25周年纪念装等） |
| 产量数值 | 数值 | 对应商品的当日产量，单位：箱 |

## 二、排产视图（表格）

### 操作按钮

| 按钮名称 | 功能说明 |
|----------|----------|
| 查询 | 按条件查询排产数据 |
| 重置 | 重置筛选条件 |
| 编辑 | 编辑对应日期的排产数量（每个日期列独立的编辑按钮） |

### 排产主表格字段（按日期维度）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 基地 | 文本 | 生产基地名称 |
| 车间 | 文本 | 车间名称 |
| 产线 | 文本 | 产线编号或名称 |
| MM-DD（每日列） | 数值+按钮 | 每日排产数量，每个单元格含"编辑"按钮，可修改该日排产数据 |

### 日期列说明

日期列从当月01日到30/31日，格式为`MM-DD`，如：
- 06-01、06-02、06-03 ... 06-30

每列均包含：
- 可编辑的排产数量输入字段
- "编辑"按钮，点击后可修改该日该产线的排产数据

### 商品信息表格字段（下方关联表格）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 序号 | 整数 | 行号 |
| 物料名称 | 文本 | 物料商品名称 |
| 物料编码 | 文本 | 内部物料编码 |
| SAP物料编码 | 文本 | SAP系统中的物料编码 |
| 线上促销 | 枚举 | 是否为线上促销物料 |
| 采购单位 | 文本 | 采购计量单位 |
| 到货规格 | 文本 | 到货规格说明 |
| 本次要货日期 | 日期 | 本次要货的日期 |
| 本次要货数量 | 数值 | 本次要货数量 |
| 订单单位 | 文本 | 订单计量单位 |

## 业务说明

1. 排产计划是原材料采购的核心环节，连接采购配额与实际生产需求
2. "总览"视图提供日历形式的每日产量概览，便于快速查看月度排产情况
3. "排产"视图提供按基地/车间/产线维度的详细排产表格，支持每日独立编辑排产数量
4. 商品信息表格关联展示相关物料的详细要货信息
5. 支持按月度进行排产规划，可通过月份导航和月份选择器切换查看
6. 排产数据与采购配额、原料采购订单、要货计划等模块关联
