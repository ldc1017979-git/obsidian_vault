## 2. 操作按钮

| 按钮 | 说明 |
|------|------|
| 新增 | 新增一级菜单 |
| 全部展开 | 展开所有子菜单 |
| 收起全部 | 收起所有子菜单 |

每行菜单项的操作按钮：

| 按钮 | 说明 |
|------|------|
| 新增 | 在当前菜单下新增子菜单 |
| 编辑 | 编辑当前菜单 |
| 删除 | 删除当前菜单 |
