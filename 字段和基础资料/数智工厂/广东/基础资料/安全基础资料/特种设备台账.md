## 二、页面概览

### 2.1 页面定位

**特种设备台账**是安全管理模块下现场管理的核心功能页面，用于管理和维护企业所有特种设备的详细信息，包括注册登记、检定检验、维护保养等全生命周期管理。

### 2.2 页面布局

页面采用左侧树形分类 + 右侧内容区域的经典布局模式：

| 区域 | 位置 | 功能描述 |
|------|------|----------|
| 顶部导航 | 页面顶部 | 系统菜单导航、搜索框、用户信息 |
| 左侧树 | 页面左侧 | 特种设备类型分类树 |
| 筛选区 | 右侧上方 | 多条件组合筛选 |
| 操作栏 | 筛选区下方 | 新建、打印标签、导入导出等操作按钮 |
| 数据表格 | 操作栏下方 | 特种设备列表展示 |
| 分页区 | 页面底部 | 数据分页控制 |

## 三、筛选区域

### 3.1 筛选字段清单

| 序号 | 字段名称 | 控件类型 | 必填 | 说明 |
|------|----------|----------|------|------|
| 1 | 关键字 | 文本框 | 否 | 支持模糊搜索 |
| 2 | 使用位置 | 文本框 | 否 | 设备安装位置 |
| 3 | 使用部门 | 文本框 | 否 | 使用该设备的部门 |
| 4 | 使用负责人 | 下拉框 | 否 | 设备责任人 |
| 5 | 启用日期 | 日期范围 | 否 | 格式：YYYY-MM-DD |
| 6 | 使用状态 | 下拉框 | 否 | 正常/异常等状态 |
| 7 | 点巡检状态 | 下拉框 | 否 | 待检查/已检查等 |
| 8 | 点巡检配置 | 下拉框 | 否 | 关联的巡检计划 |

### 3.2 操作按钮

- **搜索**：根据条件筛选数据
- **重置**：清空所有筛选条件

### 3.3 数据来源说明

数据来源：资产档案或设备台账，辅助分类【特种设备】

## 四、树形分类

### 4.1 特种设备类型结构

```
特种设备
├── 电瓶叉车
├── 柴油叉车
├── 蒸汽管道
├── 天然气管道
├── 压力容器
└── 电梯
```

### 4.2 分类说明

| 类型 | 说明 |
|------|------|
| 电瓶叉车 | 电动叉车，适用于室内作业 |
| 柴油叉车 | 燃油叉车，适用于室外作业 |
| 蒸汽管道 | 输送蒸汽的管道系统 |
| 天然气管道 | 输送天然气的管道系统 |
| 压力容器 | 承受压力的密闭容器 |
| 电梯 | 垂直升降设备 |
