# 送检报告配置

## 页面概述

- **功能说明**：用于配置送检报告标准，定义原料入库时的送检报告规则
- **页面URL**：`/warehouse-manage/base-info/ylrk/report-standard-config`
- **所属模块**：仓储管理 > 基础信息 > 原料入库配置

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 新增检验标准 | 新增一条检验标准 |
| 2 | 编辑 | 编辑检验标准 |
| 3 | 关闭 | 关闭操作 |
| 4 | 保存 | 保存配置 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 送检报告项目 | 文本 | 送检报告项目名称 |
| 2 | 送检方式 | 文本 | 送检方式（免检/按原厂报告/按比例/批固定数等） |
| 3 | 应送检数 | 数字 | 应送检数量/比例 |
| 4 | 标准描述 | 文本 | 标准描述 |
| 5 | 条码 | 文本 | 物料条码（多个以逗号分隔） |
| 6 | 物料名称 | 文本 | 物料名称（多个以逗号分隔） |
| 7 | 是否推送 | 文本 | 是否推送（是/否） |
| 8 | 备注 | 文本 | 备注信息 |

## 交互说明

1. 共9条送检报告配置记录
2. 可通过"新增检验标准"按钮新增送检报告配置

共9条送检报告配置记录。由于物料名称和条码字段内容较长，完整数据已导出保存至CSV文件。
