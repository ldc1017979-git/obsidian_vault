# 成品仓库管理

## 页面概述

- **功能说明**：用于管理成品仓库的基础信息，包括仓库名称、编码、库位等
- **页面URL**：`/warehouse-manage/base-info/product-warehouse`
- **所属模块**：仓储管理 > 基础信息

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 库存工厂编码 | 文本框 | 输入工厂编码搜索 |
| 2 | 库存库位地点 | 文本框 | 输入库位地点搜索 |
| 3 | 库存工厂名称 | 文本框 | 输入工厂名称搜索 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新增仓库 | 新增一个成品仓库 |
| 4 | 编辑 | 编辑仓库信息 |
| 5 | 删除 | 删除仓库 |
