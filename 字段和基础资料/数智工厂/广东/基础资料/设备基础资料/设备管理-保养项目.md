## 1. 页面概览

保养项目页面是设备管理模块下预防性维保功能的核心配置页面，用于管理设备保养的标准项目和明细信息。

### 页面URL
- **地址**: `https://gdmms.y1b.cn:8424/#/device-manage/device/maintain/maintenance/project`

### 页面结构
- **顶部导航**: 系统Logo、用户信息、快捷操作按钮
- **左侧菜单**: 设备管理模块下的各功能入口
- **主内容区**: 保养项目列表、搜索筛选、操作按钮

## 2. 主页面功能

### 2.1 页面截图

![保养项目主页面](截图/设备管理-保养项目-主页面.png)

### 2.2 功能说明

| 功能区域 | 说明 |
|---------|------|
| **搜索栏** | 支持关键字模糊搜索，包含搜索和重置按钮 |
| **新增按钮** | 点击可打开新增保养项目弹窗 |
| **密度设置** | 支持宽松、默认、紧凑三种显示密度 |
| **列表表头** | 包含保养内容组、资产类型、保养部位、保养项目、保养要求/标准、保养方法、保养工具/物品、设备状态、备注、操作 |
| **分页控件** | 支持分页浏览，包含上一页、下一页、跳转页码功能 |

### 2.3 搜索功能

- **关键字输入框**: 支持对保养项目相关信息进行模糊搜索
- **搜索按钮**: 触发搜索操作
- **重置按钮**: 清空搜索条件，恢复默认显示

## 4. 明细添加功能

### 4.1 明细截图

![添加明细](截图/设备管理-保养项目-新增弹窗-添加明细.png)

### 4.2 明细字段说明

| 字段名称 | 必填标识 | 说明 |
|---------|---------|------|
| **保养部位** | * | 设备保养的具体部位 |
| **保养项目** | * | 具体的保养项目名称 |
| **保养要求/标准** | * | 保养的执行标准和要求 |
| **保养方法** | - | 保养的具体操作方法 |
| **保养工具/物品** | - | 所需的工具和物品 |
| **设备状态** | - | 保养时设备应处的状态（默认静态） |
| **备注** | - | 额外说明信息 |
| **删除** | - | 删除当前明细行 |

### 4.3 明细操作

- **添加明细**: 点击"添加明细"按钮可增加一行空白明细
- **删除明细**: 点击每行的"删除"按钮可移除该行明细
