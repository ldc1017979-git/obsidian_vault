## 账号管理概述

**页面路径**: `设置 > 账号管理`

账号管理模块是数智工厂系统的用户管理核心，负责管理系统中的用户账号、角色分配和权限配置。该模块包含以下核心功能：

| 功能项 | 描述 |
| :--- | :--- |
| **账号列表** | 展示所有用户账号，支持搜索、筛选和排序 |
| **新建账号** | 创建新的用户账号并配置角色权限 |
| **编辑账号** | 修改账号信息和权限配置 |
| **批量导入** | 批量导入用户账号 |
| **导出数据** | 导出账号列表数据 |
| **IP管理** | 管理系统访问的IP白名单 |

## 账号列表管理

**功能描述**: 管理系统中所有用户账号的列表，支持关键字搜索、部门筛选和岗位筛选。

**页面截图**:

![账号管理主页面](截图/设置-账号管理-主页面.png)

**搜索条件**:

- 部门筛选
- 岗位筛选（下拉选择）

| 配置项 | 类型 | 必填 | 说明 |

| **姓名** | 下拉选择 | 是 | 用户姓名（只读） |
| **手机号/账号** | 文本 | 是 | 登录账号/手机号 |
| **密码** | 密码文本 | 否 | 用户密码 |
| **部门** | 文本 | 是 | 用户所属部门（只读） |
| **部门负责人** | 单选 | 否 | 是否为部门负责人 |
| **岗位** | 下拉选择 | 是 | 用户岗位（只读） |
