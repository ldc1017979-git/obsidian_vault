## 一、模块概述

**员工岗位管理**是数智工厂系统中人事管理模块的核心功能，用于管理企业内部所有岗位信息，包括岗位名称、所属部门、任职条件、岗位职责等详细信息。

**模块路径**：人事行政 → 人事管理 → 员工岗位管理

**页面URL**：`https://gdmms.y1b.cn:8424/#/administration-manage/index10/index107/post`

**数据总量**：共76条岗位记录

**数据更新时间**：2025年

## 四、表单字段说明

### 4.1 新增/编辑表单字段

| 字段名称 | 必填 | 类型 | 说明 |
|----------|------|------|------|
| 岗位名称 | *是 | 文本框 | 岗位的名称标识 |
| 所属部门 | *是 | 文本框 | 岗位所属部门 |
| 建议薪酬 | 否 | 文本框 | 建议薪酬范围 |
| 任职条件 | 否 | 多行文本 | 岗位任职资格要求（最多100字符） |

| 岗位职责 | 否 | 多行文本 | 岗位职责描述（最多100字符） |
| 工作地点 | 否 | 文本框 | 工作地点 |
| 工作内容 | 否 | 文本框 | 具体工作内容 |
| 岗位标配人数 | 否 | 文本框 | 标准配置人数 |
| 工作班制 | 否 | 下拉选择 | 排班制度类型 |
| 岗位作业类型 | 否 | 下拉选择 | 作业类型分类 |
| 工作班时间 | 否 | 文本框 | 天制/小时/天 |

| 按钮 | 功能 |
|------|------|
| 取消 | 关闭弹窗，不保存 |

## 五、操作功能说明

### 5.1 编辑操作

点击列表中的**编辑**按钮，弹出编辑弹窗，可修改该岗位的所有信息字段。

### 5.2 删除操作

点击列表中的**删除**按钮，可删除该岗位记录（需确认）。

### 5.3 分页功能

- 支持设置每页显示条数（默认10条/页）
- 支持上一页/下一页翻页
- 支持直接跳转到指定页码
- 共8页数据（76条记录）
