## 页面概述

**配方BOM清单**页面是生产基础信息模块下的核心功能页面，用于管理和维护产品配方的物料清单（BOM）数据。该页面提供了配方物料的增删改查功能，并支持按产品类型进行筛选。

**页面URL**: `https://gdmms.y1b.cn:8424/#/product/production-baseinfo/index156/bom-detailed-list`

**页面截图**:

![配方BOM清单主页面](截图/生产管理-生产基础信息-配方BOM清单-主页面.png)

## 操作功能

### 新增标准

点击页面顶部的**新增**按钮，弹出新增标准弹窗，用于添加新的配方BOM记录。

**弹窗包含字段**:

| 分类 | 字段名称 | 必填 | 说明 |
|------|----------|------|------|
| 物料信息 | 条码 | 是 | 物料的唯一标识条码 |
| 物料信息 | 名称 | 是 | 物料名称 |
| 物料信息 | 规格型号 | 否 | 物料规格型号 |
| 物料信息 | 分类 | 否 | 物料分类 |
| 物料信息 | 计量单位 | 否 | 计量单位 |
| 物料信息 | 品牌 | 否 | 品牌信息 |
| 物料信息 | 保留小数 | 否 | 数值保留小数位数 |
| 配方信息 | 单位 | 是 | 称重单位 |
| 配方信息 | 保留小数 | 是 | 称重数值保留小数位数 |
| 配方信息 | 标准值 | 是 | 配方标准用量值 |
| 配方信息 | 标准范围 | 是 | 配方用量允许范围 |
| 配方信息 | 单据类型 | 否 | 关联单据类型（盛料桶记录表/复合香精记录） |
| 配方信息 | 单据序号 | 否 | 单据编号 |

**截图**:

![新增标准弹窗](截图/生产管理-生产基础信息-配方BOM清单-新增标准弹窗.png)

### 编辑标准

点击表格中每条记录的**编辑**按钮，弹出编辑标准弹窗，用于修改已有配方BOM记录。

**弹窗包含字段**: 与新增标准弹窗相同，预填充原有数据。

**截图**:

![编辑标准弹窗](截图/生产管理-生产基础信息-配方BOM清单-编辑标准弹窗.png)

### 删除标准

点击表格中每条记录的**删除**按钮，可删除对应的配方BOM记录。

## 数据表格字段说明

| 序号 | 字段名称 | 说明 |
|------|----------|------|
| 1 | 条码 | 物料的唯一标识条码 |
| 2 | 物料编号 | 物料内部编号 |
| 3 | 名称 | 物料名称 |
| 4 | 分类 | 物料分类（如：配方） |
| 5 | 计量单位 | 物料计量单位（如：袋、kg、g） |
| 6 | 保留小数 | 数值保留小数位数 |
| 7 | 标准值 | 配方标准用量 |
| 8 | 标准范围 | 配方用量允许范围 |
| 9 | 称重单位 | 称重时使用的单位 |
| 10 | 称重保留小数 | 称重数值保留小数位数 |
| 11 | 单据类型 | 关联的单据类型 |
| 12 | 单据序号 | 单据编号 |
| 13 | 操作 | 编辑、删除按钮 |
