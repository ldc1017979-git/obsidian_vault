# 访客配置

## 页面概述

- 功能说明：安全管理-教育培训-外来人员管理-访客配置，用于配置访客来访协议和安全告知内容
- 页面URL：`https://gdmms.y1b.cn:8424/#/safety-manage/edu/safety-foreign-personnel/visitor-reservation`

## 页面截图

![访客配置主页面](../安全管理截图/访客配置_主页面.png)

## 列表字段

| 序号 | 字段名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 访客类型 | 访客分类类型 |
| 2 | 来访协议标题 | 安全告知协议标题 |
| 3 | 是否上传告知视频 | 是否配置了安全告知视频 |
| 4 | 是否配置答辩 | 是否配置了安全知识答辩 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 新增协议 | 新建来访安全协议 |
| 2 | 详情 | 查看协议详情 |
| 3 | 编辑 | 编辑协议内容 |
