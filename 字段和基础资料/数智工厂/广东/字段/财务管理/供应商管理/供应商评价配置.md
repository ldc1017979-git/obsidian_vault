# 供应商评价配置模块

## 一、模块概述

供应商评价配置模块用于配置和管理供应商评价的指标体系和评分标准，确保供应商评价的标准化和规范化。

## 二、功能定位

| 功能维度 | 说明 |
| :--- | :--- |
| **核心功能** | 供应商评价指标体系配置 |
| **数据来源** | 企业内部评价标准 |
| **目标用户** | 采购管理人员、系统管理员 |
| **输出形式** | 评价指标配置表 |

## 三、页面结构

### 3.1 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│                供应商评价配置页面                           │
├─────────────────────────────────────────────────────────────┤
│  【功能菜单】                                                │
│  ├─ 评价指标管理                                            │
│  ├─ 评分标准配置                                            │
│  ├─ 权重设置                                                │
│  └─ 评价模板管理                                            │
├─────────────────────────────────────────────────────────────┤
│  【主内容区域】                                              │
│  ├─ 指标列表                                               │
```

### 3.2 主要字段

| 字段编号 | 字段名称 | 类型 | 描述 |
| :--- | :--- | :--- | :--- |
| 1 | 指标编号 | 文本 | 评价指标编号 |
| 2 | 指标名称 | 文本 | 评价指标名称 |
| 3 | 指标类别 | 下拉框 | 质量/价格/服务/交期等 |
| 4 | 指标描述 | 文本 | 指标详细描述 |
| 5 | 评分标准 | 文本 | 评分规则说明 |
| 6 | 权重 | 百分比 | 指标权重 |
| 7 | 分值范围 | 文本 | 评分分值范围 |
| 8 | 指标状态 | 下拉框 | 启用/禁用 |
| 9 | 创建人 | 文本 | 创建人员 |
| 10 | 创建日期 | 日期 | 创建日期 |

## 四、交互操作

### 4.1 指标管理

1. **查看指标列表**：查看所有评价指标
2. **新增指标**：添加新的评价指标
3. **编辑指标**：修改现有指标信息
4. **删除指标**：删除不需要的指标

### 4.2 评分标准配置

1. **设置评分规则**：为每个指标设置评分标准
2. **配置分值范围**：设置评分分值区间
3. **保存配置**：保存评分标准配置

### 4.3 权重设置

1. **分配权重**：为各指标分配权重
2. **调整权重**：调整指标权重比例
3. **验证权重**：确保权重总和为100%
