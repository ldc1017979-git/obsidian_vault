# 采购项目洽商记录模块

## 一、模块概述

采购项目洽商记录模块用于记录和管理采购项目的洽商过程，确保采购洽谈的规范性和可追溯性。

## 二、功能定位

| 功能维度 | 说明 |
| :--- | :--- |
| **核心功能** | 采购洽商过程记录管理 |
| **数据来源** | 采购洽谈会议 |
| **目标用户** | 采购人员、审计人员 |
| **输出形式** | 洽商记录报表 |

## 四、交互操作

### 4.1 查询操作

1. **选择日期范围**：选择洽商日期范围
2. **输入项目名称**：搜索目标项目
3. **选择供应商**：筛选供应商
4. **点击查询**：获取洽商记录列表

### 4.2 洽商详情

1. **点击洽商编号**：查看洽商详细记录
2. **查看内容**：查看洽商具体内容
3. **查看结果**：查看洽商达成的共识

### 4.3 新增洽商记录

1. **填写基本信息**：项目名称、供应商、日期等
2. **填写参会人员**：我方和对方参会人员
3. **填写洽商内容**：记录洽商过程和结果
4. **保存提交**：保存洽商记录
