# 供应商绩效考核模块

## 一、模块概述

供应商绩效考核模块用于定期对供应商的绩效进行评估和考核，帮助企业了解供应商表现，优化供应商管理。

## 二、功能定位

| 功能维度 | 说明 |
| :--- | :--- |
| **核心功能** | 供应商绩效评估与考核 |
| **数据来源** | 采购记录、质量反馈、交货记录 |
| **目标用户** | 采购人员、供应商管理人员 |
| **输出形式** | 绩效考核报表、评估报告 |

### 3.2 主要字段

| 字段编号 | 字段名称 | 类型 | 描述 |
| :--- | :--- | :--- | :--- |
| 1 | 考核编号 | 文本 | 考核记录编号 |
| 2 | 考核周期 | 下拉框 | 季度/年度考核 |
| 3 | 考核年份 | 数值 | 考核年份 |
| 4 | 供应商 | 下拉框 | 供应商名称 |
| 5 | 考核指标 | 文本 | 考核指标名称 |
| 6 | 指标权重 | 百分比 | 指标权重 |
| 7 | 指标得分 | 数值 | 指标得分 |
| 8 | 综合得分 | 数值 | 综合考核得分 |
| 9 | 考核等级 | 文本 | A/B/C/D等级 |
| 10 | 考核评语 | 文本 | 考核评价意见 |
| 11 | 考核人 | 文本 | 考核人员 |
| 12 | 考核日期 | 日期 | 考核日期 |

## 四、交互操作

### 4.1 查询操作

1. **选择考核周期**：选择考核周期
2. **选择供应商**：筛选目标供应商
3. **选择考核状态**：筛选考核状态
4. **点击查询**：获取考核记录列表

### 4.2 考核详情

1. **点击考核编号**：查看考核详细记录
2. **查看指标评分**：查看各项指标得分
3. **查看结果**：查看考核等级和评语

### 4.3 新增考核

1. **选择供应商**：选择要考核的供应商
2. **填写考核指标**：录入各项指标得分
3. **计算综合得分**：系统自动计算综合得分
4. **填写评语**：添加考核评语
5. **保存提交**：保存考核记录
