# 仓储SRM模块

## 一、模块概述

仓储SRM（Supplier Relationship Management）模块用于管理企业与供应商之间的仓储相关业务，实现仓储管理的信息化和规范化。

## 二、功能定位

| 功能维度 | 说明 |
| :--- | :--- |
| **核心功能** | 仓储供应商关系管理 |
| **数据来源** | 仓储系统、供应商系统 |
| **目标用户** | 仓储管理人员、采购人员 |
| **输出形式** | 仓储报表、供应商评估报告 |

## 四、交互操作

### 4.1 库存查询

1. **选择仓库**：选择目标仓库
2. **输入物料信息**：物料编码或名称
3. **点击查询**：获取库存信息

### 4.2 入库操作

1. **填写入库信息**：物料、数量、供应商
2. **确认入库**：完成入库操作

### 4.3 出库操作

1. **填写出库信息**：物料、数量、用途
2. **确认出库**：完成出库操作

### 4.4 供应商协同

1. **查看供应商**：查看供应商信息
2. **发送需求**：向供应商发送采购需求
3. **确认到货**：确认供应商到货
