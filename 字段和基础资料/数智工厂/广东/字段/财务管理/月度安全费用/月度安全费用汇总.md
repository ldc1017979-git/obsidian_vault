# 月度安全费用汇总模块

## 一、模块概述

月度安全费用汇总模块用于汇总各部门的月度安全费用支出情况，形成企业整体的安全费用报表。

## 二、功能定位

| 功能维度 | 说明 |
| :--- | :--- |
| **核心功能** | 月度安全费用汇总统计 |
| **数据来源** | 各部门安全费用数据 |
| **目标用户** | 安全管理人员、财务人员 |
| **输出形式** | 安全费用汇总报表 |

## 三、页面结构

### 3.1 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│                月度安全费用汇总页面                         │
├─────────────────────────────────────────────────────────────┤
│  【筛选区域】                                                │
│  ├─ 年月选择                                                │
│  └─ 统计维度选择                                            │
├─────────────────────────────────────────────────────────────┤
│  【汇总区域】                                                │
│  ├─ 费用汇总卡片                                           │
│  ├─ 部门费用列表                                           │
│  └─ 费用类别汇总                                           │
├─────────────────────────────────────────────────────────────┤
│  【图表展示】                                                │
│  ├─ 部门费用对比图                                         │
│  └─ 费用类别分布图                                         │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 主要字段

| 字段编号 | 字段名称 | 类型 | 描述 |
| :--- | :--- | :--- | :--- |
| 1 | 统计年月 | 日期选择 | 统计的年月 |
| 2 | 部门名称 | 文本 | 部门名称 |
| 3 | 总预算 | 数值 | 安全费用总预算 |
| 4 | 总支出 | 数值 | 安全费用总支出 |
| 5 | 支出比例 | 百分比 | 支出占预算比例 |
| 6 | 部门支出 | 数值 | 各部门支出金额 |
| 7 | 类别支出 | 数值 | 各类别支出金额 |
| 8 | 同比变化 | 百分比 | 同比变化比例 |

## 四、交互操作

### 4.1 查询操作

1. **选择年月**：选择统计月份
2. **选择统计维度**：选择汇总维度
3. **点击查询**：获取汇总数据

### 4.2 明细查看

1. **点击部门**：查看该部门详细费用
2. **点击类别**：查看该类别详细费用
