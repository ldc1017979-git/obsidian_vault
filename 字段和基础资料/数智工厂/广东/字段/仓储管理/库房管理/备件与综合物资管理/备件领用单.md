# 备件领用单

## 页面概述

- **功能说明**：用于管理备件领用业务，记录有价备件出库领用的过程
- **页面URL**：`/warehouse-manage/depot-manage/integrated-manage/spare-part-receive`
- **所属模块**：仓储管理 > 库房管理 > 备件与综合物资管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单号 | 文本框 | 输入单据编号 |
| 2 | 出库仓库 | 下拉框 | 可选择仓库 |
| 3 | 商品名称 | 文本框 | 输入商品名称 |
| 4 | 单据状态 | 下拉框 | 可选择状态 |
| 5 | 创建日期 | 日期范围选择器 | 开始日期-结束日期 |
| 6 | 领用人 | 下拉框 | 可选择领用人 |
| 7 | 维修类型 | 单选框 | 生产性维修/非生产性维修 |

3. 点击"详情"按钮可查看领用单详情
4. 支持打印和数据导出功能
