# 到货计划跟进

## 页面概述

- **功能说明**：用于管理到货计划跟进，记录和追踪原料到货计划的执行情况
- **页面URL**：`/warehouse-manage/depot-manage/check/delivery-plan`
- **所属模块**：仓储管理 > 库房管理 > 原材料管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 物料名称 | 文本框 | 输入物料名称搜索 |
| 3 | 物料条码 | 文本框 | 输入物料条码搜索 |
| 4 | 计划到货日期 | 日期范围选择器 | 开始日期-结束日期 |
| 5 | 实际到货日期 | 日期范围选择器 | 开始日期-结束日期 |
| 6 | 仓库 | 下拉框 | 可选择仓库 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新建 | 新增一条到货计划跟进记录 |
