# 危废基础资料

## 页面概述

- **功能说明**：用于管理危废基础资料，维护危险废物的基础信息
- **页面URL**：`/warehouse-manage/depot-manage/auxiliary-materials/hazardous/hazardous-waste`
- **所属模块**：仓储管理 > 库房管理 > 危废管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 名称 | 文本框 | 输入名称搜索 |
| 2 | 废物类别 | 下拉框 | 可选择废物类别 |
| 3 | 废物代码 | 文本框 | 输入废物代码搜索 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新增 | 新增一条危废基础资料 |
| 4 | 打印选中标签 | 打印选中危废的标签 |
| 5 | 编辑 | 编辑危废基础资料 |
| 6 | 删除 | 删除危废基础资料 |

## 交互说明

1. 危废基础资料用于维护危险废物的基础信息
2. 支持新增、编辑和删除危废记录
3. 记录包含废物类别、危险特性、容器信息等详细数据
