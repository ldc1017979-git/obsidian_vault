# 危废库存明细

## 页面概述

- **功能说明**：用于查看危废库存明细，展示危险废物的当前库存情况
- **页面URL**：`/warehouse-manage/depot-manage/auxiliary-materials/hazardous/inventory-details`
- **所属模块**：仓储管理 > 库房管理 > 危废管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单位内部名称 | 文本框 | 输入名称搜索 |
| 2 | 危废条码 | 文本框 | 输入危废条码搜索 |
| 3 | 废物类别 | 下拉框 | 可选择废物类别 |
| 4 | 入库日期 | 日期范围选择器 | 开始日期-结束日期 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 贮存仓库信息 | 查看贮存仓库信息 |
