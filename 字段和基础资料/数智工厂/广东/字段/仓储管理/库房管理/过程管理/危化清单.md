# 危化清单

## 页面概述

- **功能说明**：用于管理危化品清单，维护危险化学品的基础信息
- **页面URL**：`/warehouse-manage/depot-manage/auxiliary-materials/hazardous/hazard-list`
- **所属模块**：仓储管理 > 库房管理 > 危废管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 关键字 | 文本框 | 支持模糊搜索 |
| 2 | 物料名称 | 文本框 | 输入物料名称搜索 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新增危化品 | 新增一条危化品记录 |
| 4 | 详情 | 查看危化品详情 |
| 5 | 编辑 | 编辑危化品信息 |
| 6 | 删除 | 删除危化品记录 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 危化品名称 | 文本 | 危化品名称 |
| 2 | 危险性类别 | 文本 | 危险性类别 |
| 3 | 危险性说明 | 文本 | 危险性说明 |
| 4 | 防范说明 | 文本 | 防范说明 |
| 5 | 使用部门 | 文本 | 使用部门 |
| 6 | 供应商 | 文本 | 供应商名称 |
| 7 | 关联物料种数 | 数字 | 关联物料种类数量 |
| 8 | 清单备注 | 文本 | 清单备注信息 |
| 9 | 操作 | 按钮 | 详情/编辑/删除按钮 |

## 交互说明

1. 在列表页可通过筛选条件查询危化品清单
2. 点击"详情"按钮可查看危化品详情
3. 数据量（共16条）
