# 成本调整单

## 页面概述

- **功能说明**：用于管理成本调整单，调整库存物料的成本信息
- **页面URL**：`/warehouse-manage/depot-manage/auxiliary-materials/cost-adjustment`
- **所属模块**：仓储管理 > 库房管理 > 辅助材料管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 仓库 | 下拉框 | 可选择仓库 |
| 3 | 经办人 | 文本框 | 输入经办人搜索 |
| 4 | 制单人 | 文本框 | 输入制单人搜索 |
| 5 | 单据状态 | 下拉框 | 可选择单据状态 |
| 6 | 制单日期 | 日期范围选择器 | 开始日期-结束日期 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新建 | 新增一条成本调整单 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本 | 调整单的唯一编号 |
| 2 | 单据状态 | 文本 | 单据当前状态 |
| 3 | 调整日期 | 日期 | 成本调整日期 |
| 4 | 调整仓库 | 文本 | 调整仓库名称 |
| 5 | 经办人 | 文本 | 经办人 |
| 6 | 制单人 | 文本 | 创建单据的人员 |
| 7 | 制单时间 | 日期时间 | 单据创建时间 |
| 8 | 单据备注 | 文本 | 单据备注信息 |
| 9 | 操作 | 按钮 | 操作按钮 |

## 交互说明

1. 在列表页可通过筛选条件查询成本调整单
2. 当前暂无数据
