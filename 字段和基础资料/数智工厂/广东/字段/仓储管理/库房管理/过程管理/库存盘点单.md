# 库存盘点单(按汇总)

## 页面概述

- **功能说明**：用于管理库存盘点单（按汇总），按汇总方式盘点库存物料
- **页面URL**：`/warehouse-manage/depot-manage/auxiliary-materials/inventory-check`
- **所属模块**：仓储管理 > 库房管理 > 辅助材料管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 仓库 | 下拉框 | 可选择仓库 |
| 3 | 单据状态 | 下拉框 | 可选择单据状态 |
| 4 | 制单日期 | 日期范围选择器 | 开始日期-结束日期 |

| 序号 | 按钮名称 | 功能描述 |

## 交互说明

1. 库存盘点单用于记录库存盘点操作
2. 点击"详情"按钮可查看盘点的详细信息，包括盘点明细和单据日志
3. 支持按盘点日期、仓库等条件筛选
