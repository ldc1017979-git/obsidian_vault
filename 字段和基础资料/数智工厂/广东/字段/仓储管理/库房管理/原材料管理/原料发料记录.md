# 原料发料记录

## 页面概述

- **功能说明**：用于记录原料发料情况，追踪原料从仓库到产线的发放过程
- **页面URL**：`/warehouse-manage/depot-manage/material-manage/contents-give-out`
- **所属模块**：仓储管理 > 库房管理 > 原材料管理

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 商品名称 | 文本框 | 输入商品名称搜索 |
| 3 | 移出仓库 | 下拉框 | 可选择移出仓库 |

## 交互说明

1. 在列表页可通过筛选条件查询原料发料记录
2. 点击"详情"按钮可查看发料记录详情
3. 详情页包含基本信息（三组）、单据日志、需求商品明细、发料商品明细四个部分
4. 数据量较大（共4003条），支持分页浏览
