# 原料库存日报汇总

## 页面概述

- **功能说明**：用于汇总原料库存日报数据，展示各物料的库存变动和余额情况
- **页面URL**：`/warehouse-manage/depot-manage/material-manage/raw-daily-summary`
- **所属模块**：仓储管理 > 库房管理 > 原材料管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 本期末日期 | 日期选择器 | 选择统计期末日期 |
| 2 | 物料条码 | 文本框 | 输入物料条码搜索 |
| 3 | 物料名称 | 文本框 | 输入物料名称搜索 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 导出 | 导出日报数据 |
| 4 | 日报配置 | 配置日报参数 |

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |

| 5 | 本期入库 | 数字 | 本期入库数量 |
| 6 | 本期出库 | 数字 | 本期出库数量 |

| 11 | 可生产天数 | 数字 | 可生产天数 |
| 12 | 单价 | 数字 | 物料单价 |
| 13 | 库存金额 | 数字 | 库存金额 |
| 14 | 操作 | 按钮 | 操作按钮 |

## 交互说明

1. 在列表页可通过筛选条件查询原料库存日报汇总
2. 可通过"导出"按钮导出日报数据
3. 可通过"日报配置"按钮配置日报参数
4. 当前暂无数据
