# 原料库存日报

## 页面概述

- **功能说明**：用于记录原料库存日报数据，按仓库统计物料库存情况
- **页面URL**：`/warehouse-manage/depot-manage/material-manage/warehouse-raw-inventory`
- **所属模块**：仓储管理 > 库房管理 > 原材料管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 关键字 | 文本框 | 支持模糊搜索 |
| 2 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 3 | 本期未日期 | 日期选择器 | 选择统计期末日期 |
| 4 | 仓库 | 下拉框 | 可选择仓库 |
| 5 | 单据状态 | 下拉框 | 可选择单据状态 |
| 6 | 创建时间 | 日期范围选择器 | 开始日期-结束日期 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新建 | 新建一条原料库存日报 |

## 交互说明

1. 在列表页可通过筛选条件查询原料库存日报
2. 点击"详情"按钮可查看日报详情
3. 详情页包含基本信息、库存明细、单据日志三个部分
