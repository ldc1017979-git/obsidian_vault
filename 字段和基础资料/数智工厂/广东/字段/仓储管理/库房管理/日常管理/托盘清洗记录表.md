# 托盘清洗记录表

## 页面概述

- **功能说明**：用于管理托盘清洗记录，记录托盘的清洗情况
- **页面URL**：`/warehouse-manage/depot-manage/daily/pallet_cleaning_record`
- **所属模块**：仓储管理 > 库房管理 > 日常管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 清洗日期 | 日期范围选择器 | 开始日期-结束日期 |
| 3 | 班次 | 下拉框 | 可选择班次 |
| 4 | 清洗人员 | 文本框 | 输入清洗人员搜索 |
| 5 | 记录人 | 文本框 | 输入记录人搜索 |
| 6 | 状态 | 下拉框 | 可选择单据状态 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新增 | 新增一条托盘清洗记录 |
| 4 | 报告导出 | 导出清洗记录报告 |
| 5 | 作废 | 作废记录 |
| 6 | 删除 | 删除记录 |
| 7 | 撤回 | 撤回记录 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本 | 记录的唯一编号 |
| 2 | 单据状态 | 文本 | 单据当前状态 |
| 3 | 清洗日期 | 日期 | 清洗日期 |
| 4 | 班次 | 文本 | 班次 |
| 5 | 清洗数量 | 数字 | 清洗数量 |
| 6 | 清洗人员 | 文本 | 清洗人员 |
| 7 | 记录人 | 文本 | 记录人 |
| 8 | 备注 | 文本 | 备注信息 |
| 9 | 操作 | 按钮 | 作废/删除/撤回按钮 |

## 交互说明

1. 在列表页可通过筛选条件查询托盘清洗记录
2. 当前暂无数据
