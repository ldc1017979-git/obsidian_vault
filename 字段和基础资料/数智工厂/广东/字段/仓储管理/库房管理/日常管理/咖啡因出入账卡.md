# 咖啡因出入账卡

## 页面概述

- **功能说明**：用于管理咖啡因出入账卡，记录咖啡因的进出库账目
- **页面URL**：`/warehouse-manage/depot-manage/daily/caffeine-account-card`
- **所属模块**：仓储管理 > 库房管理 > 日常管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 日期 | 日期选择器 | 选择日期 |
| 3 | 进货批次 | 文本框 | 输入进货批次搜索 |
| 4 | 出货批次 | 文本框 | 输入出货批次搜索 |
| 5 | 记录人 | 文本框 | 输入记录人搜索 |
| 6 | 领用人 | 文本框 | 输入领用人搜索 |
| 7 | 单据状态 | 下拉框 | 可选择单据状态 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新建 | 新增一条咖啡因出入账卡 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本 | 账卡的唯一编号 |
| 2 | 单据状态 | 文本 | 单据当前状态 |
| 3 | 记录日期 | 日期 | 记录日期 |
| 4 | 进货批次 | 文本 | 进货批次号 |
| 5 | 进货数量 | 数字 | 进货数量 |
| 6 | 出货批次 | 文本 | 出货批次号 |
| 7 | 出货数量 | 数字 | 出货数量 |
| 8 | 库存数量 | 数字 | 库存数量 |
| 9 | 安全检查 | 文本 | 安全检查结果 |
| 10 | 记录人 | 文本 | 记录人 |
| 11 | 领用人 | 文本 | 领用人 |
| 12 | 制单人 | 文本 | 创建单据的人员 |
| 13 | 创建时间 | 日期时间 | 单据创建时间 |
| 14 | 操作 | 按钮 | 操作按钮 |

## 交互说明

1. 咖啡因出入账卡用于记录咖啡因的进货和出货情况
2. 支持按记录日期等条件筛选
3. 记录包含进货批次、出货批次和库存数量等关键信息
