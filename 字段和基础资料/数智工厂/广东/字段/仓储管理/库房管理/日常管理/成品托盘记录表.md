# 成品托盘记录表

## 页面概述

- **功能说明**：用于管理成品托盘记录，记录成品托盘的出入情况
- **页面URL**：`/warehouse-manage/depot-manage/daily/tray-record`
- **所属模块**：仓储管理 > 库房管理 > 日常管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 日期 | 日期选择器 | 选择日期 |
| 3 | 车间 | 下拉框 | 可选择车间 |
| 4 | 单据状态 | 下拉框 | 可选择单据状态 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新增 | 新增一条托盘记录 |
| 4 | 数据导出 | 导出托盘数据 |
| 5 | 详情 | 查看记录详情 |

## 交互说明

1. 成品托盘记录表用于记录成品托盘的使用情况
2. 点击"详情"按钮可查看托盘记录的详细信息，包括基本信息和单据日志
3. 支持按记录日期等条件筛选
