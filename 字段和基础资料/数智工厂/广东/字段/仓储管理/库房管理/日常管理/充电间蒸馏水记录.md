# 充电间蒸馏水记录

## 页面概述

- **功能说明**：用于管理充电间蒸馏水记录，记录蒸馏水的使用情况
- **页面URL**：`/warehouse-manage/depot-manage/daily/distilled_water_record`
- **所属模块**：仓储管理 > 库房管理 > 日常管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 日期 | 日期选择器 | 选择日期 |
| 3 | 经办人 | 文本框 | 输入经办人搜索 |
| 4 | 状态 | 下拉框 | 可选择单据状态 |

| :--- | :--- | :--- |

| 4 | 报告导出 | 导出记录报告 |
| 5 | 作废 | 作废记录 |
| 6 | 删除 | 删除记录 |
| 7 | 撤回 | 撤回记录 |

| 9 | 编辑 | 编辑记录 |
| 10 | 确认提交 | 确认提交记录 |

## 交互说明

1. 充电间蒸馏水记录用于记录充电间蒸馏水的使用情况
2. 点击"详情"按钮可查看记录的详细信息，包括基本字段和单据日志
3. 支持编辑、删除、作废、撤回和确认提交等操作
