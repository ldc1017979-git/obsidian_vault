# 补码申请单

## 页面概述

- **功能说明**：用于管理补码申请，记录产品补码申请信息
- **页面URL**：`/warehouse-manage/depot-manage/daily/code-apply`
- **所属模块**：仓储管理 > 库房管理 > 日常管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 产品名称 | 文本框 | 输入产品名称搜索 |
| 3 | 产品类型 | 下拉框 | 可选择产品类型 |
| 4 | 补码日期 | 日期范围选择器 | 开始日期-结束日期 |
| 5 | 补码类型 | 下拉框 | 可选择补码类型 |
| 6 | 仓管员 | 文本框 | 输入仓管员搜索 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 新增 | 新增一条补码申请 |
| 4 | 详情 | 查看申请详情 |
| 5 | 导出报告 | 导出补码报告 |

## 交互说明

1. 补码申请单用于申请补打条码
2. 点击"详情"按钮可查看补码申请的详细信息，包括补码原因、补码数量和单据日志
3. 支持按申请日期等条件筛选
