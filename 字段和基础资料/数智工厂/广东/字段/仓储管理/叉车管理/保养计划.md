# 保养计划

## 页面概述

- **功能说明**：用于管理叉车保养计划，制定叉车的定期保养计划
- **页面URL**：`/warehouse-manage/forklift-manage/storage-others/maintain/plan`
- **所属模块**：仓储管理 > 叉车管理 > 保养管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 关键字 | 文本框 | 支持模糊搜索 |
| 2 | 资产类型 | 下拉框 | 可选择资产类型 |
| 3 | 使用位置 | 下拉框 | 可选择使用位置 |
| 4 | 临期任务 | 下拉框 | 可选择临期任务 |
| 5 | 使用部门 | 下拉框 | 可选择使用部门 |
| 6 | 状态 | 下拉框 | 可选择计划状态 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 搜索 | 按筛选条件查询数据 |
| 2 | 重置 | 清空所有筛选条件 |
| 3 | 展开 | 展开更多筛选条件 |
| 4 | 新建 | 新增一条保养计划 |
| 5 | 关闭 | 关闭操作 |

## 交互说明

1. 保养计划列表展示所有叉车的保养计划安排
2. 支持按叉车资产、计划执行时间等条件筛选
3. 点击操作按钮可查看或执行保养计划
