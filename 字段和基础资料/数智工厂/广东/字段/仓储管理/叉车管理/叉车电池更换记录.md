# 叉车电池更换记录

## 页面概述

- **功能说明**：用于管理叉车电池更换记录，记录叉车电池的上下线情况
- **页面URL**：`/warehouse-manage/forklift-manage/battery-replace-record`
- **所属模块**：仓储管理 > 叉车管理

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 单据编号 | 文本框 | 输入单据编号搜索 |
| 2 | 电瓶唯一码 | 文本框 | 输入电瓶唯一码搜索 |
| 3 | 叉车车牌 | 文本框 | 输入叉车车牌搜索 |
| 4 | 状态 | 下拉框 | 可选择状态 |
| 5 | 上线日期 | 日期范围选择器 | 开始日期-结束日期 |
| 6 | 下线日期 | 日期范围选择器 | 开始日期-结束日期 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 电瓶上线 | 电瓶上线操作 |
| 4 | 电瓶配置 | 配置电瓶信息 |
| 5 | 关闭 | 关闭操作 |

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |

## 交互说明

1. 电池更换记录展示所有叉车电池的上下线记录
2. 支持按叉车资产、电瓶唯一码等条件筛选
3. 记录包含电瓶上线和下线的完整信息
