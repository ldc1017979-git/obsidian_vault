# 包材使用情况报表

## 页面概述

- **功能说明**：用于查看包材使用情况报表，统计包材的领用和退库情况
- **页面URL**：`/warehouse-manage/forms/packing-materials`
- **所属模块**：仓储管理 > 报表

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 日期区间 | 日期范围选择器 | 开始日期-结束日期 |
| 2 | 原料仓库 | 下拉框 | 可选择仓库 |
| 3 | 货品条码 | 文本框 | 输入货品条码搜索 |
| 4 | 货品名称 | 文本框 | 输入货品名称搜索 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 导出 | 导出报表数据 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 物料大类 | 文本 | 物料大类 |
| 2 | 条码 | 文本 | 物料条码 |
| 3 | 名称/产品名称 | 文本 | 名称或产品名称 |
| 4 | 产品类型 | 文本 | 产品类型 |
| 5 | 供应商 | 文本 | 供应商名称 |
| 6 | 厂商 | 文本 | 厂商名称 |
| 7 | 单位 | 文本 | 计量单位 |
| 8 | 领用数量 | 数字 | 领用数量 |
| 9 | 退库量 | 数字 | 退库数量 |
| 10 | 退库原因 | 文本 | 退库原因 |
| 11 | 退库率 | 数字 | 退库率 |
| 12 | 操作 | 按钮 | 操作按钮 |

## 交互说明

1. 报表展示包材的领用和退库情况
2. 支持按时间范围、产品类型等条件筛选
3. 可查看退库率和退库原因等质量指标
