# 原料期初期末库存查询

## 页面概述

- **功能说明**：用于查询原料期初期末库存，按期统计原料的库存变动情况
- **页面URL**：`/warehouse-manage/forms/raw-stock-report`
- **所属模块**：仓储管理 > 报表

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 期初期末日期 | 日期范围选择器 | 选择统计期 |
| 2 | 仓库类型 | 下拉框 | 可选择仓库类型 |
| 3 | 仓库 | 下拉框 | 可选择仓库 |
| 4 | 物料条码 | 文本框 | 输入物料条码搜索 |
| 5 | 物料送检类型 | 下拉框 | 可选择送检类型 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 报表配置 | 配置报表参数 |
| 4 | 导出 | 导出报表数据 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 物料号 | 文本 | 物料编号 |
| 2 | 品名 | 文本 | 物料名称 |
| 3 | 单位 | 文本 | 计量单位 |
| 4 | 上期库存 | 数字 | 上期库存数量 |
| 5 | 本期入库 | 数字 | 本期入库数量 |
| 6 | 本期出库 | 数字 | 本期出库数量 |
| 7 | 本期末库存 | 数字 | 本期末库存数量 |
| 8 | 可生产天数 | 数字 | 可生产天数 |
| 9 | 每天生产量(箱) | 数字 | 每天生产量 |
| 10 | 可生产万罐量 | 数字 | 可生产万罐量 |
| 11 | 实时库存 | 数字 | 实时库存数量 |
| 12 | 操作 | 按钮 | 操作按钮 |

## 交互说明

1. 报表展示原料的期初期末库存数据，包括入库、出库和期末库存
2. 支持按时间范围、原料类型等条件筛选
3. 可查看可生产天数和万罐量等衍生指标
