# 备件采购与使用月报

## 页面概述

- **功能说明**：用于查看备件采购与使用月报，按月统计备件的采购入库和领用出库情况
- **页面URL**：`/warehouse-manage/forms/spare-parts-usage`
- **所属模块**：仓储管理 > 报表

## 筛选条件

| 序号 | 字段名称 | 控件类型 | 备注 |
| :--- | :--- | :--- | :--- |
| 1 | 年份区间 | 年份选择器 | 选择起始年份 |
| 2 | 至 | 年份选择器 | 选择结束年份 |
| 3 | 原料仓库 | 下拉框 | 可选择仓库 |
| 4 | 货品条码 | 文本框 | 输入货品条码搜索 |
| 5 | 货品名称 | 文本框 | 输入货品名称搜索 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 重置 | 清空所有筛选条件 |
| 2 | 搜索 | 按筛选条件查询数据 |
| 3 | 数据导出 | 导出报表数据 |

## 数据列表字段

| 序号 | 字段名称 | 字段类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 备件编码/条码 | 文本 | 备件编码或条码 |
| 2 | 备件名称 | 文本 | 备件名称 |
| 3 | 型号规格 | 文本 | 型号规格 |
| 4 | 采购入库 | 数字 | 采购入库总量 |
| 5 | 总使用量 | 数字 | 总使用量 |
| 6 | 最低库存 | 数字 | 最低库存 |
| 7 | 月度数据 | - | 按月展示入库和出库数据 |
| 8 | 1月-12月 | 数字 | 每月的入库和出库数量 |
| 9 | 操作 | 按钮 | 操作按钮 |

## 交互说明

1. 报表按月展示备件的采购入库和使用量数据
2. 支持按年份、备件类型等条件筛选
3. 可查看每月的入库和出库数量趋势
