# 能耗班次统计

## 页面概述

能耗班次统计用于按班次（夜班/白班/中班）统计能源消耗情况，支持按电表、水表、蒸汽表、燃气表分类查看，展示各仪表在不同班次的读数和用量。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/device/report-forms/energy/direct-statement/shift-statistics`
- **所属模块**: 能耗/设备报表 > 能源直报报表

## 能源类型Tab

| 序号 | Tab名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 电表 | 电能消耗班次统计（默认） |
| 2 | 水表 | 水资源消耗班次统计 |
| 3 | 蒸汽表 | 蒸汽消耗班次统计 |
| 4 | 燃气表 | 燃气消耗班次统计 |

## 搜索字段

| 序号 | 字段名称 | 输入类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 能源层级类型 | 下拉选择 | 能源层级分类筛选 |
| 2 | 采集表名 | 下拉选择 | 采集表名称筛选 |

## 交互说明

1. 通过Tab切换不同能源类型
2. 支持按能源层级类型、采集表名、抄表日期、所属分组和统计用量筛选
3. 支持导出数据
4. 按夜班/白班/中班三个班次分别统计用量
