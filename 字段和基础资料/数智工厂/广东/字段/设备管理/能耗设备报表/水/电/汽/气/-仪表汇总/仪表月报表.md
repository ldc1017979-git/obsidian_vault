# 仪表月报表

## 页面概述

仪表月报表用于按月统计各仪表的能源消耗情况，支持按电表、水表、蒸汽表、燃气表分类查看，展示月度起止读数和用量汇总。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/device/report-forms/energy/direct-statement/monthly`
- **所属模块**: 能耗/设备报表 > 能源直报报表

## 能源类型Tab

| 序号 | Tab名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 电表 | 电能月度统计（默认） |
| 2 | 水表 | 水资源月度统计 |
| 3 | 蒸汽表 | 蒸汽月度统计 |
| 4 | 燃气 | 燃气月度统计 |

## 搜索字段

| 序号 | 字段名称 | 输入类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 采集表名 | 下拉选择 | 采集表名称筛选 |
| 2 | 月份 | 月份选择 | 选择统计月份（默认上月） |

## 操作按钮

| 序号 | 按钮名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 重置 | 重置搜索条件 |
| 2 | 搜索 | 按条件搜索 |
| 3 | 导出数据 | 导出报表数据 |

## 交互说明

1. 通过Tab切换不同能源类型
2. 支持按采集表名和月份筛选
3. 支持导出数据
4. 月度统计，展示整月用量汇总
