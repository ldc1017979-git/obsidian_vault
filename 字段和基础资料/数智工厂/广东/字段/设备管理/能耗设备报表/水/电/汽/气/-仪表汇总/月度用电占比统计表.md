# 月度用电占比统计表

## 页面概述

月度用电占比统计表用于按月统计各用电区域的用电量占比，支持自定义统计方案，展示各区域正/反向电能用量及占比情况。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/device/report-forms/energy/direct-statement/monthly-electricity`
- **所属模块**: 能耗/设备报表 > 能源直报报表

## 搜索字段

| 序号 | 字段名称 | 输入类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 抄表日期 | 日期范围 | 开始日期-结束日期（必填） |

## 操作按钮

| 序号 | 按钮名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 重置 | 重置搜索条件 |
| 2 | 搜索 | 按条件搜索 |
| 3 | 导出数据 | 导出报表数据 |
| 4 | 设定统计方案 | 配置用电区域统计方案 |

## 表格列信息

| 序号 | 列名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 用电区域 | 用电区域名称 |
| 2 | 正/反向电能 | 正向或反向电能标识 |
| 3 | 倍率 | 仪表倍率 |
| 4 | 起始时间 | 统计起始时间 |
| 5 | 起码读数 | 起始读数 |
| 6 | 截止时间 | 统计截止时间 |
| 7 | 止码读数 | 截止读数 |
| 8 | 用量(kwh) | 用电量 |

## 数据示例

当前页面暂无数据，需先设定统计方案后选择日期范围进行查询。

## 交互说明

1. 需先通过"设定统计方案"配置用电区域分组
2. 选择抄表日期范围后搜索
3. 支持导出数据
4. 用于分析各区域月度用电占比，辅助能源成本分摊
