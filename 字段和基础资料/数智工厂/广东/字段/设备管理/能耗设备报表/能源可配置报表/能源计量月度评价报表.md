# 能源计量月度评价报表

## 页面概述

能源计量月度评价报表用于按月统计和评价各能源消耗指标，包括产量、污水处理量、水处理量及水/电/蒸汽/燃气总用量，支持新增评价报表和设定统计方案。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/device/report-forms/Energy-configurable-report/measure-monthly-appraise`
- **所属模块**: 能耗/设备报表 > 能源可配置报表

## 搜索字段

| 序号 | 字段名称 | 输入类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 统计月份 | 月份选择 | 选择统计月份 |
| 2 | 单据状态 | 下拉选择 | 单据状态筛选 |

## 操作按钮

| 序号 | 按钮名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 重置 | 重置搜索条件 |
| 2 | 搜索 | 按条件搜索 |
| 3 | 新增 | 新建月度评价报表 |
| 4 | 设定统计方案 | 配置统计方案 |

| 序号 | 列名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 统计月份 | 评价统计月份 |
| 2 | 产量(万罐) | 当月产量 |
| 3 | 污水处理(吨) | 污水处理量 |
| 4 | 水处理量(吨) | 水处理量 |
| 5 | 水表总用量(吨) | 水表总用量 |
| 6 | 电表总用量(Kwh) | 电表总用量 |
| 7 | 蒸汽表总用量(吨) | 蒸汽表总用量 |
| 8 | 燃汽表总用量(m³) | 燃气表总用量 |
| 9 | 单据状态 | 单据审批状态 |
| 10 | 创建人 | 创建人 |
| 11 | 创建时间 | 创建时间 |
| 12 | 操作 | 编辑/删除/审批等 |

## 数据示例

当前页面暂无数据。

## 交互说明

1. 支持按统计月份和单据状态筛选
2. 支持新增月度评价报表
3. 需先通过"设定统计方案"配置统计方案
4. 综合展示产量和各项能源消耗指标，用于月度能源绩效评价
