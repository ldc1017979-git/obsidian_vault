# 能源异常通知中心

## 页面概述

- **功能说明**：查看能源异常通知，按仪表类型（电表/水表/蒸汽表/燃气表）分类展示异常信息
- **URL**：`https://gdmms.y1b.cn:8424/#/device-manage/energy-manage/config/exception-notification`

## 单选按钮组（仪表类型切换）

| 序号 | 选项名称 | 默认选中 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 电表 | 是 | 查看电表异常通知 |
| 2 | 水表 | 否 | 查看水表异常通知 |
| 3 | 蒸汽表 | 否 | 查看蒸汽表异常通知 |
| 4 | 燃气表 | 否 | 查看燃气表异常通知 |

## 异常通知列表字段

| 序号 | 列名称 | 数据类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 仪表名称 | String | 发生异常的仪表名称 |
| 2 | 异常类型 | String | 异常类型（连接超时/数据异常/超限预警） |
| 3 | 异常描述 | String | 异常详细描述 |
| 4 | 触发时间 | DateTime | 异常触发时间 |
| 5 | 处理状态 | String | 处理状态（未处理/已处理） |
| 6 | 处理人 | String | 处理人姓名 |
| 7 | 处理时间 | DateTime | 处理时间 |

## 交互说明

1. 页面通过单选按钮切换不同仪表类型的异常通知
2. 默认选中"电表"
3. 当前各类型均显示"暂无异常通知"
4. 异常通知由异常通知配置规则触发产生
