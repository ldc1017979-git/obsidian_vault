# 异常通知配置

## 页面概述

- **功能说明**：配置能源异常通知的接收人，按表类型（蒸汽表/水表/电表）分别配置
- **URL**：`https://gdmms.y1b.cn:8424/#/device-manage/energy-manage/config/inform`

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 新增异常通知接收人 | 新增异常通知接收人 |

## 表格列信息

| 序号 | 列名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 表类型 | 仪表类型（蒸汽表/水表/电表） |
| 2 | 异常通知接收人 | 异常通知的接收人列表 |
| 3 | 操作 | 编辑接收人 |

## 现有数据

| 表类型 | 异常通知接收人 |
| :--- | :--- |
| 蒸汽表 | 苏均武, 张立文, 颜三中, 戴路长 |
| 水表 | 苏均武, 张立文, 颜三中, 戴路长 |
| 电表 | 叶大元, 张立文, 戴路长 |

## 行操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 编辑接收人 | 编辑该表类型的异常通知接收人 |

## 新增/编辑异常通知接收人弹窗字段

| 序号 | 字段名称 | 数据类型 | 输入类型 | 长度限制 | 是否必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 表类型 | String | 下拉选择 | 20 | 是 | 仪表类型（蒸汽表/水表/电表/燃气表） |
| 2 | 异常通知接收人 | String | 多选下拉 | 200 | 是 | 选择异常通知接收人（支持多选） |

## 交互说明

1. 点击"新增异常通知接收人"可添加新的接收人
2. 每行支持"编辑接收人"操作，可修改对应表类型的接收人
3. 当前已配置蒸汽表、水表、电表三种表类型的接收人
