# 仪表层级配置

## 页面概述

- **功能说明**：配置能源仪表的分组层级结构，支持水表、电表、蒸汽表、燃气表四种类型分组管理
- **URL**：`https://gdmms.y1b.cn:8424/#/device-manage/energy-manage/meter-configurine/group`

## 页签信息

| 序号 | 页签名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 水表分组 | 默认选中，管理水表分组层级 |
| 2 | 电表分组 | 管理电表分组层级 |
| 3 | 蒸汽表分组 | 管理蒸汽表分组层级 |
| 4 | 燃气表分组 | 管理燃气表分组层级 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 新增分组 | 新增一个顶层分组 |
| 2 | 全部展开 | 展开所有分组树节点 |
| 3 | 全部折叠 | 折叠所有分组树节点 |

## 表格列信息

| 序号 | 列名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 分组名称 | 分组的名称 |
| 2 | 层级类型 | 分组的层级类型（如基地总表） |
| 3 | 生产车间 | 所属生产车间 |
| 4 | 所属产线 | 所属产线 |
| 5 | 所属区域 | 所属区域 |
| 6 | 操作 | 新增子分组、编辑、删除 |

## 行操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 新增子分组 | 在当前分组下新增子分组 |
| 2 | 编辑 | 编辑当前分组信息 |
| 3 | 删除 | 删除当前分组 |

## 新增分组弹窗字段

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 分组名称 | 文本框 | 空 | 必填 | 输入分组名称 |
| 2 | 层级类型 | 下拉框 | 空 | 必填 | 选择层级类型 |
| 3 | 所属车间 | 下拉框 | 空 | 可选 | 选择所属车间 |
| 4 | 所属线别 | 下拉框 | 空 | 可选 | 选择所属线别 |
| 5 | 所属区域 | 单选框 | 空 | 可选 | 生产区/生活区/办公区 |

## 编辑分组弹窗字段

| 序号 | 字段名称 | 数据类型 | 输入类型 | 长度限制 | 是否必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 分组名称 | String | 文本输入 | 50 | 是 | 分组名称 |
| 2 | 层级类型 | String | 下拉选择 | 20 | 是 | 层级类型 |
| 3 | 所属车间 | String | 下拉选择 | 20 | 否 | 所属车间 |
| 4 | 所属线别 | String | 下拉选择 | 20 | 否 | 所属线别 |
| 5 | 所属区域 | String | 单选框 | 10 | 否 | 生产区/生活区/办公区 |

## 交互说明

1. 页面默认显示"水表分组"页签
2. 可通过页签切换不同能源类型的分组配置
3. 点击"新增分组"弹出新增分组对话框
4. 分组以树形结构展示，支持展开/折叠
5. 每行支持新增子分组、编辑、删除操作
