# 电表采集配置

## 页面概述

- **功能说明**：配置电表的采集参数，包括采集表名、所属分组、倍率、预警值设定等
- **URL**：`https://gdmms.y1b.cn:8424/#/device-manage/energy-manage/meter-configurine/electric`

## 交互说明

1. 支持按采集表名、区域、分组、工序、核算标志、统计标志进行筛选
2. 点击"新增仪表配置"弹出新增对话框，包含仪表信息和预警值设定两个区域
3. 电表特有的倍率字段为必填项，默认值为1
4. 电表区分正向和反向表码数
5. 采集表区域在选择所属分组后自动带出，不可手动编辑
6. 每行支持查看读数明细、编辑配置、删除配置、更新仪表名称操作
