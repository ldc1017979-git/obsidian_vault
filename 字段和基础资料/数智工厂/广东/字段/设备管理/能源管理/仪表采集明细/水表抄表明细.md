# 水表抄表明细

## 页面概述

- **功能说明**：查看水表的采集抄表数据明细，支持按分组树和采集时间筛选
- **URL**：`https://gdmms.y1b.cn:8424/#/device-manage/energy-manage/meter-data/water-meter-reading`

## 交互说明

1. 左侧为分组树，点击树节点可筛选对应仪表的抄表数据
2. 支持按采集时间范围和采集表名进行筛选
3. 分组树支持搜索和展开/折叠操作
4. 表格数据按采集时间倒序排列
5. 每行支持编辑操作
