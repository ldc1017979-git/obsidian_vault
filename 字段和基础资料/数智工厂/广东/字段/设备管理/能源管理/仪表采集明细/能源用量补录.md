# 能源用量补录

## 页面概述

- **功能说明**：对能源仪表用量数据进行补录，支持新增、审批、驳回操作
- **URL**：`https://gdmms.y1b.cn:8424/#/device-manage/energy-manage/meter-data/dosage-record`

## 交互说明

1. 支持按单据编号、仪表类型、仪表名称、采集日期、创建人进行筛选
2. 点击"新增"弹出新增补录对话框
3. 支持批量审批通过和批量驳回操作，需先勾选记录
4. 补录记录包含单据编号和单据状态，支持审批流程
