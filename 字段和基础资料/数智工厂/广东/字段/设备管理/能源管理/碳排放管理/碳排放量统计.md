# 碳排放量统计

## 页面概述

- **功能说明**：统计碳排放量，按日期和碳排放因子查看汇总数据，支持导出和设定统计方案
- **URL**：`https://gdmms.y1b.cn:8424/#/device-manage/energy-manage/Carbon-emissions/carbon-emission-statistics`

## 搜索筛选区字段

| 序号 | 字段名称 | 输入类型 | 默认值 | 约束条件 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 统计日期（开始） | 日期选择器 | 空 | 可选 | 统计日期起始 |
| 2 | 统计日期（结束） | 日期选择器 | 空 | 可选 | 统计日期截止 |
| 3 | 碳排放因子 | 下拉框 | 空 | 可选 | 按碳排放因子筛选 |

## 操作按钮

| 序号 | 按钮名称 | 功能描述 |
| :--- | :--- | :--- |
| 1 | 搜索 | 按筛选条件搜索 |
| 2 | 重置 | 清空所有筛选条件 |
| 3 | 导出数据 | 导出碳排放量统计数据 |
| 4 | 设定统计方案 | 设定碳排放统计方案 |

## 表格列信息

| 序号 | 列名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 统计日期 | 碳排放统计日期 |
| 2 | 碳排放因子 | 使用的碳排放因子 |
| 3 | 二氧化碳当量 | 碳排放因子对应的CO2当量值 |
| 4 | 所属仪表 | 关联的仪表名称 |
| 5 | 总用量 | 统计期间的总用量 |
| 6 | 碳排放量 | 计算得出的碳排放量 |

- 当前暂无数据

## 设定统计方案弹窗字段

| 序号 | 字段名称 | 数据类型 | 输入类型 | 长度限制 | 是否必填 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | 统计方案名称 | String | 文本输入 | 50 | 是 | 统计方案名称 |
| 2 | 统计周期 | String | 下拉选择 | 20 | 是 | 统计周期（日/月/年） |
| 3 | 碳排放因子 | String | 多选下拉 | 200 | 是 | 关联碳排放因子 |
| 4 | 统计日期范围 | Date | 日期范围选择器 | - | 是 | 统计日期范围 |

## 交互说明

1. 支持按统计日期范围和碳排放因子进行筛选
2. 点击"导出数据"可导出碳排放量统计数据
3. 点击"设定统计方案"可设定碳排放统计方案
4. 当前数据为空，属于初始状态
