# 国产化替代项目

## 页面概述

国产化替代项目页面用于管理进口备件国产化替代的立项申请和审批流程，记录项目名称、编号、立项状态、申请人和关联资产等信息。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/equipment-operate/Replacement-improvement/domestic/project`
- **所属模块**: 设备运行管理 > 国产化替代/技改

## 交互说明

1. 点击"新增"可创建新的国产化替代项目
2. 支持按关键字、立项状态、申请日期、申请人和资产名称筛选
3. 已审核项目可点击"详情"查看详细信息
4. 已审核项目可点击"反审"撤回审批
