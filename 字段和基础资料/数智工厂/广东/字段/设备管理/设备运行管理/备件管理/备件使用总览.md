# 备件使用总览

## 页面概述

备件使用总览页面用于查看备件的库存和使用情况汇总，展示每种备件的总数量、已使用数量和可用数量，支持按备件名称、条码和规格型号筛选。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/equipment-operate/spare-manage/use-overview`
- **所属模块**: 设备运行管理 > 备件管理

## 搜索字段

| 序号 | 字段名称 | 输入类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 备件名称 | 下拉选择 | 备件名称筛选 |
| 2 | 条码 | 文本输入 | 备件条码搜索 |
| 3 | 规格型号 | 文本输入 | 规格型号搜索 |

| 序号 | 按钮名称 | 说明 |
| :--- | :--- | :--- |
| 1 | 重置 | 重置搜索条件 |
| 2 | 搜索 | 按条件搜索 |

## 交互说明

1. 支持按备件名称、条码和规格型号筛选
2. 展示备件库存和使用情况的汇总视图
3. 可用数量 = 总数量 - 已使用数量
4. 本页面为汇总展示页，无新增/详情页面，备件使用数据来源于备件使用记录
