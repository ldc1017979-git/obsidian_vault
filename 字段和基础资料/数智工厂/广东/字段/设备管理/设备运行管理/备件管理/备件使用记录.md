# 备件使用记录

## 页面概述

备件使用记录页面用于详细记录每个备件的使用情况，包括关联单号、使用设备、使用时长、替换信息等，支持多维度筛选和导出。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/equipment-operate/spare-manage/use-record`
- **所属模块**: 设备运行管理 > 备件管理

## 交互说明

1. 支持按单据编号、关联单号、单据类型、备件名称、条码、使用时间和线别筛选
2. 点击"展开"可查看更多搜索条件
3. 支持导出备件使用记录数据
4. 记录包含备件使用的完整生命周期信息
