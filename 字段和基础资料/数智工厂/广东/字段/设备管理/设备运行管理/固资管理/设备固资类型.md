# 设备固资类型

## 页面概述

设备固资类型页面用于管理设备固定资产的分类类型，支持树形层级结构（如生产设备>车间>产线>工序），提供新建、编辑、删除和子类型管理功能。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/equipment-operate/Fixed-asset-management/equipment-ledger-type`
- **所属模块**: 设备运行管理 > 固资管理

## 交互说明

1. 点击"新建资产类型"可创建顶级分类
2. 点击"新增子类型"可在当前类型下创建子分类
3. 支持树形层级结构管理（如生产设备>车间>产线>工序）
4. 点击"全部展开"/"全部折叠"可快速切换树形显示
5. 点击"编辑"可修改类型信息，"删除"可删除类型
