# 空压机运行记录表

## 页面概述

空压机运行记录表页面用于记录空压机的日常运行情况，包括检查日期、检查人、所属车间及运行状态，支持按日期、检查人、车间和单据状态筛选。

- **页面URL**: `https://gdmms.y1b.cn:8424/#/device-manage/equipment-operate/daily-management/compressor-running`
- **所属模块**: 设备运行管理 > 日常管理

## 交互说明

1. 点击"新增"可创建新的空压机运行记录
2. 点击"详情"可查看运行记录详细信息
3. 点击"导出"可导出单条记录
4. 支持按检查日期、检查人、车间和状态筛选
