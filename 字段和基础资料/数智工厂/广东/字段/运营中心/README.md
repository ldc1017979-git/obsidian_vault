# 运营中心

## 模块概述

运营中心是数智工厂系统的核心管理模块，位于顶部标签栏的一级模块。

## 模块结构

```
运营中心（一级模块）
├── 生产经济技术指标（二级模块）
│   ├── 基地生产系统运行概况（表单）
│   ├── 生产基地KPI考核指标（表单）
│   └── 生产基地一般考核指标（表单）
├── 经济数据指标（二级模块）
│   └── 经济数据指标（表单）
├── 公司级年度重点工作（二级模块）
│   └── 公司级年度重点工作（表单）
└── 部门级年度重点工作（二级模块）
    └── 部门级年度重点工作（表单）
```

## 层级说明

| 层级 | 位置 | 示例 |
| :--- | :--- | :--- |
| 一级模块 | 顶部标签栏 | 运营中心、仓储管理、生产管理、质量管理等 |
| 二级模块 | 左侧菜单 | 生产经济技术指标、经济数据指标、公司级年度重点工作、部门级年度重点工作 |
| 表单 | 中间内容区 | 基地生产系统运行概况、生产基地KPI考核指标等 |

## 功能特点

1. **数据可视化**：通过图表和数据卡片直观展示各项指标数据
2. **多维度分析**：支持按时间、产品类型等多维度查看数据
3. **任务管理**：支持年度重点工作的全生命周期管理
4. **考核管理**：提供KPI和一般考核指标的完整管理功能
5. **实时更新**：数据实时更新，反映当前生产运营状况

## 使用说明

1. 通过顶部标签栏选择"运营中心"一级模块
2. 通过左侧菜单选择相应的二级模块（生产经济技术指标、经济数据指标等）
3. 在中间内容区查看对应的表单内容
4. 使用筛选条件查询特定数据
5. 对于未达标的指标，及时填写原因说明

## 注意事项

- 所有数据按月度统计，可查看历史数据和累计数据
- 未达标的指标需要填写原因说明
- 污水指标要求当月平均值及单位检测值均符合达标值
- 任务类型分为"集团层级"和"基地层级"，需根据实际情况选择
