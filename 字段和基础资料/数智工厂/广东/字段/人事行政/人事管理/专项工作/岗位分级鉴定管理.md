# 岗位分级鉴定管理

## 功能定位
岗位分级鉴定管理模块用于管理员工岗位分级评定的鉴定审批流程，对员工提交的岗位分级评定申报进行评审。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 申请日期 | 日期范围 | 选择申请日期区间 |
| 鉴定状态 | 下拉选择 | 按鉴定状态筛选 |
| 岗位级别 | 下拉选择 | 按岗位级别筛选 |
| 员工信息 | 文本输入 | 按员工姓名/工号搜索 |
| 评审类型 | 下拉选择 | 按评审类型筛选 |

### 操作按钮
- 重置
- 搜索

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 业务编号 | 系统自动生成 |
| 状态 | 当前鉴定状态 |
| 申请日期 | 申报日期 |
| 员工姓名 | 申报员工姓名 |
| 岗位 | 当前岗位 |
| 申报级别 | 申请评定的级别 |
| 已评定级别 | 已获得的级别 |
| 评审类别 | 评审分类 |
| 综合评价 | 评审综合评价 |
| 工号 | 员工工号 |
| 部门 | 所属部门 |
| 入职年限 | 入职年数 |
| 本岗位年限 | 在当前岗位的年数 |
| 报名申请备注 | 备注说明 |
| 操作 | 查看/编辑等 |
