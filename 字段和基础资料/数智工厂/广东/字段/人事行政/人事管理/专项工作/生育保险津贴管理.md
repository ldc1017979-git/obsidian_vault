# 生育保险津贴管理

## 功能定位
生育保险津贴管理模块用于管理员工生育保险津贴的申请和审批流程，支持津贴申请和津贴设置功能。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 申请日期 | 日期范围 | 选择申请日期区间 |
| 业务状态 | 下拉选择 | 按业务状态筛选 |
| 津贴类型 | 下拉选择 | 按津贴类型筛选 |
| 员工信息 | 文本输入 | 按员工姓名/工号搜索 |
| 员工部门 | 文本输入 | 按部门名称搜索 |
| 员工岗位 | 下拉选择 | 按岗位筛选 |

### 操作按钮
- 重置
- 搜索
- 生育保险津贴申请
- 生育津贴设置

### 其他元素
- 生育保险津贴申请二维码

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 业务编号 | 系统自动生成 |
| 业务状态 | 当前审批状态 |
| 申请日期 | 津贴申请日期 |
| 申请员工名称 | 申请人姓名 |
| 津贴类型 | 津贴分类 |
| 入院时间 | 住院开始时间 |
| 出院时间 | 住院结束时间 |
| 个人五险一金承担部分金额 | 个人承担金额 |
| 请假时间段 | 休假时间范围 |
| 津贴总金额 | 津贴总额 |
| 部门 | 所属部门 |
| 岗位 | 所在岗位 |
| 备注信息 | 备注说明 |
| 操作 | 查看/编辑等 |
