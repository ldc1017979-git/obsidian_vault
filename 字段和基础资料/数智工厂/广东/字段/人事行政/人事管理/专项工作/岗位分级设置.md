# 岗位分级设置

## 功能定位
岗位分级设置模块用于配置岗位分级评定的相关参数，包括岗位级别的定义和管理。

## 页面结构
页面包含标签页：岗位级别

### 标签页：岗位级别

#### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 岗位级别 | 文本输入 | 按岗位级别名称搜索 |

#### 操作按钮
- 重置
- 搜索
- 新增岗位级别

#### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 岗位级别名称 | 级别名称 |
| 状态 | 启用/禁用状态 |
| 控制比例 | 级别人数控制比例 |
| 可认证岗位范围 | 允许认证的岗位范围 |
| 显示顺序 | 排列顺序 |
| 备注信息 | 备注说明 |
| 操作 | 编辑/删除等 |

#### 新增/编辑岗位级别表单字段
点击"新增岗位级别"或"编辑"按钮打开表单，表单字段如下：

| 序号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 岗位级别 | 文本输入框 | 是 | 岗位级别名称 |
| 2 | 类别颜色 | 按钮选择 | 否 | 设置类别颜色 |
| 3 | 可认证岗位范围 | 选择框 | 否 | 可认证的岗位范围 |
| 4 | 状态 | 单选框 | 否 | 启用/禁用，默认启用 |
| 5 | 控制比例 | 数字输入 | 否 | 控制比例百分比，累计不能超过本岗位 |
| 6 | 显示顺序 | 数字输入 | 否 | 数值越大，越靠前 |
| 7 | 备注信息 | 多行文本 | 否 | 备注说明，最多100字符 |
