# 岗位分级评定申报

## 功能定位
岗位分级评定申报模块用于员工提交岗位分级评定的报名申请，支持二维码扫码申报。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 申请日期 | 日期范围 | 选择申请日期区间 |
| 申请状态 | 下拉选择 | 按申请状态筛选 |
| 岗位级别 | 下拉选择 | 按岗位级别筛选 |
| 员工信息 | 文本输入 | 按员工姓名/工号搜索 |

### 操作按钮
- 重置
- 搜索
- 新增分级评定报名申请

### 其他元素
- 岗位分级评定申请二维码

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 业务编号 | 系统自动生成 |
| 业务状态 | 当前审批状态 |
| 申请日期 | 申报日期 |
| 员工姓名 | 申报员工姓名 |
| 岗位 | 当前岗位 |
| 申报级别 | 申请评定的级别 |
| 已评定级别 | 已获得的级别 |
| 工号 | 员工工号 |
| 部门 | 所属部门 |
| 入职年限 | 入职年数 |
| 本岗位年限 | 在当前岗位的年数 |
| 报名申请备注 | 备注说明 |
| 操作 | 查看/编辑等 |

#### 新增/编辑表单字段
点击"新增分级评定报名申请"或"编辑"按钮打开表单，表单字段如下：

##### 基础信息
| 序号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 在职员工 | 点击选择 | 是 | 点击选择在职员工 |
| 2 | 工号 | 只读 | 否 | 系统自动填充 |
| 3 | 部门 | 只读 | 否 | 系统自动填充 |
| 4 | 现岗位 | 只读 | 否 | 系统自动填充 |
| 5 | 入职年限 | 只读 | 否 | 系统自动填充 |
| 6 | 单据编号 | 只读 | 否 | 系统自动生成 |
| 7 | 入职日期 | 日期选择 | 是 | 选择入职日期 |

##### 申请报名信息
| 序号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 8 | 申请日期 | 日期选择 | 是 | 选择申请日期 |
| 9 | 申报岗位级别 | 下拉选择 | 是 | 选择申报的岗位级别 |
| 10 | 申报备注 | 多行文本 | 否 | 申报备注说明，最多500字 |
| 11 | 申报附件 | 文件上传 | 否 | 支持jpg, png, gif, jpeg, pdf, zip, rar, docx, doc, xlsx, ppt, pptx, pptm, xls格式，最多10个文件，每个不超过100M |
| 12 | 已评定岗位级别 | 只读 | 否 | 系统自动显示 |
