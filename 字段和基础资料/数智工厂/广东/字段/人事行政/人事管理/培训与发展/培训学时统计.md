# 培训学时统计

## 功能定位
培训学时统计模块用于按部门或员工维度统计培训学时数据，支持查看各部门和各员工的培训参与情况。

## 页面结构
页面包含两个标签页：
1. 部门学时
2. 员工学时

### 标签页一：部门学时

#### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 培训日期 | 日期范围 | 选择培训日期区间 |
| 部门 | 文本输入（只读） | 按部门筛选 |

#### 统计汇总
- 总场数
- 有效场数
- 培训总时长(min)
- 复训场数

#### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 统计统计部门 | 部门名称 |
| 总场数 | 培训总场次 |
| 有效总场数 | 有效培训场次 |
| 培训总时长(min) | 培训总时长 |
| 复训场数 | 重复培训场次 |
| 操作 | 详情 |

### 标签页二：员工学时

#### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 培训日期 | 日期范围 | 选择培训日期区间 |
| 部门 | 文本输入（只读） | 按部门筛选 |

#### 统计汇总
- 总场数
- 培训总时长(min)

#### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 姓名 | 员工姓名 |
| 所在部门 | 所属部门路径 |
| 总场数 | 参与培训总场次 |
| 培训总时长(min) | 培训总时长 |
| 操作 | 详情 |
