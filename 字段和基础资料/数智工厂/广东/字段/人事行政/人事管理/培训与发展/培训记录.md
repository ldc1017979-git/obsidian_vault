# 培训记录

## 功能定位
培训记录模块用于记录每次培训的详细信息，包括培训执行情况、签到、评价等。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 培训类型 | 下拉选择 | 按培训类型筛选 |
| 时间安排 | 日期范围 | 选择培训时间区间 |
| 培训状态 | 下拉选择 | 按培训状态筛选 |
| 培训主题 | 文本输入 | 按培训主题搜索 |
| 培训人 | 文本输入 | 按培训人搜索 |
| 培训部门 | 文本输入（只读） | 按培训部门筛选 |

### 操作按钮
- 重置
- 搜索
- 组织培训
- 批量导入
- 导出数据

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 培训编号 | 系统自动生成 |
| 关联计划编号 | 关联的培训计划编号 |
| 培训类别 | 培训分类 |
| 部门 | 培训部门 |
| 培训主题 | 培训主题名称 |
| 培训状态 | 进行中/待验收等 |
| 培训日期 | 培训执行日期 |
| 培训时间 | 培训时间段 |
| 培训时长(min) | 培训持续时间 |
| 培训地点 | 培训场所 |
| 培训人 | 培训讲师 |
| 参加范围 | 参训人员名单 |
| 培训方式 | 内训/外训 |
| 培训内容 | 培训内容描述 |
| 培训费用(元) | 实际费用 |
| 培训交付物 | 培训产出 |
| 备注 | 备注说明 |
| 操作 | 详情/编辑/签到码/结束培训/培训评价 |

## 新增表单字段

点击"组织培训"按钮打开表单，表单字段如下：

### 基础信息
| 序号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 培训类型 | 单选按钮 | 否 | 计划外培训/计划内培训，默认计划外培训 |
| 2 | 培训主题 | 文本输入框 | **是** | 培训主题名称 |
| 3 | 培训类别 | 下拉选择框 | **是** | 培训类别选择 |
| 4 | 培训部门 | 文本输入框 | **是** | 自动填充，不可编辑 |
| 5 | 培训人 | 点击选择 | **是** | 点击选择培训人(多选) |
| 6 | 参加范围 | 点击选择 | **是** | 点击选受训人员 |
| 7 | 培训内容 | 多行文本框 | **是** | 培训内容描述，最多500字符 |
| 8 | 签到电子围栏 | 单选按钮 | 否 | 关闭/开启，默认关闭 |
| 9 | 培训费用 | 复选框组 | 否 | 听课费/教材费/培训师补贴/餐补费/其他 |
| 10 | 备注信息 | 多行文本框 | 否 | 备注说明，最多500字符 |
| 11 | 附件信息 | 文件上传 | 否 | 支持jpg, png, gif, jpeg, pdf, zip, rar, docx, doc, xlsx, ppt, pptx, pptm, xls格式，不超过100M |
| 12 | 培训现场照片 | 图片上传 | 否 | 单张不超过20M，最多10张 |
| 13 | 培训编号 | 文本输入框 | 否 | 自动生成，不可编辑 |
| 14 | 培训地点 | 文本输入框 | **是** | 培训场所 |
| 15 | 组织部门 | 文本输入框 | 否 | 自动填充，不可编辑 |
| 16 | 职务 | 文本输入框 | 否 | 自动填充，不可编辑 |
| 17 | 培训日期 | 日期范围选择器 | **是** | 开始日期-结束日期 |
| 18 | 培训时间 | 时间选择器 | **是** | 开始时间-结束时间 |
| 19 | 培训方式 | 单选按钮 | **是** | 内训/外训/公开课 |
| 20 | 创建人 | 文本输入框 | 否 | 自动填充当前用户，不可编辑 |
| 21 | 培训验收人 | 下拉选择框 | 否 | 选择培训验收人 |
| 22 | 培训交付物 | 下拉选择框 | 否 | 培训交付物类型 |
| 23 | 是否为复训 | 单选按钮 | 否 | 是/否，默认否 |
| 24 | 是否有教材 | 单选按钮 | 否 | 是/否，默认有 |
| 25 | 是否固定模板 | 单选按钮 | 否 | 是/否，默认有 |
| 26 | 培训教材 | 下拉选择框 | 否 | 选择培训教材 |
| 27 | 培训时段 | 下拉选择框 | 否 | 培训时段选择 |
| 28 | 培训方法 | 下拉选择框 | 否 | 培训方法选择 |
| 29 | 培训内容划分 | 下拉选择框 | 否 | 培训内容划分 |
| 30 | 培训类型 | 下拉选择框 | 否 | 培训类型选择 |
| 31 | 考核分类 | 下拉选择框 | 否 | 考核分类选择 |

### 操作按钮
| 按钮名称 | 描述 |
| :--- | :--- |
| 取消 | 取消编辑 |
| 确定 | 提交培训记录 |
