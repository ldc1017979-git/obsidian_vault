# 合同设置

## 一、模块概述

| 属性 | 说明 |
| :--- | :--- |
| 模块名称 | 合同设置 |
| 所属分类 | 人事管理 > 员工档案管理 |

| 功能定位 | 配置合同期限类型、法人公司、合同类型、临期提醒和试用转正提醒 |
