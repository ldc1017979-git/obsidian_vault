# 离职设置

## 一、模块概述

| 属性 | 说明 |
| :--- | :--- |
| 模块名称 | 离职设置 |
| 所属分类 | 人事管理 > 员工档案管理 |
| 页面URL | `#/administration-manage/index10/index107/dimissionSet` |
| 功能定位 | 配置离职原因和离职类型 |

## 二、标签页一：离职原因

### 2.1 搜索条件

| 序号 | 字段名称 | 类型 | 描述 |
| :--- | :--- | :--- | :--- |
| 1 | 离职原因 | 文本输入框 | 搜索离职原因 |

### 2.2 操作按钮

| 按钮名称 | 描述 |
| :--- | :--- |
| 新增离职原因 | 新增离职原因 |

### 2.3 列表字段

| 序号 | 字段名称 | 描述 |
| :--- | :--- | :--- |
| 1 | 序号 | 行序号 |
| 2 | 离职原因 | 离职原因名称 |
| 3 | 状态 | 启用/禁用 |
| 4 | 显示顺序 | 排序值 |
| 5 | 备注信息 | 备注说明 |
| 6 | 操作 | 编辑 |

现有数据：外部发展机会、身体原因、家庭原因、不适应工作、薪酬原因、达到法定退休年龄、试用期不符合录用条件、调离

### 2.4 新增离职原因表单

| 字段编号 | 字段名称 | 类型 | 必填 | 描述 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 离职原因 | 文本输入框 | **是** | 离职原因名称 |
| 2 | 类型颜色 | 颜色选择器 | **是** | 类型颜色设置 |
| 3 | 状态 | 单选按钮 | 否 | 启用/禁用（默认启用） |
| 4 | 显示顺序 | 数字输入框 | 否 | 数值越大越靠前 |
| 5 | 备注信息 | 多行文本框 | 否 | 最多100字 |
