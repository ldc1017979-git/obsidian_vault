# 收支科目设置

## 功能定位
收支科目设置模块用于配置食堂营收结算的收支科目参数。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 科目名称 | 文本输入 | 按科目名称搜索 |

### 操作按钮
- 重置
- 搜索
- 新增科目
- 设置营收单位

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 科目名称 | 科目名称 |
| 项目 | 所属项目 |
| 单位 | 计量单位 |
| 状态 | 启用/禁用 |
| 关联数据源 | 关联数据来源 |
| 显示顺序 | 排列顺序 |
| 备注信息 | 备注说明 |
| 操作 | 编辑 |
