# 机动车行驶证管理

## 功能定位
机动车行驶证管理模块用于管理企业车辆的行驶证信息，包括证件有效期、年审等。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 车牌号 | 下拉选择 | 按车牌号筛选 |
| 状态 | 下拉选择 | 按证件状态筛选 |

### 操作按钮
- 重置
- 搜索
- 新增

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 车牌号 | 车辆牌照号码 |
| 行驶证编号 | 行驶证编号 |
| 发证日期 | 发证日期 |
| 有效期 | 有效期至 |
| 状态 | 证件状态 |
| 操作 | 详情/编辑 |
