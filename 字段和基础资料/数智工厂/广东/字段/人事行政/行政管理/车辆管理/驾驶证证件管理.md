# 驾驶证证件管理

## 功能定位
驾驶证证件管理模块用于管理企业员工的驾驶证信息，包括证件有效期、准驾车型等。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 姓名 | 文本输入 | 按姓名搜索 |
| 状态 | 下拉选择 | 按证件状态筛选 |

### 操作按钮
- 重置
- 搜索
- 新增

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 姓名 | 员工姓名 |
| 驾驶证号 | 驾驶证编号 |
| 准驾车型 | 准驾车型类别 |
| 有效期 | 有效期至 |
| 状态 | 证件状态 |
| 操作 | 详情/编辑 |
