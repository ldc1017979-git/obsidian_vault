# 车辆综合信息总览表

## 功能定位
车辆综合信息总览表模块用于综合展示所有车辆的关键信息，包括档案、保险、年检、保养等状态。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 车牌号 | 下拉选择 | 按车牌号筛选 |

### 操作按钮
- 重置
- 搜索
- 导出

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 车牌号 | 车辆牌照号码 |
| 品牌 | 车辆品牌 |
| 档案状态 | 档案状态 |
| 保险状态 | 保险到期状态 |
| 年检状态 | 年检到期状态 |
| 保养状态 | 保养到期状态 |
| 操作 | 详情 |
