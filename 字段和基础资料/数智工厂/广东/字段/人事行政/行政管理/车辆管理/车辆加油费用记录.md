# 车辆加油费用记录

## 功能定位
车辆加油费用记录模块用于记录每次车辆加油的费用和油量信息。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 车牌号 | 下拉选择 | 按车牌号筛选 |
| 加油日期 | 日期范围 | 选择加油日期区间 |

### 操作按钮
- 重置
- 搜索
- 新增

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 车牌号 | 车辆牌照号码 |
| 加油日期 | 加油日期 |
| 加油量(升) | 加油升数 |
| 加油金额(元) | 加油费用 |
| 油品类型 | 油品标号 |
| 加油站 | 加油站名称 |
| 操作 | 详情/编辑 |
