# 车辆费用统计表

## 功能定位
车辆费用统计表模块用于按车辆维度汇总统计各类费用数据。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 车牌号 | 下拉选择 | 按车牌号筛选 |
| 统计日期 | 日期范围 | 选择统计日期区间 |

### 操作按钮
- 重置
- 搜索
- 导出

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 车牌号 | 车辆牌照号码 |
| 加油费用 | 加油费用合计 |
| 维修费用 | 维修费用合计 |
| 保养费用 | 保养费用合计 |
| 保险费用 | 保险费用合计 |
| 交通费用 | 交通费用合计 |
| 费用总计 | 所有费用合计 |
| 操作 | 详情 |
