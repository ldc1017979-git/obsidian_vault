# 服务费用记录

## 功能定位
服务费用记录模块用于记录车辆相关的各类服务费用，如代驾费、洗车费等。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 车牌号 | 下拉选择 | 按车牌号筛选 |
| 费用日期 | 日期范围 | 选择费用日期区间 |

### 操作按钮
- 重置
- 搜索
- 新增

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 车牌号 | 车辆牌照号码 |
| 服务类型 | 服务类型 |
| 费用金额(元) | 服务费用 |
| 费用日期 | 费用发生日期 |
| 操作 | 详情/编辑 |
