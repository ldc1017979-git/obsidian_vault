# 用车申请

## 功能定位
用车申请模块用于员工提交用车申请，包括用车时间、目的地、事由等信息，并支持审批流程。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 申请人 | 文本输入 | 按申请人搜索 |
| 用车日期 | 日期范围 | 选择用车日期区间 |
| 状态 | 下拉选择 | 按申请状态筛选 |

### 操作按钮
- 重置
- 搜索
- 新增

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 申请编号 | 系统自动生成 |
| 申请人 | 申请人姓名 |
| 用车日期 | 用车日期 |
| 出发地 | 出发地点 |
| 目的地 | 目的地点 |
| 用车事由 | 用车原因 |
| 用车时长 | 预计用车时长 |
| 状态 | 申请状态 |
| 操作 | 详情/编辑/审批 |
