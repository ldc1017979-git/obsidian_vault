# 三会召开记录

## 功能定位
三会召开记录模块用于管理企业三会（座谈会等）的召开记录，包括会议主题、时间、出席人员等。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 三会类型 | 下拉选择 | 按三会类型筛选 |
| 召开时间 | 日期范围 | 选择召开时间区间 |
| 三会状态 | 下拉选择 | 按三会状态筛选 |
| 三会主题 | 文本输入 | 按主题搜索 |
| 三会人员 | 下拉+文本 | 按人员类型和姓名搜索 |

### 操作按钮
- 重置
- 搜索
- 新增三会记录
- 批量导入
- 导出数据

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 三会编号 | 系统编号 |
| 三会类型 | 座谈会等 |
| 三会主题 | 会议主题 |
| 召开时间 | 会议日期 |
| 状态 | 待执行/已完成 |
| 地点 | 会议地点 |
| 员工建议/意见 | 员工建议内容 |
| 建议执行人 | 建议执行人 |
| 执行效果 | 执行效果 |
| 主持人 | 主持人姓名 |
| 出席人数 | 出席人数 |
| 备注 | 备注信息 |
| 操作 | 详情/反审 |
