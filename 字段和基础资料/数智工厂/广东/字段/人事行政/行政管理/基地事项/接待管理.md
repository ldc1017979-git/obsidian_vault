# 接待管理

## 功能定位
接待管理模块用于管理企业来访接待事务，包括接待安排、费用统计等。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 接待类型 | 下拉选择 | 按接待类型筛选 |
| 接待时间 | 日期范围 | 选择接待时间区间 |
| 接待状态 | 下拉选择 | 按接待状态筛选 |
| 会议名称 | 文本输入 | 按会议名称搜索 |

### 操作按钮
- 重置
- 搜索
- 新增接待管理
- 接待类型设置

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 接待编号 | 系统编号 |
| 接待周期 | 接待时间段 |
| 接待事由 | 接待原因 |
| 接待类型 | 接待类型 |
| 状态 | 接待状态 |
| 接待人数 | 来访人数 |
| 是否提供房间 | 是否安排住宿 |
| 入住房间 | 安排的房间号 |
| 餐费(元) | 餐饮费用 |
| 住宿费(元) | 住宿费用 |
| 布草费(新购，清洗) | 布草费用 |
| 易耗品费用 | 易耗品费用 |
| 接待维修费用 | 维修费用 |
| 创建人 | 创建人姓名 |
| 备注 | 备注信息 |
| 操作 | 详情/编辑 |
