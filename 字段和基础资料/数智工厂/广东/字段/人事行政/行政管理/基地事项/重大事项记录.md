# 大事记/荣誉

## 功能定位
大事记/荣誉模块用于记录企业重大事项和荣誉信息，支持批量导入和导出。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 记录类型 | 下拉选择 | 按记录类型筛选 |
| 记录时间 | 日期范围 | 选择记录时间区间 |
| 记录状态 | 下拉选择 | 按记录状态筛选 |
| 人员名称 | 文本输入 | 按人员名称搜索 |
| 荣誉等级 | 下拉选择 | 按荣誉等级筛选 |
| 获取奖励 | 下拉选择 | 按获取奖励筛选 |

### 操作按钮
- 重置
- 搜索
- 新增大事记/荣誉
- 批量导入
- 批量提交
- 导出数据

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 记录单号 | 系统编号 |
| 时间 | 记录时间 |
| 记录类型 | 记录类型 |
| 记录标题 | 记录标题 |
| 背景说明 | 背景说明 |
| 状态 | 记录状态 |
| 人员 | 相关人员 |
| 所获荣誉 | 所获荣誉 |
| 荣誉等级 | 荣誉等级 |
| 获得奖励 | 获得奖励 |
| 金额（元） | 金额 |
| 备注 | 备注信息 |
| 操作 | 详情/编辑/提交/删除 |
