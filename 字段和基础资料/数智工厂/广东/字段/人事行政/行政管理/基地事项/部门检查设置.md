# 部门安全检查设置

## 功能定位
部门安全检查设置模块用于配置部门安全检查的检查项目，包含部门安全检查项目标签页。

## 页面结构

### 标签页
- 部门安全检查项目

### 部门安全检查项目标签页

#### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 部门安全检查项目 | 文本输入 | 按检查项目搜索 |

#### 操作按钮
- 重置
- 搜索
- 新增部门安全检查项目

#### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 部门安全检查项目 | 检查项目名称 |
| 是否常规检查项 | 是否常规检查项 |
| 检查方法 | 检查方法 |
| 状态 | 启用/禁用 |
| 显示顺序 | 排序号 |
| 备注信息 | 备注信息 |
| 操作 | 编辑/删除 |
