# 团队活动

## 功能定位
团队活动模块用于管理企业各类团队活动的组织和记录。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 活动类别 | 下拉选择 | 按活动类别筛选 |
| 活动日期 | 日期范围 | 选择活动日期区间 |
| 活动状态 | 下拉选择 | 按活动状态筛选 |
| 活动主题 | 文本输入 | 按活动主题搜索 |
| 活动部门 | 文本输入 | 按活动部门搜索 |

### 操作按钮
- 重置
- 搜索
- 组织活动

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 活动编号 | 系统编号 |
| 活动类别 | 活动类别 |
| 活动部门 | 组织部门 |
| 活动课题 | 活动课题 |
| 活动状态 | 活动状态 |
| 活动日期 | 活动日期 |
| 活动地点 | 活动地点 |
| 参加范围 | 参加范围 |
| 活动费用(元) | 活动费用 |
| 备注 | 备注信息 |
| 操作 | 详情/编辑 |
