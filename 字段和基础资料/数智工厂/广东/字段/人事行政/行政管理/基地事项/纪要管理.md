# 会议纪要管理

## 功能定位
会议纪要管理模块用于管理各类会议纪要的创建、审核和存档。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 会议日期 | 日期范围 | 选择会议日期区间 |
| 业务状态 | 下拉选择 | 按业务状态筛选 |
| 会议类型 | 下拉选择 | 按会议类型筛选 |
| 会议信息 | 文本输入 | 按会议信息搜索 |
| 会议部门 | 文本输入 | 按会议部门搜索 |
| 员工信息 | 文本输入 | 按员工信息搜索 |

### 操作按钮
- 重置
- 搜索
- 新增会议纪要
- 会议类型设置
