# 宿舍可住人数

## 功能定位
宿舍可住人数模块用于管理宿舍房间的基本信息和可住人数设置。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 房间号 | 文本输入 | 按房间号搜索 |
| 区域 | 下拉选择 | 按区域筛选 |

### 操作按钮
- 重置
- 搜索
- 添加房间
- 导入数据

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 房间号 | 房间编号 |
| 区域 | 所属区域 |
| 可住人数 | 可住人数 |
| 操作 | 编辑/删除 |
