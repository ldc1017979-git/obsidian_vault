# 宿舍水电蒸汽费用

## 功能定位
宿舍水电蒸汽费用模块用于管理宿舍水电蒸汽费用的统计和结算，支持费用单价设置和统计仪表设置。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 记录年月 | 日期范围 | 选择记录年月区间 |
| 单据编号 | 文本输入 | 按单据编号搜索 |
| 状态 | 下拉选择 | 按状态筛选 |

### 操作按钮
- 重置
- 搜索
- 新增单据
- 设置费用单价
- 设置统计仪表
- 导出数据

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 单据编码 | 系统编号 |
| 记录年月 | 记录年月 |
| 单据状态 | 单据状态 |
| 费用总和(元) | 费用总计 |
| 水-用量(吨) | 水用量 |
| 水-费用(元) | 水费金额 |
| 电-用量(度) | 电用量 |
| 电-费用(元) | 电费金额 |
| 蒸汽-用量(m³) | 蒸汽用量 |
| 蒸汽-费用(元) | 蒸汽费用 |
| 操作 | 详情/编辑 |
