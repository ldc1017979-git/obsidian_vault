# 住宿统计表

## 功能定位
住宿统计表模块用于查看宿舍住宿情况的统计信息，包括区域、房间号、可住人数、实住人数等。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 区域 | 下拉选择 | 按区域筛选 |
| 房间号 | 下拉选择 | 按房间号筛选 |
| 住户姓名 | 文本输入 | 按住户姓名搜索 |
| 工号 | 文本输入 | 按工号搜索 |
| 部门 | 文本输入 | 按部门搜索 |

### 操作按钮
- 重置
- 搜索

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 区域 | 所属区域 |
| 房间号 | 房间编号 |
| 可住人数 | 可住人数 |
| 实住人数 | 实际入住人数 |
| 住户姓名 | 住户姓名 |
| 工号 | 员工工号 |
| 部门 | 所属部门 |
