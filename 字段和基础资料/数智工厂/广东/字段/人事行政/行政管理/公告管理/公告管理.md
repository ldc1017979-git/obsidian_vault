# 公告管理

## 功能定位
公告管理模块用于发布和管理企业公告通知，支持分类管理和公告类型设置。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 公告信息 | 文本输入 | 按公告信息搜索 |
| 公告类型 | 下拉选择 | 按公告类型筛选 |
| 公告状态 | 下拉选择 | 按公告状态筛选 |
| 公告部门 | 文本输入 | 按公告部门搜索 |

### 操作按钮
- 重置
- 搜索
- 添加公告
- 公告类型设置

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 公告编码 | 系统编号 |
| 公告标题 | 公告标题 |
| 关联文号 | 关联文号 |
| 公告类型 | 公司公告/部门公告等 |
| 状态 | 已完成/草稿等 |
| 发布时间 | 发布日期时间 |
| 公告部门 | 发布部门 |
| 发布范围 | 发布范围 |
| 发布人 | 发布人姓名 |
| 显示顺序 | 排序号 |
| 操作 | 详情/预览/反审/复制 |
