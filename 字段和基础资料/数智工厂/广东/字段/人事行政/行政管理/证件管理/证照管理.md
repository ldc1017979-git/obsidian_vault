# 公司级证照

## 功能定位
公司级证照模块用于管理企业各类证照信息，包括证照名称、备案编号、有效期等，支持批量审核。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 证照名称 | 文本输入 | 按证照名称搜索 |
| 临期 | 单选 | 筛选临期证照 |

### 操作按钮
- 重置
- 搜索
- 新增
- 批量通过
- 批量驳回

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 证照状态 | 待提审/已通过/已驳回等 |
| 证照名称 | 证照名称 |
| 备案编号 | 证照备案编号 |
| 登记日期 | 登记日期 |
| 到期日期 | 有效期截止日 |
| 经办人 | 经办人姓名 |
| 备注 | 备注信息 |
| 创建时间 | 创建时间 |
| 操作 | 详情/编辑/提交验收/作废 |
