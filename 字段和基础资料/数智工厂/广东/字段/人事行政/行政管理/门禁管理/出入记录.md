# 访客进出记录

## 功能定位
访客进出记录模块用于记录和查询门禁系统的访客进出记录，包括访客信息、接待信息、进出时间等。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 记录编号 | 文本输入 | 按记录编号搜索 |
| 姓名 | 文本输入 | 按访客姓名搜索 |
| 接待部门 | 下拉选择 | 按接待部门筛选 |

### 操作按钮
- 重置
- 搜索
