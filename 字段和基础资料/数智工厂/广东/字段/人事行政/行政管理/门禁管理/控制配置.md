# 门禁配置

## 功能定位
门禁配置模块用于配置门禁系统的采集表、使用地点、进出方向等信息。

## 页面结构

### 搜索条件
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 采集表名 | 文本输入 | 按采集表名搜索 |
| 使用地点 | 文本输入 | 按使用地点搜索 |
| 消息通知人 | 下拉选择 | 按消息通知人筛选 |

### 操作按钮
- 重置
- 搜索
- 新增配置

### 列表字段
| 字段名 | 说明 |
|--------|------|
| 序号 | 自动编号 |
| 采集表名 | 采集表名称 |
| 使用地点 | 使用地点 |
| 进出方向 | 进出方向 |
| 门禁用户数 | 门禁用户数量 |
| 授权关联用户数 | 授权关联用户数量 |
| 消息通知人 | 消息通知人 |
| 备注 | 备注信息 |
| 操作 | 详情/编辑 |
