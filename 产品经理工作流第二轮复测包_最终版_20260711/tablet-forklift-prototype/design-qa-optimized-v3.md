# 批量修改库位状态原型 QA

- 当前版本：`optimized-v3.html`（已同步为 `index.html`）
- 业务输入：用户最新确认规则
- 视觉输入：`evidence/mockplus-overview.png`、`evidence/original-operation-prototype.png`
- 验收截图：`evidence/v3-batch-dialog.png`、`evidence/v3-batch-result.png`
- 视口：1180 × 690 横屏平板

## 已落实规则

- 支持同时选择多个空闲库位。
- 仅空闲状态可编辑。
- 占用、锁闭状态不可编辑。
- 目标状态固定为占用，不提供其他状态选项。
- 平板主页面不展示库位详情。
- 提供“修改库位状态”按钮。
- 未选择库位时按钮禁用。
- 本次批量修改共用1～3张现场照片。
- 仅提供拍照入口，不提供相册选择。
- 已拍照片可以删除。
- 未上传照片点击完成时提示并阻止提交。
- 提交后所选库位统一变为占用状态。

## 实测结果

| 场景 | 结果 |
|---|---|
| 点击占用库位 | 选中数保持0，并提示不可修改 |
| 多选3个空闲库位 | 已选数量显示3 |
| 未拍照点击完成 | 显示“未上传照片不可提交”，弹窗保持打开 |
| 连续拍摄4次 | 数量保持3/3，并提示最多3张 |
| 删除照片 | 数量从3/3更新为2/3 |
| 完成批量修改 | 3个所选库位统一变为占用 |
| 提交后选择状态 | 清空为0，修改按钮禁用 |
| 控制台错误 | 0 |
| 页面脚本错误 | 0 |
