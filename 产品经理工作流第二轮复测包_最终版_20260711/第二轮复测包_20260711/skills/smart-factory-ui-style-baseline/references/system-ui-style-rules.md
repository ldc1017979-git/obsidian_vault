# 数智工厂系统 UI 固定基线规则

这个参考文件用于把“整个系统界面风格”压成一套后续可稳定复用的规则。

## 1. 系统气质

- 工厂数字化后台
- 企业管理系统
- 多业务域、多单据、多状态、多日志
- 高密度业务工具感

不属于：

- 营销官网
- 卡片型展示站
- 作品集首页
- 深色科技大屏

## 2. 外壳规则

- 左侧菜单约 `210px`
- 顶部业务域导航约 `50px`
- 顶部下方保留 Tags-View
- 主背景为浅灰 `#F2F3F5`
- 主内容区为白色容器

## 3. 颜色规则

- 导航/品牌蓝：`#1C53D9`
- 主按钮蓝：`#409EFF`
- 新增绿：`#67C23A`
- 编辑黄：`#E6A23C`
- 风险红：`#F56C6C`
- 主文字：`#303133`
- 常规文字：`#606266`
- 弱文字：`#909399`
- 边框灰：`#DCDFE6`

## 4. 组件规则

默认沿用 Element Plus 风格：

- 按钮
- 输入框
- 选择器
- 日期选择器
- 表格
- Tabs
- 分页
- Dialog
- Drawer
- Upload

## 5. 页面类型规则

### 工作台

- 待办、常用入口、公告、指标、预警混排
- 白色卡片模块

### 列表页

- 筛选区
- 操作区
- 表格
- 分页

### 新建/编辑页

- 顶部操作条
- 基础字段区
- 明细区
- 附件与备注

### 详情页

- 返回
- 基础信息表格
- Tabs
- 明细、日志、审批流程

### 配置页

- 左侧配置分组或顶部 Tabs
- 配置表格
- 新增、编辑、启停

### 看板页

- 保留后台壳
- 白底图表
- 指标卡 + 趋势图 + 明细

## 6. 表格规则

- 表头浅色底
- 行列线清晰
- 操作列在右侧
- 列多时允许横向滚动
- 短字段默认不强制换行

## 7. 表单规则

- 输入框高度约 `32px`
- 必填项红色 `*`
- 禁用字段灰底
- 复杂单据优先独立页，不塞弹窗

## 8. 禁止项

- 大面积渐变
- 厚重阴影
- 装饰球、光斑、霓虹
- 夸张大圆角
- 卡片流替代表格
- 默认黑色大屏风

## 9. 使用方式

任何新页面都先回答：

1. 它属于哪类页面
2. 它要不要保留后台壳
3. 它的主承载是表格、表单、详情还是图表
4. 它有没有偏离当前系统已确认风格

只有回答完这四个问题，才能开始生成页面。
