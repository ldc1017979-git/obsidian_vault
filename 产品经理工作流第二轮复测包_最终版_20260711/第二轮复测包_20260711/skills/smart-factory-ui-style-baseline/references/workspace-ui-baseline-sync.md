## 三、当前 UI 基线应冻结的重点

1. 固定后台外壳：左侧菜单 + 顶部业务域导航 + Tags-View。
2. 保持浅灰背景、白色内容容器、Element Plus 风格组件。
3. 颜色语义固定：蓝主流程、绿新增、黄编辑、红风险。
4. 页面先判断类型，再决定骨架，不允许把所有页面做成同一种卡片布局。
5. 表格仍然是后台系统主承载，不允许大量改成展示型卡片流。
6. 看板页默认也保留后台壳和白底清爽图表风。
7. 复杂单据和复杂流程页优先独立路由，不塞进小弹窗。
