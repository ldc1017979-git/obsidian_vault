# 阶段 2 查询与列表字段确认

## 1. 查询条件

| 编号 | 条件 | 必填 | 当前口径 |
|---|---|---|---|
| QF01 | 大批次号 | 是 | 作为大批次聚合查询的主条件 |
| QF02 | 日期范围 | 否 | 日期字段语义待确认 |
| QF03 | 班组 | 否 | 候选值来源待方案阶段确认 |
| QF04 | 班次 | 否 | 候选值来源待方案阶段确认 |
| QF05 | 产线 | 否 | 候选值来源待方案阶段确认 |

## 2. 结果列表公共字段

| 编号 | 字段 |
|---|---|
| LF01 | 表单名称 |
| LF02 | 大批次号 |
| LF03 | 产线 |
| LF04 | 班组 |
| LF05 | 班次 |
| LF06 | 日期 |
| LF07 | 提交时间 |
| LF08 | 提交人 |
| LF09 | 表单状态 |
| LF10 | 操作（详情按钮） |

## 3. 已确认权限交互

- 有对应表单详情权限：详情按钮可点击，跳转至对应表单详情页面。
- 无对应表单详情权限：详情按钮禁用；悬停提示“暂无该表单查看权限”。
- 禁用按钮不得触发跳转或泄露详情内容。

## 4. 与已确认结果结构的合并

- 查询区位于页面顶部。
- 查询成功后展示大批次结果总览及各类表单实际记录数。
- 下方按表单类型组织明细；明细优先使用上述公共字段。
- 表单数量仅表示实际命中数量，不作为齐套或异常判断。

## 5. 待确认

- 日期范围筛选对应“日期”还是“提交时间”。
- 大批次号和可选条件之间是否按 AND 组合筛选。
- 班组、班次、产线是否为单选或多选。
- 表单状态的完整枚举和显示口径。
