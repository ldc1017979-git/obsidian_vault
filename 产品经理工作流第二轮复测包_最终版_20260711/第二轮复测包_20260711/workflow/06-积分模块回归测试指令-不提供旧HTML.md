# 积分模块回归测试指令：不提供旧 HTML

用途：验证整合后的工作流是否能在不依赖旧 HTML 的情况下，仅基于业务需求和数智工厂基线，生成符合数智工厂风格的开发实现 HTML 原型。

## 1. 测试原则

本测试不要给 Codex：

- 旧版积分 HTML。
- 已经改过的数智工厂基线版 HTML。
- 工作台案例 HTML。

只给：

- 本整合版工作流文件夹。
- 当前工作流包内的`13_数智工厂系统风格基线/`文件夹。
- 积分模块业务需求或 PRD。

```text

然后按强引导工作流处理，不要直接生成 HTML。

本次测试要求：
1. 默认详细引导版。
```

## 4. 通过标准

只有同时满足以下条件，才算本轮通过：

1. 产品经理能被 Codex 带着完成判断，而不是被迫独自填完整问卷。
2. Codex 不依赖旧 HTML。
3. Codex 正确识别数智工厂现有系统继承关系。
4. 生成前完成页面结构、视觉基准和交互矩阵。
5. HTML 视觉和交互明显贴合数智工厂基线。
6. 开发实现原型具备真实导航、页面关系、状态变化和异常反馈。
