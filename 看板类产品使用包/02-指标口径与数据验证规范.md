# 指标口径与数据验证规范

## 1. 指标口径字典

每个指标必须写清楚：

| 字段 | 说明 |
|---|---|
| 指标名称 | 业务可理解的名称 |
| 业务含义 | 回答什么问题 |
| 统计粒度 | 用户、门店、订单、SKU、日期等 |
| 分子 | 计算分子的对象和条件 |
| 分母 | 计算分母的对象和条件 |
| 时间窗口 | 自然日、自然周、T0后7/15/30天 |
| 去重规则 | 按什么去重 |
| 排除规则 | 排除测试、内部、异常、重复等 |
| 维度 | 可按哪些维度拆分 |
| 数据来源 | 表、接口、文件或系统 |
| 更新频率 | 实时、小时、日、周、月 |
| 解释方式 | 高低代表什么，不能代表什么 |

## 2. 指标契约模板

核心指标必须升级为指标契约，不能只写指标名称。

```text
指标名称：
业务问题：
业务含义：
分子：
分母：
统计粒度：
时间窗口：
日期依据：
去重规则：
补零规则：
排除规则：
聚合规则：
能说明什么：
不能说明什么：
原始数据到结果的例子：
```

业务确认后的口径不能被静默修改。如果数据不支持原口径，必须说明缺口，并用不同名称标记近似口径。

## 3. 数据验证清单

| 检查项 | 要求 |
|---|---|
| 数据来源 | 明确正式、测试还是模拟 |
| 样本量 | 符合业务预期 |
| 日期范围 | 与需求一致 |
| 截止日期 | 页面必须显示 |
| 必填字段 | 主键、时间、维度、指标字段不能缺 |
| 空值率 | 核心字段空值需解释 |
| 去重 | 唯一键重复要处理 |
| 分子分母 | 比例必须能反推回数量 |
| 分桶 | 分桶合计等于总体基数 |
| 排除规则 | 排除前后数量能对上 |
| 页面数据 | 页面展示和输出CSV/SQL一致 |
| 原始追溯 | 复杂分类至少抽查3-5个对象从原始数据到页面 |
| 补零规则 | 明确缺失日期是0值、无样本还是不适用 |

## 4. 常见红线

- HTTP 200不等于接口数据成功。
- 页面说正式数据，但实际用了模拟数据。
- 同一天重复行为未经确认就算复购。
- 不同进入时间用户直接比较留存，没有统一观察窗口。
- 用户归因和事件归因混用。
- 非目标身份混入主分析。
- 分桶人数加总不等于总体。
- 指标名称说销售、库存、活跃，但数据只支持扫码、点击、出现次数等代理指标。
- 高维度数据强行画拥挤图表，而不是用排名表、筛选或下钻承接。

## 5. 验证用例模板

```markdown
# 数据验证用例

| 用例 | 输入数据 | 预期结果 | 验证点 |
|---|---|---|---|
| 同一天多次行为 | 同一用户同日多条记录 | 不算复购，只算集中行为 | 防止虚高复购 |
| 次日第二次行为 | 同一用户不同日期第二次行为 | 算二次行为 | 验证时间窗口 |
| 非目标身份 | 内部/渠道/测试身份 | 不进入主分析 | 验证排除规则 |
| 分桶合计 | 所有分桶 | 合计等于总体 | 验证分桶 |
```
