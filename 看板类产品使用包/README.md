# 看板类产品使用包

## 1. 这个包给谁用

给负责BI、数据看板、经营驾驶舱、专题分析、运营监控页面的产品经理使用。

看板类项目不能按普通功能PRD推进。它的核心是：

```text
业务问题
-> 数据字段与表粒度
-> 指标口径
-> 数据验证
-> 分析结构
-> HTML看板
-> 浏览器验证
-> 开发交付
```

## 2. 推荐使用顺序

1. 产品经理只看 `开始这里-产品经理只看这个.md`
2. 产品经理只说“我现在要做数据分析，我应该怎么做”时，系统按 `00-一句话启动入口.md` 执行
3. 团队统一试跑和复盘时，管理者看 `11-团队试跑固定流程.md`
4. 产品经理日常执行，使用 `09-看板类产品经理执行SOP.md`
5. 启动具体项目时，复制 `01-看板项目启动提示词.md` 到Codex
6. 准备资料时，用 `00-看板资料准备清单.md`
7. 判断分析类型和结论写法时，用 `10-数据分析方法与结论规范.md`
8. 如果有字段表或数据样本，先做字段盘点和表粒度判断
9. 用 `02-指标口径与数据验证规范.md` 定义指标和验证数据
10. 用 `03-看板结构与交互规范.md` 设计页面
11. 用 `04-数据处理与输出物规范.md` 生成脚本、SQL或输出数据集
12. 用 `05-看板验收清单.md` 检查是否能交付
13. 如果是留存/复购/生命周期，使用 `06-留存复购生命周期专项.md`
14. 如果是门店/网点/热力图，使用 `07-门店动销与热力图专项.md`
15. 管理者检查本包是否覆盖数据分析能力时，看 `12-date-fenxi-skills能力映射.md`

## 3. 产品经理最低交付

- 业务问题定义
- 分析类型判断
- 字段盘点和表粒度判断
- 指标口径字典
- 数据验证报告
- 数据分析结论
- 看板结构说明
- 数据处理逻辑或脚本说明
- 输出数据集说明
- 单文件HTML看板
- 浏览器验证记录
- 开发交付说明
- 待确认问题

## 4. 质量红线

- 没有业务问题就画图表。
- 没有表粒度就算指标。
- 没有指标口径就做看板。
- 没有数据验证就给结论。
- 同一天重复行为未经确认就算复购。
- 非目标人群混入主分析。
- 页面显示正式数据但实际使用模拟数据。
- AI结论不是基于计算结果。
- 只有图表，没有发现、证据、判断、动作。
