# 门店动销与热力图专项

## 1. 适用问题

- 哪些门店动销好或差。
- 不同动销层级门店的补货/上新/下一次行为节奏。
- 需要用热力图表达门店层级和时间区间。
- 点击某个格子后查看门店明细或构成。

## 2. 核心原则

- 先明确明细数据粒度。
- 先生成中间表，再做热力图。
- 每个门店在热力图中只能归属一个层级、一个区间。
- 同一天多个首次事件应合并为同一个事件日。
- 0值或无行为对象应单独分析，不混入活跃层级。
- 多个间隔建议用中位数代表常态，避免异常断档拉偏。

## 3. 推荐中间表

| 中间表 | 粒度 | 字段示例 |
|---|---|---|
| 门店日表 | 门店+日期 | 当日行为数、去重对象数、活跃标记 |
| 门店归属表 | 门店 | 活跃天数、日均行为、层级、代表间隔 |
| 事件明细表 | 门店+事件日 | 新事件数、间隔、分桶、维度 |
| 热力图矩阵表 | 层级+区间 | 门店数、占比 |
| 下钻明细表 | 门店/事件 | 门店名称、组织、日期、数量、状态 |

## 4. 热力图验收

| 检查项 | 要求 |
|---|---|
| 一个门店只落一个格子 | 必须 |
| 层级分桶合计 | 等于参与门店基数 |
| 无下一次行为 | 单独进入未出现下一次 |
| 0值对象 | 单独分析，不混入活跃层级 |
| 点击下钻 | 明细与格子统计一致 |
| 组织筛选 | 维度切换后数据能对齐 |
