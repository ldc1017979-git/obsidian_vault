# 看板资料准备清单

## 1. 最少必须给的信息

| 资料 | 示例 | 为什么需要 |
|---|---|---|
| 看板名称 | 库存预警看板、用户留存看板、门店动销热力图 | 用于定义项目 |
| 一句话需求 | 想看哪些门店动销差 | 启动业务问题判断 |
| 使用人 | 管理层、业务负责人、运营、一线主管 | 决定看板层级 |
| 看完后动作 | 预警、复盘、调度、运营跟进、决策 | 决定指标和下钻 |
| 时间范围 | 近30天、全年、活动期、T0后30天 | 决定统计窗口 |
| 数据来源 | Excel、CSV、SQL、API、系统导出 | 决定验证方式 |
| 字段清单或样本 | 字段表、CSV样例、接口返回 | 决定能分析什么 |

## 2. 字段资料

字段清单至少要包含：

- 主键：用户ID、订单ID、事件ID、门店ID、SKU ID等
- 时间：行为时间、订单时间、统计日期、首次日期
- 行为：扫码、购买、入库、出库、核销、访问
- 数量：件数、箱数、罐数、订单数、事件数
- 金额：销售额、支付金额、成本、毛利
- 维度：区域、渠道、门店、SKU、品牌、组织
- 标签：身份、会员、生命周期、活动、渠道来源
- 状态：有效、取消、退款、异常、已核销

## 3. 口径资料

如果已有口径，必须提供：

| 口径 | 示例 |
|---|---|
| 去重规则 | 按用户去重、按订单去重、按门店+日期去重 |
| 排除规则 | 测试用户、内部人员、异常数据、重复事件 |
| 时间窗口 | 自然日、自然周、T0后7/15/30天 |
| 分桶规则 | 0-7天、8-15天、>30天 |
| 归因规则 | 首次归因、最近归因、事件归因、门店归因 |

## 4. 数据样本

最好提供：

- 真实数据样本
- 字段说明
- 数据截止日期
- 样本量
- 是否为正式数据或模拟数据
- 是否有异常数据说明

## 5. 没有资料时怎么办

| 缺少资料 | Codex会怎么处理 |
|---|---|
| 没有用户ID | 不能做真实用户留存/复购 |
| 没有时间字段 | 不能做趋势、生命周期、活动前后 |
| 没有SKU/产品 | 不能做产品结构分析 |
| 没有门店/渠道 | 不能做门店或渠道质量分析 |
| 没有金额/成本 | 不能做收入、利润、ROI |
| 没有身份标签 | 不能自动排除非目标人群 |
| 没有数据样本 | 只能先做看板方案，不能给数据结论 |
