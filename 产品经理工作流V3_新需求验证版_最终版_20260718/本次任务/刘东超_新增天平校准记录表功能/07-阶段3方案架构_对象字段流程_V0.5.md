# 阶段3方案架构：对象、字段与流程 V0.5

> 状态：REVIEW  
> 替代V0.4及更早版本。

## 1. 已确认状态机

| 状态 | 污水操作工动作 | 生产主管动作 | 下一状态/结果 |
|---|---|---|---|
| 草稿 | 填写、修改、保存、提交 | 作废 | 提交→待审核；作废→已作废 |
| 待审核 | 只读 | 审核通过、审核驳回、作废 | 通过→已通过；驳回→已驳回；作废→已作废 |
| 已驳回 | 修改、保存、重新提交 | 作废 | 重提→待审核；作废→已作废 |
| 已通过 | 只读 | 作废 | 作废→已作废 |
| 已作废 | 只读 | 只读 | 终态 |

## 2. 新增已确认规则

| 编号 | 规则 | 状态 |
|---|---|---|
| R-020 | 污水操作工仅可修改草稿和已驳回记录 | 已确认 |
| R-021 | 生产主管驳回记录时必须填写驳回原因 | 已确认 |
| R-022 | 仅生产主管可作废任意未作废记录 | 已确认 |
| R-023 | 待审核、已通过和已作废状态下，污水操作工只读 | 已确认，由R-020推导 |
| R-024 | 已作废为终态，所有角色只读 | 已确认，由作废语义推导，待产品最终确认稿复核 |

## 3. 动作结果草案

| 动作 | 当前页结果 | 列表结果 | 关联影响 |
|---|---|---|---|
| 保存草稿 | 提示保存成功，可继续编辑 | 出现/更新草稿记录 | 无台账/外部系统影响 |
| 提交审核 | 页面转只读并提示提交成功 | 状态更新为待审核 | 生产主管可审核 |
| 审核通过 | 页面显示已通过 | 状态更新为已通过 | 无台账影响 |
| 审核驳回 | 要求填写原因，页面显示驳回结果 | 状态更新为已驳回 | 污水操作工可修改重提 |
| 作废 | 二次确认，作废原因规则待确认 | 状态更新为已作废 | 不删除历史记录 |

## 4. 风险关闭情况

| 风险 | 结论 |
|---|---|
| 审核后被操作工改写 | 已通过状态权限关闭 |
| 驳回无法获知修改原因 | 已通过必填驳回原因关闭 |
| 平均值与原始值不一致 | 仍为产品已接受P1风险；仅允许在草稿/已驳回状态修改，提交后锁定 |
