## 3. 列表契约

### 筛选区

| 字段 | 控件 | 行为 |
|---|---|---|
| 记录编号 | 输入框 | 支持按编号查询，匹配方式待研发建议 |
| 检验日期 | 日期范围 | 开始至结束 |
| 使用地点 | 输入框 | 手工录入来源，筛选匹配方式待研发建议 |
| 型号规格 | 输入框 | 手工录入来源 |
| 出厂编号 | 输入框 | 手工录入来源 |

操作：搜索、重置；返回列表时保留筛选条件。

### 表格

| 列 | 展示规则 |
|---|---|
| 记录编号 | 系统生成，可作为详情入口线索 |
| 检验日期 | 日期格式统一 |
| 使用地点 | 超长省略并支持悬浮查看（建议） |
| 型号规格 | 超长省略并支持悬浮查看（建议） |
| 出厂编号 | 文本展示 |
| 校验结论 | 合格/不合格标签 |
| 状态 | 草稿/待审核/已驳回/已通过/已作废标签 |
| 检验人 | 系统记录姓名，原型使用虚构数据 |
| 审核人 | 未审核为空或“-”；审核后展示实际审核人 |
| 审核时间 | 未审核为空或“-”；审核动作后自动记录 |
| 操作 | 固定右侧，按角色和状态展示，待确认 |

### 分页与空态

- 底部显示总数、每页条数、页码和跳页。
- 无数据时显示“暂无数据”，不使用装饰性插画。
