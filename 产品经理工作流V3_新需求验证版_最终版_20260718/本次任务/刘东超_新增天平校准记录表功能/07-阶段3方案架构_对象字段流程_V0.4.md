# 阶段3方案架构：对象、字段与流程 V0.4

> 状态：REVIEW  
> 替代对象与字段V0.3及更早版本。

## 1. 核心对象关系

天平校准记录包含天平信息快照、砝码信息、一至多个完整测量列、校准结论和审核信息。每个测量列固定包含A、B、C、D、E五个校验点及一个平均值。记录独立保存在生产管理，不关联计量台账。

## 2. 已确认规则

| 编号 | 规则 | 状态 |
|---|---|---|
| R-011 | 天平和砝码信息由污水操作工每次手工填写 | 已确认 |
| R-012 | 污水操作工负责测量并填写记录 | 已确认 |
| R-013 | 天平信息以记录快照保存，不关联计量台账 | 已确认 |
| R-014 | 一条记录允许动态增加多次完整测量，业务上暂不设置上限 | 已确认 |
| R-015 | 每次测量按A→B→C→D→E填写五个值 | 已确认 |
| R-016 | 每次测量的平均值初始由系统根据A-E五个值计算 | 已确认 |
| R-017 | 合格结论由污水操作工选择 | 已确认 |
| R-018 | 提交审核前至少完成1次完整的A-E测量 | 已确认 |
| R-019 | 平均值允许直接自由修改，不要求填写修改原因 | 已确认 |
