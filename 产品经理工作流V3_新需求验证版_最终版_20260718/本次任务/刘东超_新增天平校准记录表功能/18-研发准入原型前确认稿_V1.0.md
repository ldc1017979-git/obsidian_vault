# 研发准入原型前确认稿 V1.0

> 上游依据：已确认PRD V0.1、AC V0.1、阶段3确认稿V1.3、阶段4通过记录  
> 新项目终点：研发准入  
> 阶段5结论：PASS，可进入开发实现原型生成

## 1. 原型用途

制作可供研发走读和内部QA的开发实现原型，验证四个页面、完整状态闭环、角色权限、动态测量列、返回列表同步和结构化开发备注。原型使用虚构/脱敏数据，不连接生产系统或真实台账。

## 2. 唯一视觉基线

- 继承归档证据`数智工厂_生产管理列表页.png`的系统壳、顶部业务域、左侧过程管理菜单、Tags-View、白色内容容器、蓝色主按钮、绿色新增按钮、表格和分页风格。
- 不复用“批生产指令”字段、状态和动作。
- 不引用生产系统账号、密码、Token或登录链接。

## 3. 页面契约

| 页面 | 承载/入口 | 返回与保留状态 | 核心职责 |
|---|---|---|---|
| P-001 列表 | 可见Tags-View；左侧菜单进入 | 详情/编辑返回后保留筛选、分页、滚动 | 查询、重置、新增、详情、条件编辑 |
| P-002 新增 | 隐藏独立Tags-View；列表新增进入 | 取消/成功后返回列表 | 填写、动态测量、保存草稿、提交 |
| P-003 编辑 | 隐藏独立Tags-View；列表/详情进入 | 返回来源页并保留状态 | 编辑草稿/驳回、保存、重提、删除本人草稿 |
| P-004 详情/审核 | 隐藏独立Tags-View；列表详情进入 | 返回列表并保留状态 | 只读详情、日志、通过、驳回、作废 |

## 4. 正式业务动作与调试隔离

- 正式动作：新增、保存草稿、提交审核、编辑、重新提交、删除草稿、审核通过、驳回、作废、详情、查询、重置、分页。
- “开发备注/逻辑说明”只在开发调试入口出现，不放入正式业务按钮区。
- 角色切换、异常模拟、Mock重置只放调试面板，用于QA，不得被研发理解为正式功能。
