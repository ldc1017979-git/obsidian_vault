## 2. 背景与目标

### 2.1 当前事实

污水操作工目前使用纸质《天平校准记录》填写校准数据，由生产主管审核。当前未确认纸质方式已经造成遗失、统计困难或其他具体业务损失，因此本PRD不虚构上述痛点。

### 2.2 业务动因

将员工线下填写改为数智工厂中的线上登记，便于记录和留存数据，并正式替代纸质登记。

### 2.3 成功标准

1. 污水操作工可在线完成一条天平校准记录的填写与提交。
2. 生产主管可在线审核通过或驳回。
3. 驳回后可修改并重新提交。
4. 已审核记录可通过列表和详情查询。
5. 正式流程不要求打印或生成纸表。

## 3. 范围

### 3.1 本期范围

- 天平校准记录列表、查询和详情。
- 新增、保存草稿、编辑、提交和重新提交。
- 审核通过、审核驳回、作废和创建人删除草稿。
- 动态增加/删除测量列，每列包含A-E五个校验点及平均值。
- 操作日志和关键字段修改前后值留痕。

### 3.2 非范围

- 不生成或打印纸质表单。
- 不关联计量台账、天平台账或砝码台账。
- 不改造、迁移或复用质量管理中的既有天平校准功能。
- 不做导出、统计、到期提醒、附件上传和历史纸表迁移。
- 不自动依据量程或偏差标准判断合格结论。

## 9. 核心业务规则

### 9.1 系统与范围（R-001—R-010）

- R-001：纸质登记改为线上登记。
- R-002：本期不生成或打印纸表。
- R-003：功能位于数智工厂生产管理域。
- R-004：记录独立保存，不关联计量台账。
- R-005：不改造或迁移质量管理既有功能。
- R-006：填写角色为污水操作工。
- R-007：审核角色为生产主管。
- R-008：MVP包含新增、保存、提交、通过、驳回、重提、作废、列表和详情。
- R-009：导出、统计、提醒不属于本期。
- R-010：线上闭环正式替代纸质登记。

### 9.2 录入与测量（R-011—R-019）

- R-011—R-013：天平与砝码信息每次手工填写，并作为快照保存。
- R-014：测量列可动态增加，业务不设上限；系统安全限制转研发确认。
- R-015：每列按A→B→C→D→E填写。
- R-016：系统按A-E计算初始平均值。
- R-017：校验结论由污水操作工选择。
- R-018：提交前至少完成1列完整A-E测量。
- R-019：平均值可直接自由修改，不要求原因。

### 9.3 状态、权限与原因（R-020—R-028）

- R-020：污水操作工仅可修改草稿和已驳回记录。
- R-021：驳回原因必填。
- R-022：仅生产主管可作废未作废记录。
- R-023—R-024：待审核、已通过、已作废对操作工只读；已作废为终态。
- R-025：作废原因必填并二次确认。
- R-026：检验日期默认当天，可修改。
- R-027—R-028：检验人、审核人由系统按实际账号自动记录，不可手填。

### 9.4 字段、单位与计算（R-029—R-036）

- R-029：提交必填日期、地点、型号规格、出厂编号、砝码重量、完整测量和结论。
- R-030：温湿度、生产厂家、Max/e/d选填。
- R-031：纸表文控信息不进入线上页面。
- R-032—R-033：结论为合格/不合格；不合格时备注必填。
- R-034：A-E和平均值固定使用g。
- R-035：Max/e/d和砝码重量单位可选g/kg。
- R-036：自动平均值按A-E中最多的小数位保留。

### 9.5 页面与列表（R-037—R-049）

- R-037—R-039：确认菜单、四页面及详情审核。
- R-040：系统自动生成业务可见记录编号；格式由研发确认。
- R-041—R-043：筛选和列表列按第11章执行。
- R-044—R-045：操作工看本岗位全部，主管看本功能全部。
- R-046—R-047：列表只提供详情及条件编辑，不提供快捷流程动作。
- R-048—R-049：至少保留1列；删除有值列二次确认。

### 9.6 异常、并发和日志（R-050—R-059）

- R-050：操作工可编辑本岗位其他人员的草稿/已驳回记录。
- R-051：疑似重复提交前提示，确认后仍可提交。
- R-052：平均值手工改写不显示标识、不保留原计算值。
- R-053：多人同时编辑时最后保存覆盖之前内容。
- R-054：只有创建人可删除自己的草稿。
- R-055：网络失败保留输入，状态不变，可重试。
- R-056：重复点击一次提交动作不得生成两条记录。
- R-057：列表默认按创建时间倒序。
- R-058：每页默认10条。
- R-059：记录新增、编辑、提交、审核、驳回、作废、删除及关键字段修改前后值。

### 11.1 列表

- 筛选：记录编号、检验日期范围、使用地点、型号规格、出厂编号。
- 列：记录编号、检验日期、使用地点、型号规格、出厂编号、校验结论、状态、检验人、审核人、审核时间、操作。
- 默认创建时间倒序，每页10条。
- 所有状态显示详情；草稿和已驳回显示编辑。
- 搜索刷新列表；重置清空所有条件并回到第一页。

### 11.2 新增/编辑

- 基础信息、天平信息、砝码信息、动态测量表、结论与备注分组。
- 顶部操作条包含取消、保存草稿、提交审核；编辑已驳回记录显示驳回原因。
- 页面有未保存内容时离开应提示确认（采用系统通用行为；研发确认实现）。

### 11.3 详情/审核

- 展示基础信息、动态测量明细、结论、审核信息和操作日志。
- 待审核且当前角色为生产主管时显示通过、驳回、作废。
- 其他状态按权限显示作废或只读。

## 12. 异常与边界

| 场景 | 结果 |
|---|---|
| 必填缺失/测量不完整 | 阻止提交，字段或表格位置显示错误 |
| 不合格且备注为空 | 阻止提交并提示备注必填 |
| 疑似重复 | 展示已有记录线索，确认后可继续提交 |
| 网络失败/超时 | 停留当前页、保留输入、状态不变，允许重试 |
| 重复点击提交 | 按钮进入处理中，一次动作只生成一次状态变化 |
| 无权限/状态已变化 | 阻止动作，提示刷新；不覆盖当前服务器状态 |
| 多人同时编辑 | 最后保存覆盖之前内容，按产品确认执行 |
| 删除/作废取消 | 关闭确认框，不改变数据和状态 |
| 无数据 | 列表显示“暂无数据” |

## 13. 审计与数据安全

- 操作日志记录操作人、时间、动作、记录编号及关键字段修改前后值。
- 日志查看权限：污水操作工可在有权查看的详情中查看；生产主管可查看全部。
- 日志保存期限和具体技术存储由研发/合规确认。
- 测试数据使用虚构人员、设备编号和测量值；不使用真实签名、完整个人标识或真实账号凭据。
- 原始纸表仅作受控证据，不在原型和测试截图中展示手写签名。

## 14. 非功能与适配

- 桌面后台页面，继承现有数智工厂支持的浏览器范围。
- 目标视口至少覆盖1440×900和1180×800。
- 动态测量宽表需保持左侧校验点/基础列、横向滚动测量列和右侧操作的可用性。
- 列表加载、分页和日志数据量的性能阈值由研发结合现有系统基线确认。
- 无跨系统同步、无设备直连、无历史迁移。

- 文本长度、数值技术边界、性能阈值和浏览器范围。
