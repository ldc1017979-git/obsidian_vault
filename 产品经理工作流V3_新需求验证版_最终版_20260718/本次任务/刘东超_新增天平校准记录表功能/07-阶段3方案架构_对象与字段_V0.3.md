# 阶段3方案架构：对象与字段 V0.3

> 状态：REVIEW  
> 替代V0.2；当前有效对象与字段架构草案。

## 1. 对象关系

| 对象 | 职责 | 关系 | 数据来源 | 归属 |
|---|---|---|---|---|
| 天平校准记录 | 保存一次校准业务记录及审核结果 | 包含天平快照、砝码信息、一至多个测量列、结论和审核信息 | 污水操作工填写；生产主管审核 | 数智工厂—生产管理 |
| 测量列 | 表示一次完整A→B→C→D→E测量 | 一条记录包含一至多个测量列 | 污水操作工测量填写 | 主记录内部 |
| 校验点测量值 | 保存某测量列中A-E五个位置的数值 | 每个测量列固定包含A、B、C、D、E五个点 | 污水操作工 | 测量列内部 |
| 天平信息快照 | 保存本次地点、型号规格、出厂编号等 | 不关联计量台账 | 每次手工填写 | 主记录内部 |
| 砝码信息 | 保存本次使用的砝码重量 | 不关联标准器台账 | 每次手工填写 | 主记录内部 |

## 2. 已确认规则

| 编号 | 规则 | 状态 |
|---|---|---|
| R-011 | 天平和砝码信息由污水操作工每次手工填写 | 已确认 |
| R-012 | 污水操作工负责测量并填写记录 | 已确认 |
| R-013 | 天平信息以记录快照保存，不关联计量台账 | 已确认 |
| R-014 | 一条记录允许填写多次完整测量，次数按实际情况动态增加 | 已确认 |
| R-015 | 每次测量按A→B→C→D→E填写五个值，该次平均值为五个值的平均值 | 已确认 |
| R-016 | 业务上暂不设置测量次数上限；必要的系统安全限制转研发确认，不改变业务语义 | 已确认 |
| R-017 | 系统自动计算平均值；合格结论由污水操作工选择 | 已确认 |
| R-018 | 平均值和合格结论需要支持修改，但可修改的状态、方式和审计要求待确认 | 部分确认 |
